# 复仇者联盟：毁灭日 · 六道崩塌

> **AVENGERS: DOOMSDAY — SIX COLLAPSES**
>
> 3-6 人 · 30-45 分钟 · 12 岁以上 · 中度策略的派对博弈

---

## 1. 游戏概述

多元宇宙正在对撞。

毁灭博士（维克多·冯·杜姆）拿到了改写现实法则的钥匙。六个世界被拖进同一条时间线，天空裂成六道伤口——每道伤口就是一次**碰撞（Incursion）**。英雄再多也没用：同一个宇宙里，只能有一个「你」站上战场；两个同源的英雄撞在一起，只会互相抵消。

在这场游戏里，你不扮演某一队英雄。你扮演**一个世界的锚点指挥官**。每一轮，六道碰撞点之一亮起，所有指挥官同时把手牌扣下——你不能指挥别人，你只能赌别人会怎么做。

### 核心乐趣：说话，才是真正的武器

这是一款**允许公开讨论、也允许撒谎**的同步暗派游戏。

- 每个人手上都有 12 张英雄牌（力量、科技、魔法、战术各若干），**整局不补牌**。
- 每轮最多出 **2 张**。你能做的事只有三件：堆高一个类型的战力、分头覆盖两个类型、或者干脆少出留牌。
- **同一个类型，只认战力最高的那个人**（并列则都算占位，但该类型只按最高值算一次）。所以你出的第 2 张同类型牌，对"团队战力"毫无贡献——它只是在抢"谁算数"这个位置。

> **一句话说清这个游戏：覆盖需求类型是「公共品」，抢到占位者才是「私利」。**
>
> 全员去抢公共品，世界会被守住，但分被一个人吃掉；全员只顾私利，世界崩塌，所有人一起扣分。你得在"我想赢"和"我们不能输"之间反复横切。

适合：喜欢《狼人杀》《阿瓦隆》那种"读人"快感的玩家，喜欢《七大奇迹》式"同时选牌"节奏的玩家，以及任何看过漫威、想边吵边玩的人。

## 4. 游戏地图详解

### 4.1 布局概览

地图是一张**环形游戏垫**：外圈是分数轨道，中间环形排布六个世界格，正中央是毁灭博士的王座（Doom 轨道）。

```
        ┌──────────────────────────────────────────────┐
        │  分数轨道  0 ─ 2 ─ 4 ─ 6 ─ 8 ─ 10 ─ 12 ─ …   │
        │  ┌────────────────────────────────────────┐  │
        │  │        🌍 地球-616      🌐 地球-838     │  │
        │  │        （🏹战术签名）    （🧠科技签名）  │  │
        │  │                                        │  │
        │  │   🧊 虚空之外   ┌──────────┐   🌑 拉托  │  │
        │  │   （💪力量）    │  💀 DOOM │  维尼亚  │  │
        │  │                │  0 1 2 3 │ （🔮魔法）│  │
        │  │   🌿 克拉科     │  4 5 6   │   🪐 战界 │  │
        │  │   （🔮魔法）    └──────────┘  （🧠科技）│  │
        │  └────────────────────────────────────────┘  │
        └──────────────────────────────────────────────┘
```

每个世界格中央留出一块**放牌区**（约 2 张卡大小），右上角写该世界的**签名类型**。

### 4.2 六道碰撞点（世界）详解

| 世界 | 图标 | 签名类型 | 世界设定 | 为什么签名是这个类型 |
| :--- | :--- | :--- | :--- | :--- |
| **地球-616** | 🌍 | 🏹 战术 | 主宇宙，纽约。复仇者大厦所在 | 复仇者最擅长的从来不是蛮力，是协同作战 |
| **地球-838** | 🌐 | 🧠 科技 | 光照会宇宙，里德·理查兹的地盘 | 光照会解决问题的第一反应永远是"造个东西" |
| **拉托维尼亚** | 🌑 | 🔮 魔法 | 毁灭博士的王座，东欧小国 | 女巫议会在此集结，绿魔法是国教 |
| **虚空之外** | 🧊 | 💪 力量 | 时间尽头的虚无，万物湮灭之处 | 法则失效的地方，只剩下最原始的拳脚 |
| **战界** | 🪐 | 🧠 科技 | 由碎裂世界拼合的战场（Battleworld 雏形） | 拼合大陆本身就是一场工程学的暴行 |
| **克拉科** | 🌿 | 🔮 魔法 | 变种人庇护所，活着的岛 | 复活仪式是这座岛的心跳 |

**签名类型的作用**：在本世界**守住**时，该类型占位者额外 **+1 分**（详见 [6.4 场地加成](#64-场地加成)）。

### 4.3 地图的战术意义

1. **签名类型会吸引人流**——看到"拉托维尼亚（🔮魔法）"，所有人都会想：魔法牌是不是该留着？于是魔法类型更容易撞车。
2. **签名类型与需求类型永远不重合**（碰撞卡设计保证），所以签名是一次"额外机会"，不是"额外负担"。
3. **不同世界的难度不同**：主宇宙的碰撞卡威胁值偏低（1-2），克拉科与虚空的碰撞卡威胁值偏高（3-4）。世界越"边缘"，越难守。

### 4.4 地图资源统计

| 世界 | 该点碰撞卡数 | 威胁值分布 | 需求类型组合 |
| :--- | :--- | :--- | :--- |
| 🌍 地球-616 | 3 张 | 1 / 1 / 2 | 力+魔、科+魔、力+科 |
| 🌐 地球-838 | 3 张 | 1 / 2 / 3 | 魔+术、力+魔、术+魔 |
| 🌑 拉托维尼亚 | 3 张 | 2 / 2 / 3 | 力+科、科+术、力+术 |
| 🧊 虚空之外 | 3 张 | 3 / 3 / 4 | 魔+术、科+术、魔+科 |
| 🪐 战界 | 3 张 | 2 / 3 / 4 | 力+魔、力+术、魔+术 |
| 🌿 克拉科 | 3 张 | 2 / 3 / 4 | 力+术、科+术、力+科 |

> 威胁值总计：1 分 ×3 张、2 分 ×6 张、3 分 ×6 张、4 分 ×3 张。抽到的卡越"靠后"，本局越难。

## 5. 道具详解

### 5.1 英雄卡（资源卡）

英雄卡是全部玩法的基础。每张卡只有两个信息：**类型** + **战力**。

| 类型 | 图示 | 卡面名称示例 | 战力 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **力量** | 💪 | 浩克 / 雷神 / 金刚狼 | 1 / 2 / 3 | 纯数值，最直白的一门 |
| **科技** | 🧠 | 钢铁侠 / 蚁人 / 黑豹 | 1 / 2 / 3 | 数量最多的一门，稳定但抢得凶 |
| **魔法** | 🔮 | 奇异博士 / 绯红女巫 / 洛基 | 1 / 2 / 3 | 签名世界最多（2 个），加成机会大 |
| **战术** | 🏹 | 美队 / 鹰眼 / 黑寡妇 | 1 / 2 / 3 | 签名世界最稀有（1 个），覆盖最难 |

**获得方式**：开局一次性发 12 张，**全局不再补牌**。

**用途**：
- 每轮暗置 1-2 张，投入某个类型；
- 打出的牌进入弃牌堆，**本局不再回到手中**；
- 未打出的牌留在手里，可以跨轮规划。

> ⚠️ **最常见的误解**：Hero 卡不是"一次性技能"，是"弹药"。12 张打完就没了，所以「什么时候出高牌」比「出哪张牌」更重要。

### 5.2 碰撞卡（任务卡）

每张碰撞卡有四项信息：

```
┌────────────────────────────┐
│  🌍 地球-616               │
│  ─────────────────────     │
│  【纽约天际线失守】         │
│                            │
│  需求：💪 力量 + 🔮 魔法    │
│  威胁值：1                 │
│                            │
│  "天空裂了第二道口子。"     │
└────────────────────────────┘
```

| 字段 | 含义 | 怎么用 |
| :--- | :--- | :--- |
| **碰撞点** | 在哪个世界发生 | 把暗牌放到地图对应格；触发该世界的签名加成 |
| **需求类型** | 必须被覆盖的两个类型 | 缺一个 → 阈值 +3（见 6.3） |
| **威胁值** | 1-4 的难度数字 | **实际阈值 = 玩家人数 + 威胁值** |

**规则**：18 张碰撞卡洗混，每局只抽 **5 张**，依次对应第 1-5 轮。抽完剩下的放回盒中（所以每局的世界顺序都不一样）。

### 5.5 决战卡（终局卡）

```
┌────────────────────────────┐
│  💀 毁灭日：最后的世界      │
│  ─────────────────────     │
│  第 6 轮专用                │
│                            │
│  需求类型：由当前分数最低   │
│  的玩家指定（1 个类型）     │
│  阈值：玩家人数 + 1         │
│  得分：全部 ×2              │
└────────────────────────────┘
```

这是本作的**翻盘窗口**：第 5 轮通常是全场最惨的一轮（手牌快见底），第 6 轮用一张低阈值、双倍分的卡把戏收回来。

## 6. 游戏规则

### 6.1 准备阶段

1. **选世界**：6 个指挥官棋子摆到桌上，每人拿 1 个（3 人局自选 3 个）。
2. **发英雄牌**：洗混 72 张英雄卡，**每人发 12 张**，扣在自己面前（用挡板遮住）。剩余放回盒中，本局不用。
3. **发神器**：洗混 12 张神器卡，**每人抽 2 张**，明置在自己面前（神器是公开信息）。
4. **摆碰撞卡**：洗混 18 张碰撞卡，**抽 5 张**，按顺序排成第 1-5 轮；决战卡放在最后（第 6 轮）。其余碰撞卡放回盒中。
5. **摆干涉卡**：洗混 12 张干涉卡成一叠，放在碰撞卡旁边（新手局可整叠移除）。
6. **放标记**：Doom 标记放在中央轨道 **0** 格；每人分数标记放在分数轨道 **0**。
7. **先手**：最近看过漫威电影的人当"世界之声"（只负责翻卡、报数，没有额外权力）。

### 6.2 一轮的完整流程

```
① 翻卡      →  ② 讨论      →  ③ 暗置     →  ④ 揭晓
                                              ↓
                          ⑦ 轮末清理  ←  ⑥ 结算  ←  ⑤ 判占位
```

#### ① 翻卡（15 秒）
"世界之声"翻开本轮碰撞卡，大声读出：**世界名 + 需求类型 + 威胁值**。再翻开 1 张干涉卡（第 6 轮不翻）。

计算并报出**本轮阈值**：

> **阈值 = 玩家人数 + 威胁值**（再按干涉卡调整）

#### ② 讨论（最多 60 秒，可用计时器）
**所有人都可以说话，也可以撒谎。** 你可以说"我去力量"，也可以说"我去力量"然后出科技——没人能验证。这是本作最重要的 60 秒。

建议用这样的句式：
- 「我这轮去 💪，谁去 🧠？」
- 「谁有 3？我这边只有 2。」
- 「我不出，留着决战。」

#### ③ 暗置（同时）
所有人同时从手牌中选 **1 张或 2 张**英雄卡，扣在自己面前的世界格上（如果是多人同世界，就扣在自己面前，不放在垫子上，免得混淆）。

> 也可以**出 0 张**（待命），代价是本轮你既不得分也不扣分。

#### ④ 揭晓
所有人同时把牌翻开。按**类型**分组，把同类型的牌放在一起。

#### ⑤ 判定占位（本轮最关键的一步）

对**四个类型**分别执行：

> 该类型战力总和最高的人，成为该类型的**占位者**。
> 若最高分**并列**，则并列者**都算占位者**，但该类型的有效战力**只按最高值算一次**（不叠加）。

#### ⑥ 结算

按顺序执行三件事：

**A. 算有效战力 P**

> **P = 所有占位者所在类型的"最高战力"之和**

举几个例子：

| 情况 | 计算 | P |
| :--- | :--- | :--- |
| 💪 小雷 3、🧠 阿May 3、🔮 老陈 3 | 3 + 3 + 3 | **9** |
| 💪 小雷 3、🏹 小雷 2 和 阿May 2（并列） | 3 + 2（并列只算一次） | **5** |
| 💪 小雷 3、小雷还出了 🔮2 | 3 + 2 | **5** |
| 💪 小雷 1、阿燊 1（并列），🧠 阿May 3 | 1 + 3 | **4** |

**B. 缺门惩罚**

> 碰撞卡需求的两个类型，如果某一门**全场没有人出牌**，该门视为"现实法则失守"——**阈值 +3**（每缺一门 +3，最多 +6）。

**C. 判定守住 / 崩塌**

| 结果 | 条件 | 后果 |
| :--- | :--- | :--- |
| ✅ **守住** | P ≥ 阈值 | 见下方计分 |
| ❌ **崩塌** | P < 阈值 | 所有**出过牌**的人各 **−1 分**；Doom **+1**（若同时有缺门，再 +1） |

#### ⑦ 计分（只在守住的轮次执行）

| 得分项 | 分值 |
| :--- | :--- |
| 独占 1 个类型（唯一占位者） | **+2 分** |
| 并列占位（该类型有 2 人以上并列最高） | 每人 **+1 分** |
| 双持奖励：同一人同时独占了**两个需求类型** | 额外 **+1 分** |
| 复仇者集结：场上**四个类型全部**有人占位 | **每人 +1 分** |
| 场地加成：本世界签名类型的占位者 | 额外 **+1 分** |

> 注意：得分只看"占位"，**你出了牌但一个类型都没占到，就只有在"复仇者集结"里拿 1 分的份**。

#### ⑧ 轮末清理
打出的牌进弃牌碗。Doom 标记前进。所有人进入下一轮。

### 6.3 阈值速查表

| 玩家人数 | 威胁值 1 | 威胁值 2 | 威胁值 3 | 威胁值 4 |
| :--- | :--- | :--- | :--- | :--- |
| 3 人 | 4 | 5 | 6 | 7 |
| 4 人 | 5 | 6 | 7 | 8 |
| 5 人 | 6 | 7 | 8 | 9 |
| 6 人 | 7 | 8 | 9 | 10 |

**缺一门 → 上表 +3。缺两门 → +6。**

### 6.4 场地加成

守住时，本世界**签名类型**的占位者额外 +1 分。

> 例：在 🌑 拉托维尼亚（签名 🔮魔法）守住，若魔法类型的占位者是阿燊，阿燊 +1。

由于碰撞卡设计保证**签名类型 ≠ 任一需求类型**，这条加成永远是"白送的机会"，不会和双持奖励冲突。

### 6.5 第 6 轮：毁灭日决战

第 6 轮不抽碰撞卡，改用**决战卡**：

1. 当前**分数最低**的玩家指定本轮需求类型（1 个）。并列最低时，由其中手牌多的人指定。
2. 阈值 = **玩家人数 + 1**（低门槛，故意的）。
3. 缺门惩罚照旧（此时只有 1 门，缺了 +3）。
4. **本轮的得分全部 ×2**（+2 变 +4，+1 变 +2）。
5. 不翻干涉卡，不触发场地加成。

### 6.6 胜利条件

游戏在第 6 轮结束后结束。**先检查 Doom，再比分数**：

| 情况 | 结果 |
| :--- | :--- |
| **Doom ≤ 3** | 分数最高者获胜，称号「现实守望者」 |
| **Doom ≥ 4** | **毁灭博士获胜——全体玩家都算输** |

**平局判定顺序**：
1. 剩余手牌**张数少**的人胜（打过更多仗）；
2. 仍平 → 剩余手牌**总战力高**的人胜；
3. 仍平 → 共享胜利（一起请客）。

> Doom ≥ 4 的"全员失败"是故意设计的：当一桌人开始互相坑，谁也赢不了。这不是 bug，是本作的道德条款。

## 7. 完整游戏流程示例

### 7.1 局前准备（4 人局）

四位玩家：🔵 小雷、🔴 阿燊、🟢 老陈、🟣 阿May。

- 每人 12 张英雄牌 + 2 张神器卡。
- 抽出 5 张碰撞卡，本轮序列恰好是：**#1 纽约天际线失守 → #10 时间尽头的门 → #8 拉托维尼亚的钟声 → #12 无光之海 → #16 变种人圣火的熄灭**，第 6 轮决战。

### 7.2 第 1 轮：纽约天际线失守

**翻卡**：🌍 地球-616（签名 🏹战术）｜需求 **💪力量 + 🔮魔法**｜威胁值 **1**

**阈值** = 4 + 1 = **5**

**讨论**（节选）：

| 玩家 | 说了什么 |
| :--- | :--- |
| 🟢 老陈 | 「我魔法多，我去 🔮。」 |
| 🟣 阿May | 「那我科技，但我科技只有一张大的。」 |
| 🔵 小雷 | 「我随便，我力量还行。」 |
| 🔴 阿燊 | （心想：他们都去魔和科，我悄悄拿战术吧） |

**暗置与揭晓**：

| 玩家 | 打出 | 💪 | 🧠 | 🔮 | 🏹 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 🔵 小雷 | 💪3 + 🔮2 | 3 | — | 2 | — |
| 🔴 阿燊 | 💪2 + 🏹1 | 2 | — | — | 1 |
| 🟢 老陈 | 🔮3 + 🏹2 | — | — | 3 | 2 |
| 🟣 阿May | 💪1 + 🧠3 | 1 | 3 | — | — |

**判占位**：
- 💪 力量：小雷 3 > 阿燊 2 > 阿May 1 → **小雷**（3）
- 🔮 魔法：老陈 3 > 小雷 2 → **老陈**（3）
- 🏹 战术：老陈 2 > 阿燊 1 → **老陈**（2）
- 🧠 科技：只有阿May → **阿May**（3）

**P** = 3 + 3 + 2 + 3 = **11** ≥ 阈值 5 → **守住** ✅

**计分**：

| 玩家 | 明细 | 本轮得分 |
| :--- | :--- | :--- |
| 🔵 小雷 | 💪独占 +2；集结 +1 | **3** |
| 🔴 阿燊 | 无占位；集结 +1 | **1** |
| 🟢 老陈 | 🔮 +2、🏹 +2；集结 +1；场地（🏹签名）+1 | **6** |
| 🟣 阿May | 🧠 +2；集结 +1 | **3** |

**教学点 1**：阿燊出了 2 张牌，一分没拿到——因为他两个类型都不是最高。这就是本作最痛的一课：**出牌 ≠ 得分，占位才得分**。

**教学点 2**：四门全占触发了「复仇者集结」，连没占位的人都拿了 1 分。这是「合作者奖励」。

**当前比分**：小雷 3 ｜ 阿燊 1 ｜ 老陈 6 ｜ 阿May 3 ｜ Doom 0

### 7.3 第 2 轮：时间尽头的门（崩塌示范）

**翻卡**：🧊 虚空之外（签名 💪力量）｜需求 **🔮魔法 + 🏹战术**｜威胁值 **3**

**阈值** = 4 + 3 = **7**

**讨论**（节选）：

| 玩家 | 说了什么 |
| :--- | :--- |
| 🟢 老陈 | 「我上一轮把魔法用了不少，这轮我只有 🔮1，谁来接魔法？」 |
| 🔴 阿燊 | 「我来，我有 🔮3。」 |
| 🟢 老陈 | 「那我出个科技垫着。」 |
| 🟣 阿May | 「我战术 1。」 |

**揭晓**：

| 玩家 | 打出 | 🔮 | 🏹 | 🧠 |
| :--- | :--- | :--- | :--- | :--- |
| 🔵 小雷 | 🔮1 + 🏹1 | 1 | 1 | — |
| 🔴 阿燊 | 🔮3 | 3 | — | — |
| 🟢 老陈 | 🧠1 | — | — | 1 |
| 🟣 阿May | 🏹1 | — | 1 | — |

**判占位**：
- 🔮 魔法：阿燊 3 > 小雷 1 → **阿燊**（3）
- 🏹 战术：小雷 1 = 阿May 1 → **并列占位**，但有效战力只算 **1**
- 🧠 科技：老陈 1 → **老陈**（1）

**P** = 3 + 1 + 1 = **5** < 阈值 7 → **崩塌** ❌

（需求的两门 🔮🏹 都有人出，所以**没有缺门惩罚**；但 P 就是不够。）

**后果**：
- 所有出牌者各 **−1 分**：小雷 2、阿燊 0、老陈 5、阿May 2
- Doom **0 → 1**

> **教学点 3**：并列不是"两个人加起来 2 分"，**只算 1 分**。小雷和阿May 各出 1 张战术，团队战力只涨了 1，等于浪费了一张牌。
> **教学点 4**：阿燊出了 3 分的高牌，但一个人扛不住两门需求。这就是为什么"覆盖"必须靠分工。

**当前比分**：小雷 2 ｜ 阿燊 0 ｜ 老陈 5 ｜ 阿May 2 ｜ Doom 1

### 7.4 第 3-6 轮速记

| 轮次 | 碰撞点 | 需求 | 阈值 | P | 结果 | 小雷 | 阿燊 | 老陈 | 阿May | Doom |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 🌍 616 | 力+魔 | 5 | 11 | ✅ 守住 | 3 | 1 | 6 | 3 | 0 |
| 2 | 🧊 虚空 | 魔+术 | 7 | 5 | ❌ 崩塌 | 2 | 0 | 5 | 2 | 1 |
| 3 | 🌑 拉托维尼亚 | 科+术 | 7 | 11 | ✅ 守住 | 5 | 3 | 11 | 3 | 1 |
| 4 | 🧊 虚空 | 魔+科 | 8 | 12 | ✅ 守住 | 6 | 7 | 14 | 8 | 1 |
| 5 | 🌿 克拉科 | 力+术 | 6 | 4 | ❌ 崩塌 | 5 | 6 | 13 | 7 | 2 |
| 6 | 💀 决战 | 术（小雷指定） | 5 | 8 | ✅ 守住 ×2 | 9 | 6 | 17 | 11 | 2 |

**第 3 轮明细**（守住，展示"双占位"）：
- 小雷 🧠3 + 🏹2；阿燊 🧠2 + 🏹3；老陈 🔮3 + 💪2；阿May 🧠1 + 🏹1
- 占位：🧠 小雷(3)、🏹 阿燊(3)、🔮 老陈(3)、💪 老陈(2)
- P = 3+3+3+2 = 11 ≥ 7 ✅
- 得分：小雷 +2+1(集结)=3；阿燊 +2+1=3；老陈 +2+2+1(集结)+1(🔮签名场地)=6；阿May +1=1
- 累计：小雷 5、阿燊 3、老陈 11、阿May 3

**第 4 轮明细**（守住，展示"双门独占"）：
- 小雷 🔮2 + 🧠2；阿燊 🔮1 + 💪3；老陈 🧠3 + 🏹1；阿May 🔮3 + 🏹3
- 占位：🔮 阿May(3)、🧠 老陈(3)、💪 阿燊(3)、🏹 阿May(3)
- P = 3+3+3+3 = 12（**顶到天花板**）≥ 8 ✅
- 得分：小雷 +1(集结)=1；阿燊 +2(💪)+1(集结)+1(💪签名场地)=4；老陈 +2+1=3；阿May +2+2+1=5
- 累计：小雷 6、阿燊 7、老陈 14、阿May 8

**第 5 轮明细**（崩塌，展示"手牌见底"）：
- 小雷 🏹1；阿燊 🏹1；老陈 💪2；阿May 🏹2
- 占位：🏹 阿May(2)、💪 老陈(2) → P = 4 < 6 ❌
- 每人 −1，Doom 1 → 2
- 这就是第 5 轮的常态：**高牌都用光了，剩下的小牌凑不够阈值**。

**第 6 轮决战明细**：
- 小雷（5 分，最低）指定需求 = 🏹战术；阈值 = 4+1 = 5；得分 ×2
- 小雷 🏹3 + 🧠1；阿燊 🏹2；老陈 💪3 + 🏹1；阿May 🧠2
- 占位：🏹 小雷(3)、💪 老陈(3)、🧠 阿May(2) → P = 8 ≥ 5 ✅
- 双倍得分：小雷 +4、老陈 +4、阿May +4（每人各占一门）
- 最终：**老陈 17、阿May 11、小雷 9、阿燊 6**

**Doom = 2 ≤ 3** → 正常结算，**🟢 老陈获胜，称号「现实守望者」**。

> **教学点 5**：老陈赢在"每轮都占两门"。他从不去抢最高分的那一门，而是找"没人要的第二门"——这是本作最高效的打法。

## 8. 新手策略提示

### 8.1 三条铁律

| # | 铁律 | 为什么 |
| :--- | :--- | :--- |
| 1 | **别在一个类型上出 2 张** | 同类型只取最高值，第 2 张对 P 贡献为 0，只是在抢位置。真有把握再用（比如你确定没人跟你抢，想锁死这一门） |
| 2 | **12 张牌 = 6 轮 × 2 张，一张不多** | 你只要有一轮出了 1 张，就有一张牌永远用不上。反过来，你要是前 3 轮猛出 2 张，第 5 轮就会没牌 |
| 3 | **抢"第二门"，不抢"主门"** | 全场都会盯着签名类型和需求类型里的"高价值门"。你去找那个没人想去的门，2 分一样多得 |

### 8.2 分阶段策略

| 阶段 | 手牌状态 | 打法 |
| :--- | :--- | :--- |
| **第 1-2 轮**（热身） | 牌很多 | **优先出小牌（战力 1）建立覆盖**。阈值低，用 1 就能守住，把 3 留到后面 |
| **第 3-4 轮**（拉锯） | 中等 | 开始抢分。此时可以出 2 张：一张保覆盖（小），一张抢占位（大） |
| **第 5 轮**（危机） | 牌少且弱 | 威胁值多在 3-4、手牌最弱。**能守住最好，守不住就少出牌保住分数** |
| **第 6 轮**（决战） | 剩 2-3 张 | 分数 ×2，这是唯一值得"梭哈"的一轮。留一张 3 到这里，价值等于平时的 2 张 |

### 8.3 高级技巧

1. **"我知道你会去魔"陷阱**：讨论时故意强调"我去 🔮"，让 2 个人跟着你去 🔮 撞车，你实际去 🏹 独占一门。
2. **弃权也是一种牌**：出 0 张不扣分、不得分。当阈值明显守不住（比如 P 上限都低于阈值），**弃权比出牌好**——出牌要 −1。
3. **数牌**：一共只有 5 张战力 3 的 🏹战术。对手前两轮打了 3 张，你就知道战术门只剩 2 张大的了。
4. **Doom 是公共压力表**：Doom ≥ 4 全员输，所以你有权在讨论阶段"道德绑架"别人出牌。用不用，是你的选择。
5. **决战卡指定权是武器**：第 6 轮分数最低的人指定类型。如果你确定自己会落后，**故意在第 5 轮少得分**，把指定权留到自己手上——指定一个你手里有 3、别人手里没牌的类型。

## 9. 变体规则

### 9.1 硬核模式（推荐给老手）

- Doom ≥ 3 即全员失败（从 4 降到 3）。
- 第 6 轮决战**不再享有低阈值**，改为「阈值 = 人数 + 3」，但得分 ×3。
- 干涉卡全放 12 张。

**效果**：崩塌的代价陡增，谈判从"聊天"变成"真的在谈"。

### 9.2 背叛者模式（5-6 人）

开局随机指定 1 人为**毁灭博士的代理人**（暗牌，只有自己知道）。

- 代理人的目标：让 Doom 达到 4，或让全场最低分是自己以外的某人？——不，代理人的目标就是**让 Doom 达到 4**（大家一起输，代理人也算赢）。
- 其他人如果最终分数最高且 Doom ≤ 3，则英雄方获胜。
- 代理人可以在讨论中撒谎、故意不覆盖需求类型。

**效果**：把"半合作"变成"有内鬼"，讨论烈度翻倍。这是本作最接近《阿瓦隆》的玩法。

### 9.3 双人对抗（2 人）

- 每人手牌 **15 张**（从 72 张里各发 15 张，剩余 42 张不用）。
- 阈值 = **3 + 威胁值**（固定，不随人数变）。
- 缺门惩罚改为 **+2**（两人局覆盖本来就难）。
- 无「复仇者集结」加成。

**效果**：变成纯粹的"占位博弈"，30 分钟内可连打三局。

### 9.4 混沌模式（派对向，8 人以上）

- 两人一组共用一个手牌（一队 12 张），可以私下商量。
- 组数不变，阈值按**组数**计算（4 组 = 4 人阈值）。
- 讨论阶段缩短到 **30 秒**。

**效果**：适合聚会，吵得更凶，决策更快。

### 9.5 单人挑战（solo）

你一个人对抗"毁灭博士 AI"：每轮暗置 2 张后，掷 2 个骰子决定"虚拟对手"补上的类型与战力（1-3）。其余规则不变。目标是在 6 轮后拿到 **18 分以上**且 Doom ≤ 3。

## 10. 常见问题

**Q1：为什么同一个类型只算最高的那个？两个人加起来不行吗？**
A：这是本作的核心设定——**同一个宇宙只会有一个"你"**。两个同源的英雄撞在一起，现实法则只承认战力更强的那一个。机制上，它让"堆牌"变得低效，逼迫玩家分散投资。

**Q2：如果我和对手的同类战力完全一样怎么办？**
A：**两人都算占位者，但该类型只按最高值算一次**。守住时你们各拿 **+1**（而不是 +2）。所以"打平"是双输：你们俩都少拿一半分，团队战力也没变多。

**Q3：我能出 0 张牌吗？**
A：可以，这叫「待命」。待命的人本轮不得分也不扣分。**当阈值明显守不住时，待命是最优解**（出牌要 −1）。

**Q4：阈值里的人数是"活着的玩家数"还是"开局人数"？**
A：**开局人数，全程不变**。本作没有淘汰机制，所有人玩到最后。

**Q5：缺门惩罚是"阈值 +3"还是"P 减 3"？**
A：**阈值 +3**，每缺一门 +3，最多 +6。注意：某门没人出，它本来就不会贡献 P，所以这已经是双重惩罚了——故意让某一门空着，几乎必崩。

**Q6：我出的牌能不能收回来？**
A：只有「洛基的幻术」这张干涉卡生效时，才能收回 1 张。否则打出的牌立即进弃牌堆，本局不再使用。

**Q7：神器卡什么时候用？能一回合用两张吗？**
A：在**暗置牌之前**声明并明置（「现实宝石」在结算前，「灵魂宝石」在暗置后）。**每回合每人最多 1 张**。

**Q8：如果我手上没有需求类型的牌怎么办？**
A：那就没法覆盖那一门。这也是"12 张牌要用 6 轮"的残酷之处——**开局就要看自己哪一门薄**，薄的那门早用掉，别留到最后。

**Q9：第 6 轮为什么阈值那么低？**
A：因为第 5 轮通常已经把大家的高牌榨干了。如果第 6 轮还是高阈值，几乎必然崩塌，那这一轮就变成了"垃圾时间"。低阈值 + 双倍分，是为了让最后一轮真的能翻盘。

**Q10：Doom 到 4 真的全员输？那如果有人故意害大家呢？**
A：会。这是设计的一部分：本作默认"理性玩家"，也欢迎「背叛者模式」（见 9.2）把内鬼变成明牌玩法。如果你不喜欢，把 Doom 上限改成 5 就好。

**Q11：3 人局会不会太简单/太难？**
A：3 人局的阈值最低（4-7），但覆盖面也最窄（只有 3 个人分摊 4 个类型）。实测守住率 85.6%，和 6 人局（82.2%）基本持平。人少更"算计"，人多更"混乱"。

**Q12：能把两张同类型的高牌一起打出来"锁死"一门吗？**
A：可以，但只有在你**确定没人跟你抢**时才有意义。因为同类型只取最高值，你出 3+3 和只出 3 对团队的贡献完全一样，只是多烧了一张牌。它的唯一价值是"防止别人以 3 打平你"——本质上是在买"独占权"。

## 附录 A：数值依据

本作的平衡性由 **600 局蒙特卡洛模拟**（每人数配置 30 局 × 4 种人数，AI 为"枚举所有出牌组合 + 采样对手"的组合枚举型 AI，不是贪心 AI）验证。模型只含核心结算（不含干涉卡、神器卡、场地加成），所以实际游戏的分数会略高、分布略散。

### A1. 各人数平衡表

| 人数 | 守住率 | 覆盖完整率 | 平均团队战力 P | 平均分 | 分数标准差 | 平局率 | Doom 均值 | Doom≥4 概率 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 3 人 | 85.6% | 84.4% | 6.91 | 13.6 | 5.0 | 10% | 1.60 | 13% |
| 4 人 | 84.4% | 90.6% | 8.13 | 13.2 | 5.0 | 10% | 1.47 | 7% |
| 5 人 | 83.9% | 92.8% | 9.15 | 12.9 | 3.3 | 23% | 1.40 | 3% |
| 6 人 | 82.2% | 95.6% | 10.04 | 11.7 | 3.5 | 7% | 1.27 | 0% |

**读法**：守住率稳定在 82-86%——既不会"怎么打都赢"（无聊），也不会"怎么打都输"（沮丧）。人越多覆盖越容易（95.6%），但人均分越低（11.7 vs 13.6），这正是"人多分摊、人少吃独食"的体现。

### A2. 潮汐曲线（每轮守住率）

| 轮次 | 3 人 | 4 人 | 5 人 | 6 人 |
| :--- | :--- | :--- | :--- | :--- |
| 第 1 轮 | 100% | 100% | 100% | 100% |
| 第 2 轮 | 100% | 100% | 100% | 100% |
| 第 3 轮 | 97% | 100% | 97% | 100% |
| 第 4 轮 | 90% | 87% | 97% | 90% |
| 第 5 轮 | 67% | 57% | 40% | 50% |
| 第 6 轮（决战） | 60% | 63% | 70% | 53% |

**这是本作最重要的设计曲线**：前 3 轮几乎必然守住（爽感），第 4 轮开始吃紧，**第 5 轮是全场的谷底**（手牌最弱、威胁值最高），第 6 轮靠"低阈值 + 双倍分"拉回。

### A3. 一条可以算出来的恒等式

> **P 的天花板恒为 12。**

因为 P = 四个类型各自的最高值之和，而单类型最高只可能是 3（一人出 2 张 3 也只能算 3）。所以：

**P ≤ 4 × 3 = 12，与人数无关。**

这条恒等式推出两个反直觉结论：

1. **人越多，P 会涨，但涨到 12 就封顶**；而阈值 = 人数 + 威胁值，是**无限线性上涨**的。所以 7 人以上玩，游戏必然崩盘（这也是本作只支持 6 人的原因）。
2. **三个人同时把 2 张牌全塞进同一门**，那一门的最高值是 6，其它三门是 0 → P = 6。此时若阈值是 7（4 人局的标准值），**必崩**。所以"全员挤一门"在数学上是被禁止的策略，不需要规则去惩罚它。

### A4. 一个刚性预算恒等式

> **12 = 6 × 2。**

手牌 12 张、6 轮、每轮上限 2 张——**全局资源刚好用完，一张不多**。

- 某轮出 1 张 → 有一张牌永远用不上（因为上限是 2，不能"补回来"）。
- 某轮出 0 张 → 有两张牌作废。
- 想在第 6 轮打出 2 张 3 战力，就必须在前 5 轮少用 2 张高牌。

这条等式把"什么时候出什么牌"从模糊的感觉，变成了可以精确计算的排程问题。

## 附录 C：一页速查

```
【每轮 5 步】
1 翻卡 → 阈值 = 人数 + 威胁值
2 讨论 → 60 秒，可以撒谎
3 暗置 → 同时扣 1-2 张（或 0 张待命）
4 揭晓 → 按类型分组
5 结算 → 占位 / P / 缺门 / 守住 or 崩塌

【占位】每类型战力最高的那个人；并列则都算占位，但只按最高值算一次
【P】= 所有被占位类型的最高值之和（上限恒为 12）
【缺门】需求类型无人出 → 阈值 +3/门
【守住】P ≥ 阈值：
       独占一门 +2｜并列各 +1｜双持需求两门 +1
       四门全占 每人 +1｜签名类型占位者 +1
【崩塌】出牌者各 -1，Doom +1（缺门则 +2）
【结束】6 轮后结算；Doom ≥ 4 → 毁灭博士胜（全员输）
```
