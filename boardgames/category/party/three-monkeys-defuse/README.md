# 三猿拆弹：无声引信 (Three Monkeys Defuse: Silent Fuse)

## 🎮 游戏概述

炸弹在滴答作响。拆弹手册就在桌上——但**唯一能读懂它的人说不出话**。

《三猿拆弹：无声引信》是一款主打「受限沟通」的派对合作竞速桌游，灵感来自日本「三猿」石刻（不见·不闻·不言）与 2026 年 9 月的联机新作《三只猴子拆炸弹》。3-6 名玩家排成一条**人链**，每人被剥夺一种感官能力：队首的**读册师**看得见手册却不能说话，中间的**聋师**听不见只能看手势，**盲师**看不见只能听语音。一条「剪哪根线」的指令必须沿着人链一格一格往下传，**每传一次就失真一点**。

人链末端是**操作手**。他手里握着剪刀，但他对真实指令的全部认知，来自他前一位队友——而那位队友的认知，又来自更前面一位。你要在沙漏漏完之前，让这根信息的接力棒完好无损地跑到终点。

这款游戏的笑点不在于「谁输了」，而在于**阶段结束时所有人同时翻开译码板的那一刻**：你会亲眼看到「剪 3 号红线」是怎么一步步变成「剪 8 号蓝线」的，以及它到底是在哪一环崩掉的。

**适合人群**：朋友聚会、团建破冰、家庭游戏夜、桌游新手（规则 5 分钟讲完）。不需要任何桌游基础，不需要识字（手册卡上全是符号），**越放得开越好玩**。

### 建议准备物品

- **卡纸（200g 以上）**：手册卡、彩线卡、角色卡强烈建议用卡纸打印，避免透光透字。

- **屏风道具**：2-3 本硬壳书或 A4 文件夹，「屏风令」干扰卡要用。
- **眼罩**：建议用真正不透光的可调节眼罩，用手捂眼很容易作弊（而且没那么好笑）。
- **大号计时器**：放在所有人都能看到的位置，投屏到电视上效果最好。
- **桌边空间**：玩家需要排成一列或围成半圆，确保**相邻两人能互相看到/听到，非相邻两人不能**。

### 地形类型说明

| 区域 | 名称 | 说明 |
| :--- | :--- | :--- |
| 上部 | **线槽 ①-⑥** | 6 个插槽，自左向右编号。**剪线永远是「取下某个槽位的彩线卡」**，操作手只需要认槽号，不需要认颜色 |
| 中部 | **彩线卡** | 按当前布线卡插入，一槽一色。全场公开，所有人（除盲师外）都能看 |
| 下部 | **剪线区** | 视觉标记，提醒操作手「剪线」这个动作发生在槽位上 |
| 底部 | **引信刻度条** | 12 → 0 共 13 格。回形针从 12 出发，每次惩罚向左移动；移动到 0 时炸弹爆炸 |
| 底栏 | **惩罚速查** | 四条最常用的惩罚，贴在板上避免争论 |

### 拆弹台的特点与资源统计

| 项目 | 数值 | 说明 |
| :--- | :--- | :--- |
| 线槽总数 | 6 | 每阶段按布线卡插入 6 张彩线卡，**一槽一色，六色全上** |
| 布线方案 | 8 种 | 八种预设排列，保证每局的「颜色 ↔ 槽号」映射都不同 |
| 引信初始 | 12 点 | 允许约 6 次严重失误（每次 −2）。**这是全队共用的唯一血条** |
| 引信归零 | 💥 爆炸 | 游戏立即结束；已得分保留，比分数决出「最稳拆弹兵」 |
| 手册卡标识制 | 2 种 | **槽号制**（直接照做）与**颜色制**（需在板上换算成槽号） |
| 单阶段时长 | 3-4 分钟 | 简单/中等 3 分钟，困难 4 分钟；「急促引信」干扰卡改为 90 秒 |

**为什么颜色制手册更难？** 因为手册上写的是「剪 🟡」，而操作手剪的是「槽 ②」。这个换算必须由链条中**某个看得见炸弹板的人**完成（所有人都可以，除了盲师）。如果换算发生在链条的靠后位置，前面传递的就一直是颜色，操作手还得自己看板——多一次视觉依赖，就多一次出错机会。

### 一、手册卡（信息源 · 24 张）

手册卡是全场唯一的真相。**只有读册师能看，且看完不能说话，只能比划。**

卡面不印任何文字，只印一条 6 格的线槽条：

| 标记 | 含义 |
| :--- | :--- |
| `✂️1` `✂️2` `✂️3` | 需要剪断的线，数字是**剪线顺序** |
| `✂️`（无数字） | 需要剪断的线，**无顺序要求** |
| `🚫` | **死线** —— 碰到即引信 −3，且该阶段直接判失败 |
| 无标记 | 不用动 |

**两种标识制**（每张手册卡只用其中一种，绝不混用）：

| 标识制 | 卡面显示 | 读册师要做的事 |
| :--- | :--- | :--- |
| **槽号制** | `① ② ③ ④ ⑤ ⑥` | 直接传槽号，照做即可 |
| **颜色制** | `🔴🟠🟡🟢🔵🟣` | 需对照炸弹板，把颜色换算成槽号 |

**难度分级**：

| 🎵 | **咏叹调** | 聋师传递时只能哼唱旋律，不能说出任何具体词语。 | 🟣 重 |
| 🦵 | **手肘传令** | 禁止使用手指与手掌，只能用手肘以下整条手臂比划。 | 🟣 重 |
| 🪞 | **镜像手势** | 所有手势必须左右镜像后打出（对方看到的才是正解）。 | 🟣 重 |
| ❓ | **是非回问** | 操作手可提出一个是非题，沿链条反向传到读册师，读册师只能点头或摇头再传回。全场限 1 次，消耗额外 30 秒。 | 🔵 救命 |
| ⏱️ | **急促引信** | 本阶段倒计时缩短为 90 秒。 | 🔴 致命 |
| 🔇 | **全静默** | 本阶段禁止发出任何语音。盲师改为接收「拍肩次数」传递数字。 | 🔴 致命 |
| 🌑 | **蒙眼操作** | 操作手必须戴眼罩执行，无论他的角色是什么。 | 🔴 致命 |

> **❓ 是非回问是唯一的「保险」**：它让操作手有机会反向确认一次，代价是 30 秒。什么时候该用它，是中后期最重要的决策。

### 四、角色卡（6 张）

角色**跟着位置走**，不跟着人走。每阶段结束轮转一次，所以每个人都会轮遍所有角色。

| 图示 | 角色 | 位置 | 感官缺陷 | 接收方式 | 发送方式 |
| :---: | :--- | :--- | :--- | :--- | :--- |
| 📖 | **读册师** | 位置 1（队首） | 看得见、听得见，但**不能说话** | 阅读拆弹手册（全场唯一信息源） | 只能用**手势** |
| 🙉 | **聋师** | 位置 2 / 4 / 6（偶数位） | **听不见** | 只能用**视觉**接收手势 | 只能用**说话** |
| 🙈 | **盲师** | 位置 3 / 5（奇数位） | **看不见** | 只能用**听觉**接收语音 | 只能用**手势** |

**违规行为（每次引信 −1）**：

| 角色 | 违规行为 |
| :--- | :--- |
| 📖 读册师 | 开口说话／把手册递出去／用笔写给别人看／用手指手册上的图案 |
| 🙉 聋师 | 转头去看别处（不看上一位）／用手势传给下一位／戴耳机 |
| 🙈 盲师 | 睁眼／摘眼罩／用说话传给下一位／从眼罩缝隙偷看 |
| 全体 | 隔位传递（跳过中间的人）／回头向上一位确认／使用手机或纸笔 |

**关于末位（操作手）**：

| 人数 | 末位角色 | 操作方式 |
| :---: | :--- | :--- |
| 3 人 / 5 人（奇数） | 🙈 盲师 | **戴着眼罩摸着剪**。靠手数槽位，靠听觉接收指令 |
| 4 人 / 6 人（偶数） | 🙉 聋师 | **看着剪**。能看炸弹板，靠视觉接收手势 |

> 两种都能玩，且都很有戏。奇数局的盲师操作手是全游戏最有压迫感的角色——他看不见炸弹，看不见手势，只能听，然后伸手去摸第 3 个槽。

### 六、译码板（6 块）

**这是整个游戏的灵魂道具。**

每人 1 块。收到信息后，**立刻在板上画出你自己理解到的指令**——不是你听到/看到的原文，而是你脑子里的版本。

板面结构：

```
┌──────────────────────────────┐
│  译码板 3                     │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐│
│  │① │ │② │ │③ │ │④ │ │⑤ │ │⑥ ││   ← 在要剪的槽上画 ✂️
│  └──┘ └──┘ └──┘ └──┘ └──┘ └──┘│
│  ┌──────┐ ┌──────┐ ┌──────┐  │
│  │第1刀 │ │第2刀 │ │第3刀 │  │   ← 填顺序
│  └──────┘ └──────┘ └──────┘  │
│  ☐ 我完全确定                 │
│  ☐ 我有点不确定               │
│  ☐ 我完全是猜的               │
└──────────────────────────────┘
```

**为什么要有译码板？** 没有它，你只知道「最后剪对了没有」。有了它，你能看到：

- 信息是在**第几环**开始变形的
- 是**数字**传丢了，还是**顺序**传丢了，还是**死线**传丢了
- 谁该背锅，谁是被冤枉的（这直接决定计分）

阶段结束时全员同时翻板，是全场笑点最密集的瞬间。

## 📜 游戏规则

### 一、准备阶段

**第 1 步 · 布置拆弹台**
把炸弹板铺在桌中央，引信标记放在刻度条的「12」格上。

**第 2 步 · 排人链**
玩家按位置 1 到 N 排成一列或半圆，确保**相邻两人能互相看到/听到，非相邻两人不能**。发对应角色卡。

**第 3 步 · 备战 3 分钟**
- 抽 1 张角色卡确认，戴好眼罩（盲师）
- 摊开 4 张手势词典，统一本局要用的手势
- **备战期不占用倒计时**，可以随意说话、争论、试比划
- 建议把定好的手势写在纸上贴桌边

**第 4 步 · 准备牌堆**
手册卡、干扰卡、布线卡分别洗匀，背面朝上放好。

**第 5 步 · 确定裁判**
如果人数为 3-5 人，可以指定一名未上场的观众当裁判；6 人局则由**当前读册师**兼任裁判（因为他不需要参与传递）。裁判负责：抽卡、计时、比对译码板、移动引信标记、判罚违规。

### 二、每阶段（每颗炸弹）流程

> **阶段数 = 玩家人数**。3 人拆 3 弹，6 人拆 6 弹。

**① 布线**（30 秒）
翻开 1 张布线卡，按卡面顺序把 6 张彩线卡插入槽位 ①-⑥。裁判向盲师口头报一遍排列。

**② 抽卡并公开**
翻开 1 张手册卡（**背面朝上放在读册师面前，暂时不许看**）和 1 张干扰卡（**公开朗读**）。

**③ 读册师阅读**（10 秒）
裁判示意，读册师翻开手册卡阅读 10 秒。其他人**必须转身、闭眼或戴眼罩**，不得偷看。10 秒后裁判收走手册卡（或扣在桌上）。

**④ 倒计时开始**
裁判按下计时器（简单/中等 3 分钟，困难 4 分钟；「急促引信」改为 90 秒）。

**⑤ 信息接力**
信息沿链条**单向**传递，一格一格往下走：

```
📖 读册师 ──手势──> 🙉 聋师 ──说话──> 🙈 盲师 ──手势──> 🙉 聋师 ──说话──> 🙈 盲师（操作手）
   位置1              位置2              位置3              位置4              位置5
```

- 每个人**收到信息后立刻在自己的译码板上画下理解**，随时可以修改
- 传完之后，你**可以选择停留、可以主动重传一次**（但不许回头向上一位确认）
- 操作手**可以随时开始剪线**，也可以等确认清楚了再剪
- 操作手剪线 = 把该槽位的彩线卡取下，放在桌边

**⑥ 冻结**
操作手喊「完成」，或倒计时归零。裁判喊「冻结」，所有人立刻停止动作、停笔。

**⑦ 亮板比对**
所有人把译码板正面朝上翻开。裁判按位置 1 → N 的顺序逐人核对，与手册真实答案比对。

**⑧ 结算**
见下方「计分规则」。

**⑨ 轮转**
**队首的读册师绕到队尾，其余人整体前移一格。** 角色跟着位置走，所以每个人都会轮遍所有角色。

4 人局的轮转示例：

| 阶段 | 位置1 | 位置2 | 位置3 | 位置4（操作手） |
| :--- | :---: | :---: | :---: | :---: |
| 第 1 弹 | 阿哲 📖 | 小满 🙉 | 阿柯 🙈 | 老唐 🙉 |
| 第 2 弹 | 小满 📖 | 阿柯 🙉 | 老唐 🙈 | 阿哲 🙉 |
| 第 3 弹 | 阿柯 📖 | 老唐 🙉 | 阿哲 🙈 | 小满 🙉 |
| 第 4 弹 | 老唐 📖 | 阿哲 🙉 | 小满 🙈 | 阿柯 🙉 |

四弹下来，每人恰好当**1 次读册师、1 次操作手、2 次传令员（1 聋 1 盲）**。

### 三、计分规则

每人每阶段的得分 = **译码分 + 团队分 + 执行分（仅操作手）**。

#### 译码分（每人每阶段必得其一）

| 情况 | 得分 |
| :--- | :---: |
| 你的译码板与手册真实答案**完全一致** | **+2** |
| 你的译码板**错了**，但**前一位也错了**（忠实传递，锅不在你） | **+1** |
| 你的译码板**错了**，而**前一位是对的**（信息断在你这） | **0** |

> **判定细节**：「完全一致」指**待剪线的集合、顺序、以及死线标记三者全对**。死线写漏了也算错——死线是最容易传丢的信息，也是最容易引爆的雷。
> **读册师的前一位就是手册本身**，所以读册师只有 +2 或 0 两种结果（他要么看懂了，要么看错了）。

#### 团队分

| 情况 | 得分 |
| :--- | :--- |
| 阶段成功 → **全队每人** | **+难度系数**（简单 ×1／中等 ×2／困难 ×3） |
| 阶段失败 | 0 |

#### 执行分（仅操作手）

| 情况 | 得分 |
| :--- | :---: |
| 全部剪对（含顺序） | **+2** |
| 剪到死线 | **−2** |

#### 引信惩罚（全队共用，起始 12）

| 事件 | 引信 |
| :--- | :---: |
| 剪错 / 漏剪 / 顺序错 | −2 |
| 剪到死线 🚫 | −3 |
| 超时未完成 | −1 |
| 违反角色缺陷（说话／偷看／摘眼罩） | −1（每次） |
| 隔位传递 / 回头确认 | −1（每次） |
| 违反干扰卡规则 | −1（每次） |

#### 理论满分（脚本核算）

| 人数 | 阶段数 | 计算式 | 理论满分 |
| :---: | :---: | :--- | :---: |
| 3 人 | 3 | 4 × 3 + 2 | **14** |
| 4 人 | 4 | 4 × 4 + 2 | **18** |
| 5 人 | 5 | 4 × 5 + 2 | **22** |
| 6 人 | 6 | 4 × 6 + 2 | **26** |

> 推导：每人恰好当 1 次读册师（+2）、1 次操作手（+2 译码 +2 执行）、P−2 次传令员（+2 译码），
> 合计 2 + 4 + 2(P−2) = 2P + 4 分译码/执行分；
> 团队分按全中等算 P × 2 = 2P；
> 总计 4P + 2。

### 四、胜利条件

- **全部阶段结束后**，比个人累计得分。最高分者为**「本局最稳拆弹兵」**。
- 如果引信在过程中归零（💥 爆炸），游戏**立即结束**。已得分保留，比分数决出名次，但全队判**拆弹失败**。
- 平局时，依次比较：**当读册师那一弹是否成功 → 当操作手那一弹是否成功 → 译码分总分**。仍平手则并列。

## 🎲 完整游戏流程示例

下面是一局**完整的 4 人局**，四名玩家分别是 **阿哲、小满、阿柯、老唐**。四个阶段共享同一局、同一批人、同一套局面数据——你会看到第 1 弹埋下的隐患是如何在第 3 弹引爆的。

**备战 3 分钟**：四人商量后决定自创一套简化手势——
- **数字**用手指（1-5 普通，6 = 握拳伸小指）
- **颜色**用官方的摸身体部位法
- **顺序**用「左手先指 → 右手后指」
- **死线**用「手掌在脖子前一横」

引信起始 **12**。

- 执行分：老唐全部剪对 → +2

| 阿哲 | +4 | 4 |

| 阿柯 | +4 | 4 |

引信 **12**（无惩罚）。

### 第 2 弹 · 隐形的错误（成功，但埋雷）

**轮转**：阿哲绕到队尾。
**位置**：小满 📖 ｜ 阿柯 🙉 ｜ 老唐 🙈 ｜ 阿哲 🙉（操作手，看得见）

**布线卡 03**：槽①黄 🟡 ｜ 槽②蓝 🔵 ｜ 槽③红 🔴 ｜ 槽④紫 🟣 ｜ 槽⑤橙 🟠 ｜ 槽⑥绿 🟢

**手册卡 16**（中等 · **颜色制** · 系数 2）：

```
🔴 🟠 🟡 🟢 🔵 🟣
     ✂️1         ✂️2
🚫 位置在 🟢 上
```
**真实答案**：死线绿（= 槽⑥），先剪红（= 槽③），后剪蓝（= 槽⑤）。

**干扰卡**：⏱️ **急促引信** —— 倒计时只有 **90 秒**！

**倒计时 1:30 开始**

## 🧠 新手策略提示

### 🟢 P0 · 第一局必看

**1. 备战期一定要演练两条通道，不只练一条。**
绝大多数新手队伍只练「手势传数字」（因为最直观），结果一遇到 🎵 咏叹调、🔇 全静默这种卡就当场瘫痪。**至少各练一次**：
- 全手势链（假设全程不能说话）
- 全语音链（假设全程不能比划）

**2. 数字手势比你想的更容易错。**
「3」和「4」在快速比划时极易混淆，「5」和「2」也是。**建议在官方手势基础上加一个确认动作**——比完数字后，用手掌在空中写一遍那个数字，或者点一下自己的掌心表示「数字完毕」。牺牲 2 秒，换取准确率。

**3. 颜色制手册，读册师一定要自己换算成槽号再传。**
不要传「剪黄色」然后指望下游换算。原因有二：
- 下游可能是盲师，看不见炸弹板
- 每次换算都是一次失真机会，能少一次就少一次

**4. 死线信息比待剪信息更重要。**
剪错一根 = 引信 −2；剪到死线 = 引信 −3 且阶段直接失败。**死线是全场唯一「一旦传丢就血亏」的信息**。传递时把死线放在**最前面**，并且让每一位接收者在译码板上**先画死线**。

### 🟡 P1 · 打顺了之后

**5. 译码板要「边收边画」，不要「听完再画」。**
人的短时记忆只有 3-5 个组块。困难弹有 3 根线 + 顺序 + 死线，正好超载。**收到一个元素就画一个**，边画边听。这也是为什么译码板要放在手边而不是腿上。

**6. 利用「重传」而不是「回头确认」。**
回头向上一位确认（比如反问、指指点点）是**违规，−1**。正确做法是让上一位**主动重传一次**——这是允许的，只是耗时间。所以约定一个「重来一次 🔄」手势，比什么都重要。

**7. 操作手不要急着剪。**
新手操作手一收到信息就冲上去剪，生怕超时。但**剪错了 −2，超时才 −1**。如果你只有 60% 把握，宁可超时也不要剪错。正确姿势：先把译码板画完，看一眼炸弹板确认槽位，再动手。

**8. 数「哼声」几乎必然出错，改用「长度」或「节奏」。**
遇到 🎵 咏叹调、🔇 全静默这类卡时，不要试图让对方「哼 5 声」——数数会崩。改用**可感知的物理量**：
- 拍肩 **5 次**（触觉，盲师能感知）
- 哼一个**长音**表示大数、**短音**表示小数（只区分两档）
- 用**重复次数 + 停顿**分组（哼 3 下，停，再哼 2 下 = 「3-2」而非「5」）

### 🔴 P2 · 高手进阶

**9. 冗余编码：同一条信息传两遍，用不同通道。**
高段位队伍的常规操作：聋师说话传给盲师时，会**同时**在盲师手心里画数字。这不违规（盲师本来就能听和触摸），但给了盲师两个信源。**「语音 + 触觉」双通道能把失真率砍掉一半。**

**10. 把难度留在最后。**
手册是随机抽的，你无法选择。但你可以**在引信充裕时故意保守**——如果这一弹是困难弹且你当的是盲师（信息链长），可以考虑让操作手宁可超时（−1）也不冒险剪错（−2）。**用 −1 换 −2 的期望，是划算的。**

**11. 干扰卡的字面就是字面。**
- 🔙 背身接力只说「背对」，没说不能抬手举高 → 举到对方余光里合法
- 🤚 单手令只说「一只手」，没说不能**用两只脚**
- 🦵 手肘传令禁止「手指与手掌」，但**手腕、手肘、整条手臂**都能用
- ⏸️ 节拍令要求「拍三下手」，但**没规定拍多响**

**规则没禁止的，就是允许的。** 这既是最有趣的策略空间，也最容易引发争论——**开局前先约定：裁判的裁定是最终的。**

**12. 观察引信，动态调整风险偏好。**

| 剩余引信 | 建议策略 |
| :---: | :--- |
| 10-12 | 可以冒险。困难弹就冲，错了也扛得住 |
| 6-9 | 稳扎稳打。宁可超时，不可剪错 |
| 3-5 | **死线优先**。宁可只剪一半，也绝不能碰死线 |
| 1-2 | 保命模式。只剪最有把握的那根，其余放弃 |

## 🔀 变体规则

### 变体 1 · 竞速双弹（6 人专属 · 推荐）

6 人拆成两支 3 人小队，**同时**拆两颗炸弹（两套拆弹台，或一张台分左右半区）。两队抽**相同的**手册卡和布线卡，**不同的**干扰卡。
- 先完成且引信剩余多者获胜
- 两队在同一房间，噪音互相干扰——**这是特性，不是 bug**
- 时长缩短至 20-30 分钟，非常适合人多时

### 变体 2 · 专家模式（引信 8）

起始引信从 12 降到 **8**，且**取消「超时 −1」的宽限**（超时直接 −2）。适合已经玩过 3 局以上的队伍。

### 变体 3 · 盲师全程（致敬原作）

所有中间传令员**一律为盲师**（全部戴眼罩），只有队首读册师和末位操作手能看。链条的规则相应简化为：

```
📖 读册师 ──说话──> 🙈 盲师 ──说话──> 🙈 盲师 ──说话──> 🙉 操作手
```

难度大幅下降，但**节奏更快、笑点更密**，适合带完全没玩过桌游的朋友入门。

### 变体 4 · 谍报模式（加入卧底 · 5-6 人）

准备阶段，每位玩家秘密抽取一张身份卡：**4-5 张「拆弹兵」+ 1 张「内鬼」**。内鬼的真实目标是让引信归零，但他必须伪装——他会在传递时**故意扭曲一点点信息**（比如把「3」传成「5」）。
- 全部阶段结束后全员投票指认内鬼
- 若指认正确，拆弹兵方每人 +5 分；若错误，内鬼 +10 分
- 内鬼身份卡可用普通扑克牌代替

### 变体 5 · 无声全场（硬核）

**整局游戏禁止任何人说任何话**，包括备战期。备战只能用纸笔、手势和示范。倒计时从 3 分钟延长到 4 分钟。
> 这个变体极其搞笑，但也极其依赖团队默契。**建议作为第 3-4 局的加餐。**

### 变体 6 · 短剧模式（时间不够时）

阶段数固定为 **3 弹**，不按人数。轮转照常，但每人只能轮到 3 个位置。
- 3 人局：正常（每人轮遍）
- 4-6 人局：有人轮不到读册师/操作手，运气成分上升，但时长压到 20 分钟

## ❓ 常见问题

### 规则类

**Q1：3 个人能玩吗？会不会太简单？**
能，而且 3 人局是官方推荐的新手局。3 人只有 2 次传递，信息几乎不会失真——这正是它的价值：**让新手先理解「链条」是怎么运作的**，而不是一上来就被 5 次传递搞崩。玩顺了再加人，**每加一个人就多一次传递，难度是线性上升的**。

**Q2：手册卡上的「颜色制」和「槽号制」有什么区别？为什么不能混用？**
槽号制直接写 `① ② ③`，照做即可；颜色制写 `🔴🟠🟡`，需要对照炸弹板换算成槽号。**混用会导致逻辑冲突**——比如「死线🟠」和「剪③」，如果这一局橙色恰好插在槽③，这条指令就自相矛盾了。所以每张手册卡严格只用一种标识制。

**Q3：传令员能不能主动重传一次？**
**能，强烈鼓励。** 重传不违规，只耗时间。违规的是**回头向上一位确认**（反问、指指点点、让上一位再看一遍手册）。区别在于：重传是**上一位主动再发一次**，回头确认是**下一位向上索取**——后者会破坏单向链条的紧张感。

**Q4：操作手可以在传递完成前就开始剪线吗？**
可以。如果操作手觉得信息已经够了，随时可以动手。但**一旦剪下第一根，就不能再接收信息了**（裁判会喊停）。所以通常建议等信息传完、译码板画完再动手。

**Q5：「是非回问」干扰卡怎么用？**
操作手提出一个是非题（比如「是不是先剪 2 号再剪 5 号？」），沿链条**反向**一格一格传到读册师，读册师**只能点头或摇头**，再沿链条反向传回操作手。
- 全场**限 1 次**，消耗额外 **30 秒**（从倒计时里扣）
- 这是一张**救命卡**，通常留到困难弹、且链条较长时用

**Q6：译码板写「橙」算对还是写「⑤」算对？**
**等价换算后结果一致即判对。** 比如真实答案是「剪⑤」，而译码板写「剪橙」，且当前布线卡下橙色确实在槽⑤ → 判 +2。
但如果译码板写了颜色却**没写槽号**，而布线卡有两种颜色可能 → 判错。**建议裁判在开局前统一宣布判罚口径。**

### 执行类

**Q7：眼罩不够怎么办？**
替代方案优先级：**真正不透光的眼罩 > 围巾/毛线帽 > 用手捂眼 > 闭眼 + 全场监督**。
用手捂眼和闭眼的问题是很容易作弊，但**派对游戏本来就是靠自觉**——如果有人偷看，其他人的嘘声就是最好的惩罚。

**Q8：有人违规了，谁来判罚？**
裁判。如果 6 人局没有专职裁判，由**当前读册师**兼任（他不需要参与传递）。开局前必须约定：**裁判的裁定是最终的，不许争论超过 10 秒**（倒计时在走，争论本身就是惩罚）。

**Q9：倒计时到了但还没剪完，怎么办？**
裁判喊「冻结」，所有人立即停止。判定为**超时**，引信 −1，阶段失败。
注意：如果操作手**已经剪下了一部分**且都剪对了，仍判超时失败（因为没完成）。**「差一点」也是失败**——这就是倒计时的意义。

**Q10：干扰卡的效果和角色卡的缺陷冲突时怎么办？**
**干扰卡优先。** 比如 🔇 全静默要求「禁止任何语音」，那聋师就不能说话了，只能改用手势；而盲师接收不到手势，所以规则专门规定了「盲师改为接收拍肩次数」。**干扰卡上写明了解法，照做即可。**

**Q11：手册卡会被玩家记住吗？**
会。24 张手册卡玩过 2-3 局后，老玩家会记住「09 号是死①剪②⑤」。解决方案：
- 每局只用一部分手册卡（随机抽出人数 +2 张）
- 或者接受它——**记住手册反而会让游戏更流畅**，因为难度从「读图」转移到了「传递」上，这正是游戏的核心

**Q12：如果有人完全不会比手语/手势怎么办？**
这正是游戏的乐趣所在。**不需要任何手语基础**——官方手势词典里的动作（摸耳垂、摸膝盖、比手指）是所有人天生就会的。如果实在放不开，可以先从**变体 3 · 盲师全程**（只用语音）入门。

### 平衡类

**Q13：为什么我总分总是最低？是不是运气问题？**
是，也不是。手册卡和干扰卡确实随机，你可能在困难弹时恰好当了盲师（信息链最长）。但**阶段数 = 人数**保证了每人恰好当 1 次读册师、1 次操作手、N−2 次传令员——**长期看完全公平**。多打几局，分数会回归。

**Q14：引信 12 点够用吗？**
按设计，12 点允许约 6 次严重失误（每次 −2）。4 人局 4 弹，**平均每弹允许 1.5 次失误**——这意味着**必须至少成功 2-3 弹**。偏紧，这是故意的：宽松的引信会让游戏失去紧张感。
如果新手队伍连续两局爆炸，可以先用变体「引信 16」过渡。

**Q15：6 个人是不是太难了？**
6 人有 **5 次传递**，是 3 人的 2.5 倍。第一局建议 **4 人**（3 次传递，甜点区）。6 人局建议配合**变体 1 · 竞速双弹**（拆成两支 3 人队），既保留人数又能玩。

**Q16：能不能让玩家自己选难度？**
原版规则是随机抽。如果你想降低随机性，可以改成：**读册师抽 3 张，选 1 张**，但被选中的那张难度系数 −1（最低 1）。这样保留了策略性，又不会让人摆烂全选简单。

## 📝 设计手记

### 为什么这个机制成立

**传递次数 = 人数 − 1。阶段数 = 人数。**

这两条恒等式是整个游戏的地基：
- 3 人 2 次传递，6 人 5 次传递 —— **人数即难度**，不需要额外的平衡规则
- 每人恰好当 1 次读册师、1 次操作手 —— **长期完全公平**，运气被摊平
- 理论满分 = 4 × 人数 + 2 —— **玩家一眼能算清自己离满分差多少**

### 物理锚点：译码板

抽象的信息失真问题，被落成了一个**看得见的物理动作**——「在板上画下你理解到的东西」。玩家不需要理解信息论，只需要知道：**传完之后赶紧画下来**。阶段结束时四块板一字排开，信息在哪一环崩掉，肉眼可见。

### 灵感来源

- **《三只猴子拆炸弹》**（2026 年 9 月联机新作）：三名角色各有感官缺陷，只能靠点头、哈腰、手势传递拆弹信息
- **日本「三猿」石刻**：不见（🙈）、不闻（🙉）、不言（🙊）—— 本游戏将其转化为三种角色能力
- **传话游戏（Telephone）**：经典派对游戏，本作给它加上了**真实时间压力**和**可追踪的失真路径**

### 数值核算

所有分数、张数、排列组合均由 `scripts/gen_three_monkeys_printables.py` 脚本核算，包括：
- 手册卡自洽性（死线不与待剪线重叠、顺序号连续、无重复槽位）
- 布线卡排列合法性（8 组均为 0-5 的合法排列）
- 图标冲突扫描（手册 × 干扰 × 角色 × 手势 × 布线，零冲突）
- 理论满分推导（4P + 2）
