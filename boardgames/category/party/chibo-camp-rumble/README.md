# 蓝色星原：奇波营地大作战

> **AZUR PROMILIA · CHIBO CAMP RUMBLE**
> 一场在黄昏与黎明之间进行的「读心抢捕」派对游戏。
> 3-6 人 · 20-40 分钟 · 8 岁以上 · 派对 / 同时出牌 / 读心竞价

---

## 一、游戏概述

### 1.1 故事背景

普罗米利亚大陆的夜里，奇波会自己找上门。

你们是同一片草原上扎营的旅谣者。黄昏一到，营地外的五个栖息地就会飘出奇波的气味——风之丘的绒毛、光之庭的余晖、水之涧的湿气、岩之岬的矿盐、暗之林的菇香。谁都想在天亮前把看中的那只编进自己的图鉴，或者干脆带回家园当个帮手。

但草原只有这么大，饵料只有这么多。

大家都是行家，都知道「对口」的饵料最容易得手——于是所有人都盯着同一只奇波，同一时间伸出手，然后一起扑空。**真正的高手不是算得最准的那个，是最会数人头的那个。**

### 1.2 一句话玩法

每轮翻出一只奇波，全员**同时扣下 1 张饵料**；一起翻开，算「亲密度」，最高且过门槛的人把它抱走。

### 1.3 为什么它会好玩

| 你以为是 | 实际上是 |
| :--- | :--- |
| 比谁运气好抽到对口饵料 | 比谁猜得准「这轮有几个人跟我打同一张牌」 |
| 一直出最强的那张就行 | 出最强的人往往撞车，反而一分不得 |
| 手牌只是选项 | 手里留几张同属性，就是白送的 +2 亲密度 |
| 输了就白忙 | 差一点的人有近失补偿，逃逸的奇波还留在原地等你 |

### 1.4 适合谁

- **派对场景**：6 个人围一桌，规则 5 分钟讲完，笑声从第一轮开始
- **新手玩家**：没有文字量、没有复杂的行动点，只有一个「我出哪张」的决定
- **老手玩家**：读到第 3 轮就开始算计「阿明一定会抢水属性，我改投岩」，然后被反算
- **不适合**：想要深度策略推演、或者讨厌「猜别人心思」的玩家

## 四、游戏地图详解

### 4.1 营地版图布局

版图不是走棋的棋盘，而是一块**摆放区**：五个栖息地围成一圈，中央是星辉篝火。

```
                    ┌──────────────┐
                    │  🌪 风之丘    │
                    │  风属性       │
                    └──────┬───────┘
                           │
      ┌────────────┐       │        ┌────────────┐
      │ 🌑 暗之林   │       │        │ ✨ 光之庭   │
      │ 暗属性      │   ┌───┴────┐   │ 光属性      │
      └──────┬─────┘   │ 🔥 星辉 │   └─────┬──────┘
             │         │  篝火   │         │
             │         │ ★★★    │         │
             │         └───┬────┘         │
      ┌──────┴─────┐       │        ┌─────┴──────┐
      │ 🪨 岩之岬   │       │        │ 💧 水之涧   │
      │ 岩属性      │       │        │ 水属性      │
      └────────────┘       │        └────────────┘
                           │
              （相生环：风→光→水→岩→暗→风）
```

> 摆版图时，五个栖息地**按相生环的顺序**围成一圈（顺时针：风、光、水、岩、暗）。这样桌面本身就是一张属性轮盘，谁都不用去查表。

### 4.3 版图上的四个位置

| 位置 | 放什么 | 什么时候用 |
| :--- | :--- | :--- |
| **栖息地圆心** | 本轮翻出的奇波卡 | 每轮翻牌后立刻放上去 |
| **访客槽** | 逃逸的奇波卡 | 逃逸时留下，使该属性下一只门槛 +1 |
| **栖息地边缘** | 玩家的营地旗（棋子） | 开局摆放，捕获后可沿环移动 1 格 |

### 4.4 三种特殊摆法

| 情况 | 怎么摆 | 规则变化 |
| :--- | :--- | :--- |
| **普通一轮** | 奇波卡放对应栖息地圆心 | 每人扣 1 张饵料 |
| **星辉一轮** | 奇波卡放中央篝火 | 每人扣 **2 张**饵料，门槛 7，营地旗无效 |
| **逃逸之后** | 奇波卡留在访客槽 | 该属性下一只奇波门槛 +1；谁抓到就一并收走访客（每张 +1 星屑） |

### 4.5 为什么要有版图

没有版图也能玩（用桌面分区代替），但版图解决了三个实际问题：

1. **省掉重复解释**：「谁的水属性最强」一眼就能看到棋子，不用每轮重复
2. **访客不会忘**：逃逸卡就摆在那个属性上，门槛 +1 不会漏算
3. **属性能看见**：五个栖息地按相生环排序，新手不用背「谁克谁」

## 五、道具详解

### 5.1 属性轮盘（先看这个）

游戏里所有「加分 / 减分」都围绕一条环：

| 你投的属性 | 对奇波的关系 | 修正 |
| :--- | :--- | :--- |
| **同属性** | 对口 | **+3** |
| **相邻属性** | 相生 | **+1**（意外卡「新芽」时 +2） |
| **隔一位属性** | 相克 | **作废**，你的亲密度直接算 0 |

> **相生环**：风 → 光 → 水 → 岩 → 暗 → 风
> **相克环**：风 ↔ 水、光 ↔ 岩、水 ↔ 暗、岩 ↔ 风、暗 ↔ 光

**怎么记**：相生环上数两格就是相克。风到光是一格（相生），风到水是两格（相克）。

### 5.2 资源卡（饵料卡，40 张）

| 属性 | 图示 | 卡名 | 数量 | 获得方式 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 风 | 🍃 | 轻风果 / 羽绒饵 / 风铃蜜 | 8 | 开局抽 5 张，每轮补 1 张 | 作为出价投给奇波 |
| 光 | ✨ | 光尘糖 / 日轮籽 / 蜜光露 | 8 | 同上 | 同上 |
| 水 | 💧 | 露珠饵 / 泡沫糕 / 潮汐贝 | 8 | 同上 | 同上 |
| 岩 | 🪨 | 矿盐饵 / 岩菇干 / 石芋 | 8 | 同上 | 同上 |
| 暗 | 🌑 | 夜莓 / 暗烛蜡 / 幽菇 | 8 | 同上 | 同上 |

**关键规则：带料加成**

> 你投出的饵料，若**手里还剩同属性**的饵料，每剩 1 张 **+1 亲密度**，最多 **+2**。

这条规则是整局游戏的灵魂：

- 手里 3 张风、出 1 张 → +2（剩 2 张）
- 手里 1 张风、出掉 → +0
- **别人看不见**你有几张 → 这是唯一的隐藏信息

所以「留牌」和「出牌」本身就是一对矛盾：留得多，加成高但选项少；出得狠，加成低但灵活。

- 每人开局抽 **2 张**（旅谣学徒抽 3 张）

**什么时候最值钱**：

| 道具 | 最佳时机 |

| 蜜露瓶 | 手牌全是废属性、但这一轮大家都不对口时——偷家神器 |

2. 亲密度 = 3 + 两张饵料的修正之和 + 带料（只算一次）+ 旗帜 + 角色 − 扎堆
3. **营地旗无效**（星辉在中央篝火，不在任何栖息地）
4. 抓到得 **3 星屑**（本作最高单卡收益）

### 5.6 角色卡（6 张）

| 角色 | 图示 | 擅长属性 | 能力 |
| :--- | :--- | :--- | :--- |
| 风语者·铃兰 | 🌪 | 风 | 你的「风」饵料亲密度 +1 |
| 潮汐使·涟漪 | 💧 | 水 | 你的「水」饵料亲密度 +1 |
| 磐石匠·石臼 | 🪨 | 岩 | 你的「岩」饵料亲密度 +1 |
| 拾光人·灯见 | ✨ | 光 | 你的「光」饵料亲密度 +1 |
| 夜行者·影拾 | 🌑 | 暗 | 你的「暗」饵料亲密度 +1 |
| 旅谣学徒·小奇 | 🎒 | 无 | 起始多 1 张道具；每轮结束可弃 1 张手牌换 1 张 |

> 五个属性的角色**完全等价**，只是让你的「主场」不同。学徒没有属性加成，换来的是道具和换牌自由——他是全场最灵活、也最难算的人。

## 六、游戏规则

### 6.1 准备阶段（7 步，约 3 分钟）

| # | 步骤 | 细节 |
| :--- | :--- | :--- |
| 1 | **摊开版图** | 五个栖息地朝向全桌，牌堆与弃牌区放在两侧 |
| 2 | **洗草原牌堆** | 48 张奇波卡 + 12 张意外卡混洗，正面朝下 |
| 3 | **发饵料** | 40 张洗匀，每人抽 5 张作为起手手牌 |
| 4 | **发角色** | 洗 6 张角色卡，每人抽 1 张，正面朝上摆好 |
| 5 | **发道具** | 12 张道具洗匀，每人抽 2 张（学徒抽 3 张） |
| 6 | **摆营地旗** | 每人把棋子放到任一栖息地上，从此它就是你的地盘 |
| 7 | **定先手** | 最近去过山里的人先手（或掷骰）；先手棋子放面前，每轮左传 |

**摆营地旗的小建议**：挑你手牌里最多的那个属性。因为旗帜只在你投该属性时 +1，而「投什么属性」最终是你自己决定的——但如果你旗帜和擅长属性一致，一轮就能吃到 +2。

### 6.2 一回合 6 步

| 步骤 | 做什么 |
| :--- | :--- |
| **① 换岗** | 起始玩家的棋子交给左手玩家 |
| **② 翻牌** | 翻草原牌堆；遇到意外卡先结算再翻，直到出现奇波卡 |
| **③ 暗投** | 全员同时扣 1 张饵料（星辉轮扣 2 张），可附带 1 张道具 |
| **④ 揭示** | 倒数三声，同时翻开 |
| **⑤ 结算** | 算亲密度 → 比门槛 → 捕获 / 撞车 / 逃逸 |
| **⑥ 收尾** | 补手牌至 5 张；捕获者可沿相生环移动营地旗 1 格（可不移动） |

### 6.3 亲密度公式

```
亲密度 = 3（基础）
       + 饵料修正（对口 +3 / 相生 +1 / 相克 作废）
       + 带料加成（手里还剩同属性，每张 +1，最多 +2）
       + 营地旗（旗帜在该属性 +1）
       + 角色擅长（+1）
       − 扎堆惩罚（同属性 N 张，每张 −(N−1)，最多 −2）
       + 道具修正（星屑网 +2 / 蜜露瓶视为对口）
```

**计算顺序**（重要）：

1. 先各自算「饵料修正」——相克的人在这里就出局（亲密度记为 0，不参与比较）
2. 再统计全场同属性张数，算扎堆惩罚
3. 最后加旗帜、角色、道具

> **相克作废**意味着：你出相克牌 = 主动弃权。除非手牌真的全废，否则不要打相克牌。

### 6.4 门槛

| 奇波 | 门槛 | 典型打法 |
| :--- | :--- | :--- |
| ★ | **5** | 对口 6（单人必过）/ 相生 + 带料 5 |
| ★★ | **6** | 对口 6 / 对口 + 带料 7 / 相生 + 旗帜 6 |
| ★★★ | **7** | 必须投 2 张：对口 + 对口 = 9 |

> **门槛的意义**：它决定「扎堆到什么程度会全场白忙」。★★ 门槛 6 时，三个人抢对口 → 6−2 = 4，谁都过不了。

### 6.5 判决顺序

| 情况 | 结果 |
| :--- | :--- |
| 最高分 ≥ 门槛，且唯一 | **捕获** |
| 最高分 ≥ 门槛，且并列 | **撞车**：从本轮起始玩家开始按顺时针数，先轮到的抱走 |
| 最高分 < 门槛 | **逃逸**：奇波卡进访客槽，最高者翻 1 张宝箱卡 |
| 本轮未捕获者中亲密度最高 | 得 **1 星屑**（近失补偿） |

**撞车规则怎么执行**：所有并列者把手按在桌上，从起始玩家开始顺时针报数「1、2、3……」——报到的人抱走奇波。**提前知道自己排第几，是这个游戏的一半技巧。**

### 6.6 捕获之后：图鉴 or 家园

抓到奇波后，你**二选一**：

| 选择 | 收益 | 代价 |
| :--- | :--- | :--- |
| **编入图鉴** | 得 ★ 枚星屑（1/2/3） | 无（但星屑少 1） |
| **派驻家园** | 得 ★+1 枚星屑（2/3/4） | 占 1 个家园格（上限 3），且**不计入套装** |

**选择逻辑**：

- 想凑套装 → 放图鉴
- 家园还空着 + 这只是 ★★ 以上 → 放家园（多赚 1 分，套装本来也凑不齐）
- 家园满了 → 只能放图鉴

### 6.7 访客与收走

逃逸的奇波卡**留在该属性的访客槽**，代表它还在这片草原来回晃。

- 该属性再翻出奇波时，**门槛 +1**（每有 1 张访客）
- 抓到新奇波的人**一并收走访客卡**，每张 +1 星屑

所以逃逸不是「浪费」——它在给你攒一个「一石二鸟」的机会，只是被别人抓走时你会很心痛。

### 6.8 终局与计分

打完 **人数 × 3** 轮后进入结算：

1. **套装加成**：图鉴中同属性张数

| 同属性张数 | 2 张 | 3 张 | 4 张 | 5 张及以上 |
| :--- | :--- | :--- | :--- | :--- |
| 加成 | **+2** | **+5** | **+9** | **+14** |

2. 五个属性**各自结算**（可以同时吃到风 3 张和光 2 张的加成）
3. **星屑总数最高者获胜**

**平局判定**：图鉴中奇波总数多者胜；仍平 → 家园派驻数少者胜（更纯粹的图鉴流）。

## 七、完整游戏流程示例

### 7.1 四人局开局

| 玩家 | 角色 | 擅长 | 营地旗 | 起手手牌（属性） |
| :--- | :--- | :--- | :--- | :--- |
| 阿岚（先手） | 风语者·铃兰 | 风 | 风之丘 | 风 ×3、光 ×1、水 ×1 |

每人另有 2 张道具（本示例先不用，方便看清算法）。

### 7.2 第 1 轮：绵毛奇波（🐑 风属性 ★，门槛 5）

**② 翻牌**：翻出「绵毛奇波」，风属性，★，门槛 5。放到风之丘圆心。

**③ 暗投**：四个人各扣 1 张牌。

| 玩家 | 出牌 | 想法 |
| :--- | :--- | :--- |
| 阿岚 | 轻风果（风） | 我有 3 张风，「对口 + 满带料 + 旗帜 + 角色」，稳 |
| 小启 | 轻风果（风） | 我也只有这 1 张风，试试运气 |
| 石臼 | 轻风果（风） | 我的岩全是相克，只能跟着打对口 |
| 影拾 | 夜莓（暗） | 你们都要抢风——我走相生，还带旗帜和角色 |

**④ 揭示**：三张 🍃、一张 🌑。

**⑤ 结算**：

| 玩家 | 饵料 | 基础 | 修正 | 带料 | 旗帜 | 角色 | 小计 | 扎堆 | 亲密度 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 阿岚 | 风 | 3 | +3 对口 | +2（剩 2 张风） | +1 | +1 | 10 | −2 | **8** |

最高分 8（阿岚）≥ 门槛 5，唯一 → **阿岚捕获**。

**⑥ 收尾**：

- 阿岚选「编入图鉴」→ 得 **1 星屑**（★1），风属性图鉴 1/5
- 阿岚可以选择把营地旗沿相生环移动到【光之庭】或【暗之林】——但他选择**不动**（风的手牌还多，主场别丢）
- **近失补偿**：未捕获者中影拾亲密度最高（7）→ 得 **1 星屑**
- 四人各补 1 张饵料回到 5 张，起始棋子交给左手玩家（小启）

### 7.3 第 2 轮：篝火熄 → 汐跃豚（🐬 水属性 ★★，门槛 6+1=7）

> 水属性的关系：**对口**是水；**相生**是光、岩（环上相邻）；**相克**是风、暗。

**③ 暗投**（补牌后手牌）：

| 玩家 | 手牌 | 出牌 | 理由 |
| :--- | :--- | :--- | :--- |
| 阿岚 | 光×2、水×2、风×1 | 泡沫糕（水） | 我有 2 张水，出 1 剩 1 → 带料 +1 |
| 小启 | 光×3、水×1、岩×1 | 光尘糖（光） | 光 3 张！相生 + 满带料 + 旗帜 + 角色 |
| 石臼 | 岩×3、风×1、暗×1 | 矿盐饵（岩） | 岩 3 张，相生 + 带料 + 旗帜 |
| 影拾 | 暗×2、水×1、光×1 | 泡沫糕（水） | 想偷个对口，稳一点 |

**⑤ 结算**：

| 玩家 | 饵料 | 基础 | 修正 | 带料 | 旗帜 | 角色 | 小计 | 扎堆 | 亲密度 | 过门槛 7？ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 阿岚 | 水 | 3 | +3 对口 | +1 | 0（旗在风） | 0 | 7 | −1 | **6** | ❌ |

**⑥ 收尾**：

- 小启选「编入图鉴」→ 得 **2 星屑**（★★2），光属性图鉴 1/5
- 小启把营地旗留在【光之庭】（主场叠加，光属性以后 +1）
- 近失补偿：未捕获者中阿岚 6 分最高 → **+1 星屑**

## 八、新手策略提示

### 8.1 五条铁律

| # | 铁律 | 为什么 |
| :--- | :--- | :--- |
| 1 | **别在热门属性上扎堆** | 同属性 ≥2 张，每张 −1。6 人局全员打对口 = 谁都不够分 |
| 2 | **先数座位** | 撞车时从起始玩家顺时针定胜负。知道谁在你前面，就知道能不能赌撞车 |
| 3 | **手牌就是弹药** | 手里留 2 张同属性，出 1 张白拿 +2。一口气打光的人后三轮会很虚 |
| 4 | **相生是被低估的选项** | 对口 6 分人人抢；相生 5 分常常只有你一个人要，没人抢就是你的 |
| 5 | **旗帜别乱移** | 移旗是「公开表态」，一动全桌都知道你换主场了 |

### 8.2 什么时候该抢，什么时候该让

| 局面 | 建议 |
| :--- | :--- |
| 你是该属性的角色，还有 2 张同属性 | **抢**：8-10 分，别人追不上 |
| 你只有 1 张对口，别人手牌看不清 | **让**：大概率撞车，你还不如打相生偷分 |
| 门槛是 ★★ 且你只能打到 6 分 | **看情况**：如果你在起始玩家前面，撞车也是你赢 |
| 这只奇波能让你凑套装 | **优先抢**：套装 +5 比单只 +1 值太多 |
| 家园还空着、这不是你要的属性 | **放家园**：多赚 1 分，套装本来也凑不齐 |

### 8.3 带料的艺术

带料加成是唯一「别人看不见」的信息，所以：

- **开局别急着打光某属性**：留 2 张，之后每一轮都能吃到 +2
- **别在同一轮连着出同属性**：出掉后剩 1 张，加成从 +2 掉到 +1
- **观察对手的节奏**：某人连续两轮打风，说明他风牌多——下一轮风属性的奇波他会更强，你要避开

### 8.4 道具什么时候用

- **望远镜**：只在你「打算赌冷门」时用。确认对手都在抢热门，你就敢打冷门
- **星屑网（+2）**：比你想的更值钱——很多轮「差 1 分没抓到」就是白扔一轮
- **号角**：留到最后 1/3 局，用来打掉追分最凶的那个人
- **蜜露瓶**：手牌全废时的救命稻草，也能骗人（你以为我没对口？）

### 8.5 终局前 3 轮要做什么

1. **算套装**：你现在图鉴里哪个属性最接近 3 张？只抢那个
2. **算门槛**：追分的人一定会去抢高分奇波，你可以故意撞车让他也拿不到
3. **看星屑差**：落后 5 分以上就别想着稳，去抢 ★★★ 星辉奇波（一只 3 分 + 双饵高分）

## 九、变体规则

### 9.1 硬核模式：扎堆更痛

把「扎堆惩罚上限 −2」改为 **−3**。

- 4 人以上时，三个人抢对口就全部掉到门槛以下
- 实测 6 人局逃逸率从 13% 升到 22%，逼着所有人认真算人头
- 适合已经玩过 2-3 局、嫌不够刺激的桌

### 9.2 新手模式：门槛下调

门槛改为 **★4 / ★★5 / ★★★6**。

- 捕获率从 89% 升到 99%，几乎每轮都有人得分
- 适合带小孩、或者第一次接触桌游的朋友

### 9.3 双人模式：暗牌对冲

2 人局时：

- 每人手牌 7 张（不是 5 张），轮数 8 轮
- 每轮**双方各出 2 张饵料**（像星辉轮一样）
- 撞车时**不算优先权**，改为双方各得 1 星屑并让奇波逃逸（双人对撞太频繁，需要缓冲）

### 9.4 大乱斗（7-8 人）

- 需要两副卡（奇波 96 张、饵料 80 张）
- 每人手牌 4 张（不是 5 张），轮数 8 轮
- 扎堆惩罚上限改为 **−3**（人数多，必须加重惩罚）
- 这个模式会非常吵，适合团建

### 9.5 无道具速玩（15 分钟）

- 拿掉全部 12 张道具卡和 12 张意外卡
- 只留奇波 + 饵料 + 角色
- 一局能压到 12-15 分钟，适合「等人到齐」的碎片时间

### 9.6 星辉狂欢

- 把 8 张星辉奇波**单独洗成一副**，每 4 轮强制插入 1 张
- 保证每局至少出现 2 只 ★★★，节奏更刺激
- 适合喜欢「大场面」的桌

## 十、常见问题

**Q1：我出的饵料是相克属性，亲密度算 0 还是负分？**

算 **0**，这张牌作废，不参与比较。所以相克 = 主动弃权，除非手牌真的全废，否则不要打。

**Q2：撞车（并列）时怎么快速判定？**

从**本轮起始玩家**开始，顺时针数，先轮到的抱走。起始玩家的棋子每轮传给左手玩家，所以优先权是轮转的。

> 例：起始玩家是小启，并列的是阿岚、小启、石臼。顺时针顺序是「小启 → 石臼 → 阿岚 → 影拾」，所以小启赢。

**Q3：如果最高分的人也没到门槛，谁翻宝箱？**

**亲密度最高者**（并列则并列者各 1 张）。注意：此时「近失补偿」就不再重复发放了。

**Q4：「带料加成」怎么算，我出 2 张（星辉轮）时算几次？**

只算**一次**。取你出牌后剩下最多的那个同属性张数，最多 +2。

> 例：星辉轮你出「水 + 水」，手里还剩 1 张水 → +1。

**Q5：营地旗什么时候能移动？**

只有**捕获奇波之后**，沿相生环移动 1 格（可以不动）。移动是公开的，全桌都会看到你换了主场。

**Q6：家园的 3 格满了以后，还能派驻吗？**

不能。家园满了只能编入图鉴。所以「要不要派驻」是有时限的决定。

**Q7：套装怎么算？星辉奇波算吗？**

算。星辉奇波也有属性（例如「星辉·潮鲸」是水属性），编入图鉴后计入水属性套装。

**Q8：意外卡翻出来要不要立刻处理，还是等这轮结束？**

立刻处理，结算完弃掉，然后**继续翻牌**，直到翻出奇波卡。意外只影响当前这一轮。

**Q9：手牌用完（打光了）怎么办？**

不会打光——每轮结束都补到 5 张。抽牌堆空了就把弃牌堆洗回。

**Q10：3 人局会不会太空？**

不会，但手感不同：3 人局扎堆率低，捕获率高达 90%，基本每轮都有人得分，节奏更快、更宽松。如果你想更「刀」，3 人局可以用硬核模式（扎堆上限 −3）。

**Q11：能不能不带角色卡玩？**

可以。所有人没有属性加成，游戏更纯粹但也更「平」。我们建议第一局就带上——角色让每个人的「主场」不同，撞车率会明显下降。

**Q12：为什么我有 3 张同属性，出 1 张只加 2 分不是 3 分？**

带料加成上限就是 +2。这是刻意设计的：如果不设上限，手牌厚的人会滚雪球，越攒越强。

- **零分率接近 0**：靠「近失补偿」兜底，不会出现「一局什么都没干成」的人

### A.3 各子系统的使用频率

| 指标 | 3 人 | 4 人 | 5 人 | 6 人 |
| :--- | :--- | :--- | :--- | :--- |

| 每人平均凑成的套装数 | 0.44 | 0.47 | 0.48 | 0.49 |
| 访客收走（每局） | 0.02 | 0.02 | 0.02 | 0.03 |

**结论**：

- 星辉奇波虽然门槛 7 + 双饵，但捕获率仍有 9 成——因为双饵让分数天花板抬到 9，门槛并没有真的变难，**它的成本是「消耗两张手牌」而不是「抓不到」**，这个设计是成功的
- 家园使用率随人数下降（0.39 → 0.31）：人越多，套装越难凑，于是更多人选择「稳拿 +1」
- 访客机制触发频率很低（每局约 0.02 次）——它是**彩蛋而非机制**，别指望它改变策略

- **扎堆上限**控制「扎堆多痛」，动一格只影响 5-6 人局（6 人逃逸率 13% → 22%），适合微调手感

## 附录 B：四条设计取舍

### B.1 为什么「对口必须是单人必过」

最初我们把 ★ 的门槛设成 6，而对口只有 3+3 = 6 —— 刚好卡在线上。结果整个游戏变成「谁先把带料打光谁就废」，因为一旦有第二个人对口，两人都掉到 5 分，连 ★ 都抓不到。

**结论**：门槛必须让「单人打对口」稳定通过（6 > 5）。这样扎堆才成为一种「自找的惩罚」，而不是「连规则都在跟你作对」。

### B.2 为什么必须有「带料加成」

第一版没有带料加成，结果是：**所有人打对口都是精确的 6 分，永远并列**。实测撞车率 44-53%，也就是说一半的回合靠「顺时针谁先」来决定，游戏变成了座位游戏。

加了带料（手里剩几张同属性就 +几，上限 +2）之后：

- 撞车率从 44-53% 降到 27-37%
- 手牌第一次有了「厚度」的意义，而不只是选项池
- 出现了唯一的隐藏信息（别人不知道你剩几张），「读心」才真正成立

**这是全作最关键的一次改动。**

### B.3 为什么加「近失补偿」

没有补偿时，实测 6 人局有 **19% 的玩家一分未得**——一局 35 分钟，什么都拿不到，这在派对上是要出事的。

加了「未捕获者中亲密度最高者 +1 星屑」后，零分率降到 **0.5% 以下**。代价是总分略微膨胀（约 +2），但换来的是「每一轮都有人有收获」。

### B.4 为什么星辉奇波要「投 2 张」

如果只投 1 张，星辉门槛 7 只要「对口 + 满带料 2 = 8」就能过，跟 ★★ 没区别，★★★ 就失去了存在感。

改成「必须投 2 张」后：

- 分数天花板抬到 9-12，门槛 7 反而容易达成
- 但你要**一次交出两张手牌**，之后两三轮的带料加成都变弱
- 于是 ★★★ 变成了一次「资源承诺」——不是抓不到，是「抓了要付利息」
