# 龙珠集结：神龙召唤 (Dragon Ball: Shenron Summon)

## 🎮 游戏概述

《龙珠集结：神龙召唤》是一款以经典热血动漫《龙珠》（Dragon Ball · 那美克星篇内核，结合 2024-2025 热播动画《龙珠 Daima》与 2026 剧场版持续话题度）为背景的**纯合作桌游**。玩家扮演孙悟空、贝吉塔、短笛、小林等 Z 战士，在「那美克星」7×7 蛇形通路（共 49 格）上合作冒险：收集三种资源——**气 🟢**、**战士之魂 🔴**、**龙珠碎片 🟡**，用界王拳等绝招卡劈开弗利萨军陷阱，集齐七颗龙珠碎片后召唤**神龙 🐉** 将伙伴从危急中救回，共同赢得胜利！

游戏机制还原龙珠核心设定：用「气」驱动龟派气功、用「战士之魂」爆发界王拳、集齐龙珠召唤神龙逆转战局。陷阱卡（弗利萨军袭击）由「危机骰子」在任意时机触发，制造张弛有度的合作压力。

**适合人群**：龙珠粉丝、家庭聚会、朋友合作闯关；2-5 人，规则清晰、新手一看就懂。强调沟通与分工，而非互坑。

## 🎲 游戏规则

### 准备阶段

1. **布置地图**：将 7×7 棋盘放桌面中央，棋子放起点 🐉（格 00）。
2. **抽选角色**：每位战士抽 1 张 Z 战士角色卡，亮出并记牢技能/缺点。
3. **洗牌分堆**：资源卡（🟢🔴🟡 各 15）洗混放中央；绝招卡、弗利萨军袭击卡、龙珠宝藏卡分别洗成牌堆。
4. **发放起始资源**：每人得 **气×2、战士之魂×2、龙珠碎片×1**（悟空因缺点弃 1 张手牌；短笛因缺点各 -1）。团队生命值初始为 10。龙珠进度初始 0/7。
5. **放置危机骰**：危机骰放通路旁，用于触发弗利萨军袭击。

### 游戏流程（每个回合）

玩家轮流行动，每回合含以下步骤：

#### 1. 掷骰前进
- 掷 2 颗骰子，点数和 = 前进格数，沿蛇形通路移动棋子。

#### 2. 触发停留格效果
| 停留格 | 图示 | 操作 |
| :--- | :--- | :--- |
| 那美克村落 | 👤 | 无效果，可在此修练/出牌 |
| 资源泉 | 🟢🔴🟡 | 获得对应资源卡 1 张（贝吉塔得 2 战士之魂 / 小林得 2 龙珠碎片） |
| 界王神殿 | ⚡ | 抽 1 张绝招卡 |
| 补给站 | 🌿 | 抽 1 张龙珠宝藏卡 |
| 弗利萨基地 | 🚩 | 掷危机骰；若「危机」则抽 1 张袭击卡立即生效 |
| 终点 | 🚀 | 若龙珠进度 = 7 → 召唤神龙获胜；否则停留，下回合继续 |

#### 3. 修练绝招（可选）
用资源卡在手中「修练」绝招卡（见道具详解资源表），放入手牌备用。

#### 4. 出牌行动（可选，任意时机）
- 打出绝招卡，按效果造成攻击或支援（攻击通常用战士之魂 🔴 结算）。
- 使用龙珠宝藏卡的即时效果。
- **危机应对**：任意时机掷危机骰触发袭击时，可立即打出绝招卡防御（如仙豆回血、舞空术抵消后退）。

#### 5. 累积龙珠进度
- 每获得 1 张龙珠碎片卡 🟡，龙珠进度 +1（上限 7）。
- 到达终点时检查龙珠进度。

### 胜利条件（共同胜利）

- **集齐 7 张龙珠碎片 🟡 且任意 1 名战士抵达 🚀 神龙祭坛** → 全员共同召唤神龙，**合作胜利**！
- 若团队生命值降至 0 → 全体失败。
- 若 14 回合内未达成 → 按剩余生命值判定：生命值 > 0 则惨胜（龙珠仅集齐部分，神龙未至但击退弗利萨），否则失败。

## 📖 完整游戏流程示例

**示例 1：悟空的进攻回合**
1. 悟空（气卡效果+1）掷骰得 5，从格 00 前进到格 05（补给站 🌿）。
2. 在格 05 抽龙珠宝藏卡 → 抽到「筋斗云 ☁️」，立即前进 5 格到格 10（龙珠遗迹 🟡）。
3. 在格 10 得 1 张龙珠碎片卡（小林翻倍技能不适用），龙珠进度 1/7。
4. 用「气×2」修练龟派气功 💥（攻击 2，悟空加成后 3）。
5. 前方格 18 是弗利萨基地 🚩，掷危机骰出「安全」，安全通过。回合结束，轮到贝吉塔。

**示例 2：危机触发与合体翻盘**
1. 贝吉塔（战士之魂翻倍）在格 17（界王神殿 ⚡）抽绝招卡，修练界王拳 🔥。
2. 小林在格 18（弗利萨基地 🚩）掷危机骰出「危机」，抽「能量炮 💣」失去 1 资源卡。
3. 短笛立即打出「仙豆 🫘」回复团队生命 +2，稳住血线。
4. 贝吉塔打出「合体 🌀」与悟空联动，本回合共同攻击 +3，击破前方弗利萨本体 👑（生命 -3 被硬抗）。
5. 团队龙珠进度来到 5/7，距离胜利仅一步之遥，全员振奋！

## 💡 新手策略提示

1. **龙珠优先**：胜利硬门槛是集齐 7 龙珠碎片，小林翻倍技能务必派去龙珠遗迹抢碎片。
2. **气是核心**：龟派气功（气×2）稳定 2 攻击，是击破弗利萨军主力，优先修练。
3. **生命值管理**：团队生命只有 10，弗利萨本体一次 -3，务必留仙豆保命。
4. **危机骰时机**：弗利萨基地格提前用舞空术/合体规避，别硬闯。
5. **角色配合**：贝吉塔堆战士之魂、小林堆龙珠、悟空堆气，分工明确效率最高。
6. **补给站必抢**：7 个补给站的宝藏常是翻盘关键（如筋斗云前进 5、老界王神免袭）。

## 🔄 变体规则

### 双人死斗（合作精简）
- 仅 2 人，移除 3 张龙珠宝藏卡，加快节奏。
- 龙珠门槛降为 6 张，生命值 8。

### 团队对抗（2v2 / 2v3）
- 分队各自集龙珠，先召唤神龙队胜；袭击卡可跨队触发，增加火药味。

### 弗利萨狂潮（困难）
- 弗利萨基地格每次停留掷 **2 次**危机骰。
- 起始资源减半（各 1 张），生命值 7。
- 新增袭击：「金属弗利萨 🤖」—— 生命 -4 且失去 2 绝招卡。

### 无骰子模式
- 无骰子时，每回合固定前进 3 格（可用 APP 随机或翻 1-6 数字卡替代）。

## ❓ 常见问题

**Q：没有骰子怎么办？**
A：用手机骰子 APP，或写 1-6 数字卡翻抽代替。

**Q：资源卡用完了怎么办？**
A：中央资源堆耗尽时，把弃牌堆洗混 reuse。

**Q：危机骰什么时候掷？**
A：仅在停留弗利萨基地 🚩 格时掷；出「危机」才抽袭击卡，这是合作压力来源。

**Q：龙珠进度怎么涨？**
A：每得 1 张龙珠碎片卡 🟡 进度 +1；到终点时检查是否 = 7。

**Q：多人同时到终点怎么办？**
A：合作游戏无竞争，任一人到终点且龙珠满 7 即全员胜。

**Q：角色缺点太亏？**
A：缺点是平衡设计，技能普遍更强（如贝吉塔战士之魂翻倍远超 -1 抽），熟练后反是优势。

**Q：宝藏卡抽完不补，后期没增益？**
A：是的，所以 7 个补给站要规划抢，后期靠绝招卡和龙珠进度决胜。
