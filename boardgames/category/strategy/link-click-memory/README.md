# 时光代理人：记忆照片 (Link Click: Memory Photo)

## 🎮 游戏概述

《时光代理人：记忆照片》是一款**策略类**桌游，改编自2026年暑期档现象级国创时间穿越动画《时光代理人》(Link Click) 第三季（B站8月14日开播，全网热搜）。

玩家扮演**时光照相馆**的摄影师，承接委托人的委托，借助一张张**时光照片**潜入过去。你需要收集**记忆碎片🟣 / 时间能量🟠 / 情感共鸣🔵** 三种资源，冲洗出 **宝丽来线索📷**，在穿越途中躲避**意外反噬⚡**（蝴蝶效应），最终集齐 **记忆拼图** 并抵达 **真相终点🕰️** 的人获胜！

- **适合人群**：2–4人，朋友聚会、家庭娱乐、动漫粉丝；规则清晰、一看就懂。
- **核心乐趣**：路线规划 + 资源运营 + 互坑反噬，既有策略深度也有"改变过去"的爽感。

## 🃏 道具详解

### 资源卡（基础材料）

资源卡是运营的核心，三种资源共同驱动"冲洗照片""升级相机""化解反噬"。

| 资源 | 图示 | 获得方式 | 用途 |

| **时间能量** | 🟠 | 停在 🟠 格 | 穿越移动、触发相机绝招 |
| **情感共鸣** | 🔵 | 停在 🔵 格 | 化解意外反噬、解锁角色被动 |

### 工具卡（相机装备）

相机工具卡对应《时光代理人》中"潜入照片"的能力，提供特殊移动或增益。每张为**唯一**卡（共8种）。

| 工具 | 图示 | 使用所需 | 效果 |
| :--- | :--- | :--- | :--- |
| **潜入照片** | 📸 | 时间能量×1 | 本回合移动后可再额外移动2格 |
| **定格瞬间** | ⏸️ | 时间能量×2 | 跳过下1个意外格不结算 |
| **双重曝光** | 🎞️ | 记忆碎片×2 | 立即冲洗1张宝丽来（无视所在格） |

| **委托契约** | 📜 | 记忆碎片×1 | 偷看任意一名对手的手牌1张 |
| **时光跳跃** | 🌀 | 时间能量×3 | 直接移动到地图上任意一格（不结算途经） |

| :--- | :--- | :--- | :--- |

| **时间悖论** | ⏳ | 后退3格（不结算途经终停格） | 用"时光跳跃"脱离 |
| **情感反噬** | 💔 | 失去1张情感共鸣卡 | 用"心灵之眼"预判规避 |
| **委托失败** | ❌ | 本回合无法冲洗宝丽来 | 用"双重曝光"提前冲洗 |
| **旁观者察觉** | 👁️ | 公开你所有手牌给众人看1回合 | 用"委托契约"反查对手 |
| **照片燃毁** | 🔥 | 随机弃掉1张宝丽来宝藏卡 | 用"显影液"保护 |
| **循环困局** | 🔁 | 原地停留1回合（下回合才能动） | 用"回溯"重掷避免踏入 |

## 🎲 游戏规则

### 准备阶段

1. **布置地图**：将7×7地图置于桌面中央。
2. **选角色与棋子**：每人选1张角色卡与1枚彩色棋子，全部置于格00 📸。
3. **洗牌**：分别洗混资源堆、相机工具堆、意外堆、宝丽来堆。
4. **分发初始资源**：每人获得 **记忆碎片×2 / 时间能量×2 / 情感共鸣×1**，并抽 **2张相机工具卡**。
5. **抽宝丽来**：每位玩家从宝藏堆各预先抽 **1张宝丽来**（若有"合影拼图"立即计入拼图数）。

### 游戏流程（每个回合）

玩家轮流行动，每回合：

#### 1. 掷骰移动
- 掷1颗D6，按点数沿道路上下左右移动（不可斜走，不可穿越非道路障碍）。
- 中途经过的特殊格**不结算**，仅**最终停留格**结算。

#### 2. 结算停留格

| 停留格 | 图示 | 操作 |
| :--- | :--- | :--- |
| 照相馆/道路 | 📸/⬛ | 无效果 |
| 记忆碎片 | 🟣 | 获得1张记忆碎片卡（程小时+1） |
| 时间能量 | 🟠 | 获得1张时间能量卡 |
| 情感共鸣 | 🔵 | 获得1张情感共鸣卡 |
| 意外 | ⚡ | 抽1张意外卡并执行（可用情感/相机化解） |
| 宝丽来 | 📷 | 冲洗1张宝丽来宝藏卡（抽完不补） |
| 真相终点 | 🕰️ | 若已集齐5块记忆拼图→**你获胜**；否则停留待下回合 |

#### 3. 行动阶段（任意顺序，可选）
- **冲洗宝丽来**：若在 📷 格或持"双重曝光"。
- **使用相机工具卡**：消耗资源触发效果。
- **升级/交易**：可与对手用资源卡1:1交换（须公开）。

#### 4. 回合结束
将回合交给下一位玩家。当有人集齐拼图并抵达终点，游戏立即结束。

### 胜利条件
**首位**集齐 **5块记忆拼图** 且 **抵达格48 🕰️ 真相终点** 的玩家获胜。若牌堆宝丽来抽完仍无人集齐，则**拼图最多者**获胜；平局则**最接近终点者**胜。

## 📖 完整游戏流程示例

**第1回合 · 玩家A（程小时）：**
1. 掷骰得 **4**，从格00沿道路移动：01(🟣)→02→03(🟠)→04，停格04（道路）。
2. 中途经过01、03不结算，仅停留格04结算 → 无效果。
3. 行动阶段：用初始时间能量×1打出"潜入照片"，额外移动2格 → 06(📷)。
4. 停留格06为宝丽来点 → 冲洗1张宝丽来，抽到"合影拼图A" → **记忆拼图=1块**。
5. 回合结束。

**第2回合 · 玩家B（陆光）：**
1. 掷骰得 **5**，从格00移动：01→02→03→04→05(🔵)→06(📷)，停格06。
2. 结算格06宝丽来 → 抽到"旧日街角"（下次移动+2）。
3. 行动阶段：打出"时光跳跃"(时间能量×2) 直接移动到格14(📷)，冲洗"合影拼图B" → **拼图=1块**。
4. 回合结束。

> 设计意图：先到终点（格48）并不等于赢——必须沿途冲洗"合影拼图"积累门槛，制造"领先者未必先赢"的终局悬念，鼓励玩家在资源点与宝丽来点之间权衡路线。

## 💡 新手策略提示

1. **路线优先宝丽来点**：5块拼图主要来自"合影拼图"卡，务必规划经过 📷 格的路线。
2. **资源别乱花**：时间能量是移动与绝招的硬通货，前期留2–3张保底。
3. **提前备化解牌**：手中常备"显影液/定格瞬间"，应对 ⚡ 意外反噬。
4. **角色互补组队**：程小时刷记忆、陆光强机动、欣然控信息、刘枭阴人——多人局可分工。
5. **终点前集齐拼图**：别冲太早到格48却拼图不够，被对手反超。

## 🔄 变体规则

### 1. 双人竞速（精简）
- 仅用格00–28区域（上半盘），终点改为格28 📷 作为临时真相；拼图门槛降为3块。

### 2. 合作模式（齐心破案）
- 所有玩家同队，共享资源与拼图进度；共同对抗"意外堆"的集体惩罚（每抽到🦋蝴蝶效应全员退1格），集齐团队10块拼图通关。

### 3. 暗影乱斗（高互坑）
- 允许在对手停留 ⚡ 格时，用"委托契约"偷看并**塞入**1张意外卡到其手牌；刘枭角色强度×2。

### 4. 速通模式（15分钟）
- 初始每人记忆拼图已含2块；宝丽来堆仅留"合影拼图"类；先到终点即胜。

## ❓ 常见问题

**Q：没有骰子怎么办？**
A：用手机骰子App，或写1–6数字卡翻抽代替。

**Q：资源卡用完了？**
A：将弃牌堆洗混后作为新资源堆复用。

**Q：宝丽来抽完了还没集齐拼图？**
A：按胜利条件，拼图最多者获胜；也可用"真相之钥"豁免1块。

**Q：多人同时抵达终点？**
A：先完成"集齐拼图+抵达"宣言者胜；同回合则拼图多者胜。

**Q：可以斜着走吗？**
A：不可以，只能上下左右移动。

**Q：中途经过特殊格结算吗？**
A：不结算，仅最终停留格结算。

**Q：相机工具卡能重复使用吗？**
A：每张唯一，打出后即入弃堆，本局不再获得（除非变体规则补充）。
