# 水浒传：一百零八星宿

> *「大河向东流哇，天上的星星参北斗哇。」*
> **一百零八位星君应劫下凡，星位既定，座次未定。谁能聚齐最耀眼的星宿，谁就是聚义厅的主人。**

---

## 1. 游戏概述

《水浒传：一百零八星宿》是一款 **2–4 人 / 60–90 分钟** 的**策略经营类**桌游。

北宋末年，天罡三十六星、地煞七十二星共计一百零八位星君，因一场劫数散落九州。玩家扮演梁山泊的四路**招贤头领**，各自下山延揽好汉上山聚义。

但你很快会发现两件要命的事：

1. **山寨只有 6 把交椅。** 你一局最多能招 12 位好汉，却只能留住 6 位——**「淘汰谁」不是意外，而是本作每局必然发生 6 次的核心决策。**
2. **好汉的星位是天定的，不能改。** 座次必须严格按星位从小到大排。**想让一个星位更小（更强）的人上山，就得让所有星位比他大的人「往后挪」——而每挪动一位，就要扣掉他 1 点忠心。**

于是本作的核心交易浮出水面：

> **招天罡（终局 ×3 分）不是免费的，它的价格就是忠心。**
> **忠心不是血条，是本作真正的货币；银两只是忠心的兑换券。**

同时，桌中央还有一条**「招安天平」**——它从 6 起步，每回合自动 +1，走到 12 就**立刻结束游戏**。

> **全场谁都不出手的话，游戏只有 6 回合。**
> **想要打满 12 回合，全场必须有人累计「扯反旗」6 次。**

而「扯反旗」要花掉一个宝贵的行动点。**领先者会想尽办法让天平快点触顶，落后者会拼命把它压回去——这就是本作的自动追赶机制，不需要任何额外的平衡规则。**

## 5. 道具详解

### 5.1 好汉卡（资源卡）

好汉卡是本作**唯一的资源**，也是**唯一的计分物**。

**卡面结构：**

```
┌────────────────────────┐
│ 天罡              [14] │   ← 阵营 + 星位（越大越弱）
├────────────────────────┤
│ 天伤星                 │   ← 星宿名
│ 🐯 行者 · 武松          │   ← 类型 + 绰号 + 姓名
│ ❤️❤️            ×3     │   ← 初始忠心 + 终局倍率
│ ──────────────────────│
│ 打虎：终局若寨中忠心   │   ← 技能（忠心 ≥2 时持续生效）
│ 最高，+5 分            │
└────────────────────────┘
```

| 字段 | 说明 |
| :--- | :--- |
| **星位** | 1–107 的数字。**越小越强**（天罡 1–36，地煞 37–107 且全为奇数）。决定座次顺序，也是本作的核心排序键 |
| **阵营** | 天罡（红边）/ 地煞（绿边）。决定终局倍率与遣散义气 |
| **类型** | 🐯🔥⛰️🌪️💰🌊 六种。仅用于「结义」配对 |
| **初始忠心** | 入寨时的忠心值。天罡 1–2（傲），地煞 2–3（韧） |
| **倍率** | 终局阵容分 = 忠心 ×（天罡 3 / 地煞 1） |
| **技能** | 忠心 ≥2 时持续生效。忠心降到 1 时**技能失效**（但人还在） |

**忠心规则（最重要）**

| 事件 | 忠心变化 |
| :--- | :--- |
| 入寨 | 设为卡片初始值 |
| 有新好汉插到他左边（新人星位更小） | **−1** |
| 被「安扰兄弟」行动安抚 | **+1**（花 2 银） |
| 降到 0 | **立即下山**，转为义气（天罡 +2 / 地煞 +1，全额） |

## 6. 游戏规则

### 6.1 准备阶段

1. **布置中央区**：把招安天平板放在桌子正中，把**天平标记放在刻度 6** 上。
2. **洗牌**：把 72 张好汉卡洗匀，背面朝上放成**好汉牌堆**；12 张朝廷诏令卡洗匀，背面朝上放成**诏令堆**。
3. **开招贤榜**：从好汉牌堆顶翻 **4 张**到「招贤榜 壹/贰/叁/肆」，正面朝上。
4. **发山寨板**：每位玩家拿 1 块山寨板、1 枚棋子，取 **5 银**作为启动资金。
5. **决定首回顺位**：任意方式（最像宋江的人先动）。
6. **发速查卡**：每人 1 张。

### 6.2 一个回合（「回」）的流程

每回合按以下 5 步进行：

```
① 翻诏令  →  ② 定顺位  →  ③ 依次行动  →  ④ 结算离寨  →  ⑤ 天平推进
```

**① 翻诏令**：翻开诏令堆顶 1 张，全场共享本回合效果（详见 5.2）。

**② 定顺位**：按以下优先级排序，**人少分低者先动**：

1. 寨中好汉**人数少**的在前
2. 人数相同 → **义气分低**的在前
3. 仍相同 → 沿用上回合顺位

> **这就是本作的自动追赶机制之一**：你寨子越空，越早挑人。

**③ 依次行动**：每位玩家有 **2 点行动力（AP）**，可自由分配：

| 行动 | AP | 效果 |
| :--- | :--- | :--- |
| ⚔️ **下山招贤** | 1 | 从招贤榜选 1 位好汉入寨（**每回合限 1 次**）。招走后立即从牌堆补 1 张到该格 |
| 💰 **劫富济贫** | 1 | **+3 银两** |
| 🤝 **安抚兄弟** | 1 | 花 **2 银**，指定 1 位寨中好汉 **忠心 +1** |
| 🔥 **扯反旗** | 1 | 招安天平 **−1**，自己 **+1 义气** |
| 📜 **受招安** | 1 | 招安天平 **+1**，立刻 **+8 银**；**此后本局不能再招贤**，改为**每回合末 +3 分**。**每局限 1 次，不可逆** |
| 🚪 **遣散** | **0** | 随时可执行。遣散寨中任意 1 位好汉：天罡 **+2 义气** / 地煞 **+1 义气** |

**④ 结算离寨**：处理所有忠心归 0 的好汉（下山，全额义气）与超载被挤走的好汉（半款义气）。

**⑤ 天平推进**：招安天平 **+1**。若天平达到 **12**，**游戏立即结束**，跳到计分。

### 6.3 ★ 座次铁律（本作最重要的规则）

> **山寨里的好汉必须按「星位从小到大 · 从左到右」排列。**

招入一位星位为 `x` 的好汉时，按以下顺序结算：

```
1️⃣ 找出寨中所有【星位 > x】的好汉，每人 忠心 −1
2️⃣ 把新人插入他们左边（即新人排在最后一个比他小的好汉之后）
3️⃣ 忠心降到 0 的好汉 → 立即下山（全额义气：天罡 +2 / 地煞 +1）
4️⃣ 若此时寨中超过 6 人 → 最右（星位最大）那位被挤下山
                          （半款义气：天罡 +1 / 地煞 +0）
```

**举例**：寨中为 `[10天, 30天, 50地, 70地]`，现在招入星位 **25** 的天罡：

| 步骤 | 结果 |
| :--- | :--- |
| 找出星位 > 25 的 | 30、50、70 共 **3 人** |
| 三人忠心各 −1 | 30 从 ❤2 → ❤1；50 从 ❤3 → ❤2；70 从 ❤2 → ❤1 |
| 插入座次 | `[10天, 25天, 30天, 50地, 70地]` |
| 若有人忠心归 0 | 立即下山 |
| 检查超载 | 5 人 ≤ 6，安全 |

### 6.4 ★ 恒等式：本作的三条数学骨架

| 编号 | 恒等式 | 含义 |
| :--- | :--- | :--- |
| **A** | 一局最多经手 **12** 人，最多留住 **6** 人 ⇒ **至少 6 人必须离寨** | 「淘汰谁」每局必然发生 6 次 |
| **B** | 天平起始 6，每回 +1，触顶 12 ⇒ **默认游戏只有 6 回**；打满 12 回需**全场净扯旗 6 次** | 游戏长度是玩家自己决定的 |
| **C** | 24 AP = **12（招满）+ 6÷P（扯旗分摊）+ 10.5（自由，4 人局）** | 自由 AP 全劫富 = 31.5 银；全安抚 = 10.5 忠心（需 21 银） |

### 6.5 ★★ 恒等式 F：本作最反直觉的一条

> **「零插队」与「高阵容分」在数学上互斥。**

推理：

1. 零插队 ⇒ 每次招的人星位必须 **大于** 寨中所有现有好汉。
2. 但超载时被挤走的，是**星位最大的那位**。
3. 于是你寨里留下来的，永远是**你招过的人里星位最大的 6 个**。
4. 而星位大 = 地煞 = **终局 ×1**。

| 路线 | 终局阵容 | 阵容分上限 |
| :--- | :--- | :--- |
| **零插队流** | 6 个地煞（星位最大的 6 个） | 6 × 3 × 1 = **18 分** |
| **天罡流** | 6 个天罡（每招一个都要插队） | 6 × 2 × 3 = **36 分** |

> **⇒ 想要天罡的 ×3 倍率，就必须接受插队、必须付忠心、必须用银两安抚。**
> **⇒ 本作真正的货币是「忠心点」，银两只是忠心的兑换券（2 银 = 1 忠心）。**

这条恒等式在第 7 节的连续剧示例里会被**完整演示一次**——「严格升序」的那位玩家最终垫底。

### 6.6 胜利条件

游戏在以下两种情况之一结束时计分：

1. **招安天平达到 12**（立即结束）
2. **第 12 回合结束**（上限）

**终局计分表**

| 项目 | 计分方式 |
| :--- | :--- |
| 🏯 **阵容分** | 寨中每位好汉：当前忠心 ×（天罡 **3** / 地煞 **1**） |
| 🤝 **结义分** | 座次**相邻**且**同类型**的每一对：+3 分 |
| 🔥 **义气分** | 所有离寨好汉：主动遣散 / 气走 天罡 **+2**、地煞 **+1**；**被挤走半款**（天罡 +1、地煞 +0）<br>外加每次「扯反旗」+1 |
| 📜 **招安分** | 受招安后每回合末 +3 |
| 💰 **银两分** | 每 3 两 +1 分（向下取整） |

**平局裁定**（依次比较）：
1. 寨中**天罡数量**多者胜
2. 寨中**星位最小**的那位，星位更小者胜
3. 仍并列 → 并列第一

## 8. 新手策略提示

### 8.1 三条记忆锚（记住这三条就够了）

| # | 记忆锚 | 说明 |
| :--- | :--- | :--- |
| ① | **永远先挑榜上星位最大的那个** | 零插队 = 零代价。**但见 7.7——它不是唯一标准** |
| ② | **自己送走拿全款，被挤走拿半款** | 主动遣散天罡 +2；被挤走只有 +1。**寨子快满时主动遣散** |
| ③ | **寨子满了以后，招「最大的」= 白招** | 他会立刻坐最右然后被挤走，只拿半款 |

### 8.2 开局三件事

1. **第一张牌决定你整局的门槛。** 招到星位 5 的关胜，后面 90% 的牌都能零插队；招到 95 的地煞，你从此只能招 97/99/101/103/105/107——**那是 6 张牌里的 6 张，基本等于自封退路**。
2. **别在第一回抢最强的。** 星位 1–5 的宋江 / 卢俊义 / 吴用 / 公孙胜 / 关胜看似诱人，但**招了他们，之后每一张牌都会插队**。除非你打算全程买单，否则让他们烂在榜上。
3. **前 3 回别忙着扯旗。** 让天平自然涨到 8–9，观察谁在扯；**最后扯旗的人最赚**（他付的成本最少，享受的时间一样）。

### 8.3 银两怎么用最划算

| 用法 | 换算 | 评价 |
| :--- | :--- | :--- |
| 安抚天罡（忠心 1→2） | 2 银 → +3 分 | ✅ **最划算**（1.5 分/银） |
| 安抚地煞（忠心 2→3） | 2 银 → +1 分 | ❌ 最不划算（0.5 分/银） |
| 攒着换终局分 | 3 银 → 1 分 | ⚪ 保底（0.33 分/银） |

> **⇒ 结论：银两只该花在天罡身上。地煞不值得安抚。**

### 8.4 什么时候该主动遣散

| 情形 | 做法 |
| :--- | :--- |
| 寨中 6 人，榜上只有大号 | ✅ 遣散最右那位再招（拿全款 +2/+1） |
| 某位天罡忠心只剩 1 且你没银子安抚 | ✅ 立刻遣散（+2 义气），比等他气走（也是 +2）没亏，但**腾出了交椅** |
| 寨中有人忠心 1 且下一回很可能被插队 | ✅ 提前遣散，别让他白白气走 |
| 寨中不足 6 人 | ❌ 别遣散，先填满 |

### 8.5 天平的政治学

| 你的处境 | 推荐做法 |
| :--- | :--- |
| **明显领先**（阵容分第一） | **受招安** —— 天平 +1，你锁定 +3 分/回，并让游戏提前结束 |
| **明显落后** | **扯反旗** —— 用 1 AP 换全场多一个回合，且自己 +1 义气 |
| **持平** | 什么都别做，让天平自己走。**看谁先沉不住气** |
| **寨子已经满了且很强** | 受招安，越早越好 |
| **寨子空荡荡** | 扯反旗拖时间，同时拼命招人 |

> **★★ 本作的社会困境**：扯反旗对**全场**有利，对**自己**亏（1 AP 只换 1 义气）。
> **所以人人都希望别人去扯旗。若全场都这么想，游戏 6 回就结束了——大家都是输家。**

### 8.6 天罡流的正确姿势

1. **先把寨子填满便宜的**（地煞大号，零插队）。
2. **等到第 6–8 回，寨子成型了，才开始换血**：招天罡，气走地煞，回收义气。
3. **每次换血后立刻安抚留下来的天罡**（2 银 = 3 分，超值）。
4. **别在早期换血**——早期寨子空，气走的人换不回多少义气，纯亏。

### 8.7 三个新手必踩的坑

| 坑 | 症状 | 解法 |
| :--- | :--- | :--- |
| **「挑最大」上瘾** | 12 回下来寨中 0 个天罡，阵容分 11 | 见恒等式 F。第 4–6 回必须主动招 1–2 个天罡换血 |
| **不舍得遣散** | 寨子满了还在招大号，白扔牌 | 见记忆锚 ②③ |
| **抢着扯旗** | 前 3 回就扯 3 次，浪费 3 AP | 让天平先涨到 8 再扯，成本一样、威慑力更大 |

## 9. 变体规则

### 9.1 「快棋」变体（30 分钟）

天平起始改为 **9**（而非 6）。默认游戏只有 3 回；打满 12 回需净扯旗 9 次。
适合时间紧或新手教学局。

### 9.2 「持久战」变体（120 分钟）

天平起始改为 **3**，且**触顶上限提到 14**。默认 11 回；打满 12 回只需净扯旗 1 次。
适合喜欢长线经营的玩家。

### 9.3 ★ 「真·一百零八」变体（硬核）

把地煞补足到真实的 **72 张**（星位 37–108 全部偶奇数补齐），总卡数 **108 张**。
- 招贤榜开 **5 张**
- 山寨容量仍是 6
- 其余规则不变

> **效果**：地煞占比从 50% 升到 66.7%，天罡变得**极其珍贵**，插队代价暴涨。适合玩过 3 局以上的老手。

### 9.4 「招安竞速」变体（半合作）

开局**公开**宣布：若天平在第 N 回（N = 玩家人数 × 2）之前触顶，**全场额外 +5 分**（招安成功，皆大欢喜）；否则所有人 **−3 分**。
⇒ 把「是否扯旗」变成一个真正的团队决策。

### 9.5 2 人局调整（**强烈建议**）

2 人局里「受招安」威力过大（每回 +1 天平，会让游戏在第 3 回就结束）。调整为：

> **受招安**：天平 **+1**，+8 银；**此后不能再招贤**，每回合末 **+3 分**；**且立即遣散寨中星位最大的 1 名好汉**。

这样加速的代价是立刻削弱自己，2 人局即可正常游玩。

### 9.6 「独行」变体（1 人）

1 人也能玩：
- 天平起始 6，每回 +1，**你必须在 12 回内达到目标分**
- 目标分：简单 40 / 中等 55 / 困难 70
- 不设受招安
- 达成即胜

## 10. 常见问题

### 10.1 为什么我招了人，寨子里的人反而少了？

**两种可能**：
1. 有人忠心被扣到 0，**气走**了（全额义气）
2. 寨子超过 6 人，最右那位被**挤走**了（半款义气）

**注意**：寨子满 6 人时招一个「星位最大」的人 ⇒ 他坐最右 ⇒ 立刻被挤走 ⇒ **等于白招**。这是新手最常见的失误（见 7.5 第 11 回阿水）。

### 10.2 星位到底是「大好」还是「小好」？

**星位小 = 强**。星位 1 是天魁星宋江（最强），星位 107 是地妖星杜迁（最弱）。
座次上，**星位最小的坐第 1 把交椅（头领席）**。

### 10.3 招贤榜上没人要的牌会一直挂着吗？

会。**榜上的牌只有被招走才会补充，没有「自动轮换」机制。**
这就是为什么 7.4 节里 `20天🌪️` 这张牌从第 4 回一直挂到第 7 回——**因为它会插队，谁都不想先要它**。
⇒ **看到一张牌挂了很久，就该想想：是不是它其实很值，只是时机不对？**

### 10.4 我可以不招人吗？

可以。**招贤是可选的。** 你有 2 AP，可以全部用来劫富济贫（+6 银）或扯反旗。
这在寨子已满、榜上无好牌时是正确选择。

### 10.5 「安抚兄弟」能给同一个人反复用吗？

可以，只要你有银子。**忠心没有上限**（虽然卡牌初始值最高 3）。

### 10.6 忠心降到 0 一定要下山吗？

是的，**立刻下山，无法挽回**。所以看到忠心 1 的人要尽早处理——安抚或遣散。

### 10.7 技能什么时候失效？

技能在**忠心 ≥2** 时持续生效。忠心降到 1 时人还在、还能计分，但**技能失效**。
⇒ **「把对手的关键好汉插队到忠心 1」是一种软性攻击**（虽然本作没有直接攻击手段）。

### 10.8 受招安之后还能做什么？

受招安后：
- ❌ 不能再招贤（永远）
- ✅ 可以继续劫富济贫（+3 银）
- ✅ 可以继续安抚兄弟（保住现有阵容的分数）
- ✅ 可以继续遣散
- ✅ 可以继续扯反旗（**有趣的反向操作**——你既招安又扯旗）
- ✅ 每回合末 +3 分

### 10.9 为什么「受招安」的分数这么低？

因为它**不是用来得分的，是用来提前结束游戏的**。
真正的用法是：**当你阵容已经很强时，用它锁死比赛，不给对手追赶的时间。**

### 10.10 结义分怎么算？「相邻」是什么意思？

寨中的好汉按星位排成一排。**相邻 = 在座次上紧挨着**（第 1 与第 2 把、第 2 与第 3 把……）。
若这一对**类型相同**（如都是 🌊），就 +3 分。
6 人寨有 5 个相邻位，理论最多 5 对 = 15 分。

### 10.11 结义是不是太难凑了？

**是的，故意的。** 随机 6 人寨出现至少 1 对同源的概率是 57.3%，5 对全同源只有 0.085%。
⇒ **结义是「锦上添花」不是「核心路线」**。7.6 节的老柴拿到 2 对（6 分）已经是很好的成绩。
⇒ 想凑结义，必须**招类型相同且星位连续的好汉**，这需要刻意规划。

### 10.12 银两最后没花完怎么办？

每 3 两 +1 分（向下取整）。**所以银两是保底分，不是废纸。**
但它的效率很低（0.33 分/银），远不如安抚天罡（1.5 分/银）。

### 10.13 天平到 0 以下怎么办？

**天平最低为 0，不会变成负数。**
扯反旗在天平已经是 0 时仍然执行（你仍 +1 义气），只是天平不再下降。

### 10.14 游戏一定要打满 12 回吗？

**不。** 默认（无人扯反旗）游戏只有 **6 回**。
打满 12 回需要全场净扯旗 **6 次**。这是玩家的选择，不是规则强制。

### 10.15 我该在什么时候扯反旗？

**越晚越好。** 扯 1 次的效果（天平 −1）与何时扯无关，但**早扯会让别人有更多时间准备**。
⇒ 最优策略：让天平涨到 10–11，全场恐慌时再扯——**此时你的 1 AP 价值最大，还能向别人索取回报**（"我扯旗，你下回合把那张牌留给我"）。

### 10.16 天罡忠心只有 1–2，是不是太脆了？

**是故意的。** 天罡 ×3 分、平均 5.00 分/人，是地煞（2.53）的两倍。
⇒ **脆就是它的价格。** 不脆的话，天罡流会碾压全场。

### 10.17 山寨板是不是有点多余？我不能把手牌摊开就行吗？

可以，**但强烈建议用板**。板上的 6 个格子让你一眼看出「第几把交椅是谁」，这是本作的物理锚点。
用手牌堆叠时，座次顺序极易搞错，而座次错了整个结算就错了。

### 10.18 我算不清插队会扣多少忠心，怎么办？

**数一下寨中星位比他大的有几个人，就扣几点。**
举例：寨中 `[10, 30, 50]`，招 25 ⇒ 比 25 大的有 30、50 两个 ⇒ **扣 2 点**（这 2 人各 −1）。

### 10.19 一局大概多久？

| 人数 | 首次游玩 | 熟练后 |
| :--- | :--- | :--- |
| 2 人 | 75 分钟 | 45 分钟 |
| 3 人 | 90 分钟 | 55 分钟 |
| 4 人 | 105 分钟 | 70 分钟 |

**若触发提前结束**（天平在第 6–8 回触顶），时间会缩短 30–40%。

### 10.20 卡牌能手绘吗？

完全可以。**只需要 4 个信息**：星位（1–107）、阵营（天罡/地煞）、类型（🐯🔥⛰️🌪️💰🌊）、初始忠心（1–3）。
技能可以省略（不影响平衡，只减少变化）。

### 10.21 为什么游戏叫「一百零八星宿」，却只有 72 张好汉卡？

72 张 = 天罡 36（完整）+ 地煞 36（精选代表）。
真实的地煞是 72 位，本作从中精选 36 位（星位取 37, 39, …, 107 共 36 个奇数），保证数值分布均匀。
**想要完整地煞 72 位，请用变体 9.3「真·一百零八」。**

### 10.22 受招安是「背叛」吗？会不会破坏氛围？

**恰恰相反——它是本作最「水浒」的设计。**
原著的核心矛盾就是「聚义 vs 招安」。当你选择受招安，你就是在重演宋江的选择：**用兄弟的前程，换一个安稳的结局。**
而其他人扯反旗，就是在重演李逵、武松的选择。
⇒ **规则即叙事，这就是本作的野心。**

### 10.23 可以两个人同时受招安吗？

可以。每人每局限 1 次，互不冲突。
但注意：**两个人都受招安 = 天平每回 +3**（自然 +1，两人各 +1）⇒ 游戏 2 回就结束。
⇒ 这通常对**已经很强**的人有利，是合法的但极端的战术。

### 10.24 我想玩得更凶一点，有建议吗？

用变体 **9.3「真·一百零八」** + **9.5「2 人局调整」**。
天罡变得极稀缺，插队代价暴涨，每一张牌都要抢。

### 10.25 4 人局会不会太挤？

4 人局招贤榜只有 4 张，**意味着最后一个行动的人可能没得挑**。
这就是顺位规则存在的意义：**寨中人数少的先动**（自动追赶）。
若你觉得还是太挤，可用变体：**4 人局招贤榜开 6 张**。

### 10.26 新手第一局建议怎么玩？

1. 用 **变体 9.1「快棋」**（天平起始 9），30 分钟打完一局熟悉流程
2. 不看技能（第一次玩忽略技能行）
3. 记住三条记忆锚（见 8.1）
4. 第二局开始正式规则
