# 影之刃：杀气连斩

> *「心脏已被贯穿，你只剩六十六天。」*
> **在影境里，杀气不是血条——它是油门。踩得越深，刀越快；烧干了，就是破煞。**

---

## 1. 游戏概述

《影之刃：杀气连斩》是一款 **2–5 人 / 45–75 分钟** 的**卡牌构筑 + 推挤（push-your-luck）**桌游。

### 背景

影境——一个武侠与蒸汽机械扭曲交织的黑暗世界。朝廷的铁骑踏遍江湖，杀手的刀被齿轮取代，只剩一群被称作「**影**」的流亡刀客还在用血肉之躯对抗机关武傀。

你扮演其中一名影。**你的心脏被一枚机关钉贯穿，只剩 66 天可活。** 唯一的续命之物，是武傀核心里的「杀意结晶」。三尊武傀，九轮夜战，斩得碎就有明天，斩不碎就死在今夜。

### 你要做的唯一一件事

每一轮，你会把招式卡**一张一张横着排在自己面前**，串成一条**连招链**。

> **第 n 段的伤害 = 卡面基础值 + 3×(n−1)**
> **把一张牌接到第 n 段，要付 n 点杀气**

于是这条链有个**物理上的硬上限**：

```
1 + 2 + 3 + 4 = 10 = 杀气上限
⇒ 一条链最多 4 段，而且打满 4 段恰好把满槽杀气烧得一干二净
```

**与人数无关、与流派无关、与运气无关。** 这是本作的第一条铁律。

### 三条刻在骨子里的恒等式

**恒等式 A · 节奏表**（杀气上限 10，每轮末回复 +3）

| 链长 | 杀气消耗 | 每轮净变化 | 定位 |
| :---: | :---: | :---: | :--- |
| 1 段 | 1 | **+2** | 攒气 |
| 2 段 | 3 | **±0** | **呼吸（永续）** |
| 3 段 | 6 | **−3** | 透支 |
| 4 段 | 10 | **−7** | 豪赌 |

> **记住这张表：「1 段攒气 / 2 段呼吸 / 3 段透支 / 4 段豪赌」。**
> 打 2 段链可以永远打下去；打 3 段链每轮净亏 3 点，满槽也只够撑 4 轮；打 4 段链之后杀气归零，**下一轮你手上只有 3 点，只能打 2 段**——爆发之后必然疲软。

**恒等式 B · 效率递增**（招式卡基础值全局均值 1.95）

| 链长 | 总伤害（均值） | 杀气 | 每点杀气的伤害 |
| :---: | :---: | :---: | :---: |
| 1 段 | 1.95 | 1 | 1.950 |
| 2 段 | 6.90 | 3 | 2.300 |
| 3 段 | 14.85 | 6 | 2.475 |
| 4 段 | **25.80** | 10 | **2.580** |

> **链越长，每一点杀气越值钱。** 长链严格优于短链——唯一拦着你的，是杀气总量和**破煞风险**。

**恒等式 C · 爆发周期**

从杀气 5 攒到满槽 10，需要连续 3 轮只打 1 段（5→7→9→10）。加上第 4 轮的满链，**一个完整爆发周期 = 4 轮**。

| 4 轮里…… | 总伤害 | 说明 |
| :--- | :--- | :--- |
| 攒气爆发（3 轮 1 段 + 1 轮 4 段） | 3×1.95 + 25.80 = **31.65** | 外加「见切」+5 分 |
| 永续呼吸（4 轮全打 2 段） | 4×6.90 = **27.60** | 稳定、无风险 |

> **爆发路线伤害高出 15%，再加上见切 +5 分——看起来稳赢。**
> **但攒气的那 3 轮你每轮只有 1.95 伤害，几乎必然丢掉一整尊武傀的名次分（−8 或 −5）。**
> **这就是本作的核心决策：你敢不敢空 3 轮？**

### 第二条铁律：破煞

武傀每轮会翻开一张**招式卡**（9 张全部公开，第 1 轮就能看到第 9 轮），上面写着它这轮**封锁**哪几类招式。

> **你的链里只要出现一张被封锁的招式 ⇒ 破煞：本链伤害归零、残命 −2、立即收招。**

所以「贪第 4 段」永远是在**看得见的风险**下做决定——你知道这轮封什么，你也知道自己手上有什么。

**核心用法：**
1. **高基础值的牌留给后面的段位吗？** 不——因为段位加成是**加法**（+3(n−1)），与基础值无关。**所以基础值高的牌放哪一段都一样。** 真正要考虑的是：
   - 把**机关类**放在不相邻的两段（如 ① 和 ③），吃满 2.75 的高均值；
   - 把**低基础值**的牌用在你反正要打的短链上；
   - 别让高基础值的牌在破煞时一起报销。
2. **「保头不保尾」**——① 段的牌一定用得出去，④ 段的牌有 3 次机会被打断。**资源紧张时优先保证前两段合法。**

### 5.2 秘具卡（工具卡 · 24 张）

秘具**不占段位、不付杀气**，附加在你链上的任意一段。**每条连招链最多使用 1 张。**

| 秘具 | 图标 | 张数 | 效果 | 使用时机建议 |
| :--- | :---: | :---: | :--- | :--- |
| 铁钩 | 🪝 | 3 | 本段伤害 **+2** | 通用；短链时收益占比最高 |
| 爆竹 | 🧨 | 3 | 本段伤害 **+3**，但**下一段 −2** | 放在**最后一段**，纯粹 +3 |
| 血引 | 🩸 | 3 | 立即 **+2 杀气**（本轮上限可至 12） | 差 1–2 点杀气凑满链时救命 |
| 镜面 | 🪞 | 3 | 本段**无视封锁** | 千手轮（封 3 类）价值最高 |
| 锁链 | ⛓️ | 3 | 本段伤害 **×2**，随后**强制收招** | 放在链尾；配合高段位收益爆炸 |
| 药酒 | 🍶 | 3 | 残命 **+3** | 残命 ≤ 4 时优先打出 |
| 副刃 | 🔪 | 3 | 复制**上一段**的伤害（第 1 段不可用） | 放在段位最高的那一段之后 |
| 烛照 | 🕯️ | 3 | 查看牌库顶 3 张并任意排序 | 早期打出，为后续轮次铺路 |

> **爆竹放在最后一段 = 白赚 +3；锁链放在第 4 段 = 该段伤害翻倍。**
> 「秘具放哪一段」是本作最容易被新手忽略、但收益最直观的技巧。

### 5.3 破煞（陷阱）

破煞是**本作唯一的直接惩罚**，两种触发方式：

| 类型 | 触发条件 | 后果 | 应对方法 |
| :--- | :--- | :--- | :--- |
| **封锁破煞** | 你的链里出现**本轮被封锁**的类别 | 本链伤害归零 + 残命 −2 + 立即收招 | 看武傀卡再决定链长；手上备 🪞 镜面 |
| **过热破煞** | 链中**连续两段**都是 ⚙️ 机关 | 同上 | 机关之间插别的类别；或选 🦾 机关臂流派 |

**破煞的三个反直觉要点：**
1. **破煞不是「你打出的那张牌作废」，而是「整条链作废」。** 已经花掉的杀气也退不回来。
2. **破煞不会打断你的回合之外的任何事**——你只是这一轮白干，下一轮照常。所以破煞的代价主要是**伤害损失**，不是致命伤。
3. **残命 −2 才是长期成本。** 残命归零 ⇒ 力竭（此后链长上限 1 段 + 终局 −8 分），这才是真正的死亡螺旋。

### 5.4 见切（宝藏）

> **以 4 段满链安全收招 ⇒ 见切，立即 +5 分。**

见切是本作唯一的「高难度成就分」，也是**爆发路线的核心收益来源**。

| 项目 | 数值 |
| :--- | :--- |
| 打出 4 段满链的门槛 | ① 杀气 10 点（需攒 3 轮）② 手上 4 张**可用**招式 |
| 手上 5 张含 ≥4 张招式卡的概率 | **55.6%**（超几何分布，牌库 84 / 招式 60） |
| 见切奖励 | +5 分 / 次 |
| 实战期望次数 | 每人 1–2 次 |

> **见切 +5 分，正好等于爆发路线相对呼吸路线的全部超额收益。**
> **换句话说：如果你攒了 3 轮气却因为手牌不够只打出 3 段链，你这次爆发就是纯亏。**

### 5.5 流派卡（5 张）

| 流派 | 图标 | 能力 | 代价 / 限制 | 适合路线 |
| :--- | :---: | :--- | :--- | :--- |
| 影刃 | ⚡ | 你的 ⚔️ 上段斩基础值 **+1**（该类均值 1.75 → 2.75） | ⚔️ 被封时（R1/R7/R9）能力归零 | 稳健流 |
| 铁伞 | ☂️ | 残命上限 **16**（+4） | **杀气上限 8 ⇒ 链长硬上限 3 段，永远打不出满链、拿不到见切** | 透支流 / 硬抗反击 |
| 机关臂 | 🦾 | 你的 ⚙️ 机关**不会过热** | ⚙️ 只有 12 张，且 R6/R8 都被封 | 爆发流 |
| 毒镖 | 🧪 | 4 段满链收招时，**追加 3 点伤害** | 需要打得出 4 段才有意义 | 极限爆发流 |
| 双刃 | 🌙 | 手牌上限 **6 张**（招式卡期望 4.29 张） | — | 万能 |

> **铁伞是本作唯一「物理上被排除在满链之外」的流派**——1+2+3 = 6 ≤ 8 < 1+2+3+4 = 10。
> 它的补偿是 16 点残命和稳定的 3 段链。**不要把它当成弱流派**：示例局里铁伞以 92 分屈居第二，只差 3 分。

### 5.6 武傀（Boss）

| 武傀 | 图标 | 登场轮次 | HP（4人） | 风格 |
| :--- | :---: | :---: | :---: | :--- |
| 铁蝉 | 🪲 | R1–R3 | 52 | 教学。封锁温和，1 轮减伤 |
| 赤蛛 | 🕷️ | R4–R6 | 68 | 惩罚长链（毒牙）+ 双封锁 |
| 阎罗 | ☠️ | R7–R9 | 84 | **每段 −2 + 三封锁**，全场最难 |

**斩杀与脱逃：**
- **斩杀**：HP 归零 ⇒ 立即结算本尊名次分（第 1/2/3/其余 = +8/+5/+3/+1）。
- **溢出不计分**：斩杀瞬间的多余伤害**不算分**。⇒ **尾刀是有价值的**：抢到尾刀的人拿走剩余 HP 的全部伤害分。
- **脱逃**：第 3 轮结束时 HP 仍 > 0 ⇒ 该尊脱逃，**全员失去这尊的名次分**（已造成的伤害分仍保留）。
- **调息**：斩杀后本夜剩余轮次，全员改为**调息**——残命 +3，杀气照常 +3，但不能进攻。

## 6. 游戏规则

### 6.1 准备阶段

1. **发放板件**：每人 1 张玩家板 + 1 枚杀气标记 + 1 枚残命标记 + 1 枚棋子。
2. **放置武傀板**：桌中央摊开 3 张武傀板，按人数设定 HP 标记（见 4.3 表）。
3. **摊开武傀招式卡**：9 张按 R1–R9 顺序**全部正面朝上**摊在桌中央。
4. **选流派**：每人从 5 张流派卡中选 1 张（可暗选后同时揭示，也可商量着分），放在自己玩家板的流派卡位。
5. **组牌库**：60 张招式卡 + 24 张秘具卡共 84 张，洗匀作为牌库。留出弃牌堆位置。
6. **初始状态**：
   - 每人**杀气 = 5**（不是满槽！）
   - 每人**残命 = 12**（☂️ 铁伞 = 16）
   - 每人**补牌到手牌上限**（5 张；🌙 双刃 6 张）
7. **决定起始玩家**：任意方式。起始玩家标记每轮顺时针传递。

### 6.2 一轮的流程

每轮依次执行 4 个阶段：

```
┌─────────────────────────────────────────────────────────┐
│ ① 夜幕阶段  翻开本轮的武傀招式卡（已公开，只是翻到当前） │
│             ⇒ 本轮的封锁 / 减伤 / 反击立即生效           │
├─────────────────────────────────────────────────────────┤
│ ② 连招阶段  从起始玩家起顺时针，每人依次进行            │
│             「连招回合」（见 6.3）                       │
├─────────────────────────────────────────────────────────┤
│ ③ 回气阶段  每人杀气 +3（上限 10，溢出作废）             │
├─────────────────────────────────────────────────────────┤
│ ④ 补牌阶段  每人补牌到手牌上限；牌库空则洗弃牌堆         │
└─────────────────────────────────────────────────────────┘
```

### 6.3 连招回合（本作的核心）

在你的连招回合里，**逐张把招式卡横着排到自己面前**，从左到右就是 ①②③④ 段。

每一步你**必须**做下列之一：

| 选项 | 操作 | 结果 |
| :--- | :--- | :--- |
| **接续** | 从手上打 1 张招式卡到第 n 段（n = 当前链长 + 1） | 支付 **n** 点杀气 |
| **贴秘具** | 打出 1 张秘具卡，附在任意一段上 | 不付杀气；每条链限 1 张 |
| **收招** | 宣告结束本回合 | 结算链上全部伤害，链清空，回合结束 |
| **调息** | （仅当本尊武傀已斩杀）不进攻 | 残命 +3，不付杀气 |

**强制收招的两种情况：**
1. **杀气不足以支付下一段** ⇒ 你必须收招（安全结算，不破煞）。
2. **链长已达 4 段** ⇒ 第 5 段需 5 点杀气，而你满槽也只有 10 − (1+2+3+4) = 0 ⇒ **物理上打不出第 5 段**，自动收招。

**伤害结算：**

```
每段伤害 = max(0, 卡面基础值 + 3×(段位−1) + 本轮武傀修正)
本链总伤害 = 各段之和 + 秘具加成
```

- 武傀修正（如「甲壳 每段 −1」「熔炉 每段 −2」）**逐段**计算，每段最低 0。
- 结算后的伤害打在**当前登场的武傀**上。
- **溢出不计分**。

**回合结束后：** 你打出的招式卡与秘具卡进弃牌堆，链清空。

### 6.4 破煞判定

在你把一张招式卡放到链上时，立即检查：

| 检查项 | 破煞？ |
| :--- | :--- |
| 这张卡的类别是否**在本轮被封锁**？ | 是 ⇒ 破煞 |
| 这张卡是 ⚙️ 且**上一段也是 ⚙️**（且你非 🦾 机关臂）？ | 是 ⇒ 过热破煞 |

**破煞后果（三者同时）：**
1. 本链**全部伤害归零**（含秘具加成）；
2. 你的**残命 −2**；
3. 立即**收招**，本回合结束。

> 🪞 镜面可以让本段无视封锁，但不能防过热。

### 6.5 调息规则

当本尊武傀已被斩杀，本夜剩余的轮次所有人进入**调息**：

- 不能进攻（不能接续、不能贴秘具）；
- **残命 +3**（不超过上限）；
- 杀气照常在回气阶段 **+3**；
- 照常补牌。

> **调息是「用时间换状态」**：斩杀得越早，你能攒的气越多、回的血越多，但**全队的伤害分也越少**（因为伤害分被总 HP 封顶）。
> **⇒ 恒等式 G：斩杀越早，全队伤害分总额越少；斩杀越晚，破煞风险越大且可能脱逃。最优解是让武傀恰好在第 3 轮倒下。**

### 6.6 胜利条件与计分

游戏固定 **9 轮**（3 尊 × 3 轮），结束后结算。

| 计分项 | 计算方式 |
| :--- | :--- |
| **伤害分** | 你对武傀造成的每 1 点**有效**伤害 = 1 分（溢出不计） |
| **名次分** | 每尊斩杀时，按本尊伤害排名：第 1 / 2 / 3 / 其余 = **+8 / +5 / +3 / +1** |
| **见切分** | 每次 4 段满链**安全**收招 = **+5** 分 |
| **残命分** | 终局每剩 1 点残命 = **+1** 分 |
| **力竭惩罚** | 残命归零过一次 ⇒ **−8** 分（只扣一次） |

**平局裁定：** 名次分打平时，**残命高者优先**；仍平则按**顺时针座次**先者优。

**总分最高者获胜。**

**分数参考（4 人局）：**

| 档位 | 总分 | 说明 |
| :--- | :--- | :--- |
| 顶尖 | 85–95 | 拿到 2 个以上第一名 + 至少 1 次见切 |
| 良好 | 65–80 | 稳定 2–3 段链，残命几乎无损 |
| 普通 | 45–60 | 破煞 2–3 次，或攒气时机全错 |
| 崩盘 | < 40 | 力竭，或三尊中有一尊脱逃 |

## 7. 完整游戏流程示例

下面是一局**完整的 4 人局**（9 轮），四位玩家的流派与路线各不相同：

| 玩家 | 流派 | 路线 | 思路 |
| :--- | :---: | :--- | :--- |
| **阿影** | ⚡ 影刃 | 呼吸流 | 大部分回合打 2 段，攒到满槽时抓机会打 4 段 |
| **老铁** | ☂️ 铁伞 | 透支流 | 稳定 3 段（杀气上限 8，打不了 4 段），靠 16 点残命硬抗反击 |
| **小机** | 🦾 机关臂 | 爆发流 | 攒气到满槽，靠机关类高均值打出巨额伤害 |
| **阿双** | 🌙 双刃 | 见风使舵 | 手牌 6 张，看武傀卡决定链长 |

**初始状态**：杀气 5 / 残命 12（老铁 16）/ 铁蝉 HP 52。

### 7.1 第一夜 · 铁蝉（HP 52）

#### R1 · 风压（封 ⚔️ 上段斩）

| 玩家 | 链 | 组成 | 伤害 | 杀气变化 |
| :--- | :---: | :--- | :---: | :--- |
| 阿影 | 2 段 | ⚙️基3 + 🔱基1 + 🪝铁钩 | 3 + 4 + 2 = **9** | 5 −3 → +3 ⇒ 5 |
| 老铁 | 2 段 | 🌊基1 + 🗡️基3 + 🪝铁钩 | 1 + 6 + 2 = **9** | 5 −3 → +3 ⇒ 5 |
| 小机 | 1 段 | 🔱基3 + 🪝铁钩 | 3 + 2 = **5** | 5 −1 → +3 ⇒ 7 |
| 阿双 | 2 段 | 🗡️基2 + 🔱基2 + 🪝铁钩 | 2 + 5 + 2 = **9** | 5 −3 → +3 ⇒ 5 |

| :--- | :---: | :--- | :--- | :---: |
| 阿影 | 2 段 | 🌊基2 + ⚙️基4 | (2−1) + (7−1) = **7** | 20 → 13 |
| 老铁 | 2 段 | ⚙️基3 + ⚔️基3 + 🪝铁钩 | (3−1) + (6−1) + 2 = **9** | 13 → 4 |

**铁蝉伤害榜**：老铁 18（+8） / 阿影 16（+5） / 小机 9（+3） / 阿双 9（+1）

> **调息不是浪费，是存钱。**

#### R4 · 吐丝（封 🗡️ 下段撩）

| 玩家 | 链 | 组成 | 伤害 | 杀气变化 |
| :--- | :---: | :--- | :---: | :--- |
| 阿影 | 2 段 | ⚔️基3（含⚡+1）+ 🌊基1 | 3 + 4 = **7** | 8 −3 → +3 ⇒ 8 |

**赤蛛 HP：68 − 46 = 22**

#### R5 · 毒牙（链长 ≥ 3 者残命 −2）

| 玩家 | 链 | 组成 | 计算 | 伤害 | 后果 |

## 8. 新手策略提示

### 8.1 三条记忆锚（背下这三条就够打完第一局）

> **① 「1 段攒气 / 2 段呼吸 / 3 段透支 / 4 段豪赌。」**
> 打 2 段永远不亏。想打更长，先算清楚你攒了几轮。

> **② 「满链之后，下一轮只有 3 点杀气。」**
> 爆发必接疲软。别在你最需要输出的那一轮之前爆发。

> **③ 「减伤轮惩罚短链，封锁轮惩罚长链。」**
> 甲壳 / 熔炉（每段 −X）⇒ 打长链；千手 / 铁面（封多类）⇒ 打短链攒气。

### 8.2 前两轮的标准开局

1. **R1（封 ⚔️）**：打 2 段。杀气 5 刚好够（耗 3），剩 2 + 3 = 5，下一轮还是 5。**保持这个节奏。**
2. **R2（甲壳 每段 −1）**：打 2 段依然划算（(2−1)+(5−1) = 5，只损失 2 点）。但**如果手上有高基础值的牌，这一轮打 3 段更好**——段位越深，−1 的占比越小。
3. **R3 若已斩杀**：调息，把杀气顶到满槽，为第二夜做准备。

### 8.3 什么时候该攒气？

**看后面两轮的武傀卡。** 攒气需要连续 3 轮打 1 段，所以：

| 如果 R+1、R+2 是…… | 建议 |
| :--- | :--- |
| 两段都是**封锁轮**（封 2 类以上） | ✅ **立刻攒气**——反正这两轮你也打不长了 |
| 一段是**无封锁或封 1 类** | ❌ 别攒，那轮该打 2–3 段 |
| 一段是**减伤轮**（甲壳 / 熔炉） | ⚠️ 攒，攒到满槽在减伤轮打 4 段（阿影的打法） |
| 武傀血量快见底 | ❌ 别攒，抢尾刀 |

### 8.4 秘具的使用优先级

1. **🪝 铁钩**：万能，链越短收益占比越高（1 段链 +2 等于翻倍）。
2. **🧨 爆竹**：**永远放在最后一段**，纯 +3。
3. **⛓️ 锁链**：放在**段位最高**的那一段（第 3 段 8 → 16，第 4 段 11 → 22）。
4. **🔪 副刃**：放在第 2 段之后（复制第 1 段没意义）。
5. **🪞 镜面**：留到**千手轮（R9）**，那一轮无视封锁 = 白赚一段。
6. **🩸 血引**：差 1–2 点杀气凑满链时用，这是它唯一的价值。
7. **🍶 药酒**：残命 ≤ 6 就该用了，别等到力竭。
8. **🕯️ 烛照**：早期打出，帮自己和后续轮次铺牌序。

### 8.5 机关类（⚙️）的正确用法

⚙️ 均值 2.75，是全场最高，但**不能连着用**。

| 链长 | 机关的正确摆法 | 均值提升 |
| :---: | :---: | :--- |
| 2 段 | ⚙️ + 其他 | +1.0 |
| 3 段 | ⚙️ + 其他 + ⚙️ | +2.0 |
| 4 段 | ⚙️ + 其他 + ⚙️ + 其他 | +2.0 |

> **⚙️ 放在奇数段（①③）或偶数段（②④）都可以，但绝不能相邻。**
> 🦾 机关臂流派可以连续放——那他 4 段全放 ⚙️ 能到 2.75×4 + 18 = 29 点，全场理论最高单链。

### 8.6 抢尾刀的时机

因为**溢出不计分**，尾刀价值极高（吃掉剩余全部 HP）。

- **武傀 HP ≤ 20 时**，紧盯它：你的链长只要能超过剩余 HP 就是尾刀。
- **顺位在后的人天然吃亏**（前面的人可能已经斩杀）。**所以顺位靠后时，要么打长链抢，要么干脆调息存气。**
- 反过来，**顺位靠前的人应该主动留一点**——让后面的人去斩，你保住杀气打下一尊。（这是本作唯一的"合作"成分）

## 10. 常见问题

### 10.1 链长真的是硬上限 4 段吗？能不能打第 5 段？

**不能。链长硬上限恒为 4 段**，这是本作不可打破的物理定律：

| 项 | 数值 |
| :--- | :--- |
| 前 4 段总消耗 | 1 + 2 + 3 + 4 = **10** |
| 杀气上限 | **10** |
| 打完 4 段后剩余杀气 | **0** |
| 第 5 段所需杀气 | **5** |

即使使用 🩸 血引（本轮上限临时提升到 12），打完 4 段后也只剩 2 点，仍然付不起第 5 段的 5 点。
**⇒ 唯一的 5 段路径不存在。想再打长链，只能等下一轮回气。**

### 10.2 我可以在一条链里用多张秘具吗？

**不可以。** 规则明确规定**每条连招链最多使用 1 张秘具**。这是为了防止「锁链 + 爆竹 + 铁钩」的三重叠加把单段伤害推到离谱的数值。

### 10.3 破煞之后已经花掉的杀气能退回来吗？

**不能。** 杀气在接续的瞬间就支付了，破煞不退。
**但破煞也不额外扣杀气**——你只是这一轮白干。

### 10.4 残命归零会立刻出局吗？

**不会出局。** 残命归零 ⇒ **力竭**，后果有两条：
1. 本局剩余的轮次里，你的**链长上限变为 1 段**；
2. 终局结算 **−8 分**。

力竭后你依然要打完剩下的轮次（1 段链虽然弱，但 1.95 伤害也不完全是零）。

### 10.5 斩杀武傀后的调息轮，我能不能选择不调息、继续进攻？

**不能。** 武傀已斩，没有攻击目标。调息是强制的。
**这也是「早斩」的隐性代价**：斩得越早，全队能打的伤害越少，伤害分总额越低。

### 10.6 为什么我攒了满槽杀气却只能打 1 段？

因为**封锁**。封 2 类时期望可用招式只有 2.14 张，封 3 类（R9 千手）只有 **1.43 张**。
**⇒ 满槽杀气遇到封锁轮，等于白亏 3 点回气（回气阶段 +3 会溢出作废）。**
**解法：翻武傀卡后再决定这轮要不要攒气。**

### 10.7 铁伞是不是最弱的流派？它永远打不出满链。

**不是。** 铁伞的杀气上限 8 ⇒ 1+2+3 = 6 ≤ 8 < 10 ⇒ 链长上限 3 段，确实拿不到见切分（+5）。
**但它的补偿是 16 点残命**，可以硬吃毒牙（−2）、阎罗帐（−2）这类反击，稳定打 3 段。
示例局里铁伞拿了 **92 分**，只比冠军少 3 分。**它是"下限最高"的流派**，适合新手。

### 10.8 机关类连着用会破煞，那机关臂流派是不是没用了？

**恰恰相反。** 🦾 机关臂是**唯一能连续放机关**的流派，4 段全 ⚙️ 的理论伤害是 2.75×4 + 18 = **29 点**，全场最高单链。
它的弱点是 ⚙️ 在 R6（八足）和 R8（熔炉）都被封——**那两轮老老实实打 2 段就行**。

### 10.9 「每段 −X」到底惩罚长链还是短链？

**惩罚短链。** 因为段位加成是 **+3**，而减伤只有 **−1** 或 **−2**：

| 段位 | 原始（均值） | 甲壳 −1 | 损失占比 | 熔炉 −2 | 损失占比 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 第 1 段 | 1.95 | 0.95 | **51%** | 0 | **100%** |
| 第 2 段 | 4.95 | 3.95 | 20% | 2.95 | 40% |
| 第 3 段 | 7.95 | 6.95 | 13% | 5.95 | 25% |
| 第 4 段 | 10.95 | 9.95 | **9%** | 8.95 | **18%** |

> **⇒ 恒等式 H：减伤轮是长链的天堂。阿影正是靠这一条在 R8 熔炉轮打出 4 段满链拿下冠军。**

### 10.10 段位加成是加法，那基础值高的牌该放前面还是后面？

**都一样。** 因为总伤害 = Σ(基础值) + 3×(0+1+2+3)，基础值的位置**完全不影响**总伤害。
真正要考虑的是：
- ⚙️ 不能相邻（放 ①③ 或 ②④）；
- 🧨 爆竹 / ⛓️ 锁链放在**最后一段**；
- 破煞风险——把最可能被封的类别放在**后面**（前面已经吃到的段位不会因为后面破煞而保留，但至少你能早点发现风险）。

> **注意最后一条：破煞是「整条链作废」，所以没有"保住前半段"这回事。** 位置只影响你的决策顺序，不影响风险。

### 10.11 名次分打平怎么算？

**残命高者优先**；仍平则按**顺时针座次**先者优。
示例局里出现过两次：铁蝉的小机 vs 阿双（都是 9 伤害、12 残命 ⇒ 按座次）、赤蛛的老铁 vs 小机（都是 16 伤害 ⇒ 老铁残命 14 > 小机 12）。

### 10.12 5 人局牌库不够用怎么办？

牌库 84 张，5 人局 9 轮消耗约 5×9×2.5 = 112 张，**会在第 7 轮左右洗第一次弃牌堆**。这是设计内的正常现象。
建议：洗牌时把弃牌堆**充分洗匀**，并且**公开洗牌**（所有人能看到）。

### 10.13 能不能只用一副扑克牌代替？

**可以，但需要映射。** 用花色对应 5 类招式（需要去掉一类或自行分配），点数对应基础值：

| 扑克 | 映射 |
| :--- | :--- |
| ♠ / ♥ / ♦ / ♣ | 上段斩 / 下段撩 / 突刺 / 横扫 |
| A–5 | 基础 1 |
| 6–10 | 基础 2 |
| J–Q | 基础 3 |
| 大小王 ×2 | 机关类（基 2 / 基 3） |

秘具卡无法用扑克替代，建议单独打印。

### 10.14 一局大概多久？

| 人数 | 时长 |
| :---: | :--- |
| 2 人 | 40–55 分钟 |
| 3 人 | 45–65 分钟 |
| 4 人 | 55–75 分钟 |
| 5 人 | 65–85 分钟 |

熟练后（每人连招回合 15–20 秒）可压缩到 40 分钟以内。
