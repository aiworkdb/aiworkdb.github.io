# 样品2 互动教具页方案：《玩具的家在哪里？》

**品牌**：小步绘本 | **对应绘本**：《玩具的家在哪里？》

> 3页互动教具，对应绘本关键情节。把"整理"变成一场帮玩具找家的魔法冒险。

---

## 教具页1：我的物品寻家地图

**名称**：我的物品寻家地图
**对应绘本**：P3-P5（温暖声音告诉宝宝"玩具们迷路了，每件东西都有自己的家"，宝宝开始为每件玩具找家）

**设计内容**：
A4竖版。页面主体是一张房间俯视图，房间四个角落画着四个"家"（用暖橙色虚线框出，框内写上家的名字）：
- 左上角：床（画一个俯视的床铺轮廓，标注"床的家"）
- 右上角：书架（画3-4层小书架俯视图，标注"书架的家"）
- 左下角：玩具箱（画一个敞口大箱子，标注"玩具箱的家"）
- 右下角：衣柜（画一排小格子俯视图，标注"衣柜的家"）

房间中间的空地上散落着6件物品（可爱手绘风，每件物品下方有虚线连接起点）：
1. 红色小汽车
2. 蓝色绘本
3. 彩色积木块
4. 一盒彩笔
5. 小外套
6. 小拖鞋

孩子需要用笔从每件物品画一条线，连到正确的"家"。

页面底部设有"物品回家记录表"（暖橙色表格框）：
| 物品名称 | 它的家在哪里 | 回家成功打勾 |
|---------|------------|------------|
|         |            | ☐          |
|         |            | ☐          |
|         |            | ☐          |
|         |            | ☐          |
|         |            | ☐          |
|         |            | ☐          |

表格上方写一行引导文字："每送一件物品回家，就在格子里打勾，看看你能送几件回家！"

**使用方法**：
1. 共读完P3-P5后，拿出这张地图，对孩子说："宝宝正在帮玩具找家，我们也来当一回寻家小帮手好不好？"
2. 让孩子先用手指指一指：每件物品应该回哪个家。说对了就夸"你找得真准"。
3. 再让孩子用笔（蜡笔或水彩笔都行）画线连起来，一边连一边说："小汽车，回玩具箱的家！"
4. 全部连完后，把这张地图贴在孩子的房间门上或墙上。每次真实整理时，对照记录表打勾，攒满6个勾可以换一个小奖励。

**打印建议**：彩色打印最佳（暖橙+莫兰迪绿配色，物品颜色鲜艳便于辨认）。若黑白打印，可让孩子先给物品和"家"涂色再连线，增加参与感。建议用稍厚的纸（120g以上）便于反复指认和保存。

## 教具页2：整理魔法师证书

**名称**：整理魔法师证书
**对应绘本**：P6-P8（物品归位后房间变亮，宝宝体会到整理的成就感）

**设计内容**：
A4竖版。页面分为上下两部分，中间用一条莫兰迪绿色的虚线分隔（沿虚线剪开使用）。

**上半部分——整理魔法师证书**：
背景为暖橙渐变色，四角画着小星星和魔法光芒。证书内容排版如下：
- 顶部：标题"整理魔法师证书"（大字，带金色描边效果）
- 中间留出可填写区域：
  - "魔法师姓名：___________"（孩子名字）
  - "成功帮___件物品找到了家"（填数字）
  - "颁发日期：___年___月___日"
- 底部：一行小字"小步绘本认证 · 每个会整理的孩子都是魔法师"，旁边是暖橙色脚印Logo
- 右下角留一个圆形盖章区（家长可画一个笑脸章或贴贴纸）

**下半部分——4个魔法任务卡**（每张卡片带虚线边框，可沿虚线剪下）：
卡片统一为圆角小卡片样式，顶部有莫兰迪绿色色条，写着"魔法任务卡"，下方是任务内容和小图标。

- 任务卡①（图标：玩具车+家）："把3件玩具送回家"
- 任务卡②（图标：书本+书架）："把2本绘本放回书架"
- 任务卡③（图标：小衣服+衣柜）："把衣服挂到衣柜"
- 任务卡④（图标：桌面+分类箭头）："把桌面上的东西分类放好"

每张卡片右下角有一个小圆圈，写着"完成后打勾 ☐"。

**使用方法**：
1. 共读到P8（房间变亮）时，拿出这张教具，对孩子说："宝宝把房间变亮了，变成魔法师了！你也想当整理魔法师吗？"
2. 先把下半部分的4张魔法任务卡沿虚线剪下来，像抽签一样背面朝上放好。
3. 让孩子随机抽一张任务卡，读出任务内容，然后去真实房间完成这一项整理。
4. 完成一张打一个勾。集齐4张任务卡后，把上半部分的"整理魔法师证书"填好，由家长郑重颁发（可以让孩子站在中间，家长双手递上，配上"恭喜你成为整理魔法师！"的仪式感）。
5. 证书可贴在孩子房间或冰箱上展示，作为持续激励。

**打印建议**：彩色打印（暖橙证书部分需要彩色才有仪式感）。建议用稍厚纸张打印证书部分（可单独彩印保留），任务卡用普通纸即可。任务卡可过塑反复使用。

## 教具页3：我的整理日记

**名称**：我的整理日记
**对应绘本**：P8-P10（整理成为日常习惯，宝宝最终在积木堆下找到小布熊，体会到"每件东西回家"的意义）

**设计内容**：
A4竖版。这是一份一周整理打卡日记，整体配色为暖橙标题+莫兰迪绿表格框。

页面顶部标题："我的整理日记"（大字，旁边画一个戴魔法帽的小脚印Logo）。
标题下一行小字："每天帮玩具找家，看看一周能帮多少件物品回家！"

主体为一周七天的打卡区，每天一个横向小卡片（暖橙色左边框），从上到下排列：

| 星期 | 日期 | 我今天整理了什么（画一画或写一写） | 心情 | 印章格 |
|-----|------|-------------------------------|------|-------|
| 周一 | __/__ |                               | 😊 / 😐 / 😢 | ☐ |
| 周二 | __/__ |                               | 😊 / 😐 / 😢 | ☐ |
| 周三 | __/__ |                               | 😊 / 😐 / 😢 | ☐ |
| 周四 | __/__ |                               | 😊 / 😐 / 😢 | ☐ |
| 周五 | __/__ |                               | 😊 / 😐 / 😢 | ☐ |
| 周六 | __/__ |                               | 😊 / 😐 / 😢 | ☐ |
| 周日 | __/__ |                               | 😊 / 😐 / 😢 | ☐ |

说明："心情"栏让孩子圈出今天的表情（笑脸=很开心、普通脸=还行、哭脸=不太想整理）。"印章格"供家长盖章或贴贴纸。"整理了什么"栏孩子可以画画（画一个玩具+箭头指向家），也可以让家长代写文字。

页面底部是"一周总结区"（莫兰迪绿色圆角框）：
- 大字："本周我帮 ___ 件物品找到了家！"
- 下方一行小字："我是___级整理魔法师！"（参考：1-10件=见习魔法师，11-20件=高级魔法师，20件以上=大师魔法师）
- 最底部一行："下周我想帮________找到家。"

**使用方法**：
1. 共读完整本绘本后，把这份整理日记贴在孩子房间醒目位置（建议贴在与孩子视线平齐的高度）。
2. 每天睡前花2-3分钟，和孩子一起回顾："今天我们帮哪些东西找到家了？"让孩子自己画或说，家长代写。
3. 让孩子圈出今天的心情表情。如果孩子圈了哭脸，不要否定，可以说："今天有点累对不对？没关系，明天再帮玩具找家，它们会等你的。"
4. 完成一天就在印章格贴一个贴纸或盖个小章（仪式感很重要）。
5. 每周日晚做"一周总结"：数一数帮了多少件物品回家，填上数字和魔法师等级，让孩子感受累积的成就感。
6. 可以连续用4周，观察孩子从"需要提醒"到"主动整理"的变化。

**打印建议**：彩色打印（表情图标和边框需要彩色）。建议一次打印4-5张备用，每周换一张。可过塑后用白板笔反复填写擦除，更环保。配套准备一些小贴纸或印章，作为每日打卡奖励。
