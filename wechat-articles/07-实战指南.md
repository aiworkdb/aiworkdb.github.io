## 设计团建活动的三个核心问题

**问题一：这个团队，真正需要什么？**  
不是"他们想玩什么"，是"他们现在的痛点是什么"。

**问题二：游戏组合的节奏，是否合理？**  
不是"越多越好"，是"有张有弛，有体验有复盘"。

**问题三：复盘能不能连接到真实工作？**  
不是"玩得开心就好"，是"明天回到办公室，他们会改变什么"。

## 第一步：需求诊断——这个团队真正需要什么？

## 第二步：设计时间轴——让活动有节奏感

### 标准一日团建时间轴（6–7小时）

| 时间 | 环节 | 主要游戏 | 目标 | 节奏 |
|------|------|---------|------|------|
| 09:00–09:30 | 到达 & 开场 | — | 签到、破冰预热 | 慢 |
| 09:30–10:00 | 破冰一 | [人类宾果](https://ai.aitboy.cn/teambuilding/games/icebreaker/human-bingo.html) | 记住名字、发现共同点 | 轻快 |
| 10:00–10:30 | 破冰二 | [两真一假](https://ai.aitboy.cn/teambuilding/games/icebreaker/two-truths-one-lie.html) | 加深了解 | 轻快 |
| 10:30–12:00 | 主体活动一 | [人结](https://ai.aitboy.cn/teambuilding/games/collaboration/human-knot.html) | 团队协作、沟通 | 中高 |
| 12:00–13:30 | 午餐 & 休息 | — | 放松、自由交流 | 放松 |
| 13:30–15:00 | 主体活动二 | [盲人方阵](https://ai.aitboy.cn/teambuilding/games/communication/blind-polygon.html) | 精准沟通、信任 | 高 |
| 15:00–15:30 | 下午茶歇 | — | 补水、休息 | 放松 |
| 15:30–16:30 | 信任活动 | [盲行](https://ai.aitboy.cn/teambuilding/games/trust/blind-walk.html) | 信任建立 | 中 |
| 16:30–17:00 | 整体复盘 & closing | — | 整合体验、行动计划 | 沉淀 |

### 时间轴设计原则

1. **开场要轻**：第一个游戏必须是破冰类，低压力、高参与度
2. **中间要深**：主体活动放在精力最旺盛的时段（上午10:30–12:00，下午13:30–15:00）
3. **结尾要沉淀**：最后30分钟必须留给复盘和closing，不要急着结束
4. **休息要够**：每90分钟，至少15分钟休息（喝水、上厕所、放松）

## 第三步：引导复盘——让团建不只是"玩"

### 复盘的4F模型（必备工具）

| 阶段 | 英文 | 中文 | 核心问题 | 时间分配 |
|------|------|------|---------|---------|
| 1 | Facts | **事实** | 刚才发生了什么？ | 20% |
| 2 | Feelings | **感受** | 你当时是什么感觉？ | 20% |
| 3 | Findings | **发现** | 这和工作/团队有什么相似？ | 40% |
| 4 | Future | **行动** | 回到工作中你会改变什么？ | 20% |

### 复盘引导话术（即拿即用）

**复盘开场**：
> "好，游戏结束。给大家1分钟，先安静回想一下刚才的过程。  
> （等1分钟）  
> 好，谁愿意分享一下，刚才最印象深刻的一个瞬间是什么？"

**从Facts过渡到Feelings**：
> "刚才我们说了发生了什么。现在我想问——  
> 当______发生的时候，大家是什么感受？"

**从Feelings过渡到Findings**：
> "感谢大家的分享。我注意到______（总结一个关键观察）。  
> 如果把这个过程看成我们团队工作的缩影，大家看到了什么相似的地方？"

**从Findings过渡到Future**：
> "今天体验到的这些东西，回到工作中，有什么是你明天可以做一些不同的事情的？  
> 不需要大改变，一个小的行动就好。"

**复盘收尾**：
> "谢谢大家的分享。我今天印象最深的一句话是：'______'。  
> 希望大家带着这个体验，回到工作中。  
> 我们今天的团建，到这里就结束了。谢谢大家！"

## 第四步：教练工具箱——话术、安全、物资、评估

### 话术库（必备）

| 场景 | 话术 |
|------|------|
| 第一次见面 | "大家好，我是今天的教练______。今天我们会通过几个小活动，让大家互相认识、体验一下团队协作的感觉。不需要任何基础，所有活动大家都能参与。" |
| 讲解规则 | "这个游戏我们想体验的是______。规则很简单，只有三条：1. ______ 2. ______ 3. ______。我找两位志愿者，我们演示一下——" |
| 过程干预（场面混乱） | "好，停一下。我观察了一下，大家现在的问题是______。我们调整一下：______。然后继续，从______开始。准备好了吗？3、2、1——" |
| 有人不敢参与 | "没问题，你今天担任'观察员'角色。你的任务是：观察团队在游戏中的互动方式，复盘的时候告诉我们你看到了什么。" |

### 安全清单（必备）

| 安全类别 | 检查项 |
|---------|---------|
| **身体安全** | 场地周围无尖锐物品、蒙眼活动有教练监控、信任背摔有双重保护 |
| **心理安全** | 不强迫参与、不点名批评、不翻旧账、强调"游戏没有坏人，只有系统" |
| **情绪安全** | 复盘时不针对个人、讨论"模式"而非"某人的问题"、允许"跳过"不舒适的话题 |

### 物资清单（必备）

| 类别 | 物资 | 数量 |
|------|------|------|
| **基础道具** | 绳子（直径6–8mm尼龙绳） | 20米 |
| | 眼罩 | 人数的一半 + 20%备用 |
| | 空白卡片 + 马克笔 | 100张 + 20支 |
| | 计时器 | 1个（可投影更佳） |
| | 口哨 | 2个 |
| **户外追加** | 急救包（创可贴、碘伏、冰袋） | 1套 |
| | 防晒霜 / 驱蚊液 | 各1瓶 |
| | 足够饮用水 | 按人数准备 |

### 效果评估（活动后必做）

| 评估维度 | 方法 |
|---------|------|
| **参与者反馈** | 活动结束后，用手机扫码填写反馈问卷（5道题，2分钟完成） |
| **教练自我反思** | 用复盘记录模板，记录关键观察、精彩语录、反思与改进 |
| **客户反馈** | 活动后当天或次日，发反馈邮件给甲方（活动概况 + 观察与建议） |

## 如何选择合适的游戏组合？

### 决策树

```
开始
│
├─ 团队人数 < 10人？
│   ├─ 是 → 选择需要小人数/小组进行的游戏（两真一假、你说我画、魔法学院）
│   └─ 否 → 继续
│
├─ 有户外场地吗？
│   ├─ 有 → 可以加入户外游戏（人结、风火轮、信任背摔）
│   └─ 否 → 选择室内游戏（传话游戏、谣言工厂、红黑游戏）
│
├─ 有充足预算买道具吗？
│   ├─ 有 → 可以加入需要道具的游戏（盲人方阵、珠行万里、岛屿求生）
│   └─ 否 → 选择零道具或低道具游戏（名字接龙、两真一假、齐眉棍可用替代道具）
│
└─ 根据核心目标选择游戏类别
    ├─ 破冰 → 人类宾果、两真一假、名字接龙
    ├─ 沟通 → 盲人方阵、传话游戏、你说我画
    ├─ 协作 → 人结、齐眉棍、珠行万里
    ├─ 信任 → 信任背摔、盲行
    ├─ 领导力 → 红黑游戏、七巧板
    └─ 创意 → 10元买创意、报纸塔挑战
```

## 常见坑与规避方法

| 常见坑 | 规避方法 |
|---------|---------|
| **游戏太多，时间不够** | 一日团建最多3个主体游戏（含复盘），不要贪多 |
| **复盘太浅，没有连接工作** | 复盘时间至少占游戏时长的30%，用4F模型深度引导 |
| **有人不参与，站在一边看** | 教练主动介入，给TA安排角色（观察员、记录员） |
| **气氛太尬，大家放不开** | 从低压力游戏开始（破冰类），逐步升温 |
| **甲方/领导在场，大家不敢说话** | 开场时明确说："今天没有对错，只有体验。领导也是参与者。" |
