# 物资与效率工具

> **一句话**：出发前一晚对着这三张表打勾，比到现场再想「还缺什么」省两个小时。

> 现场最容易崩的不是游戏，是"东西没带""人分错了""没人记时间"。

## 一、通用物资清单（按包准备）

分三个包，每个包一张表，出门前逐项打勾。

### A 包 · 基础包（每场必带）

- [ ] 计时器 / 手机倒计时（加一个备用）
- [ ] 口哨 1 个（叫停用，比喊话有效）
- [ ] 白板笔 2 色 + 白板擦（或大白纸 + 马克笔）
- [ ] A4 纸 1 包
- [ ] 便利贴 1 本
- [ ] 胶带（美纹纸 1 卷 + 透明胶 1 卷）
- [ ] 剪刀 2 把
- [ ] 签字笔 10 支
- [ ] 垃圾袋 2 个
- [ ] 湿巾 + 纸巾
- [ ] 创可贴 / 小急救包
- [ ] 打印好的名单 + 紧急联系人（**纸质**，别只存手机）
- [ ] 充电宝

### B 包 · 分组与计分包

- [ ] 队伍标识（贴纸/袖标/头巾，按组数 ×1.2 备）
- [ ] 计分板（白板或大纸）与磁贴/马克笔
- [ ] 抽签工具（纸条 / 扑克牌 / 号码球）
- [ ] 小奖品（可选，控制在 10 元以内，避免攀比）
- [ ] 秒表（多组并行时每组一个更省事）

### C 包 · 项目包（按当天选中的游戏配）

按游戏文档最后的「物资清单」逐项配，**每个游戏单独装一个袋子并贴名字**。现场翻包找东西是最耗时间的环节。

## 二、分组方法（比你想的重要）

### 常用五种，按目的选

| 方法 | 做法 | 适合 | 副作用 |
|---|---|---|---|
| 随机抽签 | 抽号码/扑克牌 | 打破小圈子 | 强手可能全在一组 |
| 报数分组 | 1-2-3-4 循环报数 | 最快，30 秒完成 | 相邻的人容易同组 |
| 拼图分组 | 撕开的图片拼回一组 | 有仪式感，适合开场 | 需要提前准备 |
| 特征分组 | 按星座/月份/鞋码 | 制造意外组合 | 可能强化标签 |
| 指定分组 | 教练提前排好 | 需要控制实力均衡 | 显得不透明，需说明理由 |

### 三条经验

1. **人数不整除时，余数进"流动组"**，不要让人单着。流动组可以当裁判、计时、摄影，任务要具体。
2. **组数不超过 2 的幂**，比如 4 组比 5 组好安排对阵。
3. **换组比固定组更有价值**——整个活动至少换一次组，让"没说过话的人"有机会合作。

### 组内角色（每组 4–8 人时最好都设）

- 组长（对外沟通、拍板）
- 计时员（盯时间）
- 记录员（写方案、记分数）
- 物资员（管道具、回收）

临时指定即可，重点是**让每个人都有事做**，避免"一个人干三个人看"。

## 三、现场执行时间轴（以半日 3.5 小时为例）

| 时间 | 事项 | 谁负责 |
|---|---|---|
| 提前 60 min | 场地布置、道具分袋、设备测试 | 后勤 |
| 提前 20 min | 签到、发标识、播背景音乐 | 接待 |
| 0:00–0:10 | 开场、目标说明、安全边界 | 主教 |
| 0:10–0:30 | 破冰（低门槛、全员参与） | 主教 |
| 0:30–0:40 | 分组 + 组内角色 | 助教 |
| 0:40–1:50 | 主项目 1（含规则讲解与复盘） | 主教 |
| 1:50–2:05 | 休息（真休息，不安排内容） | — |
| 2:05–3:05 | 主项目 2 | 主教 |
| 3:05–3:30 | 总复盘（4F 收口） | 主教 |
| 3:30–3:40 | 收尾、合影、回收物资 | 全员 |

**关键**：每个环节都要留"过渡时间"，规则讲解与换场各留 3–5 分钟。把时间排满的方案，现场一定超时。

## 四、结束前 10 分钟必做

- [ ] 道具全部回收并清点（对照 C 包清单）
- [ ] 场地恢复原状（桌椅、垃圾、地面）
- [ ] 分数与照片整理归档
- [ ] 收集反馈（问卷或一句话）
- [ ] 和对接人道别并确认下次

## 五、效果反馈问卷（匿名，5 题）

打印或扫码，**当场填**，离场后回收率会掉到三成以下。

1. 今天最有收获的一个环节是：__________
2. 今天最没感觉的一个环节是：__________
3. 我在团队里更了解的一位同事是：__________
4. 有一件事我希望我们团队回去后能改：__________
5. 如果可以改进一个环节，我会改：__________

**用法**：第 1、2 题统计环节排序，用来优化下次流程；第 3 题统计"关系是否真的变化"；第 4、5 题是给组织方的行动建议。

**注意**：
- 匿名，不记名，不要求写部门
- 空题不补 0，不强行凑满
- 结果只用于改进，**不与个人绩效挂钩**，事先说明
- 小组人数少于 5 人时，公开结果要做合并处理，避免被认出
