# 团建 & 培训游戏库

![封面](images/readme-cover.png)

> 面向培训老师、团建教练的实用游戏与流程资源库。
> 所有游戏统一收录，通过标签区分使用场景（团建 / 培训 / 通用）。
> 每款游戏均围绕「团队能力提升」设计：卡片与文档内标注 🟢 团建能力标签，含「适合的培训主题」与 4F 深度复盘框架。

---

## 快速检索

按四个维度快速匹配适合的游戏：

| 维度 | 选项 |
|------|------|
| **目的** | 破冰热场 · 沟通表达 · 团队协作 · 信任建立 · 领导力 · 创新思维 · 问题解决 · 剧本杀 · 综艺娱乐 · 桌游团建 |
| **团队能力** | 🟢 每款游戏标注能力标签（如信息共享 / 迭代思维 / 即兴表达）——先定「要提升什么」，再选「玩什么」 |
| **形式** | 室内 · 户外 · 线上 · 智力 · 体力 · 混合 |
| **人数** | 小组 < 10人 · 中组 10–30人 · 大组 > 30人 · 任意人数 |
| **时长** | 热身 5–15 min · 短篇 15–30 min · 中篇 30–60 min · 长篇 > 60 min |

👉 使用方式：确定当前场景的四个维度 → 在下方索引表中筛选 → 打开对应游戏文档。

每款游戏都围绕「团建目标 → 游戏体验 → 复盘迁移」设计，包含以下章节：

```
1. 游戏目标与团建核心价值（这款游戏提升什么团队能力）
2. 核心规则（流程步骤、胜负判定、角色分工）
3. 引导要点（如何讲解、控场、观察点）
4. 复盘设计（快速三问 + 4F 完整框架：事实→感受→洞察→迁移）
5. 适合的培训主题（2-3 个培训场景映射，含关键词与适用场景）
6. 变体适配 + 参与限制与安全（人数/场景调整、零接触替代方案）
7. 效果评估与教练笔记（团队协作指标、观察清单）
```

> 桌游团建（boardgame）为指南型文档：完整规则与 printables 打印页外链至[桌游库](https://ai.aitboy.cn/boardgames/)，本体聚焦团建流程编排、引导要点、复盘框架与团建增值变体。

## 贡献与更新

欢迎补充新游戏或改进现有内容。**完整流程与踩坑经验见 [开发指南.md](开发指南.md)**，硬性要求：

- 放入对应 `games/<目的>/` 目录
- 文件名使用英文小写 + 连字符（如 `human-bingo.md`）
- 在本文档的索引表中补充一行（含团队能力列）
- 选款前先做 slug 查重 + 能力矩阵查空缺，别与已有款撞车
- 围绕团建主线写：必须含「团建核心价值」标准列表（`- **短词**：说明`，供索引提取能力标签）+ 复盘三问 + 4F 框架 + 培训主题 + 教练笔记，不做纯游戏介绍
- 生成链路：`md2html.py` → `gen_index.py` → capacity-picker 数据同步 → 公众号/日历联动（详见开发指南 Step 5-7）
