## 产品规划（按优先级详列）

### T1 团建方案生成器 2.0 · P0
- **用途**：HR/教练选游戏 → 一键生成可执行的完整团建方案
- **功能**：四维筛选（目的/形式/人数/时长）→ 推荐游戏组合 → 生成时间轴方案（含话术/复盘提示）→ 打印/导出
- **设计**：单选按钮组 + 生成按钮 + 方案卡片列表；数据内置游戏库（来自仓库 58 款）
- **入口**：`tools/plan-generator/index.html`

### T2 随机分组器 · P0
- **用途**：快速公平分组，避免"熟人抱团"
- **功能**：粘贴名单（每行一人）→ 选组数 → 随机分配 → 手动微调 → 复制/打印结果
- **设计**：textarea 输入 + 分组数选择 + 名单卡片分组展示
- **入口**：`tools/group-splitter/index.html`

### T3 游戏环节计时器 · P0
- **用途**：团建流程控场，多环节倒计时
- **功能**：预设环节列表（名称+时长）→ 逐个开始 → 全屏倒计时 → 结束提示音 → 下一环节
- **入口**：`tools/timer/index.html`

### G1 两真一假 · 线上版 · P0
- **用途**：破冰神器，远程/线下都可用
- **玩法**：主持人开新局 → 每位玩家出题（两个真话一个假话）→ 全员投票（大屏点选）→ 揭晓 → 计分 → 排行榜
- **无后端方案**：单设备主持模式，轮流出题+全员围观投票；结果本地计算
- **配套文章**：破冰篇·两真一假（已写）
- **入口**：`games/two-truths-one-lie/index.html`

### G2 人类宾果 · 在线版 · P0
- **用途**：线上破冰，互相发现共同点
- **玩法**：主持人选格子池 → 每人生成不同 5×5 卡 → 主持人喊特征 → 玩家点卡标记 → BINGO 判定
- **无后端方案**：主持模式（大屏生成卡+喊格）+ 玩家模式（自己手机点卡）；卡片 localStorage 保存
- **配套文章**：破冰篇·人类宾果（已写）
- **入口**：`games/human-bingo/index.html`

### G3 团队知识竞答 · P0
- **用途**：线上团建知识竞赛，可定制公司文化题
- **玩法**：题库（预置 + 可导入自定义）→ 主持人出题 → 限时抢答 → 计分排行
- **入口**：`games/team-quiz/index.html`

## 技术规范（所有产品必须遵守）

1. **纯前端单文件**：每个产品一个 `index.html`，CSS/JS 内联，零外部依赖（不引 CDN，离线可用）。
2. **移动优先**：430px 竖屏设计基线，触摸友好，大屏自适应。
3. **无后端**：所有游戏为「主持模式 + 同屏/本地存储」实现，保证 100% 可玩。
4. **统一风格**：浅色主题、圆角卡片、大按钮，与游戏库 `index.html` 视觉一致。
5. **底部互链**：每个页面底部含「返回产品总览」与「配套文章/游戏库」入口。
