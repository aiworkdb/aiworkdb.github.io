# 团建在线工具与在线游戏 · 产品开发说明

> **一句话目标**：把仓库里 58 款团建游戏 + 81 款桌游 + 24 篇公众号文章的内容资产，转化为「教练可用的在线工具」和「团队可玩的在线游戏」，用**文章引流 → 工具/游戏承接 → 服务转化**的闭环放大价值。
> **配套使用**：本说明与 `wechat/` 公众号系列、`README.md` 游戏索引联动，每个产品均标注配套文章来源。

---

## 一、背景与目标

### 1.1 为什么做

当前仓库**内容资产极其丰富，但数字化产品寥寥**：

| 资产类型 | 数量 | 现状 |
|---------|------|------|
| 团建游戏文档 | 58 款 | ✅ 全部有完整 6 段式文档 |
| 桌游文档 | 81 款 | ✅ 全部有规则文档 |
| 团建流程方案 | 6 套 | ✅ 一日/半日/工作坊/线上/新员工/跨部门 |
| 教练工具箱 | 4 个 | ✅ 话术/复盘/安全/物资 |
| 公众号文章 | 24 篇已写 + 80+ 篇规划 | ✅ 破冰8篇、协作10篇、IP6篇 |
| **在线工具** | **1 个** | ⚠️ 仅「团建方案生成器」 |
| **在线游戏** | **3 个** | ⚠️ 宾果、重力翻转、双生逆行（分散且未联动文章） |

**核心矛盾**：文章里介绍的游戏「读者想看但玩不到」，文档里的游戏「教练想用但要靠手工准备」。数字化工具与游戏，正是把内容资产变成**可体验、可传播、可转化**产品的关键一环。

### 1.2 目标

1. **内容变现**：58 款游戏 → 至少 15 款拥有在线工具/游戏形态，成为公众号文章的"可玩化"落点。
2. **涨粉钩子**：每篇文章末尾 CTA → 引导体验对应在线工具/游戏，工具页底部反哺关注公众号，形成循环。
3. **服务展示**：线上互动工具成为对外展示专业能力的「活名片」，承接团建服务咨询。
4. **技术收敛**：全部为纯前端单文件 HTML（与现有仓库一致），GitHub Pages 零成本部署，无需后端。

## 三、差距分析（内容 vs 数字化）

```
文章/文档层（内容资产，充足）         产品层（数字化，严重不足）
─────────────────────────────       ─────────────────────────────
58 款游戏文档   ──只有 1 款──▶  在线游戏（宾果）
24 篇文章      ──没有──▶      文章对应可玩工具
6 套流程方案   ──只有 1 个──▶  方案生成器（弱）
81 款桌游      ──只有 1 个──▶  卡牌生成器（未联动）
4 个工具箱     ──没有──▶      话术/复盘/物资数字化工具
```

**三个结构性缺口**：
1. **线上团建场景无产品**：`online/` 5 款游戏只有宾果做了 HTML，其余 4 款（我从未、你画我猜、知识竞答、虚拟密室）只有文档。
2. **教练执行侧工具缺失**：分组、计时、计分、复盘、物资清单全靠教练手工。
3. **文章 ↔ 产品零互链**：24 篇文章没有任何一篇内置在线工具入口，产品页也没有公众号引流位。

## 五、分产品说明（P0 详细、P1/P2 简版）

### T1 团建方案生成器 2.0（升级现有）

- **用户**：HR / 团建策划 / 培训师
- **核心功能**：① 四维筛选（目的/形式/人数/时长）② 生成完整执行方案（时间轴 + 游戏卡片 + 引导话术 + 复盘问题 + 物资清单）③ 一键导出 Markdown/打印 ④ 方案收藏与分享链接
- **现状**：`generator.html` 已有基础框架，升级 UI 与导出能力
- **配套文章**：流程系列（一日团建模板、半日团建模板）
- **技术**：纯前端，`html2canvas`/`jsPDF` 可选 CDN
- **成功指标**：周访问 UV ≥ 200；从公众号文章跳转率 ≥ 5%

### T2 随机分组器

- **功能**：输入名单/人数 → 按预设规则（打散部门、男女比例、随机）生成分组 → 可微调、可导出
- **配套文章**：工具箱·分组方法
- **开发量**：0.5 天，单文件 HTML

### T3 游戏环节计时器

- **功能**：多轮次编排（每环节时长/名称）、全屏倒计时、结束提示音、中途暂停
- **配套文章**：流程方案文章（文中"控场"痛点）
- **开发量**：0.5 天

### G1 两真一假 · 线上版

- **玩法**：房主开房 → 玩家轮流出题（两个真话一个假话）→ 全员投票 → 揭晓 + 计分 → 排行榜
- **核心价值**：把线下最火的破冰游戏搬到线上，远程团队直接可玩；已写文章《两真一假》即可嵌入
- **技术**：无后端方案——同一设备传递模式（大屏主持 + 扫码投票，投票存 localStorage/URL 参数）；远期可接第三方房间服务
- **开发量**：3 天

### G2 人类宾果 · 在线版

- **玩法**：主持人设置格子内容池（支持自定义/从题库选）→ 每人生成不同 5×5 卡 → 主持人喊格 → 玩家自动标记 → 首位 BINGO 揭晓
- **核心价值**：现有 `online-bingo.html` 为静态卡，升级为「动态卡 + 主持模式」
- **配套文章**：破冰篇·人类宾果（已写）
- **开发量**：2 天

### G3 团队知识竞答

- **玩法**：主持人从题库出题（支持导入）→ 全员/分组抢答 → 限时计分 → 排行榜
- **核心价值**：文档 `team-quiz.md` 已有完整玩法，直接照做 HTML；题库可做公司文化定制（服务转化点）
- **开发量**：3 天

### 其余产品（P1/P2，简述）

|------|--------------|---------|
| T4 积分计分板 | 房间内多队伍加减分，大屏展示 | 数据同一设备，避免并发 |

## 六、文章 ↔ 产品联动机制（闭环设计）

### 6.1 文章侧（每篇公众号文章）

```
┌────────────────────────────────────────────┐
│  文章正文（游戏玩法拆解）                      │
│         ↓ 文末 CTA 卡片                       │
│  【玩一下】点击体验「XX 游戏 · 在线版」→ 工具页 │
│  【领资料】回复"游戏库" → 58款索引资料包        │
│  【找我们】团建服务咨询入口                    │
└────────────────────────────────────────────┘
```

### 6.2 工具/游戏侧（每个产品页）

```
┌────────────────────────────────────────────┐
│  产品主体（可玩/可用）                        │
│         ↓ 底部固定条                          │
│  📖 看这篇文章了解玩法 → 公众号文章链接         │
│  ⭐ 关注公众号，每周 2-3 个团建游戏            │
│  🔗 更多游戏 → 游戏库索引页                    │
└────────────────────────────────────────────┘
```

### 6.3 联动规则（开发时必须遵守）

1. 每个产品页底部必须含「配套文章」链接位与公众号引导位。
2. 已写的 24 篇文章，在发布时补挂对应产品链接（两真一假→G1、人类宾果→G2、岛屿求生→G8 等）。
3. 每篇**新文章**的产出流程固定为：先做产品 → 再写文章 → 文章内嵌产品（一次产出双交付物）。
4. `teambuilding/play/` 总览页同时是公众号菜单「在线玩」的落地页。
