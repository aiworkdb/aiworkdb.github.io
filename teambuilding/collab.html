🧭 六组分别是什么

🪢 身体默契 · 一动就知道（5 款）

不用讲道理，身体会先把问题暴露出来——全组被「卡住」的那一下，就是协作最真实的样子。
✅ 什么情况下选它
开场或破冰后的第一个协作环节 / 只有 20–45 分钟 / 没道具没桌子 / 队伍还互相不认识。
⛔ 什么时候别选它
想复盘「资源怎么分」「信息怎么传」这类组织问题时别选：它照出来的是身体同步，迁移不到流程上。

🍳 瓶颈与流水线 · 卡在哪一工位（6 款）

交付是一串环节，不是一堆人。任一工位堵住全队都堵——而堵点往往不是最弱的那一个。
✅ 什么情况下选它
「每个人都很忙，整体却不前进」/ 刚做完一轮交付想复盘流程 / 要讲局部最优害全局。
⛔ 什么时候别选它
少于 4 人（凑不出多个工位），或真正的问题是「人不愿意开口」——那是沟通类，不是这一类。

🧭 资源与取舍 · 不够分的时候怎么办（9 款）

总量是固定的，给这边就没那边。真正的分歧不在「怎么分」，在「先保哪一个」。
✅ 什么情况下选它
要练取舍 / 长期主义 vs 救火 / 跨部门抢资源 / 预算被砍之后的优先级共识。
⛔ 什么时候别选它
团队还互相不熟（没信任时取舍会变成吵架），或只想做一场轻松的活动。

🔦 信息不对称 · 谁手里有那块拼图（7 款）

真相分散在每个人手里，谁的都不全。不互通就一定做不成——而「我以为对方知道」是最贵的错觉。
✅ 什么情况下选它
跨职能团队 / 出过「我以为你处理了」这类事 / 要讲信息孤岛与主动同步。
⛔ 什么时候别选它
彼此不信任时别选：信息会被当成筹码藏着，复盘会跑偏到人际关系上。

🎭 角色互补 · 不一样才需要配合（8 款）

每人能力不同、视角不同，谁都没法单独完成。练的是「认别人的账」和「把后背交给专才」。
✅ 什么情况下选它
职能差异大的团队（研发 / 销售 / 运营）/ 要练传帮带 / 想讲「能者多劳」是怎么拖垮团队的。
⛔ 什么时候别选它
少于 3 人（角色凑不齐），或只想做一场所有人同质参与的活动。

🏗️ 共享总账 · 一荣俱荣的那本看不见的账（4 款）

各小组都在忙自己的活，头顶却挂着一本全队共享的账（健康度 / 繁荣指数 / 结界能量 / 经验沉淀）。它掉下去，没人能单独赢。
✅ 什么情况下选它
要讲部门墙 / 局部最优害全局 / 组织健康度 / 长期主义；其中未来城市建造师、丝绸之路支持 6–12 人分多组同时开局。
⛔ 什么时候别选它
只有一个小组（这一类的张力全来自组与组之间），或时间少于 45 分钟。

⚠️ 三个最容易挑错的地方

坑为什么
想练「说清楚 / 问明白」别在协作里找协作 39 款里只有「🔦 信息不对称」这组跟沟通沾边，其余练的是配合。真要练表达，去 💬 沟通表达（8 款）。
人数少于 4 人时，两类开不起来🍳 瓶颈与流水线（要多个工位）和 🏗️ 共享总账（要多个小组）都靠「组」产生张力，人少了只能从 🪢 / 🧭 / 🔦 / 🎭 四组里挑。
赶时间先看前两组🪢 身体默契（20–45 min）和 🍳 瓶颈与流水线（30–90 min）里有多款 45 分钟以内的；🧭 / 🎭 / 🏗️ 三组最短也要 45 min。
协作是全库最大的分类（39/85，46%），但它同时也是最容易被误用的一个：很多人想解决的其实是「沟通」或「信任」，却在协作里翻了半天。先确认你要的是「一起把事做成」，再回来挑。
