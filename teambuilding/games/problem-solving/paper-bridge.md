# 纸桥承重赛（Paper Bridge）

> **一句话**：几张 A4 纸、30 厘米跨度、不断加码的配重——结构的事，往往不是「更用力」而是「换个形状」。

| **游戏名称** | 纸桥承重赛（Paper Bridge） |
| **目的标签** | 问题解决 · 结构思维 · 迭代优化 |
| **形式标签** | 室内 · 分组 · 桌面 |
| **人数** | 建议 每组 3–5 人 |
| **时长** | 40–55 min |
| **难度** | ⭐⭐ 中等（规则简单，优化空间极大） |
| **道具需求** | 有（A4 纸 + 胶带 + 配重硬币） |
| **场景标签** | 团建 · 培训 · 工程思维工作坊 |
| **核心目标** | 在有限材料下做多轮承重测试，体验「结构改造 > 材料堆叠」和「每次只改一个变量」 |

---

**团建核心价值**：
- 🏗️ 结构思维：形状决定承载力，不是厚度
- 🔬 单变量迭代：一次只改一件事，才知道什么起作用
- 📉 失败数据化：塌了也要知道塌在多少克
- 🧠 约束创新：材料固定，唯一变量是设计

## 1. 游戏概览

两张 A4 纸，架在 25 厘米的跨度上，能承多重？多数人第一反应是「折厚一点」，结果只能扛住几百克。而把纸折成瓦楞、卷成筒、做成三角桁架，同一张纸能扛起几公斤。

这个游戏的设计要点在于**测试是公开、连续、可量化的**：每加一次配重就报一次数，所有人都听得见。于是团队会自然进入一个循环——测、塌、改、再测。

而这个循环里最容易犯的错，是**一次改三个地方**。改完塌了，谁也不知道是哪个改动导致的；改完成功了，也不知道该保留哪一条。教练的任务就是把「单变量」这条科学方法，用一次真实的塌桥讲明白。

## 2. 核心规则

### 准备（每组）

| 物资 | 数量 |
|---|---|
| A4 纸（80g 普通复印纸） | 4 张 |
| 胶带（透明胶，1.5cm） | 30 厘米 |
| 桥墩（两叠书或两块砖，等高水平） | 2 个 |
| 加载物（矿泉水瓶装水 / 砝码 / 硬币卷） | 若干 |
| 承载板（硬纸板 10×10cm，用来均匀受力） | 1 块 |

### 流程

1. **公布规则 + 给 3 分钟讨论**（不能动手）
2. **第一轮搭建 10 分钟** → 测试承重 → 记录数字
3. **第二次搭建 8 分钟**（可复用材料，但纸的折痕不能复原，这点要提前说）
4. **第二轮测试** → 记录
5. **第三轮 5 分钟**（只允许改一个地方）→ 最终测试
6. 公布成绩 + 复盘

### 规则细节（决定成败，务必讲清）

- 桥面**跨度 25 厘米**，两端各至少搭在桥墩上 3 厘米
- 桥必须**自己架住**，测试时手离开
- 加载板放在桥面正中，逐次加配重，**每次加完停 3 秒**，不塌即算成功
- 塌了就是塌了，不能「扶一下再算」
- 胶带只能用 30 厘米，用完为止（这条最容易被忽视，也最影响策略）

### 胜负判定

按最终承重排序。另设一个「效率奖」：承重 ÷ 用纸张数，鼓励用更少的材料做到更多——这一项往往比冠军更有讨论价值。

## 3. 引导要点

### 讲解脚本（1 分钟）

> 4 张纸、30 厘米胶带，架一座能跨 25 厘米的桥。中间放板子，往上加重量，看谁扛得住。
>
> 有一点要注意：每轮之间，你们只能改**一个地方**。为什么？待会儿你们就知道了。

### 教练在场边做什么

- **第一轮几乎全部会塌**，这是设计好的。不要提前说「你们要不要试试折成瓦楞」。
- 报数要大声、清晰：「第一组，1.2 公斤，成功」「第二组，800 克，塌了」。**数字的公开性是这个游戏的核心机制**。
- 第三轮「只改一处」是硬约束，要真的执行。有人偷改两处，提醒但不惩罚。
- 记录每组「三轮的承重变化曲线」，复盘时画出来，比任何说教都直观。

### 安全边界

- 配重用不易碎容器（水瓶、砝码），**不用玻璃**
- 桥墩要稳，不要用易倒的高叠物
- 塌落区域清空，手不要放在桥下

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 三轮的承重分别是多少？变化最大的那一轮，改了什么？
- 哪一组的「效率」（承重/用纸）最高？
- 塌的时候，断在哪一个位置？

### Feelings（感受）

- 第一次塌的时候，团队气氛怎么样？
- 数字被别人超过的时候，着急吗？着急之后改策略了吗？
- 第三轮只准改一处，是束缚还是帮助？

### Findings（发现）

- 为什么「折成瓦楞」比「叠厚」更有效？
- 我们每次改动的，是「结构」还是「细节」？
- 如果没有公开的承重数字，我们还能迭代得这么快吗？

### Future（应用）

- 我们工作里的「纸桥」是什么？（资源固定、目标明确的那个任务）
- 我们做优化时，是不是也常常一次改三件事，最后说不清哪个有效？
- 下次做 A/B 测试或方案对比，能不能只留一个变量？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 时间紧（25 分钟） | 只做两轮，第二轮必须改结构不能改细节 |
| 大团队 | 多组并行 + 每轮统一报数，制造「排行榜」氛围 |
| 低龄 / 非工程背景 | 材料换成报纸 + 吸管，规则不变 |
| 工程/研发团队 | 引入「预算」：每张纸 10 元、每 10cm 胶带 5 元，做成本-承重双目标 |
| 需要更强对抗 | 加「破坏环节」：允许对手用一颗乒乓球从 30cm 落下砸桥面 |
