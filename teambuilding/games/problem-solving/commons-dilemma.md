# 公共资源博弈（Commons Dilemma / 公地悲剧 · 捕鱼达人）

> **一句话**：湖里有一百条鱼，每个人都知道"多抓一条就多赚一条"，也都知道"都这么想，湖就空了"——然后湖真的空了。

| **游戏名称** | 公共资源博弈（Commons Dilemma / 公地悲剧 / 捕鱼达人 / 鱼塘博弈） |
| **目的标签** | 资源共享 · 承诺可信 · 长期与短期 |
| **形式标签** | 室内 · 多队并行 · 每轮秘密决策 |
| **人数** | 全场 30–200 人（分 4–8 队，每队 6–15 人） |
| **时长** | 120–180 min |
| **难度** | ⭐⭐⭐ 中等（规则 5 分钟，博弈 2 小时） |
| **道具需求** | 有（资源池记录板 + 每队决策卡 + 累计计分表 + 鱼形代币） |
| **场景标签** | 跨部门协作 · 资源分配 · 预算争夺 · 中高层 · 平台/产研 |
| **核心目标** | 让"每个人都理性"如何一步步毁掉公共资源，变成看得见的曲线 |

---

**团建核心价值**：
- 🐟 资源共享：一个池子，多支队伍，没有产权
- 🤝 承诺可信：可以谈判、可以结盟、可以不履约
- ⏳ 长期与短期：多抓一轮的收益，抵不过池子崩溃的代价
- 📉 不可逆：池子崩了，再生能力就回不去了

## 1. 游戏概览

一片湖，湖里有一群鱼。四到八支捕鱼队，每轮同时决定"这一轮抓多少"。抓上来的鱼就是收益，留在湖里的鱼会繁殖。

**每一轮每个人都能算清楚：多抓一条，自己立刻多赚一条。** 但如果所有人都这么想，湖会在某一轮突然空掉，之后再也恢复不了原来的水平。

**它和红黑游戏的区别（容易被混为一谈，其实完全不同）：**

| | 红黑游戏 | 公共资源博弈 |
|---|---|---|
| 参与者 | 两方 | **多方** |
| 资源 | 无（纯策略矩阵） | **有，且会再生** |
| 核心机制 | 囚徒困境（单次背叛最赚） | **公地悲剧（集体透支最赚，但会耗尽）** |
| 关键差别 | 没有"存量"概念 | **存量可观测、可量化、崩溃不可逆** |
| 教学落点 | 信任与背叛 | **透支与可持续** |

**为什么它对跨部门场景杀伤力最大**：因为它精确复刻了"抢共用资源"的日常——共用测试环境、共用预算池、共用设计师、共用数据权限。每个部门抢一点都是"合理的"，合起来就把资源池抽干了。

## 2. 核心规则

### 准备

- **场地**：会议室，每队一张桌，队与队之间**有视线遮挡**（可以用文件夹立起来），确保"秘密决策"
- **资源池记录板**：一块大白板，画成表格（轮次 / 本轮总捕捞 / 池中剩余 / 是否崩溃），**全场可见**
- **决策卡**：每队一套数字卡（0–20），每轮亮牌用
- **计分表**：每队 1 张，记录每轮自己的捕捞量与累计

### 核心参数（可直接执行）

| 项 | 数值 |
|---|---|
| 初始鱼量（K₀） | 100 条 |
| 队伍数 | 4–8 队 |
| 轮次 | 10 轮 |
| 每轮单队可捕 | 0–20 条（整数） |
| 繁殖率 | **剩余量 × 1.8**（向下取整） |
| 环境容量上限 | 150 条（超过则按 150 计） |
| 崩溃阈值 | 池中剩余 **< 20 条** |
| 崩溃后 | 繁殖率降为 **×1.2**，且容量上限降为 **60 条**（永久） |

> 💡 这组参数是**故意设计的**：如果 5 队、每队每轮抓 10 条，池子会稳定在 90–150 之间，可持续 10 轮。只要每队多抓 3 条（13 条/轮），池子会在第 4–5 轮崩。**临界点非常窄**，这正是真实资源争夺的样子。

### 规则

1. 每轮开始，讲师宣布"本轮开始"，各队在**30 秒内**秘密决定捕捞量，把数字卡扣在桌上
2. 全场同时亮牌，讲师汇总总捕捞量，从池中扣除
3. 剩余量按繁殖率计算，写入下一轮的池中存量（公开）
4. 每队把本轮捕捞量计入自己的累计
5. **第 5 轮结束后，公开累计排名**（这一步是设计好的，会显著加速崩溃）
6. 第 6–10 轮继续，规则不变
7. 第 10 轮结束，按**累计捕捞总量**排名
8. 全程允许：谈判、结盟、公开喊话、签"协议"、互相监督
9. 全程不允许：查看别人的决策卡、威胁人身、拒绝参与

### 关键设计点：允许谈判，但不强制履约

这是全项目的核心。规则必须明确：

> **你们可以谈，可以承诺，可以签协议，可以指定监督人。但没有任何机制强制履约。**

这句话一说出口，房间里的气氛会变。因为所有人都知道：**承诺是廉价的**。

### 流程（150 分钟）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 讲规则 | 10 min | 参数、结算方式、允许谈判 |
| 第 1–2 轮 | 15 min | 试水，多数队伍会保守 |
| 第 3–4 轮 | 20 min | 开始有人加量，出现第一次谈判 |
| **第 5 轮 + 公布排名** | 15 min | 公开累计排名 |
| 第 6–7 轮 | 20 min | 竞争白热化，联盟开始瓦解 |
| 第 8–9 轮 | 20 min | 池子接近崩溃，出现"最后捞一把" |
| 第 10 轮 | 10 min | 终局 |
| 结算 + 复盘 | 40 min | 见第 4 节 |

## 3. 引导要点

### 讲解脚本（3 分钟）

> 湖里有一百条鱼。你们四到八支队伍，一共抓十轮。
>
> 每轮你们同时决定抓多少，最多二十条。抓上来的，就是你们的。
>
> 抓完之后，湖里剩下的鱼会繁殖——**剩下多少，乘以 1.8**。上限一百五十条。
>
> 但有一个问题：**如果湖里剩下不到二十条，这个湖就废了。** 之后繁殖能力永久下降，上限掉到六十条。
>
> 你们可以谈判。可以约定"大家都抓八条"。可以指定一个人监督。**但没有任何机制强制你们守约。**
>
> 现在，第一轮，三十秒。

### 教练在场边做什么

- **必须严格执行"同时亮牌"**。一旦有人先看到别人的数字，博弈就退化成跟随
- **只报数字，不做评论**。"本轮总捕捞 52 条，池中剩余 48 条，繁殖后 86 条。"——就这样，一个字都不多说
- **第 5 轮公布排名时，只念数字**。不要点评"某某队领先很多"，那会变成羞辱
- **记录四类素材**：① 谁最先提出"我们要节制" ② 谁最先违约 ③ 有没有出现监督机制 ④ 崩溃那一刻房间的声音
- **池子崩溃后什么都不说**。让沉默持续 15 秒
- **不要救场**。有队伍喊"教练这样不公平"，回答"规则就是这样"，然后继续

### 四个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 集体透支 | 前 3 轮各队都抓 12–15 条，第 4 轮崩 | 每个人都做"局部最优"，没人做"总量核算" |
| 承诺失效 | 谈好各抓 8 条，第 6 轮有人抓 14 条 | 违约无成本，且违约者短期收益最高 |
| 最后捞一把 | 池子快崩时，反而有人加大捕捞 | "反正要崩，不如我多拿" |
| 指责循环 | 崩溃后互相指责"是你们先超的" | 没有共同的核算机制，只有各自的记忆 |

### 语言禁区

- ❌「你们这样会把池子抽干的」——直接给答案，游戏结束
- ❌「大家要有点大局观」——说教，且暗示"应该牺牲"
- ✅「上一轮池子里剩多少？这一轮你们打算抓多少？依据是什么？」
- ✅「刚才那个约定，你们打算怎么保证它被执行？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 池子在第几轮崩溃？崩溃前一轮的剩余量是多少？
- 全场有没有出现过明确的"约定"？约定的数字是多少？实际执行了几轮？
- 第 5 轮公布排名之后，总捕捞量是上升还是下降？升了多少？
- 累计第一名是"抓得最多的"，还是"抓得最久的"？

### Feelings（感受）

- 第一轮你写下的数字，比"可持续量"多还是少？为什么？
- 有人说"我们约定都抓 8 条"时，你信吗？
- 池子崩的那一轮，你什么感觉？（愤怒？无所谓？还是"果然如此"？）

### Findings（发现）

- 为什么"每个人都理性"会导致集体毁灭？（因为理性是按自己的收益算的，不是按池子的存量算的）
- 为什么"允许谈判但不强制履约"，会让承诺迅速贬值？
- 为什么第 5 轮公布排名，会加速崩溃？（排名把"长期合作"变成"短期竞赛"）
- 崩溃之后为什么恢复不了？（因为繁殖率与容量上限被永久下调——现实里对应"信任"和"团队士气"）
- 抓得最多的那队，真的是赢家吗？（累计排名 vs 池子终值，两个榜往往不一致）

### Future（应用）

- 我们公司/部门里，有没有一个"湖"？（共用预算、共用人力、共用环境、共用客户资源）
- 我们有没有"总量核算"的机制？还是每个人只算自己的账？
- 我们达成的跨部门约定，靠什么保证执行？还是靠"大家自觉"？
- 上一次资源被透支，是谁先动手的？他当时是不是也觉得"很合理"？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（30 以下） | 4 队，每队 6–8 人；轮次缩到 8 轮 |
| 人数多（150–200） | 8 队分两组，各开一个湖（互不知情），最后对比两个湖的结局 |
| 只做 60 分钟 | 6 轮，取消第 5 轮排名公布（会得到更"合作"的结果，适合讲"可持续"） |
| 想讲"监管" | 第 7 轮开始，允许全场投票设立"捕捞上限"（观察：上限能不能被自发执行） |
| 想讲"信息" | 不公开池中剩余量，只公布"崩溃/未崩溃"（信息缺失下会更早崩） |
| 想讲"产权" | 把湖分成 4 块，各队只在自己那块捕（公地变成私地，结果会完全不同） |
| 想强化"跨部门" | 每队必须含 3 个以上部门，且队内也要"内部谈判" |
| 线上版 | 用共享表格 + 私聊收数，讲师逐轮公布 |

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 资源池记录板（大白板） | 1 块 | 全场可见，逐轮更新 |
| 决策卡（0–20） | 每队 1 套 | 必须扣牌，禁止偷看 |
| 计分表 | 每队 1 张 | 记录每轮捕捞与累计 |
| 鱼形代币（或棋子） | 150–200 个 | 视觉化"湖里还有多少"，效果远好于只写数字 |
| 遮挡板（文件夹立起） | 每队 2 个 | 保证秘密决策 |
| 计时器 | 1 个 | 30 秒决策必须严格 |
| 大白纸 + 马克笔 | 若干 | 供队伍自己写"协议"（**签协议这个动作很重要，一定要允许**） |
| 奖品 | 1–3 个 | 累计第一 / 池子终值最高（两个奖，制造反差） |
