# 城市定向（City Orientation / 极速前进 · 城市寻宝）

> **一句话**：三小时、二十个点位、一张积分榜——分最多的队，通常不是跑得最快的，是**最先决定"放弃哪几个点"的**。

| **游戏名称** | 城市定向（City Orientation / 极速前进 / 城市寻宝 / 定向闯关） |
| **目的标签** | 路线规划 · 时间预算 · 取舍决策 |
| **形式标签** | 户外城市街区 / 景区 · 小队分散行动 · 步行/公共交通 |
| **人数** | 全场 50–300 人（分 10–40 队，每队 5–8 人） |
| **时长** | 180–300 min（半天） |
| **难度** | ⭐⭐⭐ 中等（走路不难，取舍极难） |
| **道具需求** | 有（任务小程序/纸质任务书 + 队旗 + 号码牌 + 少量现金） |
| **场景标签** | 城市团建 · 新员工 · 跨部门 · 年会 · 外地会议配套 |
| **核心目标** | 用"点太多、时间不够"，逼出真正的优先级决策 |

---

**团建核心价值**：
- 🗺️ 路线规划：点位分散，必须先算再走
- ⏱️ 时间预算：3 小时能走几个点，是可以算出来的
- ✂️ 取舍决策：**放弃哪些点**，比拿到哪些点更能看出团队的判断力
- 👥 分工落地：导航、计时、拍照、记账、对外沟通，五个角色缺一不可

## 1. 游戏概览

把一座城市（或一个景区/园区）变成棋盘：设 15–30 个点位，每队按自己的路线去打卡、完成任务、拿积分，限时回到终点。

**它和"徒步/拉练"的区别**：走路只是载体，真正的内容是**决策**。

**它天然具备四个分维度**（这也是它比单一游戏更适合大场的原因）：

| 维度 | 怎么体现 | 考察什么 |
|---|---|---|
| 智力 | 点位问答题、解谜、找线索 | 信息处理 |
| 体力 | 步行距离、爬楼、限时冲刺 | 执行耐力 |
| 策略 | 路线组合、点位取舍、队友分工 | 规划能力 |
| 运气 | 随机事件卡、隐藏点位 | 应变心态 |

**为什么它对 50 人以上特别好用**：它天然是"分散"的。200 人分成 40 队散在城市里，不会互相干扰，也不需要大场地。这是极少数"人越多越不拥挤"的大场项目。

## 2. 核心规则

### 准备

- **范围**：以终点为圆心，半径 **2 公里**内（步行 15 分钟内可达）。范围太大，时间全耗在路上
- **点位数量**：**15–25 个**。经验值：**点位数 ≈ 队数 × 1.5**（20 队 → 30 个点，保证每队路线不同、不撞车）
- **点位类型**：

| 类型 | 数量 | 分值 | 说明 |
|---|---|---|---|
| **基础点** | 8–12 | 10 分 | 拍照打卡即可，用来"保底" |
| **挑战点** | 5–8 | 20–30 分 | 需要完成任务（答题/解谜/与路人互动/采购特定物品） |
| **隐藏点** | 3–5 | 40 分 | 不在地图上，靠线索推理或随机事件解锁 |
| **终点任务** | 1 | 50 分 | 全员到齐后完成（如拼图/合影造型） |

- **时间窗**：**3 小时**（含往返）。**超时扣分：每超 1 分钟扣 5 分**（这条必须严格执行）
- **交通**：默认**步行 + 公共交通**；**禁止打车/自驾**（安全与公平）
- **每队配**：队旗 1 面、号码牌、任务书/小程序、**50 元应急现金**、1 部充满电的手机 + 充电宝

### 规则

1. 每队 **5–8 人**，出发前 **15 分钟**看地图、定路线（这 15 分钟是全场最重要的时间）
2. 全员必须**同时到达**点位才算打卡（防止有人代打）
3. 打卡方式：小程序 GPS 定位 + 拍照（照片必须含队旗或号码牌）
4. **每队必须至少完成 3 个基础点**，否则终点任务不计分（防止只赌高分点）
5. 挑战点失败不扣分，但**消耗时间**
6. 隐藏点线索在出发时发放（每条线索指向 1 个隐藏点，也可能指向空）
7. 终点按**到达顺序**额外加分：第 1 名 +30，第 2 名 +20，第 3 名 +10
8. **安全规则（硬性）**：不许闯红灯、不许翻越护栏、不许进入施工区域、不许单独离队超过 50 米
9. 任何队员身体不适 → 立即全队停止，联系安全员（**该队成绩保留**）

### 计分示例

| 项 | 分值 |
|---|---|
| 基础点 × 10 | 最多 120 |
| 挑战点 × 25 | 最多 200 |
| 隐藏点 × 40 | 最多 160 |
| 终点任务 | 50 |
| 到达顺序加分 | 30 / 20 / 10 |
| 超时扣分 | −5 / 分钟 |

> 💡 **设计要点**：让"理论满分"远高于"实际可得"。比如理论满分 560，而 3 小时只够拿 250–320。这样"取舍"才是真问题。如果满分轻松可达，项目就退化成"体力赛"。

### 流程（半天版）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 集合 + 规则 | 20 min | 发任务书、讲安全、讲计分 |
| **路线规划** | 15 min | 各队原地定路线（**不许提前出发**） |
| 出发（分批） | 5 min | 每 1 分钟发 1 队，避免跟随 |
| 城市任务 | 180 min | 自由行动 |
| 返回 + 终点任务 | 20 min | 全员到齐后完成终点任务 |
| 统计 + 复盘 | 30 min | 见第 4 节 |

## 3. 引导要点

### 讲解脚本（4 分钟）

> 二十多个点位，三个小时。**你们不可能全拿到。**
>
> 基础点十分，挑战点二十五，隐藏点四十。超时每分钟扣五分。
>
> 所以等一下你们会有十五分钟，站在原地把路线定下来。**这十五分钟比后面三小时更重要。**
>
> 安全三句：不闯红灯、不翻护栏、不单独离队。
>
> 最后一句：**分最高的队，往往不是跑得最快的。** 是最先决定"哪些点我们不去了"的。

### 教练/安全员做什么

- **路线规划那 15 分钟必须盯**：有没有人在真的算距离？有没有人一提"我们全都要"就没人反对？
- **分批出发**，每 1 分钟一队。同时出发会导致所有队走同一条路
- **安全员分布**：在 3–4 个高风险路口/点位驻守，其余机动巡逻
- **实时看后台榜单**，但**不要向队伍公布排名**（公布会引发盲目冲刺，安全风险陡增）
- **记录"放弃决策"**：哪一队明确说了"这个点不去了"？是谁说的？有没有人反对？
- **超时严格执行**。第一次心软，后面所有队都会拖

### 四个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 贪多全都要 | 前 1 小时跑 8 个点，后 2 小时在路上 | 没算过"点均耗时" |
| 无分工 | 8 个人围着一个人看地图 | 没人被指定为"导航" |
| 沉没成本 | 为一个远点位走了 25 分钟，到了发现要排队 | 不会中途放弃 |
| 末尾崩盘 | 最后 20 分钟还在赶点，超时扣分吃光收益 | 没有"回程时间预算" |

### 语言禁区

- ❌「加油，我们能全拿！」——教练鼓励"全都要"，等于放弃项目主旨
- ❌「你们怎么才拿了这么点分」——结果导向的指责
- ✅「你们决定放弃几个点？谁决定的？」
- ✅「回程要走多久？现在几点？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 出发前那 15 分钟，你们做了什么？（算了距离？还是直接走了？）
- 最终拿了几个点位？主动放弃了几个？
- 有几次是"走到一半决定放弃"？那一次损失了多少时间？
- 有没有超时？超了几分钟？
- 队里谁负责导航、谁负责计时、谁负责记录？

### Feelings（感受）

- 看到别的队跑向一个你们放弃了的点位，什么感觉？
- 决定放弃某个点时，队里有争议吗？
- 最后冲刺阶段，什么感觉？

### Findings（发现）

- 为什么"分最高的队不是跑得最快的"？（因为分数来自选择，不来自速度）
- 为什么必须"至少完成 3 个基础点"？（防止赌徒心态，也保证基本盘）
- "点均耗时"这个概念，你们是什么时候才意识到的？
- 放弃一个点位时，最难的是什么？（是算不清，还是不甘心）

### Future（应用）

- 我们做项目时，有没有"先算点均耗时再排期"？
- 我们有没有明确说过"这件事我们不做了"？（大多数团队只会加，不会减）
- 我们的分工，是出发前定的，还是跑起来才自然形成的？
- 上一次"沉没成本"把我们拖垮，是什么项目？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（30–50） | 6–8 队，点位 12–15 个，半径缩到 1.5 km |
| 人数多（200–300） | 40 队分批出发（每 30 秒 1 队）；点位 30–40 个；增加安全员到 10 人以上 |
| 园区/厂区版 | 不出园区，半径 1 km，点位 10–15 个，适合制造企业（安全可控） |
| 室内版（商场/展馆） | 楼层即"地形"，点位设在店铺/展项，1.5 小时可完成 |
| 只有 2 小时 | 点位 8–10 个，半径 1 km，只保留基础点 + 2 个挑战点 |
| 想强化"信息" | 隐藏点线索改为"必须向路人询问"才能获得 |
| 想强化"资源" | 给每队 100 元"预算"，交通/门票/道具都要花钱，模拟成本约束 |
| 想弱化体力 | 增加答题/解谜类挑战点，减少步行距离 |
| 新员工专场 | 点位设在公司各部门/工位，任务是与老员工合影+问一个问题（融入效果极佳） |

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 任务小程序 / 纸质任务书 | 每队 1 套 | 纸质必须有备份（手机没电/无信号） |
| 队旗 | 每队 1 面 | 拍照凭证，必须出现在每张打卡照里 |
| 号码牌 | 每人 1 个 | 便于安全员识别与清点 |
| 地图（打印 A3） | 每队 2 张 | 标点位与编号；**不要标分值**（逼他们看任务书） |
| 线索卡 | 每队 1 套（3–5 张） | 隐藏点线索 |
| 应急现金 | 每队 50 元 | 交通/应急 |
| 充电宝 | 每队 1 个 | 手机没电 = 全队失联 |
| 安全员袖标 + 对讲机 | 按安全员数 | 必须能互通 |
| 计时器 / 大钟 | 1 个（终点） | 超时判定 |
| 记分板 | 1 块 | 终点统计 |
| 医药包 | 2 套 + 随队 1 套 | 扭伤、中暑 |
