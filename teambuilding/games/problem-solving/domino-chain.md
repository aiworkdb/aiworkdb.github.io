# 多米诺连锁（Domino Chain Reaction）

> **一句话**：每组只做一小段，接口必须对上——整条链能不能倒下去，取决于两个组交接处那一厘米。

| **游戏名称** | 多米诺连锁（Domino Chain / 接力连锁反应） |
| **目的标签** | 跨组协作 · 接口标准 · 全局视角 |
| **形式标签** | 室内 · 多组接力 · 蹲姿/站姿 |
| **人数** | 建议 每组 4–8 人（全场 12–60 人，至少 3 组） |
| **时长** | 50–70 min |
| **难度** | ⭐⭐⭐ 偏高（单段都简单，接起来必翻车） |
| **道具需求** | 有（多米诺骨牌/扑克牌/麻将牌 每组 60–100 张 + 胶带 + 计时器） |
| **场景标签** | 大型团建 · 跨部门协作 · 年会 · 项目收尾 |
| **核心目标** | 用一次真实的「接口失败」，让各组体验局部完美 ≠ 整体成功 |

---

**团建核心价值**：
- 🔗 接口意识：组内怎么排都行，交接处必须统一标准
- 🏗️ 局部 vs 全局：每组都在做「自己那段最好」，结果全线卡住
- 📐 标准先于执行：不倒翁式的「先试再调」在长链上代价极高
- 🎉 高情绪回报：一次成功的长链倒塌，是团建里少见的「全场同时欢呼」

## 1. 游戏概览

这是大型团建里最有仪式感的一个项目，也是最容易翻车的一个。

玩法：全场分成若干组，每组负责一段「多米诺跑道」。各组独立设计自己那段的图案、间距、造型。最后所有段首尾相接，推倒第一张牌，看整条链能不能一路倒到底。

**每组单练时都能成功。** 但拼起来之后，第一次倒塌的成功率通常不到三成。

原因几乎永远是同一个：**交接处**。

- A 组最后一张牌间距 3 厘米，B 组第一张牌间距 5 厘米 → 能量不够，断了
- A 组结尾是向右转，B 组开头是向左转 → 方向反了，撞不上
- A 组把牌摆得离边界太近，B 组接不上 → 中间空了 10 厘米，谁也没负责

而最要命的是：**没有人觉得自己那组有问题。** 因为每组在自己的地盘上确实是成功的。

这就是这个项目的全部价值：**它把「接口」这件事变成物理的、可见的、会当场失败的东西。**

## 2. 核心规则

### 准备

- 场地：一条长桌拼起来，或清空的地面，长度按组数定（每组约 1.5–2 米）
- 道具：多米诺骨牌最好（每组 60–100 张）；没有的话用扑克牌（对折立起来）、麻将牌、书本、纸板条都能替代
- 地面必须**平整、无震动**（有人在旁边走路都会倒）
- 每组划出一段边界，用胶带标出**起点线和终点线**

### 规则

1. 每组负责一段，**段长相同**
2. 段内图案自由设计（直线、转弯、分叉、螺旋都行）
3. **段与段之间必须物理连通**：上一段的最后一张牌倒下时，必须能碰到下一段的第一张牌
4. 每段的两端（接口处）由**相邻两组的组长共同确认**
5. 全员完成后，由教练推倒第一张牌，一次机会
6. 中途断了，可以修，修完重新从断点之后推（但整链成功只算一次）

### 流程（60 分钟）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 分组 + 讲规则 | 5 min | 划段、发牌、讲接口要求 |
| 独立搭建 | 20 min | 各组在自己段内自由设计，可反复试倒 |
| **接口协商** | 8 min | 相邻组两两对接，确定间距/方向/高度 |
| 合并调试 | 12 min | 全线接通，局部试推（只推一小段） |
| 总倒塌 | 3 min | 教练推第一张，一次机会 |
| 复盘 | 12 min | 见第 4 节 |

**「接口协商」这 8 分钟必须单独留出来，且必须让相邻组面对面谈。** 如果不留，各组会一直到合并时才发现问题，那时改起来代价极大。

### 接口的三条硬标准（教练提前公布）

| 标准 | 要求 |
|---|---|
| 间距 | 交接处牌距 = **2.5 厘米**（全场统一，用一张对折的纸条当量尺） |
| 方向 | 交接处必须是**直线**，不许在接口处转弯 |
| 高度 | 牌必须同型号同规格（不同组不许混用不同尺寸的牌） |

这三条就是「接口协议」。公布之后不再改。

### 计分（可选）

| 项 | 分值 |
|---|---|
| 整链一次倒完 | 30 |
| 倒了 80% 以上 | 15 |
| 每段内图案有创意设计 | +5（教练评） |
| 提前完成 | +1/分钟 |
| 因接口问题断裂 | 该段 0 分（段内设计再好也 0） |

最后一条是重点：**接口失败，段内做得再漂亮也是 0 分。**

## 3. 引导要点

### 讲解脚本（3 分钟）

> 每组负责一段跑道，段内怎么设计你们自己定，越好看越好。
>
> 但有三条硬标准，是**全场统一**的：交接处间距 2.5 厘米、交接处必须走直线、牌必须同规格。
>
> 为什么这么严？因为**最后推倒的只有第一张牌**，后面全靠传导。任何一处间距不对，链就断在那里。
>
> 我要提前说一句：**你们组自己练的时候会成功，合起来大概率会断。** 断的地方，通常就在两个组的交界处。

### 教练在场边做什么

- **独立搭建阶段不干预**，甚至不要提醒「注意接口」——让他们先各自完美
- **接口协商阶段盯住一件事**：相邻两组有没有真的**面对面谈**？还是各派一个人隔空喊「你那边调到 2.5 就行」？
- **必须要求「实物验证」**：接口处必须由两组一起试倒一次，不许只靠口头确认
- **合并调试时只允许推本地段**（推 5 张看看），**不许提前推全链**——提前推会毁掉「一次机会」的紧张感
- **总倒塌前留 30 秒静场**：让所有人停手、退后、屏息。仪式感是这项目的另一半价值
- **断裂后不要立刻让修**。先让全场安静看 10 秒断点在哪，再开始修

### 三个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 间距不一致 | 一组 3 cm，一组 5 cm | 没有统一量具，靠眼估 |
| 方向不匹配 | 一组结尾右转，一组开头左转 | 接口处没人负责 |
| 越界侵占 | 一组摆到自己线外，另一组没地方了 | 边界只标了线，没人管 |

### 语言禁区

- ❌「你们这组拖后腿了」——接口问题从来不是单方责任
- ❌「早就说了要注意接口」（事后诸葛亮，且会引发对抗）
- ✅「断点在哪里？两边间距各是多少？」
- ✅「这个接口，谁是负责人？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 第一次总倒塌倒了几成？断在第几段的接口？
- 接口协商那 8 分钟，相邻组真的面对面谈了吗？谈了几分钟？
- 有几处接口是「口头确认」的？有几处是「实物试倒」的？
- 各组段内的设计复杂度，和接口处的严谨度，成比例吗？

### Feelings（感受）

- 自己那段单独成功的时候，什么感觉？
- 全链断在你们组旁边，什么感觉？（委屈？还是觉得不怪自己？）
- 整条链一路倒到底的时候，全场的反应是什么？

### Findings（发现）

- 为什么每组都能成功，合起来却失败？（因为「成功」的定义不一样：段内成功 ≠ 接口成功）
- 为什么接口最容易被忽略？（因为它在两组的边界上，**没有人的 KPI 覆盖它**）
- 「2.5 厘米」这个标准，为什么必须用**量具**而不是靠眼睛？（人眼估距的误差普遍在 30% 以上）
- 提前推全链和只推本地段，哪个更聪明？为什么？

### Future（应用）

- 我们项目里有没有「接口」？谁负责？（通常是：没人）
- 两个团队交接的地方，有没有统一标准？还是各做各的然后对接时吵？
- 我们的考核，是奖励「段内做得漂亮」还是「整链能跑通」？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（< 12） | 2 组即可，但至少要有 1 个接口，才能体现问题 |
| 人数多（> 60） | 分成「主干 + 分支」：主链由 4 组接力，其余组做侧链并入 |
| 没有多米诺骨牌 | 扑克牌对折立起（间距要改小）、麻将牌、书本、纸板条均可 |
| 想在室内桌面做 | 桌子拼成一条，牌用小号（4 厘米高），间距按比例缩到 1.5 厘米 |
| 时间只有 30 分钟 | 跳过「独立搭建」，直接从「接口协商 + 合并调试」开始 |
| 想加难度 | 加一个「必须有一段上坡/转弯」的强制要求 |
| 想突出「标准制定」 | 不给 2.5 厘米，让全场自己推选一个「标准委员会」定标准 |
| 年会 / 大型场 | 主题化：把长链摆成公司 logo 或年份数字，段边界提前画好 |

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 多米诺骨牌 | 每组 60–100 张 | 全场必须同规格；扑克牌/麻将牌可替代 |
| 美纹胶带 | 每组 1 卷 | 划段边界、标接口线 |
| 量尺纸条 | 每组 2 张 | 对折成 2.5 厘米宽度，当统一量具 |
| 平整桌面 / 地面 | 全长贯通 | 必须平整、无震动；旁边禁止走动 |
| 计时器 | 1 个 | 各阶段控时 |
| 收纳盒 | 每组 1 个 | 装牌，防止混规格 |
| 相机 / 手机 | 1 台 | 记录倒塌全程，复盘时回放断点 |
