# 氦气棒（Helium Stick）

> **一句话**：所有人的手指都托着一根轻杆，任务是把它放到地上——但它一定会先往上飘，因为每个人都在往上抬。

| **游戏名称** | 氦气棒（Helium Stick / 漂浮杆） |
| **目的标签** | 协同控制 · 非语言协同 · 系统反馈 |
| **形式标签** | 室内外均可 · 全员 · 站姿 |
| **人数** | 建议 8–36 人（每组 8–12 人，可分多组同时进行） |
| **时长** | 20–30 min |
| **难度** | ⭐ 偏低（动作极简单，结果极反直觉） |
| **道具需求** | 有（轻质长杆 1 根/组 + 计时器） |
| **场景标签** | 团建 · 培训 · 大团队分组热身 |
| **核心目标** | 用一个「越用力越失败」的任务，让人亲身感受个体正确叠加成集体错误 |

---

**团建核心价值**：
- 🙌 协同控制：12 根手指同时托住一根杆，任何一个人用力都会失衡
- 🔄 系统反馈：每个人的「轻一点」在集体里变成了「抬起来」
- 🤐 非语言协同：可以不说话，靠节奏和呼吸对齐
- 😲 反直觉：第一次做的人几乎 100% 失败，且失败原因完全想错

## 1. 游戏概览

这是最便宜、最容易解释、也最容易让人当场愣住的一个项目。

道具就是一根很轻的杆——伸缩杆、晒衣杆、PVC 管、竹竿都行，越轻越好。玩法是：

> 两排人面对面站好，每人伸出一根食指，**把杆托在这排手指上**。任务是**所有人一起把杆放到地上**。全程每个人的手指都不能离开杆。

然后会发生一件所有人都没想到的事：**杆会往上飘。**

不是慢慢降，是往上升。全场会先安静两秒，然后爆笑，然后有人说「谁在抬啊」，然后所有人互相看，然后杆继续往上升。

原因很简单：每个人都在做一件「自以为正确」的小动作——**为了不让杆掉下去，手指会本能地往上顶一点**。12 个人各顶一点，杆就飞了。

这个游戏的杀伤力就在于：**没有一个人做错，但集体结果完全相反。** 这就是大部分组织问题的原型。

## 2. 核心规则

### 准备

- 杆：**越轻越好**，直径 2–4 厘米，长度按人数定（10 人约 1.5–2 米）
- 杆身必须光滑，无毛刺（手指要贴着滑）
- 场地：平整，每人站得下即可，不需要大空间
- 每人摘掉手表、戒指

### 基本规则

1. 两排人面对面站，相距约 60 厘米
2. 所有人伸出**同一只手**的食指，与肩同高
3. 把杆放在这一排手指上（教练放，或由一端的人放入）
4. 教练宣布开始，全员把杆降落到地面
5. **任何人的手指全程必须接触杆**，离开即重来
6. 杆落地即完成，计时记录

### 判定

| 情况 | 判定 |
|---|---|
| 杆接触地面 | 完成，记录用时 |
| 有人手指离开杆 | 本轮作废，从头开始 |
| 有人抓住杆（五指握住） | 本轮作废 |
| 杆一端触地倾斜落地 | 算完成（但要记录「不平稳落地」的情况） |

### 三轮递进

| 轮次 | 规则 | 通常结果 |
|---|---|---|
| 第一轮 | 不许说话 | 杆上升，2 分钟后仍悬在空中，超时失败 |
| 第二轮 | 可以说话 | 会有人喊「大家都轻一点」，成功率明显提高 |
| 第三轮 | 不许说话，但允许「一个人数拍子」 | 成功率最高，用时最短 |

**第三轮的关键发现**：有效的协同不需要所有人达成共识，只需要**一个节拍**。

### 加难变体（第二轮之后）

- 杆上放一个小球/纸杯，不许掉
- 全员闭眼
- 只允许用一只手的小指
- 人数增加到 16 人以上（难度陡增）

## 3. 引导要点

### 讲解脚本（90 秒）

> 规则很简单：所有人一根手指托着这根杆，**一起把它放到地上**。手指不许离开。
>
> 就这么简单。开始。
>
> （等 30 秒，杆开始上升时，什么都别说。）
>
> （通常有人会喊「怎么往上了」，这时才开口）**我没说不能往上。我说的是放到地上。**

关键在**不要提前解释「它会上升」**。提前说破，这个游戏就只剩一个笑话，没有了「发现自己做错了」的那一刻。

### 教练在场边做什么

- **第一阶段闭嘴**。让他们在困惑里待够 30–60 秒，这个困惑是全部价值
- **不要提示原因**。有人问「为什么会上升」，回答「你觉得呢？」
- **严格执法「手指不许离开」**。这条一松，团队就会开始「抬着走」，游戏失效
- **第二轮结束时间一句**：「刚才那句『大家都轻一点』，是谁说的？他说完，大家都照做了吗？」
- **第三轮前给一个提示**（只给这一句）：「你们可以试试，让一个人的声音变成所有人的节拍。」

### 为什么会上升（教练要能讲清）

> 每个人都在执行一个**局部正确**的策略：「我的手指要托住杆，不能让它掉。」
>
> 而「托住」这个动作，在物理上就是「施加一个向上的力」。
>
> 12 个人各施加一点点向上的力，合力就是明显的上升。
>
> **没有人做错。每个人都只是在防止失败。而所有人一起防止失败，就制造了失败。**

这段话是整个游戏的落点，务必讲。

### 语言禁区

- ❌「因为它很轻啊，所以会飘」（把物理原因当成答案，掩盖了行为原因）
- ❌「你们要配合好」（空话）
- ✅「刚才你手指用了多大的力？」
- ✅「你是在往下压，还是在往上托？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 第一轮杆升到了多高？花了多久才降到地？
- 第二轮有人喊「轻一点」之后，情况改善了吗？改善了多少？
- 第三轮用了多长时间？有没有出现一个统一的节拍？

### Feelings（感受）

- 杆往上飘的时候，你第一反应是什么？（以为自己搞错了？以为别人在捣乱？）
- 发现「其实是我自己在往上顶」的那一刻，什么感觉？
- 第三轮跑顺的时候，全场的氛围有什么变化？

### Findings（发现）

- 为什么每个人都做对，结果却全错？（局部最优 ≠ 全局最优）
- 「大家都轻一点」这句话为什么有效？（它把隐含假设说出来了）
- 为什么第三轮「一个人数拍子」比「所有人商量」更有效？（共识成本高，节拍成本低）
- 你在第一轮用的力，和以为自己用的力，一样吗？（人对自己输出的感知极不准确）

### Future（应用）

- 团队里有没有「每个人都在防止出问题，结果一起把事搞砸」的例子？
- 我们的流程里，有多少「保险动作」叠加起来变成了负担？（审批、复核、二次确认）
- 谁是我们团队里那个「数拍子」的人？有没有？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（< 8） | 6 人也能玩，但要用更短的杆（1 米）；难度会降低 |
| 人数多（> 36） | 分多组同时进行，最后比用时；或做「大赛」：每组 12 人，淘汰制 |
| 没有长杆 | 用拖把杆、扫帚柄（需擦净）、PVC 管、卷起的瑜伽垫均可 |
| 想加难度 | 杆上放一个装水的小纸杯，不许洒 |
| 想突出「信息不对称」 | 只让一半人知道「它会上升」，另一半不知道 |
| 想突出「领导」 | 第三轮指定一人为唯一可发声者，其余人只能听节拍 |
| 线上 / 远程 | 无法替代身体版。改为「共享光标」实验：多人同时控制一个光标画线 |
| 儿童 / 学生场 | 完全适用，且效果比成人更好（成人更容易「想太多」） |

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 轻质长杆 | 每组 1 根 | 伸缩杆/竹竿/PVC 管；越轻效果越好，重了不会上升 |
| 计时器 | 1 个 | 全场可见 |
| 小球 / 纸杯 | 每组 1 个 | 可选，加难变体用 |
| 卷尺 | 1 把 | 可选，量杆上升高度，复盘更有画面 |
| 湿巾 | 1 包 | 杆身擦净，手感更好 |
