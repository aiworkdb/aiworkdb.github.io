📌 定位与核心矛盾

核心矛盾

线上会议里 3 个人说了 80% 的话，剩下的人从头到尾没出声——而这在现场会议里几乎不会发生，因为你看得见他不说话。摄像头一关，沉默就变成隐形的。

本作把这件事做成三条硬规则：① 开口要投发言筹码（每人 3 枚，用完就没了）；② 开口必须凑齐三句发言单；③ 同一批建议先跑一轮匿名、再跑一轮实名，把两轮的结论摊在一起比。

🎯 团建价值

远程会议最常被抱怨的一句话是「这个会拉我干嘛」——但它极少被当成一个可以改的问题，通常被当成"线上会议就这样"。

现场会议里，谁没说话是一眼可见的事实；线上会议里，没说话的人和没来的人长得一模一样：一个黑屏的方格。于是发言自然向口才更好、职级更高、网络更顺的人集中，而团队会误以为"大家没意见"。

🔎 差异化定位

线上分类其余 6 款——线上宾果（轻量破冰）、我从未（暴露共同点）、画图猜词（表达与理解）、知识竞答（知识协同）、虚拟逃脱（同步解谜）、异步接力（跨时区交接）——关心的都是"事怎么往下走"。

本款关心的是"话是谁在说"。它是线上分类里唯一一款：把发言权做成可点数资源；用同一批建议、两种署名状态测出这个团队的会议到底按什么决策；并把「零发言人数」写进胜利条件。

它刻意让团队看见一个平时看不见的东西：同一句话，署上名字之后，分量会变。

🧩 核心机制

1. 共享「共识值」（0-12）⭐

全组唯一计分。起始 6（6 代表"会开得下去"，不是真好），目标 ≥ 10，归零则「会白开了」全体失败，直接进复盘。每次变动都必须当场说明理由。

2. 发言配额（每人 3 枚筹码）⭐

  • 每人在共享文档里有自己的一行：🎟️ 🎟️ 🎟️ + 姓名。
  • 开口之前必须划掉一枚，并当场写下三句发言单。筹码用完当日不再发言，可以写字、可以投表情，不能开麦。
  • 发言从"想说就说"变成"这是一笔有限的预算"。线上会议里最稀缺的不是时间，是均衡。

3. 三句发言单（缺一不许开麦）⭐

句句式缺了会怎样
① 我的判断我认为应该 __别人不知道你到底主张什么
② 我的依据因为我看到 __变成纯立场，无法被检验
③ 我希望谁回应我想听 __ 说一句说完就散，责任落不到人身上

三句写全 → 划掉一枚筹码，开麦；缺第 ③ 句 → 教练当场打断，该次不计消耗但不许继续说。

4. 匿名轮（本作灵魂）⭐

第一轮 12 分钟：全员闭麦 + 关摄像头，只许在匿名便签区写建议。

每人发到一种颜色，只有匿名官知道颜色对应谁。便签上不许署名、不许写只有自己部门才懂的黑话。期间禁止讨论、禁止追问——这一轮的全部价值在于让内容先于身份出现。写完后全组无记名投 3 票，票数当场公开。

5. 实名轮（第二轮）

  • 第二轮 15 分钟：开麦，逐条讨论第一轮产生的同一批建议，重新投票。
  • 讨论规则照常：投筹码、凑三句、不许打断。
  • 教练把两轮的票数并排写在白板上——这就是本作要拿出来的证据。

6. 翻转计数（本作特有）

翻转＝匿名轮进了前 3、实名轮却掉出前 3 的建议。每条翻转，共识值 −2，并在白板上标一个 🔄。翻转 ≥ 3 条 → 直接触发特殊失败「按人投票」，不再计胜。

设计意图：翻转说明这条建议在内容没变的情况下被重新评判了——变的只有"现在知道是谁说的"。

7. 让麦（把话递出去）

任何人可以说一句「我想先听 __ 的」，把发言权让给本轮还没说过话的人：每次 +1（本轮上限 +3）。被让的人仍然要投自己的筹码——让麦让的是顺序，不是预算。

8. 共识值变动表

情形变化
匿名轮产出 ≥ 人数 × 1.5 条建议+2
匿名轮有人开麦 / 自称身份−2（每次，最严重）
实名轮每条被采纳建议都说清"采纳理由"+1（上限 +3）
有人主动让麦给还没说过话的人+1（本轮上限 +3）
打断 / 抢麦−1（每次）

结束时零发言人数 ≥ 3−3
说话最多的 2 人占比 ≤ 35%+2
说话最多的 2 人占比 > 50%−3

🎭 角色分工（5 种）

角色组织映射职责观察点（教练重点看）
🧭 议题主团队负责人 / 需求方提出一个真实的待决议题，并写清"这次要决定什么"是把议题写成选择题，还是丢一个开放话题让大家随便聊
🎙️ 发言者全体成员投筹码 → 凑三句 → 开麦是在说观点，还是在说情绪；第 ③ 句指名的是同级还是特定的人
🗂️ 记录员PMO / 观察员只记正字与翻转，全程不许发言团队能不能容忍一个人只记录不参与
⏱️ 计时官会议主持 / 运营管静默期与每轮时间盒，到点即喊停超时时团队是加时还是砍内容
🕵️ 匿名官教练兼任掌管匿名区，唯一知道颜色对应谁的人守不守得住匿名——守不住，本作立刻失效

6-8 人小团队：议题主 + 全员发言，记录员 / 计时官由教练一人兼任，匿名官必须仍由教练担任（不能交给组内任何人）。

🎲 游戏流程

准备（8 分钟）

  1. 提出一个真实的待决议题——必须是选择题，例如「下季度团建预算砍 30%，是砍场地还是砍天数？」「新人上手文档由谁维护，是轮值还是固定 Owner？」
  2. 建在线白板（Miro / 飞书白板 / 腾讯文档），划出三块：匿名便签区 / 发言筹码区 / 共识值刻度（0-12）
  3. 发颜色：每人一种，只有教练知道谁是谁；白板上只显示颜色名（🔴 🟢 🔵 …）
  4. 每人发 3 枚筹码（在筹码区自己那行画 🎟️🎟️🎟️）
  5. 约定时间盒：匿名轮 12 分钟 + 实名轮 15 分钟
1

第一轮 · 匿名轮（12 min）

全员闭麦 + 关摄像头，只许在匿名区写建议（每人至少 2 条）；禁止讨论与追问，疑问写进"疑问墙"留到第二轮；无记名投票 3 票，票数当场公开。

2

第二轮 · 实名轮（15 min）

开麦，逐条讨论第一轮那批建议并重新投票；每次发言划一枚筹码 + 三句发言单（缺第 ③ 句当场打断）。

3

并排对照

教练把两轮票数并排抄在白板上，标出所有 🔄——翻转是本作唯一的核心证据，不展示等于白做。

胜利条件（须同时满足三条）

条件阈值
✅ 共识值≥ 10
✅ 翻转数≤ 1
✅ 零发言人数= 0

共识值 ≤ 0 或 翻转 ≥ 3 → 「会白开了」 / 「按人投票」，全体失败，直接复盘。

⚠️ 双重特殊失败（各触发不同复盘方向）

🎭 失败 A：「按人投票」

  • 触发：翻转 ≥ 3 条。
  • 现象：匿名时排第一的建议，一旦知道是谁提的就被推翻了。内容一点没变，变的是署名。
  • 复盘方向：我们团队最近一次"方案本身没问题、但因为是谁提的所以没过"是什么时候？如果所有建议都匿名，我们上次会的结论会不一样吗？

🪑 失败 B：「配额富余」

  • 触发：结束时 ≥ 1/3 的人还剩 ≥ 2 枚筹码没用掉。
  • 现象：规则已经把机会让出来了，还是没人说。这比失败 A 更常见，也更难改——因为它说明问题不在"被抢麦"，而在"开口本身有成本"。
  • 复盘方向：剩下的那两枚筹码，是"没机会说"还是"说了也没用"？上一次团队里有人说了、但什么都没改变，是什么时候？

两种失败都不计胜，但都是极好的复盘素材。尤其失败 B——它揭示的不是会议技巧问题，是心理安全感问题。

🔍 4F 复盘框架（18 分钟）

阶段引导问题
Facts 事实匿名轮出了几条建议？实名轮翻转了几条（🔄 几个）？说话最多的 2 人占了多少？有几个人全程零发言？
Feelings 感受匿名那 12 分钟里，你写得比平时多还是少？
看到自己的建议被翻转时，第一反应是什么？
Findings 发现翻转的那几条，内容变了吗？如果没变，那变的是什么？
实名轮里说话最多的那个人，匿名轮里写得多吗？
Future 行动回到岗位，我们团队的例会能不能固定先跑 3 分钟匿名书写？
下一次开会，我打算把自己那枚筹码先用在第几句上？

落点

线上会议缺的从来不是"让大家发言"的号召，是让发言变得有限且可分配的规则。复盘时把匿名轮和实名轮的两张票数表并排贴出来——差别就是这次团建的全部结论。

🌀 变体玩法（7 种）

变体适用改法
1. 全匿名版想把压力降到最低取消实名轮，全程匿名（适合首次带、心理安全感偏低的团队）
2. 反序版想先测实名基线先跑实名、再跑匿名，对比方向相反，结论同样有效
3. 一票否决版决策型团队议题主实名轮结束前可一票否决，但必须当场说出否决理由
4. 黑话禁令想暴露术语壁垒匿名轮禁用本部门缩写与黑话，出现一次该条作废
5. 静默实名想练"憋住不说"实名轮只允许被教练点名的人开麦，其余人只许在文档里写
6. 反向配额想逼出沉默者先给每人 3 枚，但必须先让 3 名零发言者用完才能自由发言
7. 议题主闭麦想测职级影响议题主（通常是负责人）全程不准发言，只在最后说结论

🧭 教练注意事项

  1. 匿名官必须由教练本人担任——交给组内任何人，匿名轮都可能在 30 秒内被"我不小心说漏嘴"击穿。
  2. 匿名轮期间不许任何人开麦，包括"我补充一句""这个是不是指…"。破一次，本作立刻退化为普通讨论会。
  3. 第 ③ 句"我希望谁回应"必须当场打断式把关——它最容易被跳过，也最能决定这次会能不能落地。
  4. 两轮票数必须并排展示，且翻转要逐条标 🔄。翻转是本作唯一的核心证据，不展示等于白做。
  5. 不要评判谁说得多——教练只验收"共识值 / 翻转数 / 零发言人数"；失败 B 出现时尤其要克制，那是安全感问题不是态度问题。
