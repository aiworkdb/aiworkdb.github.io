# 💻 异步接力 · 交接不断线（线上团建版）

> 定位：全库**唯一一款异步**线上团建游戏
> 核心矛盾：你上线的时候，我不在线——交接便签写得清不清楚，决定了第二个人是**接着干**还是**重做**

## 🎯 团建价值

远程协作真正的难点，不是"大家不在一起"，而是**"你上线时我不在线"**。

同步协作里，一句"这个什么意思？"三秒就有答案；异步协作里，同样一句话要等一整个时区。于是大多数人选择了更省事的做法——**不看便签，自己重做一遍**。

本作把这件事做成三条硬规则：① 下线前必须写**三栏便签**；② 上线后**只能读便签**，不能问已下线的人（哪怕他就在群里）；③ 看不懂可以追问，但要付**回看税**，而且**下一棒才回答**。

### 🔎 差异化定位

线上分类其余 5 款——**我从没…**（破冰暴露）、**线上宾果**（轻量互动）、**你画我猜**（表达与理解）、**团队竞答**（知识协同）、**虚拟密室**（同步解谜）——全部是**同步实时**的：所有人同时在线，问题当场就能澄清。

**本款是线上分类里唯一一款异步游戏**，专攻跨时区 / 混合办公的**交接质量**；也是全库**唯一把「重做次数」做成核心扣分项**的一款。

它刻意剥夺了"当场问一句"这个选项，逼团队把"我停在哪里"写清楚——这是远程团队最缺、也最少被专门练习的一项能力。

## 🧩 核心机制

### 1. 共享「接力值」（0-12）⭐

全组**唯一计分**。起始 **4**（4 代表"还愿意看便签"，不是真交接），目标 **≥ 10**，归零则**「接力断线」**全体失败，直接进复盘。每次变动都必须**当场说明理由**。

### 2. 三栏便签（本作灵魂）⭐

每一棒**下线前**必须写一张便签，三栏缺一不可：

| 栏位 | 句式 | 缺了会怎样 |
| :--- | :--- | :--- |
| ① **我做了什么** | 我完成了 \_\_，改动在第 \_\_ 段 | 下一棒不知道现状是什么 |
| ② **我停在哪里** | 我停在 \_\_，**没做完的是** \_\_ | 下一棒以为做完了，或找不到断点 |
| ③ **下一步建议你先做** | 建议你先 \_\_，因为 \_\_ | 下一棒自己猜，大概率猜错方向 |

三栏写全 → 接力值 **+1**（每棒上限 +1）；缺任意一栏 → **−1**。

### 3. 只读写，不许问（最硬的一条）⭐

- 上线后有 **90 秒读签窗口**，期间**群内静默**，只允许读文档和便签。
- **已下线的人不得回答任何问题**——哪怕他就在群里、就在会议里。违反一次，接力值 **−1**。
- 这一条是本作全部的张力来源。教练必须真的执行，否则游戏立刻退化成普通同步协作。

### 4. 回看税（追问的成本）⭐

读不懂可以发**一条追问**，代价是：

- 接力值 **−1**（成本由提问的人付，不是由写便签的人付）
- **下一棒才回答**——模拟跨时区，提问的人必须**带着这个不确定性继续做**
- 追问被回答并写进下一张便签 → 该棒 **+1**（本棒封顶 +1）

> 设计意图：让"便签没写清"的代价**当场显形**，而不是让下一棒默默兜底。

### 5. 重做计数（本作特有）

后一棒**推翻并重写**前一棒已完成的部分，每次接力值 **−2**，并在便签区标一个 🔁。

> 远程团队最大的隐形浪费就在这里：不是没人干活，是同一件事被干了三遍。

### 6. 交付物验收（最后一棒）

最后一棒是**验收人**，他**只看交付物、不看过程**。必须说出一句：

> **「这解决了我的什么。」**

说得出 → 接力值 **+2**；说不出 → **−2**，且退回最后一棒重写便签。

### 7. 接力值变动表

| 情形 | 变化 |
| :--- | :--- |
| 三栏便签写全 | **+1**（每棒上限 +1） |
| 便签缺任意一栏 | **−1** |
| 后一棒照便签直接接上、无返工 | **+1** |
| **重做**前一棒已完成的部分 | **−2**（标 🔁） |
| 使用追问（回看税） | **−1** |
| 追问被回答并写进下一张便签 | **+1**（本棒封顶 +1） |
| 读签窗口内有人违规回答 | **−1** |
| 验收人说出"这解决了我的什么" | **+2** |
| 验收人说不出 | **−2**，退回重写便签 |

## 🎭 角色分工（6 种）

| 角色 | 组织映射 | 职责 | 观察点（教练重点看） |
| :--- | :--- | :--- | :--- |
| 🧭 **发起人** | 项目负责人 / 需求方 | 写第一张三栏便签，**定义"完成是什么"** | 有没有说清验收标准，还是只丢了个题目 |
| ✍️ **接力手 A / B / C** | 一线成员（分布在不同时区） | 读签 → 做事 → 写下线便签 | 是照着便签接上，还是推翻重来 |
| 🔍 **验收人** | 客户 / 需求方 / 接手方 | **只看交付物，不看过程** | 是认真验收还是走过场；说不说得出"这解决了我的什么" |
| 🗂️ **便签官** | PMO / 观察员 | **只整理便签时间线，不许参与内容** | 团队是否允许"被否决的意见"被留下来 |
| ⏱️ **计时官** | 会议主持 / 运营 | 管时间盒，到点即喊停 | 时间盒被超时时，团队是加时还是砍内容 |

> **棒组为 4-6 人**时：发起人 + 接力手 2-3 人 + 验收人，便签官与计时官由教练或其中一人兼任。

## 🎲 游戏流程

### 准备（8 分钟）

1. 分组（4-6 人一个棒组；超过 12 人分 2-3 组并行，各自开独立文档）
2. 建**一份共享文档**（腾讯文档 / 飞书 / 语雀 / Notion），群里开一个**便签区**
3. 约定一个**真实任务**——需要 4-6 棒才能完成的交付物，例如：
   - 「下季度团建方案初稿（含目标 / 形式 / 预算区间）」
   - 「新人上手指南 1.0（目录 + 前 3 节）」
   - 「我们团队异步协作公约（草案）」
4. 白板画 **0-12 接力值刻度**（起始 4）
5. 约定时间盒：**读签 90 秒 + 做事 6 分钟 + 写下线便签 90 秒**

### 每棒流程（3 步，共 5-6 棒）

1. **读签（90 秒）**：上线者读上一张三栏便签，**群内静默**，不许问
2. **做事（6 分钟）**：在共享文档里推进；需要追问则发一条（付回看税），然后继续做
3. **写下线便签（90 秒）**：三栏写完，@ 下一棒，然后**闭麦 / 退会**

> **最后一棒**：验收人上线，只看交付物，说"这解决了我的什么"。

### 胜利条件（须**同时**满足三条）

| 条件 | 阈值 |
| :--- | :--- |
| ✅ 接力值 | ≥ 10 |
| ✅ 交付物 | 通过验收人验收（说得出"这解决了我的什么"） |
| ✅ 重做次数 | ≤ 1 |

接力值 ≤ 0 → **「接力断线」**，全体失败，直接复盘。

## ⚠️ 双重特殊失败（各触发不同复盘方向）

### 🧱 失败 A：「各自为战」

- **触发**：接力值 ≥ 10，但验收人指出交付物存在 **≥ 2 处前后矛盾 / 无法拼接**。
- **现象**：每一棒都很努力、便签也都写了，但合起来**不是一份东西**——三段的口径、粒度、前提各不相同。
- **复盘方向**：我们团队最近一次"每个人都做了、但拼不起来"的事情是什么？是谁负责保证它是一份，而不是三份？

### 🔁 失败 B：「原地打转」

- **触发**：重做 ≥ 3 次，或追问 ≥ 4 次。
- **现象**：每一棒都在推翻上一棒。不是不干活，是同一件事被干了三遍。
- **复盘方向**：便签里最缺的是哪一栏？**"我停在哪里"** 这一栏，我们平时写了吗？

> 两种失败**都不计胜**，但都是极好的复盘素材。尤其是「各自为战」——远程团队最贵的成本从来不是沟通时间，是**返工**。

## 🔍 4F 复盘框架（20 分钟）

| 阶段 | 引导问题 |
| :--- | :--- |
| **Facts 事实** | 全局几棒？重做了几次（🔁 几个）？用了几次追问？三栏便签有几次缺栏？验收人说得出那句话吗？ |
| **Feelings 感受** | 读签的 90 秒里，最想做的是什么？<br>发现上一棒方向不对时，是照着接还是推翻？那一瞬间你在想什么？ |
| **Findings 发现** | 哪一张便签最有用？它比别的便签多写了什么？<br>重做发生在第几棒？是便签的问题，还是任务本身没定义清"完成是什么"？ |
| **Future 行动** | 回到岗位，**我们团队的交接便签能不能统一成这三栏**？<br>下一次跨时区交接，我打算把"我停在哪里"写成几句话？ |

> **落点**：异步协作不是"各自找时间干活"，是**把断点写清楚**。
> 复盘时把写得最好的一张便签和最差的一张并排贴出来——差别几乎总在第 ② 栏（我停在哪里）。

## 🌀 变体玩法（7 种）

| 变体 | 适用 | 改法 |
| :--- | :--- | :--- |
| 1. 真时区版 | 有 1-2 天窗口的团队 | 真的隔夜接力（每棒间隔 12-24 小时），最真实 |
| 2. 无追问版 | 想逼便签一次写清 | 取消回看税与追问权，看不懂只能靠便签 |
| 3. 跨部门版 | 想暴露术语差异 | 每棒由不同部门的人接，禁用本部门黑话 |
| 4. 静默读签 | 想压住"顺口问一句" | 读签窗口全程禁言（含私聊），违规扣接力值 |
| 5. 倒序验收 | 想检验便签自洽性 | 验收人先看结论、再看过程，检验便签能否独立支撑结论 |
| 6. 单文档版 | 想杜绝"另起一份" | 禁止新建文档，所有痕迹必须在同一份文档 + 便签区内 |
| 7. 新人接最后一棒 | 想检验便签对"零背景的人"够不够 | 最后一棒换成完全不了解背景的人，看他能不能接上 |

## 🧭 教练注意事项

1. **"不许问已下线的人"必须真的执行**——这一条一旦破例，本作立刻退化成普通同步协作，全部教育意义归零。教练要主动挡住那些"我补充一下"的发言。
2. **三栏便签缺一不可**，尤其第 ② 栏"我停在哪里"；写不出来就不许下线，**教练不要代笔、不要提示**。
3. **回看税由提问的人付**——这是刻意的，让"便签没写清"的成本显形，而不是让下一棒默默兜底。
4. **验收人真的只看交付物**——给他看过程记录，这一棒就白做了。他必须能说出"这解决了我的什么"。
5. **不要评判谁写得好**——教练只验收"重做次数 / 追问次数 / 三栏完整率 / 验收通过与否"，不做个人能力评价。
