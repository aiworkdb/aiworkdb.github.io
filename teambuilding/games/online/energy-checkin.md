# 💻 能量明牌 · 远程看得见的人（线上团建版）

> 定位：全库**唯一一款以「人」而不是「任务」为对象**的线上团建游戏
> 核心矛盾：现场办公时你**看得见**同事今天状态不好——脸色、叹气、午饭没吃；远程办公时你只看得见他的交付。于是状态信息归零，而每个人又默认"别人都挺好的"。

## 🎯 团建价值

远程团队最先丢掉的不是协作效率，是**彼此的状态**。

现场办公时，这些信息是**免费**的：谁今天不对劲、谁连续加了三天班、谁卡在什么地方不好意思开口。远程办公把这些全部删掉了，剩下的只有交付物——**于是"他今天没交"会被直接读成"他不行"**，而真实原因可能是他这周根本没余量。

更麻烦的是：远程里每个人都觉得**只有自己这样**。因为你看不见别人，只能看见自己，而人的默认值是假设别人都正常。

本作把状态做成三件硬东西：① 能量值必须**明牌**（且禁止填 5）；② 每人 2 张**求助券**可以匿名投出去，**不用即作废**；③ 被求助的人必须当场说**「我接」或「我这周接不了」**——不许沉默，不许"有空再说"。

### 🔎 差异化定位

线上分类其余 7 款——**线上宾果**、**我从未**、**画图猜词**、**知识竞答**、**虚拟逃脱**、**异步接力**、**无声会议**——练的全是**协作技能**：怎么交接、怎么表达、怎么解谜、怎么让话分下去。

**本款练的是"看见彼此"**，是线上分类里唯一一款：

- 把**「有没有人接住你」做成硬指标**（接住率）——其余都以任务完成度为验收，本款以人的连接为验收；
- **明令禁止汇报工作进度**——盲区交换里问进度即违规，这是全库唯一一款把"聊工作"判违规的团建游戏；
- **强制示弱**（求助券不用即作废）——不是"鼓励"求助，是让不求助产生可观测的代价。

它刻意让团队练习一件远程里最贵的事：**在自己还撑得住的时候，先把"我快撑不住了"说出来。**

## 🧩 核心机制

### 1. 能量值明牌（0-5）⭐

开局每人**必须在共享看板上亮出**自己本周的能量值（0-5）+ 一句"为什么是这个数"。

- **禁止填 5**——5 代表"我不需要任何帮助"，等于**退出本局**。教练看到 5 直接打回重填。
- 允许填 4，但必须写明"哪一块在消耗我"。
- 白板上按数字分栏站队（0-1 / 2-3 / 4），**所有人当场看见分布**——这一步本身就是本作的一半价值。

### 2. 求助券（每人 2 张）⭐

- 每人 2 张，可以**匿名**投给场上任意一人，写一句「我有一件事想请你帮」。
- **不用即作废**——这是刻意的：让"我不需要帮助"这个姿态产生可观测的代价，而不是让它无声通过。
- 券可以投给**任何人**，包括不在自己小组里的人；也可以投给教练（教练不接，但会念出来并统计）。
- 被求助的人**当场**必须二选一：**「我接」** / **「我这周接不了」**。**禁止沉默、禁止"有空再说"**。

### 3. 盲区交换（本作灵魂）⭐

两人一组，进分组会议室 **8 分钟**，只许问这三类问题：

| 类 | 问题 | 禁止 |
| :--- | :--- | :--- |
| ① **只有我记得** | 你最近一次觉得"这事也就我还记得"是什么时候？ | 不许问进度 |
| ② **想说没说** | 你上一次想找人说话但没找，是因为什么？ | 不许追问细节、不许给建议 |
| ③ **想划掉** | 如果这周有件事可以从你的清单上划掉，你最想划掉哪件？ | 不许说"我可以帮你" |

- 结束后**各写一张「我猜你现在是…」状态卡**交给对方，对方判定**准 / 不准 / 一半**。
- **判定为"不准"的卡不记分**，但要保留——它们是复盘时最该看的东西：**你以为的他，和他实际的他，差在哪。**

### 4. 接住规则（不许含糊）⭐

被求助者只有三种合法回答：

| 回答 | 要求 | 记分 |
| :--- | :--- | :--- |
| ✅ **我接** | 必须说清**什么时候**（本周几 / 几点） | 记「接住 +1」 |
| ⛔ **我这周接不了** | 允许，不加分也不扣分，但**必须说出原因的一个词** | 记 0 |
| 🚫 **有空再说 / 回头找你 / 我看看** | **判违规**，教练当场要求重说一次 | 记 0，并触发复盘提醒 |

> 设计意图：远程里最伤人的不是拒绝，是**含糊**。含糊的人以为自己留了余地，求助的人收到的是"我被敷衍了"。

### 5. 接住率（唯一硬指标）

> **接住率 ＝ 被明确接住（含约定具体时间）的券 ÷ 发出的券**

- 目标 **≥ 80%**
- 教练当场公布，不做事后统计——**数字必须是在场的人一起看见的**

## 🎭 角色分工（4 种）

| 角色 | 组织映射 | 职责 | 观察点（教练重点看） |
| :--- | :--- | :--- | :--- |
| 🔋 **明牌者** | 全体成员 | 亮出能量值 + 一句原因，投出 2 张求助券 | 是填真实数字还是往高了填；券投给了同级还是只投给熟人 |
| 🤝 **接住者** | 被求助的人 | 当场说「我接 + 时间」或「我这周接不了 + 原因」 | 是接得干脆还是说得含糊；接不住时给不给理由 |
| 🗂️ **看板官** | PMO / 观察员 | 只维护能量分布与券的流向，**不许参与内容** | 团队是否允许"状态"这种软信息被白纸黑字记下来 |
| ⏱️ **计时官** | 会议主持 / 运营 | 管 8 分钟分组与全场时间盒 | 8 分钟会不会被"再聊两句"拖长，超时的组在聊什么 |

> **6-10 人小团队**：全员明牌者 + 接住者，看板官与计时官由教练一人兼任。

## 🎲 游戏流程

### 准备（8 分钟）

1. 建**在线白板**（Miro / 飞书白板 / 腾讯文档），划三块：**能量分布区**（三栏 0-1 / 2-3 / 4）／**求助券区**／**接住率计数**
2. 说明硬规则三条：**禁止填 5** · **券不用即作废** · **不许"有空再说"**
3. 每人准备 2 张虚拟券（白板上两个带自己编号的方块即可）
4. 两两配对（奇数由教练补位），建好分组会议室

### 第一轮：明牌（8 分钟）

1. 全员在能量分布区写下自己的数字 + 一句原因，**同时落笔**（避免跟着别人填）
2. 教练逐栏念出人数分布，不点名
3. 有填 5 的 → 当场打回重填，并重申"5 = 退出本局"

### 第二轮：投券与接住（10 分钟）

1. 每人把 2 张券匿名投出（可以投给同一人，也可以弃权——弃权的券同样作废并计入分母）
2. 随机抽取若干张当场念出（**不念投票人**），被点到的立即回答「我接 + 时间」/「我这周接不了 + 原因」
3. 教练同步更新接住率，含糊回答当场要求重说

### 第三轮：盲区交换（12 分钟）

1. 进分组会议室，8 分钟，只问三类问题
2. 各写一张「我猜你现在是…」状态卡交给对方，判定 准 / 不准 / 一半
3. 回主会场，每人只说一句：**「我猜的那张，准了还是没准」**

### 胜利条件（须**同时**满足三条）

| 条件 | 阈值 |
| :--- | :--- |
| ✅ 接住率 | ≥ 80% |
| ✅ 真实接住 | 至少 **2 张券**约定了**具体时间**（不是"回头找你"） |
| ✅ 明牌有效 | 能量值 ≤ 4 的人 ≥ 2/3（否则明牌失效，当场重来） |

## ⚠️ 双重特殊失败（各触发不同复盘方向）

### 🔋 失败 A：「满格会」

- **触发**：填 5 的人数 **≥ 1/3**，或**全员都填 4-5**。
- **现象**：明牌区看上去一片欣欣向荣。这不是团队状态好，是**没人敢在这个场合露怯**。
- **复盘方向**：我们团队里，"我最近有点撑不住"这句话说出来会发生什么？上一次有人说，后来怎样了？

### 📮 失败 B：「券没人用」

- **触发**：求助券使用率 **< 50%**。
- **现象**：规则把求助包装成了"券"，还是没人投。说明团队把**求助等同于暴露弱点**，而不是等同于协作。
- **复盘方向**：那张没投出去的券，本来想请谁帮什么？如果投出去了，最坏会发生什么？

> 两种失败**都不计胜**，但都是极好的复盘素材。尤其失败 A——**一个全员满格的团队，比一个全员低能量的团队更值得担心。**

## 🔍 4F 复盘框架（18 分钟）

| 阶段 | 引导问题 |
| :--- | :--- |
| **Facts 事实** | 能量分布落在哪几栏？券发出去几张、接住几张？有几次"有空再说"？状态卡判"不准"的有几张？ |
| **Feelings 感受** | 落笔那一刻，你有没有想往上填一格？<br>自己的券被念出来时，你更希望被接住还是希望没被念到？ |
| **Findings 发现** | 填得低的人，券是投出去了还是没投？<br>判"不准"的那些卡，我们以为的和他实际的差在哪一类事上？ |
| **Future 行动** | 回到岗位，**我们能不能在周会开头用 30 秒亮一次能量值**？<br>这周我打算把那张没投出去的券，投给谁、请他帮什么？ |

> **落点**：远程不是"看不见人"，是"**没有给状态留一个出口**"。
> 复盘时把能量分布和接住率并排贴出来——**一个全员满格却接住率很低的团队，问题不在忙不忙，在敢不敢。**

## 🌀 变体玩法（7 种）

| 变体 | 适用 | 改法 |
| :--- | :--- | :--- |
| 1. 实名券版 | 想降低匿名带来的轻率 | 求助券署名，接住率照算 |
| 2. 强制低能量版 | 想逼开第一句话 | 要求每人至少填 ≤3 之一，并写清"哪块在消耗我"（适合熟团队） |
| 3. 跨组投券 | 想打破小圈子 | 券必须投给本小组以外的人 |
| 4. 只看不评版 | 心理安全感极低 | 取消状态卡判定环节，只写不判定，降低暴露风险 |
| 5. 求助墙 | 想让求助常态化 | 白板常驻一个「本周求助墙」，团建结束后保留 2 周 |
| 6. 反向券 | 想练"主动给" | 每人另发 1 张「我能帮」券，写明自己能提供的具体帮助 |
| 7. 一月回访 | 想看留存 | 4 周后回看：当时接住的那几件事，做完了吗？（唯一的延时变体） |

## 🧭 教练注意事项

1. **禁止填 5 必须真的执行**——这是本作的第一道闸门。看到 5 就打回，不要"这次算了"，破一次例后面全是 5。
2. **能量值含义只讲一遍，不逐个解释**——解释越多，越容易变成汇报。"为什么是这个数"限一句，超过一句教练可以打断。
3. **含糊回答必须当场拦**：「有空再说」「回头找你」「我看看」一律要求重说一次。这是唯一需要教练态度强硬的地方。
4. **状态卡"不准"的结果只说事实不做分析**——念出来即可，不要让被猜的人当场解释"我其实是因为…"。
5. **心理尺度兜底**：若有人明显不适，立即允许其退出盲区交换环节（改为只做明牌与投券）。本作涉及真实状态暴露，**宁可少一轮，不可硬推**——行前请先读 [安全与管理](../../toolbox/safety.html)。
