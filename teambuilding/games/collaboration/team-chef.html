🎯 游戏概述

《协作大厨》是一款改编自桌游《怪物厨师》的团队协作类团建游戏。

玩家分为几个小组，每个小组扮演一个"厨房团队"，需要在限定时间内完成一系列"团队任务"（相当于原版的烹饪料理）。每个任务需要不同的技能和资源，团队必须合理分工、高效沟通、互相配合才能完成任务！

与传统团建游戏不同，这款游戏的核心在于任务协作系统：不同的团队成员拥有不同的"技能卡"，只有合理搭配技能、共享资源，才能高效完成所有任务。玩家需要建立良好的沟通机制、明确的角色分工，并学会在压力下保持团队协作！

适合想要提升团队协作能力、沟通效率和任务分配能力的团队。

🎲 游戏规则

准备阶段

  1. 分组：将参与者分为2-4个"厨房团队"，每队4-5人
  2. 分配技能：每位玩家随机抽取1张技能卡，保密自己的技能
  3. 设置得分板：在白板上画出得分表，记录各队得分
  4. 准备卡牌：
    • 洗混任务卡堆、资源卡堆、技能卡堆
    • 每位玩家起始获得2张资源卡（随机）
  5. 设定时间：总游戏时间设定为45分钟（可根据情况调整）

游戏流程

游戏分为多个"服务轮次"，每个轮次包含以下阶段：

第一阶段：采购阶段（5分钟）

  • 每位玩家轮流抽取2张资源卡
  • 团队可以内部交易资源卡（每人每轮最多交易1次）
  • 技能卡能力可以在此阶段使用（如：采购员额外获得1张）

第二阶段：任务选择（3分钟）

  • 翻开3张任务卡，团队选择其中1个完成
  • 考虑：团队拥有的资源、成员技能、任务得分
  • 团队需要讨论并达成一致选择

第三阶段：任务执行（10分钟）

根据选择的任务卡，执行相应挑战：

类型A：时间限制任务

  • 教练计时，团队在规定时间内完成任务
  • 如使用"计时员"技能，可延长30秒

类型B：掷骰子任务

  • 团队成员轮流掷骰子（2颗）
  • 若点数之和达到任务要求，任务完成
  • 如使用"品质检查员"技能，可重复掷1次

类型C：创意任务

  • 团队需要展示创意（如：用现有资源设计一个"创意料理"）
  • 教练或其他团队投票评分

类型D：全员协作任务

  • 所有团队成员都必须参与
  • 如使用"团队激励师"技能，全员掷骰子+1

第四阶段：得分与复盘（2分钟）

  • 任务完成后，团队获得相应得分
  • 教练提问1-2个引导问题（见下方"复盘引导问题"）
  • 团队简要讨论：刚才的合作过程如何？

第五阶段：下一轮准备

  • 将使用过的资源卡放入弃牌堆
  • 补充新手牌：每位玩家抽取1张资源卡
  • 进入下一轮"采购阶段"

游戏结束条件

  • 时间结束：45分钟到达，游戏结束
  • 任务完成：所有任务卡完成，游戏结束

胜利条件

  • 团队目标：所有团队的得分相加达到100分，全员胜利
  • 竞争模式：得分最高的团队获胜（可选）

📖 完整游戏流程示例

示例1：普通任务完成

蓝队第2轮：

  1. 采购阶段：队员A抽到🥩，队员B抽到🥬，队员C抽到🌶️
  2. 任务选择：翻开3张任务卡，团队选择"快速备菜"（需要🥬×2）
  3. 资源调配：队员B有🥬×1，队员C用技能"调度员"与队员A交换得到🥬×1
  4. 任务执行：3分钟内，团队完成"切菜"挑战（模拟切菜动作，教练计时）
  5. 得分：任务完成，蓝队获得10分
  6. 复盘：教练问："刚才的资源调配过程，沟通是否顺畅？"

示例2：困难任务与技能使用

红队第4轮：

  1. 采购阶段：队员D有🥩×2，但缺少🍳（厨具）
  2. 任务选择：选择"主菜烹饪"（需要🥩×2 + 🔪×1）
  3. 技能使用：队员E使用"资源回收员"技能，从弃牌堆回收1张🍳
  4. 任务执行：掷骰子，队员D掷出3+2=5点，5≥4，任务完成！
  5. 得分：红队获得15分，总得分达到60分
  6. 复盘：教练问："在资源不足时，团队是如何解决问题的？"

示例3：团队协作用于困难任务

绿队第6轮（最后一轮）：

  1. 任务选择：选择"完美服务"（需要🥩×3 + 🌶️×2，无失误完成）
  2. 挑战：这个任务非常难，需要全员配合
  3. 技能组合：
    • 队员F（主厨）同时使用2张技能卡
    • 队员G（团队激励师）使用技能，全员掷骰子+1
    • 队员H（品质检查员）准备重复掷骰子
  4. 任务执行：
    • 全员参与"模拟服务"挑战（如：按顺序传递物品，不能掉落）
    • 第一次尝试失败，但"品质检查员"技能允许重复1次
    • 第二次尝试成功！
  5. 得分：绿队获得35分，总得分90分
  6. 游戏结束：所有团队总得分=90+80+85=255分，超过100分，全员胜利！

💡 教练引导指南

游戏前说明

  1. 强调合作：这个游戏的核心不是竞争，而是团队协作
  2. 解释技能：确保每位玩家理解自己的技能如何使用
  3. 说明目标：团队目标是共同达到100分，不是打败其他团队

游戏中观察要点

  • 沟通效率：团队内部沟通是否顺畅？有没有"沉默成员"？
  • 资源分配：资源是如何分配的？是否合理？
  • 决策过程：任务选择是如何做出的？是民主讨论还是某人主导？
  • 压力应对：在时间压力下，团队表现如何？

复盘引导问题

每轮结束后（简短复盘）：

  1. 刚才的任务中，谁发挥了关键作用？
  2. 如果重新来一次，你们会怎么做？
  3. 团队成员之间的沟通是否高效？

游戏结束后（深度复盘）：

  1. 在这个游戏中，你们团队最成功的时刻是什么？为什么成功？
  2. 遇到资源不足或任务困难时，团队是如何应对的？
  3. 你们的决策过程是怎样的？是否充分听取了每个人的意见？4. 这个游戏和我们的日常工作有哪些相似之处？
  4. 如果将这个游戏中的协作经验应用到工作中，你们会怎么做？

🔄 变体规则

简单模式（新手团队）

  • 减少任务难度：掷骰子条件降低（≥3即可）
  • 增加起始资源：每位玩家起始获得3张资源卡
  • 延长每轮时间：任务执行阶段延长至15分钟
  • 增加提示：教练可以在每轮给出1次提示

困难模式（高绩效团队）

  • 增加时间压力：总时间缩短至30分钟
  • 增加任务难度：部分任务需要2个技能卡组合使用
  • "失误惩罚"：任务失败时，团队失去5分
  • 隐藏技能：技能卡不公开，团队需要猜测谁有什么技能

竞争模式

  • 团队之间是竞争关系，先达到50分的团队获胜
  • 可以增加"偷取资源"规则：特定技能允许从其他团队获取资源
  • 适合团队氛围比较活跃、喜欢竞争的群体

无卡牌模式（快速版）

  • 不使用实体卡牌，改用"口头任务"
  • 教练口头宣布任务，团队口头回应如何完成
  • 适合时间有限或物料准备不足的情况

❓ 常见问题

Q：如果团队成员人数不是4-5人怎么办？ A：可以调整团队数量。8-12人适合2个团队，13-20人适合3-4个团队。如果人数不足8人，可以改为个人竞争模式。

Q：技能卡的使用时机是什么？ A：技能卡可以在任何阶段使用，但需要公开宣布。每个技能每轮只能使用1次。

Q：资源卡可以不使用吗？ A：可以。资源卡可以保留到后续轮次使用。但每位玩家的手牌上限为5张。

Q：如果任务失败怎么办？ A：任务失败后，消耗的 resource 卡不返还，但团队可以 choose 继续尝试或放弃。放弃后进入下一轮。

Q：可以多个团队同时获胜吗？ A：可以！这个游戏鼓励合作，所有团队总得分达到100分，全员获胜。

Q：游戏时间可以调整吗？ A：可以。根据团队数量和游戏节奏，可以调整为30-60分钟。

🎯 学习要点

团队协作核心能力

  1. 有效沟通：如何清晰、简洁地传递信息
  2. 资源整合：如何最大化利用有限资源
  3. 角色分工：如何根据技能合理分工
  4. 决策机制：如何高效做出团队决策
  5. 压力管理：如何在压力下保持团队效率

应用于工作场景

  • 项目协作：如何将游戏中的协作经验应用到项目团队中？
  • 资源管理：如何优化团队的资源（时间、人力、预算）分配？
  • 沟通机制：如何建立更高效的团队沟通机制？
  • 压力应对：如何在紧迫的项目 deadlines 下保持团队士气？

📝 教练笔记

适用团队类型：

  • ☐ 新组建的团队（需要破冰和协作磨合）
  • ☐ 跨部门协作团队（需要提升沟通效率）
  • ☐ 项目团队（需要优化任务分配）

注意事项：

  1. 确保游戏规则讲解清晰，避免 confusion

  • 复盘讨论：20分钟
  • 总计：75分钟
