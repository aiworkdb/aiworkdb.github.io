🎮 游戏概述

《数据侦探社》改编自合作推理桌游《虚拟侦探社 Virtual Detective Agency》。原作里，玩家扮演赛博世界的虚拟侦探，在犯罪倒计时归零之前，跨城市移动、收集线索、破解密码、分析数据，最终拼出真相、阻止犯罪。

这正是跨职能团队的真实写照：一个问题往往分散在"数据 / 安全 / 产品 / 业务"不同人手里——谁的情报都不全，必须互通才能拼出全局；而头顶始终悬着一根倒计时的绳子（交付期限 / 客户耐心 / 风险敞口），逼你在"信息不充分"时也要做出证据驱动的判断。

团建版把"线索卡"译成"分散在不同人手里的事实碎片"，把"证据卡"译成"关键结论 / 决策依据"，把"犯罪倒计时"译成"交付期限 / 风险窗口"，把"危机卡"译成"突发干扰 / 信息失真"。

🎯 团建改造重点

  • 信息整合（核心反转）：胜利不靠一个人聪明，而靠所有人把碎片拼成全局——"信息孤岛"是最大敌人
  • 证据驱动决策：在不确定下，用已有线索做"可证伪 / 可迭代"的判断，而非拍脑袋
  • 时间盒压力：倒计时逼团队"先收敛主线、再补细节"，拒绝完美主义拖延
  • 跨职能互补：黑客 / 分析师 / 追踪者 / 解密专家 / 潜入者，映射"技术 / 业务 / 运营 / 风控 / 外部协调"不同视角
  • 共享心智：所有线索公开、技能共享，逼出"主动同步"的习惯
  • 复盘框架：每局结束 4F 复盘，迁移到真实的项目协同

无打印方案（临时团建）

  • 地图：白纸画 7×7 网格，标起点🎮与四个区域入口（🏢数据中心 / 🏰别墅 / 🕳️地下基地 / 🌐中央广场）
  • 倒计时：纸带写 0-10，硬币当指针，初始指 10
  • 卡牌：便签写名称 + 效果（🔍线索 / 📁证据 / 💻技能 / ⚠️危机），分类面朝下抽
  • 棋子：硬币 / 纽扣代替
  • 骰子：手机骰子 APP，或 1-6 数字卡抽签

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，映射跨职能团队的"技术 / 业务 / 运营 / 风控 / 外部协调"视角：

角色图示团建映射被动 / 核心能力
黑客 · 技术 / 数据💻把系统、埋点、日志里的信号挖出来查看并移除 1 张危机卡（提前排雷）
分析师 · 业务 / 研究📊把碎片拼成结论、做归因额外获得 1 条线索（信息增益更高）
追踪者 · 运营 / 执行📍盯住关键路径、推进落地可直接移动到任意位置（打通卡点）
解密专家 · 风控 / 合规🔓识别风险、破解"加密"的隐性约束解锁加密文件（暴露被隐藏的约束）
潜入者 · 外部协调 / 客户🎭协调外部、免疫干扰保节奏本回合免疫危机效果（稳住交付）
少于 5 人时可合并角色（如"分析师+追踪者"= 业务运营一体），或增设观察员记录"信息是否流动"。

🎲 游戏流程（每回合）

玩家轮流行动，每回合包含：

  1. 掷骰移动：2 颗骰子之和 = 移动步数，上下左右在网格移动
  2. 执行落点事件：
    • 🔍 线索点 → 抽取 1 张线索卡（分散的事实碎片）
    • 💻 技能点 → 学习 1 项技能卡
    • ⚠️ 危机点 → 抽危机卡，倒计时 -1
    • 📁 证据点 → 获得 1 份证据卡（关键结论）
    • 🏢/🏰/🕳️ 区域入口 → 进入建筑内部，触发特殊事件（稀有线索 / 证据）
  3. 使用技能（可选）：技能为共享资源，可作用于自己或队友
  4. 传递线索（可选）：玩家间可传递线索卡（消耗 1 行动点）——鼓励互通
  5. 犯罪回合：所有玩家行动后，倒计时 -1（≤5 时危机加倍；=0 立即失败）

核心机制 · 信息整合（团建灵魂）

线索分散在每个人手里，单看毫无意义；只有公开 + 拼合才能逼近真相。团队必须在"继续收集"与"及时收敛推理"之间抉择——收集太多会烧光倒计时，收敛太早会漏掉关键证据。

共享轨道与危机

共享轨道初始警告 / 失败阈值
犯罪倒计时（交付期限）10每回合 -1；≤5 危机加倍；=0 立即失败
线索池空需收集 ≥5 种不同类型线索才能推理
证据卡0需持"幕后黑手照片"方可阻止犯罪
危机蔓延-危机点停留 / 危机卡随机施压

关键：胜负不取决于"谁最聪明"，而取决于"信息是否互通、证据是否扎实、在倒计时内是否收敛出可执行的结论"。

💡 团建引导提示

阶段
要点
游戏前（5分钟）
定调："你们每人手里只有真相的一角，必须互通才能破案；倒计时是交付期限。"
游戏中（观察）
记录：信息是否在流动？谁在藏线索？是否有人拍脑袋下结论？是否拖延到倒计时告急？
游戏后（4F复盘）
事实→感受→发现→迁移，约 15-20 分钟；把"信息整合 / 证据决策 / 时间盒"迁移到真实工作。

4F 复盘提问示例

  • Fact（事实）：我们收集了几条线索？谁手里有关键碎片没及时说？
  • Feel（感受）：信息不全时做决策，焦虑还是兴奋？
  • Find（发现）：信息孤岛是怎么形成的？证据不足时我们怎么拍的板？
  • Future（迁移）：回到工作，我们的"线索"散在谁手里？怎么建立主动同步机制？

🔄 变体玩法

变体
说明
观察员模式
超 5 人时多出玩家任观察员，记录"信息是否流动、谁在藏、谁在拍脑袋"，复盘提供第三方视角
限时挑战
设 45 分钟沙漏，强化交付期限压迫感
角色轮换
每 3 回合轮换角色，体验技术 / 业务 / 风控不同视角，强化相互理解
无声推理
部分回合禁言，凸显"提前约定同步机制、显性共享信息"的价值
部门混编
拆散同部门到不同角色，强制"技术 / 业务 / 职能"跨界搭档，共破一案
真实问题叠加
把线索卡换成团队真实一个难题的"已知碎片"便签，游戏结束 = 一次跨职能问题诊断会
证据驱动决策
要求每次"推理结论"必须引用 ≥3 张线索卡作为依据，训练"用证据说话"

🧩 这套游戏被哪些流程用过

⚠️ 还没有任何现成流程收录它 —— 它属于「挑一个环节塞进去」型：本页有完整玩法，但没有配套时间轴。按参数 2–5 人 / 45–70 分钟，能落地的位置是：
最合适的落点是一日团建流程方案的主体活动二（13:30–15:00，90 min）：这一格是「沟通 / 信任方向」的整块，本页 45–70 分钟放进去还剩 20 分钟，正好够它的复盘展开——这款的价值本来就在复盘：信息散在各人手里，不先拼齐事实就没法判断。
别往半日模板里塞：半日团建流程模板的核心活动 II 只有 40 min，本页最短 45 分钟都装不下，塞进去只能砍掉 4F，那是把产品砍了。
上面是建议不是既有收录：这些流程的原表里没有它，塞进去时前后各留 5 分钟交接；塞之前先核一遍人数和时长，别看标题。
