黄金结界 · 团队守护版

🎮 游戏概述

《黄金结界 · 团队守护版》改编自合作桌游《猎魔女团：黄金结界 Huntrix: Golden Honmoon》（取材自 2025–2026 全球现象级动画音乐电影《KPop Demon Hunters / 猎魔女团 / HUNTR/X》）。原作里，风靡全球的女子组合 HUNTR/X 其实是猎魔女团，她们用歌声织起一道名为「Honmoon（结界）」的魔法屏障，把深渊恶魔挡在人间之外。玩家在 7×7 的都市棋盘上穿梭：登台应援、排练旋律、汲取灵能、装备术式、清扫恶魔之门、封印结界节点，最终击溃魔王，重新点亮「黄金结界」。

团建版的关键反转在两处：① 「结界 = 团队的共享心理安全与信任」——它亮着，团队就稳；它裂开，内耗、倦怠、信任裂痕、目标漂移、沉默螺旋就钻进来。② 「结界是从内部裂开的」（呼应原作：隐秘的心结让屏障出现裂痕）——最危险的从不是外部攻击，而是没被说出口的痛点、被压抑的张力、缺位的心理安全。于是本游戏聚焦一个和既有改造游戏都不同的视角：团队文化与心理资本的"能量守恒"——你不能只"打怪"（救火），还必须靠登台表演（团队仪式、认可、充电）主动续能；同时把隐患摆上台面，别让它在沉默中啃噬团队。

🎯 团建改造重点

  • 能量守恒（核心反转）：结界每整轮自然削弱，须靠"登台表演/团队仪式"主动续能——高绩效需要刻意充电与认可
  • 5 团队健康支柱：目标共识 / 心理安全 / 信任 / 成长 / 认可——每维护好一个，团队韧性 +1
  • 把痛点摆上台面：恶魔生于沉默，靠公开对话（共唱）清除——沉默才是最大杀手
  • 角色互补：凝聚Leader / 攻坚冲突管理 / 活力带动 / 资源统筹彼此依赖
  • 合力决战：大魔王 = 结构/文化级裂痕，需五支柱齐亮、全队同步
  • 复盘框架：每局结束 4F 复盘，迁移到真实的团队文化建设

🎯 团建目标

能量守恒

体感"结界会默默流失"，把"团队需要刻意充电、认可与仪式"具象化

心理安全

看见"掩盖裂痕会蔓延"，训练把隐患、痛点、张力摆上台面讨论

五大支柱

用 5 个结界节点映射团队健康维度，游戏结束变"健康度看板"

合力攻坚

五支柱齐亮方能开魔王殿——全队同步、相互兜底才能啃下结构性难题

🖨️ 无打印方案（临时团建）

  • 地图：白纸画 7×7 网格，左上角标"🎤 主舞台(HQ)"，右下角标"👑 魔王殿"
  • 威胁值：纸带写 0-10 刻度，硬币当指针，初始指 0
  • 资源：三色围棋子代表应援⭐黄 / 旋律🎵青 / 灵能💜紫，放公共池
  • 卡牌：便签写名称 + 效果（⭐/🎵/💜/👹/🏆），分类面朝下抽
  • 骰子：手机骰子 APP，或 1-6 数字卡抽签

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，映射高绩效团队的"凝聚 / 攻坚 / 活力 / 统筹"（超 5 人时加"守护者"）：

🎤 主唱 · Rumi（凝聚Leader / 共同叙事）

被动：封印节点时额外降低 0.5 威胁

团建映射：把团队故事讲好、凝聚目标与意义感——"我们为什么在一起"

🎤 Mira（说唱 · 攻坚 / 冲突管理）

被动：对"凝视魔 / 信任裂痕"类恶魔伤害 +1

团建映射：啃硬骨头、把冲突摆上台面、直面棘手议题

💃 Zoey（舞担 · 活力 / 新人带动）

被动：在主舞台登台额外 +1 应援

团建映射：带氛围、带动新人、把团队能量点燃（主动充电）

🎧 经纪人（资源统筹 / PMO）

被动：每回合可多 1 个行动点用于"装备 / 补给"

团建映射：调度资源、排期、对外争取、横向补位

🛡️ 守护者（扩展 · 后方兜底 / HRBP）

被动：结界护盾生效时 +1 能量

团建映射：为同伴挡一次风险或情绪冲击（情绪缓冲 / 兜底），专门做"护人"

🎲 游戏流程（每回合 4 阶段）

每回合依次执行：① 表演 / 移动（每人 1 次免费） → ② 行动阶段（最多 2 AP） → ③ 恶魔结算（即时） → ④ 回合结束与威胁推进（威胁 +1，回合 +1）。

核心机制 · 能量守恒（团建灵魂）

结界每整轮自然削弱（威胁 +1），不主动"登台表演"续能就会崩——对应高绩效需要刻意充电与认可，否则士气在沉默中流失。

把裂痕摆上台面（心理安全）

恶魔生于"沉默"：内耗 / 倦怠 / 信任裂痕 / 目标漂移 / 沉默螺旋。它们靠公开对话（共唱 / 1on1 / 向上反馈）清除——被掩盖的裂痕才会蔓延到魔王殿。

5 大健康支柱（结界节点）

维护好一个节点 = 为一项团队健康维度（共识 / 安全 / 信任 / 成长 / 认可）建立显性实践，威胁 −1。游戏结束，5 张节点卡即"团队健康度看板"。

共享轨道与危机

共享轨道初始警告 / 失败阈值
结界威胁（Threat）0 点每整轮 +1；达 10 = 结界崩塌（全员失败）
已维护支柱0 / 5达 5 = 魔王殿开启
成员能量 ❤️每人 3 点全员同时归零 = 团队耗尽（失败）
资源池每人 ⭐×6应援⭐ / 旋律🎵 / 灵能💜 三类公共牌库

⚠️ 关键：胜负不取决于"打怪最快"，而取决于"是否在结界崩塌前，维护好 5 大支柱、把隐患摆上台面、备足合力打 Boss"——光救火不充电，结界必崩；光充电不打怪，节点永远封不上。

💡 团建引导提示

游戏前（5分钟）

定调："我们守护的'黄金结界'就是团队的信任与心理安全。它会被内部裂痕啃噬，也会靠仪式与坦诚续能。先保住 5 大支柱，再合力打 Boss。"

游戏中（观察）

记录：谁在"登台充电"？谁在掩盖裂痕（沉默）？5 支柱覆盖几个？低能量成员有人兜底吗？资源投到了消耗还是沉淀？

游戏后（4F复盘）

事实→感受→发现→迁移，约15-20分钟；重点迁移能量守恒、把隐患摆上台面、5 大支柱待建设项。

🔄 变体玩法

观察员模式

超5人时多出玩家任观察员，专记"是否有人在掩盖裂痕 / 谁在主动充电 / 5 支柱覆盖几个"，复盘给第三方视角。

限时挑战

设60分钟沙漏，强化"结界倒流"的压迫感与能量守恒紧迫性。

角色轮换

每3回合轮换角色，体验凝聚/攻坚/活力/统筹不同职能，强化相互理解。

无声协奏

部分回合禁言分配/维护，凸显"提前约定、显性同步"对抗沉默螺旋的价值。

部门混编

拆散同部门到不同角色，强制"业务/技术/职能"跨界搭档，共守结界。

真实支柱叠加

把5张节点卡换成团队真实5个健康维度便签，游戏结束变"团队健康度看板"。

真实裂痕叠加

把恶魔卡换成团队真实痛点便签（如"跨团队墙""需求频繁变更"），清恶魔 = 把真实议题摆上台面。
