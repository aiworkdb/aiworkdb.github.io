🎮 游戏概述

《轮回地下城 · 团队复盘迭代版》改编自合作桌游《轮回地下城 Loop Dungeon》（Roguelike 地牢合作主题）。玩家扮演被困在时间轮回里的冒险者：每当局势不利（全员阵亡），时间就倒流回地牢入口——但上一次轮回里收集的"记忆碎片"会被保留，用来购买永久升级。目标是在有限的轮回次数内，打通 5 层地牢、击败最终 Boss「轮回守护者」。

在团建语境下，这座地牢就是一支在持续交付中反复迭代的团队：每一轮轮回是一个冲刺（Sprint），打不过去就复盘、沉淀经验、带着更强的基线再战；那些跨轮回保留下来的"记忆碎片"，正是复盘行动项的累积、组织过程资产（OPA）的沉淀。

🎯 团建改造重点

  • 复盘迭代而非一次定胜负：阵亡不归零，记忆碎片永久留存，模拟"快速失败、安全试错、越战越强"
  • 知识沉淀：记忆碎片 = 跨周期的复盘收获，让"组织过程资产"可见、可积累、可兑换
  • 共享资源管理：全队共享精力与带宽，暴露"谁在透支、谁在囤力"
  • 渐进式能力建设：永久升级映射"流程/工具/默契"带来的基线抬升
  • 复盘框架：每轮轮回结束（成败皆然）引导微复盘，迁移到持续改进

🎯 团建目标

复盘心智建立

体验"失败不是终点，而是带着记忆重启"，建立安全失败的心理安全感

知识沉淀意识

把记忆碎片具象化为复盘行动项，反思"经验有没有被记录、被复用"

共享资源管理

全队共享精力与带宽，觉察"谁在默默扛、谁在囤力不输出"

渐进能力建设

永久升级机制映射"流程/工具/默契"如何把团队基线一点点抬升

物品名称数量用途

玩家/怪物棋子3-5/12个标记冒险者与风险/阻碍位置
精力/轮回标记各1个精力轨道(0-10)与轮回(1-5)追踪

永久升级板1张记录精力+/带宽+/初始装备等基线提升

骰子1颗移动步数及战斗检定（1d6）

🖨️ 无打印方案（临时团建）

  • 地图：方格纸画 5 层，每层 5 房，标入口与 Boss
  • 精力/轮回：纸条刻度+硬币标记
  • 记忆碎片：彩纸折 20 小片，代表跨轮回留存经验
  • 卡牌：便签写名称+效果，分类面朝下抽
  • 骰子：手机骰子 APP，或 1-6 数字卡抽签

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，模拟真实团队中的职能分工与相互依赖（也可按性格由教练分配）：

🗡️ 前锋探索者 · 攻坚手 / 业务突破手

被动：高攻击，把最硬的骨头啃下

团建映射：团队里的"攻坚手"——把最难的事干成

🛡️ 盾卫守护者 · 风险兜底 / 质量守护

被动：高防御，替队友承接风险与反击伤害

团建映射：团队"定海神针"——筑防线、稳基本盘、治未病

💚 治愈术师 · 团队修复 / 情绪缓冲

被动：治愈术回精力、复活掉队者

团建映射：HR / PMO / 支持位——把人从"阵亡"边缘拉回来

⚙️ 机关匠师 · 工具赋能 / 流程优化

被动：强化装备（流程）+ 群体增益

团建映射：工程效能 / 中台——用工具把全队基线抬升

🧭 领航者 · 决策统筹 / 方向把控

被动：定调、分配带宽、战略取舍

团建映射：Leader / PM——关键时定方向，但要警惕"单点决策"

🎲 游戏流程（每轮回多回合）

每位玩家每轮回有 2 个行动点（AP）：探索房间 / 移动房间 / 装备使用 / 收集碎片 / 购买升级。

核心机制 · 🌀 轮回重启（团建灵魂）

团队共享精力降为 0（全员阵亡）时：当前轮回结束 → 保留记忆碎片（复盘经验）→ 装备金币丢失 → 轮回 +1 → 从 1F 重启，但用碎片买的永久升级持续生效。

地图 · 5 层地牢 = 项目生命周期

1F 立项 → 2F 方案 → 3F 执行 → 4F 验证 → 5F 上线/Boss。每层都在消耗精力、挤压带宽，怪物房是风险、陷阱房是隐形坑。

战斗 · 怪物 = 风险/阻碍

需求变更 / 线上故障 / 资源缺口，战斗消耗的是团队共享精力——而非个人血量。

共享轨道与危机

共享轨道初始失败阈值
团队精力（心力/信任）10降为 0 即触发轮回
轮回计数5达到 5 轮仍未击败 Boss 即失败（改进窗口关闭）

⚠️ 关键：轮回 = Sprint 迭代；记忆碎片 = 复盘行动项；永久升级 = 组织过程资产。每一次"失败重启"都在让团队基线更强——正是对"心理安全 + 持续改进"最直观的体感。

💡 团建引导提示

游戏前（5分钟）

介绍主题："每一轮轮回是一个冲刺，打不过去就复盘、攒经验、带着更强的基线再战"；强调失败可安全重启。

游戏中（观察）

记录：谁在做复盘？谁在透支？领航是否单点？跨轮回有没有复用经验？失败后情绪如何？

游戏后（4F复盘）

事实→感受→发现→迁移，约15-20分钟；并建议每轮结束做 2 分钟微复盘。

🔄 变体玩法

观察员模式

超5人时多出玩家任观察员，记录复盘行为，微复盘提供第三方视角。

限时挑战

设45分钟沙漏，以"是否打通 Boss"判胜负，适合时间有限团建。

角色轮换

每1轮轮回轮换角色，体验"攻坚"与"兜底/赋能"两类职能。

无声回廊

部分轮回禁言，凸显"提前约定、隐性默契"对协作的价值。

部门混编

拆散同部门到不同角色，专为"打破部门墙"设计。

真实复盘叠加

每得 1 碎片写一条真实可落地行动项，游戏结束便签直接变改进看板。
