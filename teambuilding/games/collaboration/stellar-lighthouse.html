🎮 游戏概述

《星际灯塔守护者 · 守望协作版》改编自合作桌游《星际灯塔守护者 Stellar Lighthouse》（宇宙科幻 + 设施守护主题）。玩家扮演古老太空设施「星际灯塔」的守护者：在能量持续衰减（每回合 -1）的条件下，维护灯塔设施、修复不断出现的故障、抵御黑暗能量侵蚀，把一艘艘迷失在星海中的飞船引导回灯塔核心。

在团建语境下，「星际灯塔」就是一支需要长期守护某件关键事物（核心服务 / 关键系统 / 团队凝聚力）的团队：能量是团队精力 / 载荷，故障是技术债 / 流程债，迷失飞船是掉队的同事或待支持的新人 / 客户，黑暗能量是突如其来的折腾。能不能在能量见底前把船都接回来、又不让故障堆到崩溃，正是真实工作中"长期主义 + 精力管理 + 技术债可控 + 及时拉人一把"的缩影。

🎯 团建改造重点

  • 长期守护：灯塔能量是一条"只能补、不能停"的续航线——映射系统 / 团队的可持续性
  • 精力续航：能量每回合 -1，低能触发警报——体感"精力是消耗型资源，要持续充电而非一次榨干"
  • 技术债可视化：故障标记逐回合累积到 10 即崩——把"小毛病不管会垮"的拖延代价具象化
  • 引导掉队者：把船引导回核心 = 拉回沉默同事 / 融入新人 / 接住客户
  • 复盘框架：每局结束 4F 复盘，把"守护与续航"迁移到真实工作的稳定性建设

🎯 团建目标

守护意识

把"维护关键事物长期可用"当作共同责任，而非谁的 KPI

精力续航

体验"能量是消耗型资源，要持续补"，反思是否常一次性榨干

技术债直觉

看见故障一颗颗累积，建立"小债不还是会爆"的体感

拉人一把

把引导飞船当成高优动作——接住掉队同事 / 新人 / 客户

🖨️ 无打印方案（临时团建）

  • 地图：白纸中心画灯塔，四角能量站、上下零件库、左右星图室、外围黑暗区
  • 能量/故障：纸条写能量 0-15 当轨迹，灰色纸片当故障标记
  • 飞船：硬币当迷失飞船，外围摆 6-12 个
  • 卡牌：便签写名称 + 效果（🔋/🔧/🗺️），分类面朝下抽
  • 骰子：手机骰子 APP，或 1-6 数字卡抽签

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，模拟真实团队中的"守护型"职能分工与相互依赖（也可按性格由教练分配）：

🛠️ 工程师 · 工程 / 中台 / 运维

被动：修故障效果+1、每回合免费清 1 故障

团建映射：稳底盘、还技术债——"风险兜底与系统守护"

🧭 导航员 · 协调 / PMO / 新人导师

被动：引导飞船移动+1、可看下一张事件

团建映射：拉人一把、知走向——"横向协调与引导"

⚡ 能源师 · 资源 / 后勤 / energetics

被动：充能效果+1、每回合多摸 1 能量卡

团建映射：持续给团队充电——"精力续航与补给"

📡 通讯官 · 横向链接 / 跨部门

被动：可与任意人交易 1 张资源卡、每回合分享 1 卡

团建映射：让资源流动——"链接者与破壁者"

🔬 科学家 · 架构 / 质量 / 改进

被动：升级灯塔（能量上限+）、合成工具卡

团建映射：提升系统基线——"能力建设与改进"

🎲 游戏流程（每回合 4 阶段）

每回合依次执行：① 事件阶段 → ② 行动阶段（每人 2 行动点） → ③ 检查阶段 → ④ 结束阶段（能量 -1）。

核心机制 · 精力续航（团建灵魂）

能量每回合自动 -1，≤ 5 触发低能警报、≤ 0 灯塔熄灭即失败。没有人持续去充电，灯迟早会熄——这正是"精力是消耗型资源、要持续补给而非一次性榨干"的体感。

地图 · 星际灯塔 = 需要长期守护的系统 / 团队

核心=关键服务；能量站=充电入口；零件库=底座/中台；星图室=导航/协调；黑暗区=折腾/突发。所有人从核心出发，各有守护段。

危机 · 故障标记 = 技术债 / 流程债

只增不减，堆到 10 灯塔崩溃。清故障就是还债——逼团队建立"债不积压"的本能，而非等爆仓才救。

共享轨道与危机

共享轨道初始警告 / 失败阈值
灯塔能量10≤5 低能警报；≤0 即失败（系统宕机 / 团队崩）
故障标记0每回合只增不减；≥10 即失败（技术债爆仓）
迷失飞船6-12艘全部飞出边界即失败（掉队者无人接住）

⚠️ 关键：胜负不取决于"谁冲得快"，而取决于"有没有人持续充电、有人清债、有人专门去接船"。每一次把家守住，都让团队离全员归港更近一步。

💡 团建引导提示

游戏前（5分钟）

介绍主题："灯塔=要长期守护的关键事物，能量=精力，故障=技术债，船=掉队者/新人/客户"；强调续航、鼓励接船。

游戏中（观察）

记录：谁在充电？谁在还债？谁在接船？故障到几了（可观测）？通讯官在流动吗？

游戏后（4F复盘）

事实→感受→发现→迁移，约15-20分钟；把"守护与续航"迁移到真实工作稳定性。

🔄 变体玩法

观察员模式

超5人时多出玩家任观察员，记录"充电/清债/接船"行为，复盘提供第三方视角。

限时挑战

设45分钟沙漏，以"归港≥6艘"判胜负，适合时间有限团建。

角色轮换

每2回合轮换角色，体验"充电"与"清债/接船"两类职能。

无声守护

部分回合禁言，凸显"提前约定、显性同步"对守护型协作的价值。

部门混编

拆散同部门到不同角色，专为"打破部门墙"设计。

真实技术债叠加

把故障换成当前真实技术债/风险便签，每清一次=认领推进，便签变改进看板。

新人护航

标2-3艘"新人船"由导航员对接，复盘重点："怎么让新人最快归港"。
