🎮 游戏概述

《银河小馆 · 双线突围版》改编自合作桌游《星际餐厅大逃亡 Space Diner Escape》。原作的美妙张力在于——玩家既要前场接待顾客、完成订单、赚取星际信用点，又要后场合力修复飞船 4 个关键系统，6 轮内逃出陨石带；光顾前场赚不到配件，光修船又会被客诉离场。

这正是真实产研 / 运维 / 互联网团队的日常缩影：一边是前场业务交付（接需求、出活、保客户满意度），一边是后场系统稳定性（修 Bug、还技术债、扛故障），而两者争抢的是同一池有限资源——工时 / 预算 / 人力。团建版把"飞船系统损坏"译成"稳定性健康度"，把"信用点"译成"团队预算 / 工时池"，把"顾客超时"译成"需求逾期 / 客户流失"，把"6 轮"译成"一个迭代周期 / 交付期限"。

🎯 团建改造重点

  • 双线作战（核心反转）：单一目标拆成"前场交付"与"后场稳定"两条必须并行的线
  • 资源零和分配：信用点只能二选一花在"赚"或"修"——逼团队直面接需求 vs 还技术债的预算博弈
  • 角色互补：业务 owner / 运维 SRE / 客户成功 PM / 风险 PMO / 技术专家
  • 危机即突发：陨石撞击 = 线上故障、顾客投诉 = 客诉、系统干扰 = 临时插队需求
  • 稳定性可视：4 条系统损坏条就是 4 张健康度仪表盘，任一满格 = 事故
  • 复盘框架：每局结束 4F 复盘，迁移到真实工作的需求与稳定性治理

🎯 团建目标

双线平衡观

体感"前场交付"与"后场稳定"必须同时跑，反思是不是总顾一头丢一头

资源博弈

看见"接需求赚的钱"和"修系统花的钱"抢同一池预算，体感还债被挤压

角色互补

业务 / 运维 / 客户成功 / PMO / 技术专家彼此依赖，"没有谁是无用的位置"

稳定性前移

引擎到 3 格就每轮多一张危机牌——体感隐患不修会滚雪球，训练治未病

🖨️ 无打印方案（临时团建）

  • 地图：白纸分两区——上"系统面板"（4 条各 5 格）、下"餐厅 + 后厨"（灶台 / 餐桌 / 服务台 / 商店）
  • 损坏条：4 张纸条各写 0-5，初始各标 2 格
  • 信用点：一堆放 10 枚硬币当公共池
  • 卡牌：便签写名称 + 效果（🌌/🍜/⚠️/🔩），分类面朝下抽
  • 骰子：手机骰子 APP，或 1-6 数字卡抽签

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，模拟真实团队的"攻与守"分工与相互依赖（也可按性格由教练分配）：

👨‍🍳 厨师长 · 业务 Owner / 交付主力

被动：烹饪仅耗 ½ 点

团建映射：高产出的核心交付手——"冲业务、出活"

🤖 修理机器人 · 运维 / SRE / 架构

被动：修复 -1 点且 +1 修复值

团建映射：稳定性兜底与还债——"修系统、扛故障"

🐙 章鱼服务员 · 客户成功 / 项目经理

被动：一次给 2 桌上菜

团建映射：横向补位、对接需求——"客户成功 / PM"

👩‍🚀 导航员 · PMO / 风险官

被动：每轮预览下 1 张危机牌

团建映射：风险前置、提前规划——"谁在盯隐患"

🧙 星际厨神 · 技术专家 / 架构师

被动：把普通料理升精致

团建映射：流程 / 质量优化——"把普通活做成精品"

🎲 游戏流程（每回合 4 阶段）

每回合依次执行：① 分配行动点 → ② 行动阶段（每人 4 行动点） → ③ 检查顾客等待 → ④ 危机事件（轮次 +1）。

核心机制 · 双线作战（团建灵魂）

前场接单烹饪上菜赚信用点，后场买配件修系统保稳定——两条线缺一不可。一个人只能在一个区行动，团队必须把人排兵布阵到双线。

资源 · 信用点 = 预算 / 工时池（零和）

接单赚的、修系统花的，都是同一池信用点。钱花在"赚"就少修，花在"修"就少交——这正是"接需求 vs 还技术债"的预算博弈。

危机 · 系统损坏条 = 稳定性健康度

引擎到 3 格每轮多翻 1 张危机牌（隐患滚雪球）；任一系统到 5 格即立即失败（线上事故）。游戏逼团队"稳定性前移"。

共享轨道与危机

共享轨道初始警告 / 失败阈值
系统损坏（4条）各2格3格 = 每轮多1张危机牌；5格 = 立即失败（事故）
公共信用点10点买配件 / 接单周转；归零且无收入 = 失败
顾客等待2桌在途超时 = 投诉扣信用点（客户流失）
轮次计数第1轮达6轮未达标 = 失败（交付期限到）

⚠️ 关键：胜负不取决于"谁做菜最多"，而取决于"前场交付与后场稳定是否双线达标"——光挣不修会出事，光修不交会被客诉。

💡 团建引导提示

游戏前（5分钟）

双线定调："既要接单交付，又要在 6 轮内把 4 个系统修健康，缺一不可。"

游戏中（观察）

记录：双线是否失衡？预算怎么花？谁在兜底稳定性？隐患前移了吗？前后台吵没吵？

游戏后（4F复盘）

事实→感受→发现→迁移，约15-20分钟；把"双线平衡"迁移到真实工作。

🔄 变体玩法

观察员模式

超5人时多出玩家任观察员，记录"双线是否失衡、预算流向、谁在兜底稳定性"，复盘提供第三方视角。

限时挑战

设60分钟 / 6 轮沙漏，以"是否双线达标"判胜负，适合时间有限团建。

角色轮换

每2回合轮换角色，体验"冲交付"与"修系统"两类职能，强化前后台相互理解。

无声前场

部分回合禁言接单 / 修系统，凸显"提前约定、显性同步"对双线协作的价值。

部门混编

拆散同部门到不同角色，强制"业务 / 技术 / 职能"跨界搭档，专为打破部门墙设计。

真实技术债叠加

把系统损坏条换成当前真实技术债/隐患便签，每修1格=还1项债，便签变技术债治理看板。

真实需求池叠加

把订单卡换成当前在途需求/客户承诺便签，超时=真实客诉，复盘直接盘点需求优先级。

⚙️ 难度调整

模式调整适合
简单损坏降至1格、耐心+1轮、信用点15、危机堆减4张新团队/非玩家
标准（推荐）损坏各2格、信用点10、共6轮、四系统各≤1格+信用点≥5+无超时大多数团建
