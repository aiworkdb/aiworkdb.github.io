# 芙莉莲的旅程 (Frieren's Journey)

> **团队协作 · 慢旅途 · 角色互补**  
> 适合：团队协作 / 角色分工 / 压力沟通 / 目标共识训练

---

## 🎯 游戏目标

改编自同名合作桌游（《葬送的芙莉莲》同人创作）。玩家组成一支冒险小队，沿着艾兰大陆的旅途路线，穿越森林、山脉、荒漠与海岸，最终抵达传说中的「天国之地」。

**团建核心价值**：
- 🤝 **高度合作**：抉择事件必须团队讨论、共享胜负，天然促进团队感
- 🎭 **角色互补**：4 种职能卡模拟真实团队分工与相互依赖
- ⏳ **时间管理**：有限的「时间沙漏」模拟项目 deadline 与节奏压力
- 🗺️ **目标共识**：抵达终点只是起点，结局评级考验过程中的取舍
- 💬 **深度沟通**：二选一抉择事件强迫团队对齐价值观与优先级

### 无打印方案（临时团建）

- **地图**：白纸画起点→终点线性路线，标出 8 个区域名
- **卡牌**：便签写事件/委托名称与效果，面朝下抽
- **角色卡**：直接写字说明职责
- **沙漏**：6 枚硬币，每到达新区消耗 1 枚

## 🗺️ 旅途地图（8个区域）

团队从 🏰**奥伊伦贝尔** 出发，沿线性路线前进，最终抵达 🏔️**天国之地**。

| 顺序 | 区域 | 特色 |
| :--- | :--- | :--- |
| 1 | 🏰 奥伊伦贝尔（起点） | 整备出发，接取初始委托 |
| 2 | 🌲 艾兰大森林 | 可采集草药（回复HP） |
| 3 | 🏔️ 维根山脉 | 移动消耗+1，但获得魔法石 |
| 4 | 🏘️ 各各马大公国 | 村庄：休息 + 接委托 |
| 5 | 🏜️ 南部荒漠 | 移动需掷骰>3，否则停留 |
| 6 | 🌊 西部海岸 | 可交易资源、补充物资 |
| 7 | 🏛️ 王都 | 魔法遗迹：学习新魔法 |
| 8 | ⛰️ 终焉山脉 → 🏔️ 天国之地（终点） | 最终章节，触发结局评级 |

> 💡 **团建映射**：8 个区域 = 项目的时间线里程碑；时间沙漏 = 固定交付周期；村庄休息 = 阶段性复盘与补给。

## 👥 角色分配（团建核心改造）

每位玩家承担一个专属角色，对应团队中的典型职能：

| 角色 | 职能定位 | 特殊能力 | 团建观察点 |
| :--- | :--- | :--- | :--- |
| 🧙 **芙莉莲** | 魔法核心 / 输出·辅助 | 「魔法精通」：学魔法时查看3选1 | 专业能力 vs 资源节制 |
| 🗡️ **费伦** | 坦克 / 主输出 | 「勇者之剑」每回合额外攻击1次 | 保护他人、承担风险 |
| ⚔️ **修塔尔克** | 远程输出 / 灵活支援 | 「精灵弓箭手」可打后排 | 信息侦察与灵活补位 |
| 🛡️ **海塔** | 治疗 / 支援（扩展） | 「治愈术」每回合为1队友回2HP | 隐性价值与兜底保障 |

**教练提示**：首轮自由选角，次轮轮换角色，体验「输出」与「守护」两类截然不同的职能压力。

## 🎲 游戏流程（每回合）

每回合按固定顺序推进，强调「先讨论、再行动」：

#### 阶段1：移动阶段（团队讨论）
- 当前玩家掷骰（1d6），沿路线前进
- 经过村庄可短暂停留（接委托 / 休息）

#### 阶段2：地形揭示
- 到达新区域抽取地形卡，触发对应效果

#### 阶段3：事件阶段（关键沟通点）
- 友好事件：立即获得好处
- 危险事件：立即承受后果
- **抉择事件**：团队讨论后共同决定（需全员同意或多数表决）——这是团建复盘最丰富的素材

#### 阶段4：委托阶段（可选）
- 在村庄可接取委托卡，完成后获得奖励与声望

#### 阶段5：遭遇阶段（如触发战斗）
- 抽魔物卡进入战斗，魔物攻击目标由团队共同决定（保护HP低者）

#### 阶段6：学习阶段
- 在遗迹/魔法塔消耗魔法石学习新魔法

#### 阶段7：回合结束
- 消耗 1 个时间 token；token 用尽触发「时间耗尽」，3 回合内未达终点即**团队失败**

## 🏆 胜利与失败

### 胜利条件（共享胜利）
| 结局 | 条件 |
| :--- | :--- |
| 🏆 完美结局 | 抵达「天国之地」且完成 ≥3 个B级委托 |
| 🎯 标准结局 | 抵达「天国之地」 |
| 🌟 隐藏结局 | 集齐 8 张 II 级以上魔法卡且全员存活到达 |

### 失败条件
- ⏳ 时间沙漏用尽且 3 回合内未达终点
- 💀 所有玩家 HP 归零且无人持有「复活魔法」
- 💀 累计失败 5 次委托

## 🤔 复盘框架（4F）

| 维度 | 引导问题 |
| :--- | :--- |
| **事实 Facts** | 哪个抉择事件引发了最大分歧？时间沙漏最早在哪段路程告急？委托优先级是如何定的？ |
| **感受 Feelings** | 扮演[角色]让你感觉如何？被保护 / 被忽视的时刻是什么？时间耗尽压力下你的情绪变化？ |
| **发现 Findings** | 谁的意见被忽略？"赶路 vs 接委托"的取舍反映了什么？角色轮换后你对其他职能的理解有何变化？ |
| **迁移 Future** | 这段旅途像你工作中的哪个项目？我们可以立即改进协作的一件事是什么？ |

## 🔄 变体玩法（团建专用）

| 变体 | 规则 | 团建目的 |
| :--- | :--- | :--- |
| 观察员模式 | 超 4 人时多出玩家任观察员，记录协作过程 | 第三方视角复盘 |
| 限时挑战 | 沙漏压缩至 45 分钟 | 增强决策压力 |
| 角色轮换 | 每 2 区域轮换角色 | 换位思考、体验职能差异 |
| 沉默旅途 | 抉择事件后回合仅用写字/肢体沟通 | 凸显非语言沟通 |
| 剧情模式 | 按动漫顺序解锁区域，加入「经典台词」情感卡 | 建立情感联结、破冰 |

## 💡 教练引导指南

### 开场话术
> "接下来我们要一起完成一段旅途。你们是一个小队，共享时间、共享胜负。旅途中会不断遇到需要共同决定的岔路口——有人想赶路，有人想接委托，关键是没有人能替所有人做主。注意你们的讨论方式，这往往就是工作中协作模式的缩影。"

### 观察要点
1. **决策主导者**：谁在抉择事件中最常发声？谁被边缘化？
2. **时间观**：团队是激进赶路还是保守接委托？谁在提醒"时间不够了"？
3. **角色认知**：扮演辅助/治疗角色的玩家是否感到被需要？
4. **冲突处理**：分歧出现时是辩论、妥协还是表决？
