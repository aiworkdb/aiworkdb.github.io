# 猎人小队 · 协同升级版 (Hunter Squad)

## 🎯 游戏概述（团建版）

《猎人小队 · 协同升级版》改编自合作桌游《独行猎人 Solo Leveling Hunters》（改编自动漫《我独自升级》的合作地下城桌游）。原作里每位玩家都是独自刷副本、靠击杀升级的个人英雄；团建版里，玩家组成一支**猎人小队**，组队深入 5 层地下城，通过分工清怪、共享经验与装备、搭伙打 Boss，把"我独自升级"彻底改写成"**团队一起升级**"。

原作最迷人的系统——击杀累积经验、升级提升属性、从萌新到满级——正是真实团队里"能力成长"的绝妙隐喻。但原作默认"各练各的"，团建版特意把它反转为：**你的成长不是孤立的，团队的传帮带、经验共享、搭子制度，会把每个人的成长曲线都拉得更陡**。在团建语境下，地下城就是一支**正在爬坡/攻坚的团队**，怪物是业务风险与能力短板，Boss 是那个绕不过去的里程碑；能不能让全员一起升起来、而不是只有少数人在扛，正是真实工作中"共同成长 vs 能者多劳"的缩影。

### 团建改造重点

- **协同升级（核心反转）**：把"我独自升级"改成"团队经验池共享"——经验入池、按需分配给最需要成长的人，体感"传帮带让成长更陡"
- **角色互补**：剑士（兜底）/ 法师（攻坚）/ 弓箭手（点杀）/ 牧师（补给）/ 战术指挥（统筹），映射真实团队的攻守与调度
- **装备/资源共享**：把"好东西给最需要的人"而非囤积，训练"资源流向最该用的地方"
- **搭子带练（mentor）**：新手与资深绑成搭子，经验加成——还原"师徒制 / buddy 系统"的价值
- **成长焦虑与期限**：30 回合塌陷（交付期限）+ 队伍士气（离职潮 / 团队崩），逼团队在"催进度"与"养人"之间平衡
- **复盘框架**：每局结束 4F 复盘，把"升级与成长"迁移到真实工作的能力建设

## 🎯 团建目标

1. **协同升级观**：体验"经验共享 + 传帮带"比"各练各的"成长更快，反思团队里是不是总靠少数人在扛
2. **角色互补**：看见坦克兜底、输出攻坚、辅助补给、指挥统筹的相互依赖，体感"没有谁是无用的位置"
3. **资源流向**：把好装备 / 经验给最需要的人，训练"资源去到最产生价值的地方"而非囤积
4. **带练文化**：搭子模式下新手持资深搭子加成——体感"师徒 / buddy 系统"不是负担而是加速器
5. **团队复盘**：每局引导 4F 复盘，把"升级与成长"迁移到真实工作的能力建设与人才培养

## 🗺️ 游戏地图（简化版）

地下城为**5 层线性副本**，团建语境里它是团队"能力进阶"的五个阶段：

| 层级 | 团建隐喻 | 怪物强度 | 功能点 |
| :--- | :--- | :--- | :--- |
| 第 1 层 · 入门 | **新人融入 / 上手期** | 弱（哥布林） | 休息点🌿、观察点👀多，安全练手 |
| 第 2 层 · 进阶 | **独立承担** | 中（兽人） | 宝藏点💰、事件点🎲 |
| 第 3 层 · 熟练 | **独当一面** | 强（骷髅/巨魔） | 怪物巢穴，需配合 |
| 第 4 层 · 精通 | **攻坚突破** | 很强（巨魔/龙族） | 宝藏库💎，资源丰但险 |
| 第 5 层 · 突破 | **里程碑 / 大考** | Boss🐲（300 血） | 全队合力才能过 |

> 💡 **核心张力**：原作里"越深层越强，全靠自己扛"；团建版里深层怪物**必须靠角色互补 + 经验共享才打得过**——一个人再强也顶不住 Boss，这正是"团队成长 > 个人英雄"的设计意图。

## 🎲 游戏规则（团建版）

### 准备阶段

1. **展开地图**：5 层地下城依次排开，玩家棋子放第 1 层入口
2. **设置轨道**：经验池 = 0；士气 = 10；回合计数 = 0
3. **分配角色**：每人选 / 抽 1 张角色卡，了解职能映射与被动
4. **洗混卡牌**：怪物 / 装备 / 技能 / 事件 / 消耗品各自洗混面朝下
5. **带练绑定（变体7）**：若启用，将新手与资深绑成搭子，经验 +20%
6. **决定先手**：投骰点数大者先手

### 角色分工（团建核心改造）

为加强团队协作，每位玩家承担专属职能，映射真实团队中的"攻守与调度"：

| 角色 | 图示 | 团队职能映射 | 被动能力（团建视角） |
| :--- | :--- | :--- | :--- |
| **剑士** | 🛡️ | 质量 / 中台 / 风险兜底 | 承受伤害+1、替队友挡刀——"稳底盘、兜底" |
| **法师** | 🔮 | 业务攻坚 / 技术突破 | 范围伤害、群体秒怪——"主攻手、攻坚" |
| **弓箭手** | 🏹 | 精准突破 / 要事第一 | 必中弱点、点杀关键——"抓关键窗口" |
| **牧师** | ✨ | 情绪补给 / 资源协调 | 群体治疗、共享 MP——"心理安全 / 补给 / PMO" |
| **战术指挥** | 📜 | 统筹 / PMO / Leader | 预看事件、分配经验——"调度 / 传帮带" |

> 💡 **团建提示**：3-4 人局可让任意角色"兼任"两种职能；首轮自由选角，次轮轮换（换位思考）。战术指挥"分配经验"是复盘重点——真实团队里"谁在负责让大家一起成长"？

### 游戏流程（每回合 4 阶段）

#### 阶段一：事件阶段 🎲（必须）
翻开 1 张事件卡立即执行（好运或挑战）；全员共同承受效果（士气 +/- / 经验 +/-）。

#### 阶段二：行动阶段 🎯（每人 2 行动点）
按座位顺序，每人 2 次行动（移动 / 攻击 / 用技能 / 用消耗品 / 搜装备 / 休息 / 经验入池）。

#### 阶段三：结算阶段 🔍（必须）
- 击败怪物 → **经验入团队池**（非个人！），可立即按 100/级分配给最需成长者
- 队员阵亡 → 入口复活，损失部分装备；士气 -1
- 装备掉落 → 落入公共区，**可交易 / 分配**给最需要的人

#### 阶段四：结束阶段 🔚（必须）
回合计数 +1（逼近 30 塌陷）；士气自然 -0（仅事件/阵亡扣）；传递先手；检查是否已清完 5 层 + 击败 Boss。

### 共享轨道与危机

| 共享轨道 | 初始 | 警告 / 失败阈值 |
| :--- | :--- | :--- |
| 团队经验池 | 0 | 每 100 升 1 级（能力基线）；全员满级即"团队出师" |
| 队伍士气 | 10 | ≤ 3 触发"低迷警报"；≤ 0 即失败（离职潮 / 团队崩） |
| 副本深度 | 第 1 层 | 清完 5 层 + 击败 Boss = 胜利 |
| 回合计数器 | 0 | 达 30 塌陷 = 失败（交付期限到了还没打完） |

### 胜利与失败

**主胜利（同时满足）**：全队推进至第 5 层并击败 Boss🐲（300 血），且**至少 1 名玩家存活、士气 > 0**。

**失败（任一即全队失败）**：
- 队伍士气 ≤ 0（团队崩 / 离职潮）
- 回合计数达到 30（副本塌陷 / 交付期限到了）
- 全员阵亡且无法复活

> 💡 **关键**：胜负不取决于"谁杀怪最多"，而取决于"经验有没有共享、装备有没有给对人、新人有没有被带起来、士气有没有守住"。这正是"团队成长 > 个人英雄"的体感。

## 📖 完整游戏流程示例

### 示例：5 名玩家的第 6 回合（深入第 3 层）

**阵容**：剑士（兜底）、法师（攻坚）、弓箭手（点杀）、牧师（补给）、战术指挥（统筹）。其中弓箭手为新人，与牧师绑成搭子（经验 +20%）。

**当前状态**：经验池 420（已升 4 级）；士气 7；第 3 层，前方 2 只巨魔 + 1 只骷髅。

**阶段一 · 事件**：🎲「神秘商人」——可花经验换 1 件稀有装备。战术指挥决定：**把稀有护甲给剑士（兜底更稳），不囤**。

**阶段二 · 行动**
- **剑士**：挡在前面吸引 2 只巨魔火力，承受伤害但护甲减伤（兜底立功）
- **法师**：范围火球清掉骷髅群（攻坚秒小怪）
- **弓箭手（新人）**：在牧师搭子加成下点杀 1 只巨魔弱点（成长曲线被带陡）
- **牧师**：群体治疗拉回全员血量 + 与弓箭手共享 MP（补给 + 传帮带）
- **战术指挥**：把本回合击杀所得 80 经验优先分 30 给弓箭手（让他更快升级）

**阶段三 · 结算**：经验池 420→500；弓箭手分到经验后接近升级；通关第 3 层，进入第 4 层。

**阶段四 · 结束**：回合 6→7；士气 7 安全；战术指挥复盘式提醒："别光顾着冲，弓箭手还在成长期，护着他。"

> 💡 **团建点**：团队当场体感——"如果经验都归自己，弓箭手要很久才起得来；但指挥把经验分给最该成长的人、牧师还绑了搭子，新人的曲线一下就陡了。最稳的不是个人最强，是大家一起强。"这正是带练文化的日常。

## 💡 团建引导提示

### 游戏前（5分钟）

1. **反转主题**："原作叫《我独自升级》，但我们今天玩的是《我们一起升级》——经验进团队池，谁最需要就分给谁。"
2. **强调共享**："怪物掉的好装备别囤，给最该用的人；经验别自己独吞，带新人才是加速器。"
3. **角色分配**：自由选角，或教练按性格分配（让爱冲的人做攻坚、让细致的人做兜底、让资深的人做搭子）。
4. **期限提醒**："30 回合副本就塌了——和真实工作一样，既要催里程碑，也要养人，别到最后没人能打。"

### 游戏中（观察要点）

教练或观察员应记录：

1. **谁在带人？** 经验是不是流向了最需要成长的人，还是被老员工"顺手"拿走？
2. **谁在兜底？** 剑士默默扛伤——这些"底座工作"被看见了吗？
3. **装备去哪了？** 好东西是分给最该用的人，还是谁手快归谁 / 谁强归谁？
4. **新人怎样？** 搭子模式下新人有没有真的被带起来，还是被晾在一边？
5. **士气几了？** 团队有没有"养人 vs 催进度"的平衡意识？

### 游戏后（复盘框架 · 4F）

使用以下框架引导团队复盘（15-20分钟）：

#### 1. 事实（Facts，4分钟）
> "哪一回合最险？当时经验池几、士气几？是谁先说'经验分给新人'还是'我自己升'？"

#### 2. 感受（Feelings，5分钟）
> "新人被带起来时你什么感受？装备被分给别人时你舍得吗？士气见底时你慌吗？"

#### 3. 发现（Findings，6分钟）
> "我们的经验是不是又流回老员工手里（能者多劳视角）？谁在负责'让大家一起成长'？新人真的被带起来了吗？"

#### 4. 迁移（Future，5分钟）
> "这个游戏让你联想到工作中的哪个场景（如某新人入职后没人带、某能力强的人一直被榨、培养机制缺失）？一件能立即做的事是什么？"

## 🔄 变体玩法（团建专用）

### 变体1：观察员模式（适合大型团队）
人数超 5 人时，多出玩家任 **观察员**：专门记录"经验流向、谁在兜底、新人是否被带"，复盘时提供第三方视角。

### 变体2：限时挑战（增加紧迫感）
设沙漏 60 分钟 / 30 回合即结算，以"是否清完 5 层 + 击败 Boss"判胜负；适合时间有限团建。

### 变体3：角色轮换（换位思考）
每 2 回合轮换一次角色，确保每人都体验"兜底"与"攻坚 / 补给 / 统筹"几类职能，强化相互理解。

### 变体4：无声副本（沟通挑战）
部分回合禁言，凸显"提前约定、显性同步"对配合型协作的价值。

### 变体5：部门混编（跨部门磨合）
将同部门的人拆散到不同角色，强制跨部门搭档，专为"打破部门墙、训练横向补位"设计。

### 变体6：真实能力短板叠加（能力建设主题 · 推荐）
把"怪物卡"替换成团队 **当前能力短板 / 待提升项**（便签上墙），每击败 1 只"怪"= 突破 1 项能力短板；游戏结束便签直接变能力改进看板。

### 变体7：新人带练（融入 / 培养主题 · 推荐）
将 1-2 名新手与资深绑成 **搭子**，经验 +20%、可共享 MP / 装备；复盘重点讨论"我们怎么让新人最快成长起来"。

## ⚙️ 难度调整

### 简单模式（新手团队 / 第一次团建）
- 怪物血量与攻击减半、初始士气 12、经验门槛降到 80/级、回合上限 40
- **适合**：刚组建的团队、非游戏爱好者

### 标准模式（推荐）
- 怪物标准、士气 10、经验 100/级、回合上限 30、第 5 层 Boss 300 血
- **适合**：大多数团建场景

### 困难模式（成熟团队 / 攻坚主题）
- 怪物血攻 ×1.5、初始士气 8、回合上限 22、Boss 450 血、禁囤装备（必须分配）
- **适合**：业务攻坚 / 冲刺团队，强调极限协同与培养

## ❓ 常见问题

**Q：3个人怎么玩？**
A：选 3 名核心角色（剑士 / 法师 / 牧师），其余职能标注"兼任"；共享经验池与士气机制不变，仍强调协同升级。

**Q：为什么强调"经验入团队池"而不是各练各的？**
A：因为原作的核心反转就在这里——真实团队里"一个人再强也顶不住 Boss"，让经验流向最需要成长的人，整体成长更快。这恰是带练 / 传帮带的价值。

**Q：士气为什么重要？**
A：它隐喻团队状态 / 离职潮——光催进度不打气，士气归零团队就崩。游戏逼团队在"催里程碑"与"养人"之间找平衡。

**Q：没有骰子怎么办？**
A：手机骰子 APP，或准备 1-6 / 1-20 数字卡代替。

**Q：为什么把怪物换成真实能力短板（变体6）？**
A：游戏瞬间变成一次低风险的"能力盘点会"，让"成长与培养"直接服务于真实工作，复盘结论更易落地。

## 🧰 教练工具箱

### 引导话术

**游戏前**：
- "记住，今天不玩《我独自升级》，我们玩《我们一起升级》。"
- "怪掉的经验和好装备，进公共池——给最该用的人，别囤。"
- "30 回合副本就塌，既要打 Boss，也要把新人带起来。"

**游戏中**（适时提醒）：
- "经验池现在几了？要不要先分给新人一级？"
- "剑士又在扛伤，有人看到吗？"
- "士气到几了？别光冲进度忘了养人。"

**复盘时**：
- "先安静 30 秒，回想一下弓箭手升级那一刻。"
- "我想听听[沉默玩家]的想法，你当时在守哪块？"
- "我们的经验是不是又流回老员工手里？下次怎么更均衡？"

### 安全与边界

1. **心理安全**：若因士气归零失败而沮丧，教练应强调"这是游戏，成长本来就是用来练手的"——把失败正常化
2. **包容性原则**：对游戏不擅长的玩家提供额外指导，而非让其感到羞耻
3. **知识落地**：变体6 / 7 的便签看板建议拍照留存，真的可能变成团队的能力改进项 / 新人培养计划
4. **时间管理**：严格控制游戏与复盘时间，避免拖延
