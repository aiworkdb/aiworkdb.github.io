🎮 游戏概述

《末日种子库》改编自同名合作桌游。公元2048年，全球生态连锁崩溃，人类最后的希望埋藏在永冻层深处的全球种子库。玩家扮演种子库的守护者团队，在生命支持系统逐步衰竭的极限环境下远征探险、收集濒危物种、维护系统运转。

所有玩家通力合作——分配电力、维持温度、保障氧气，在系统完全崩溃前保存足够多的植物物种。这是一个关于资源协作与危机取舍的绝佳团建载体。

🎯 团建改造重点

  • 合作而非竞争：共享系统状态、共享资源库、共享胜负
  • 角色分工：5种专属职责，模拟真实团队职能
  • 共享资源管理：三系统在崩溃边缘考验共同决策
  • 危机应对：事件卡不断施压，模拟真实 deadline
  • 复盘框架：每局结束引导反思采集与守护的权衡

🎯 团建目标

共享资源管理

在系统濒临崩溃时共同制定策略与优先级

角色分工

体验不同角色的职责边界与相互依赖

压力沟通

在系统告警的紧迫中清晰表达、同步信息

危机决策

权衡"再采一批 vs 先保系统"，学会取舍

🖨️ 无打印方案（临时团建）

  • 系统轨道：纸上画3条进度条，用笔画标记当前值
  • 卡牌：便签写名称与效果，面朝下抽
  • 地图：白纸画基地与6地点节点并连线
  • 事件卡：教练口述效果

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，模拟真实团队中的职能分工与相互依赖：

👷‍♀️ 首席工程师

职责：维护系统、修复损伤

被动：修复系统效果+1｜主动：「紧急重启」将任一系统恢复到上限一半

🌾 植物学家

职责：专注种子入库

被动：入库资源需求-1（每类至多-1）｜主动：「绿色奇迹」任意1张种子卡无视资源直接入库

🛡️ 安全主管

职责：防控风险与事件

被动：免疫远征地点特殊风险｜主动：「全面封锁」取消本次事件卡效果并销毁

📦 后勤官

职责：保障资源供给

被动：资源交换比优化（2:1代替3:1）｜主动：「战时配给」每人各得 ⚡×1+🍖×1+💊×1

🧭 野外探险家

职责：外出采集种子

被动：移动与远征搜索各省1 AP｜主动：「极限生存」本次远征免风险且搜索+1张

提示：3人局推荐 探险家+后勤官+植物学家；首轮自由选角，次轮可轮换角色体验不同职能。

🗺️ 远征地图（7个地点）

团队从🏠基地营地（安全区）出发，沿连线移动到相邻地点搜索种子，回合结束自动返回基地。

🏠 基地
基地营地｜安全｜恢复1HP；免费存取资源库｜无风险
🌿 亚马逊
亚马逊废墟｜★★☆｜高概率普通/稀有种子｜毒虫叮咬（失1HP或1食物）
❄️ 西伯利亚
西伯利亚冻土｜★☆☆｜耐寒物种；必得1能量｜严寒冻伤（需1食物或失1HP）
🦁 非洲
非洲草原｜★★★｜高概率稀有/史诗｜野生动物袭击（失2HP）
🏝️ 太平洋
太平洋环礁｜★★☆｜稀有沿海物种；可能得设备｜海啸警报（弃种子或失2HP）
⛰️ 喜马拉雅
喜马拉雅山谷｜★★★★｜极高概率稀有/史诗/传说｜高原反应+雪崩（需1医疗+1食物，否则-3HP）
🫒 地中海
地中海遗迹｜★★★｜栽培遗产种子；可能出传说｜辐射泄漏（需1零件修复，否则-2HP）

🎲 游戏流程

阶段一：准备与守护启动（10分钟）

  • 布置面板：三系统置于 电力10/温度8/氧气9
  • 选角分工：每位玩家选择一个角色
  • 初始资源：公共库 ⚡×6🍖×6💊×4🔧×4；每人 ⚡×2🍖×2 + 随机3张种子
  • 明确目标：保存 ≥25 种不同物种，在系统崩溃前达成

阶段二：守护远征（40分钟）

玩家轮流行动，每回合约 4个行动点：移动 / 远征搜索 / 发电 / 配给 / 调配 / 搜索零件 / 入库 / 修复系统 / 治疗 / 传递资源；回合末抽1张事件卡并执行。

系统危机：任意系统归零产生严重负面叠加；2个及以上系统同时归零团队立即失败。

阶段三：总结复盘（15分钟）

使用下方 4F 框架进行深度反思（事实→感受→发现→迁移）。

🤔 复盘框架（4F）

事实 Facts（发生了什么？）

  • 哪条系统最早告急？最关键的取舍决策是什么？谁提出的？
  • 资源分配是共同商议，还是某人替大家决定？

感受 Feelings（体验如何？）

  • 系统一路告警时，你最紧张/最有安全感的时刻是什么？
  • 扮演[角色]让你感觉如何？是否被需要？

发现 Findings（学到了什么？）

  • 谁的意见被忽视了？面对系统崩溃我们怎么处理的？
  • 如果重来一次，外出采集与守护系统的节奏会怎么调整？

迁移 Future（接下来做什么？）

  • 这个游戏让你联想到工作中的哪个场景？
  • 我们可以做哪些改变？一件能立即改进的事是什么？

🔄 变体玩法

观察员模式

超6人时多出玩家任观察员，记录协作过程，复盘时提供第三方视角。

限时挑战

沙漏55分钟，时间到即时结算，增加紧迫感与决策压力。

角色轮换

每2回合轮换角色，体验"外出"与"守护"两类职能，强调换位思考。

沉默守护

系统告警后的回合不能说话，仅肢体/写字，凸显非语言沟通。

⚙️ 难度调整

简单模式

三系统各+2、移除4张最严危机、胜利降至20种。适合新手团队。

标准模式

电力10/温度8/氧气9、胜利25种。适合大多数团建场景。

困难模式

三系统各-2、加入选择事件、胜利升至30种。适合高层/抗压主题。

💡 设计思路

为什么选这个游戏？

  1. 高度合作：共享系统与胜负，天然促进团队感
  2. 角色互补：5种职能卡模拟真实团队分工
  3. 危机渐进：系统逐一告警，模拟项目推进中的风险累积
  4. 取舍即终点：广度优先取胜，呼应"抗风险靠覆盖面"

与工作场景的映射

游戏要素工作场景
三系统（电/温/氧）预算、人力、时间等公共资源
事件卡突发风险、竞争对手、政策变化
5种角色团队成员的职能专长
