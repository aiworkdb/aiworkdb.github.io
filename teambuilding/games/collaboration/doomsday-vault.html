🎯 游戏概述（团建版）

公元 2048 年，一场全球性的生态连锁崩溃摧毁了地表绝大部分生态系统。人类最后的希望，埋藏在斯瓦尔巴群岛永冻层深处——全球种子库（Global Seed Vault）。

玩家扮演种子库的守护者团队，必须在生命支持系统逐步衰竭的极限环境下，通过远征探险收集濒危物种种子、维护种子库运转、应对各类危机事件。所有玩家通力合作，目标是在系统完全崩溃前，成功保存足够多的植物物种，为人类文明的复兴保留最后的火种。

团建改造重点

  • 合作而非竞争：所有玩家共享种子库系统状态、共享资源库、共享胜负，强调团队一盘棋
  • 角色分工：每位玩家承担专属职责（工程 / 植物 / 安全 / 后勤 / 探险），模拟真实团队职能
  • 共享资源管理：有限的电力/温度/氧气三大系统需要团队共同决策，考验资源分配与优先级判断
  • 危机应对：事件卡不断给系统施压，模拟真实工作中的突发风险与 deadline 压力
  • 复盘框架：每局结束引导团队反思"外出采集 vs 维护系统"的权衡过程

🎲 游戏规则（团建版）

准备阶段

  1. 布置面板：主面板放中央，3条系统轨道置于初始值（电力10 / 温度8 / 氧气9），已保存物种库区域预留25格
  2. 放置地图：远征地图放旁边，每位玩家棋子放在🏠基地营地
  3. 洗牌分组：种子卡、资源卡（按4类分堆）、事件卡（按人数裁剪）洗混
  4. 分发初始资源：公共资源库 ⚡×6、🍖×6、💊×4、🔧×4；每位玩家手牌 ⚡×2、🍖×2 + 随机3张种子卡
  5. 选择角色：5张角色卡正面朝上，按顺时针选角（或教练按性格分配）
  6. 决定先手：掷骰子点数最大者为"值班守护者"，顺时针轮流

角色分工（团建核心改造）

为加强团队协作，每位玩家需承担一个专属角色：

角色职责被动技能主动技能（每局限1次）
首席工程师 👷‍♀️维护系统、修复损伤修复系统效果+1「紧急重启」：将任一系统直接恢复到上限一半
植物学家 🌾专注种子入库入库资源需求-1（每类最多减1）「绿色奇迹」：任意1张种子卡无视资源直接入库
安全主管 🛡️防控风险与事件免疫远征地点特殊风险「全面封锁」：取消本次事件卡效果并销毁
后勤官 📦保障资源供给资源交换比优化（2:1代替3:1）「战时配给」：每人各得 ⚡×1+🍖×1+💊×1
野外探险家 🧭外出采集种子移动与远征搜索各省1 AP「极限生存」：本次远征免风险且搜索+1张
💡 团建提示：3人局推荐 探险家+后勤官+植物学家；首轮自由选角，次轮可轮换角色体验不同职能。

游戏流程（每个回合）

每位玩家轮流行动，每回合含 4个行动点（AP）（野外探险家因被动得 5 AP）：

行动消耗说明
🚶 移动1 AP移动到相邻地点（探险家0 AP）
🔍 远征搜索2 AP在当前地点搜索，掷1d6得1-3张种子卡，触发特殊风险
⚡ 发电2 AP获得 ⚡×2（仅基地）
🍖 配给口粮1 AP获得 🍖×1（仅基地）
💊 调配医疗2 AP获得 💊×1（仅基地）
🔧 搜索零件2 AP获得 🔧×1（仅基地）
📦 入库保存1 AP+资源消耗对应资源，将1张种子卡放入物种库
🛠️ 修复系统1-3 AP消耗 🔧，使系统回复（1AP=+1，2AP=+3，3AP=+5）
💉 治疗1 AP+💊自身/他人恢复 2 HP
🤝 传递资源1 AP向他人或公共库转交资源
😴 休息1 AP在基地恢复1 HP

回合末：当前玩家从事件堆抽1张事件卡并立即执行；检查系统状态（电力≤3则下家行动+1AP、氧气≤3则全员回合开始-1HP、事件堆耗尽则进入最终3回合倒计时）。

系统轨道与危机

系统图标初始归零后果
电力系统⚡10所有行动+1 AP成本；无法使用设备卡
温度控制❄️8稀有/传说种子每回合随机损失1张
氧气循环🫁9所有玩家每回合失去1 HP
⚠️ 关键：单个系统归零不立即判负（但有严重负面叠加）；若 2个或以上系统同时归零，团队立即失败！

胜利与失败

主胜利：已保存物种库中不同名称物种 ≥ 25 种 即获胜（同名种子重复只算1种，鼓励去不同地点）。

失败（任一即全队失败）：

  • 双重崩溃：2个或以上系统同时归零
  • 全军覆没：所有玩家 HP 归零（进入重伤）
  • 时间耗尽：事件堆用完且最终3回合后仍未达25种

📖 完整游戏流程示例

示例：4人游戏第1-3回合

阵容：小明（首席工程师4HP）、小红（植物学家4HP）、小刚（后勤官5HP）、小兰（野外探险家3HP）

第1回合 — 小明（首席工程师）

  1. 移动（1 AP）：基地 → 亚马逊废墟 🌿
  2. 远征搜索（2 AP）：掷 d6=4 → 得2张种子（水稻🌱 + 咖啡☕🌿）
  3. 触发风险 — 毒虫叮咬：付1张🍖免疫伤害 ✅
  4. 剩1 AP → 返回基地（远征后免费返回）
  5. 抽事件：太阳风暴 ☀️⚡ → 电力 10→7
  6. 手牌：水稻🌱、咖啡☕🌿、⚡×2、🍖×1

第2回合 — 小红（植物学家）

  1. 入库—水稻（1 AP）：普通种子，无需资源 ✅（物种库+1）
  2. 入库—咖啡（1 AP+⚡×1）：被动使需求-1，正好需⚡×1 ✅（物种库+1，2VP）
  3. 调配医疗（2 AP）：获 💊×1
  4. 抽事件：救援物资空投 ✈️📦 → 公共库 +⚡×3+🍖×2+💊×1

第3回合 — 小刚（后勤官）

  1. 发电（2 AP）：获 ⚡×2
  2. 配给口粮（1 AP）：获 🍖×1
  3. 传递资源（1 AP）：把起手 ⚡×2 转公共库
  4. 抽事件：能源抉择 ⚡🤔 → 团队讨论选B：每人 +⚡×2
💡 小结：3回合内物种库已收入2种、资源充裕，但系统已现波动（电力7）。团队开始意识到"外出采集"与"守护系统"的张力。

💡 团建引导提示

游戏前（5分钟）

  1. 介绍主题："世界正在崩塌，我们是最后的种子守护者。要在系统彻底停摆前，为文明留下25种希望。"
  2. 强调合作："电力、温度、氧气都是共享的，一个人耗尽系统，全队一起遭殃。"
  3. 角色选择：让玩家自由选角，或教练按性格分配（如让平时少发言者选安全主管，锻炼"喊停"的勇气）
  4. 鼓励沟通："系统开始告警时，请大声同步！别等归零才说。"

游戏中（观察要点）

教练或观察员应记录：

  1. 谁在做系统决策？ 是值班守护者，还是某位强势玩家替大家决定？
  2. 谁很少发言？ 是否有玩家被边缘化（尤其后勤、安全这类"幕后"角色）？
  3. 资源分配是否共同商议？ 还是某人独占公共资源库？
  4. 面对系统告警时团队反应如何？ 互相指责还是共同求解？
  5. 是否知道"何时收敛"？ 还硬撑外出采集直到双重崩溃？

游戏后（复盘框架 · 4F）

使用以下框架引导团队复盘（15分钟）：

1. 事实（Facts，3分钟）

"我们哪条系统最早告急？最关键的取舍决策是什么？是谁提出的？"

2. 感受（Feelings，4分钟）

"系统一路告警时你最紧张/最有安全感的时刻是什么？扮演[角色]让你感觉如何？是否被需要？"

3. 发现（Findings，5分钟）

"我们的资源分配公平吗？谁的意见被忽视了？面对失败（系统崩溃）我们怎么处理的？如果重来一次，外出与守护的节奏会怎么调整？"

4. 迁移（Future，3分钟）

"这个游戏让你联想到工作中的哪个场景（如临近上线的项目、预算紧张的周期、多人抢同一资源）？我们可以做哪些改变？一件能立即改进的事是什么？"

🔄 变体玩法（团建专用）

变体1：观察员模式（适合大型团队）

人数超过6人时，多出玩家任观察员：记录协作过程（主导者/沉默者/冲突/亮点/建议），不干扰游戏，复盘时提供第三方视角。

变体2：限时挑战（增加紧迫感）

设置沙漏 55分钟，时间到即时结算，以当前物种数判胜负；事件堆不再限制回合数。适合时间有限的团建。

变体3：角色轮换（深度体验换位思考）

每2回合轮换一次角色，确保每位玩家体验"外出采集"与"守护系统"两类职能，强调换位思考。

变体4：沉默守护（沟通挑战）

系统告警（任一系统≤3）后的一整回合，玩家不能说话（仅肢体/写字），凸显非语言沟通与提前约定。

⚙️ 难度调整

简单模式（新手团队/第一次团建）

  • 三系统初始值各 +2（电力12 / 温度10 / 氧气11）
  • 事件堆移除4张最严厉危机事件
  • 胜利条件降至 20 种物种
  • 适合：刚组建的团队、非游戏爱好者

标准模式（推荐）

  • 初始值 电力10 / 温度8 / 氧气9
  • 胜利条件 25 种
  • 适合：大多数团建场景

困难模式（成熟团队/抗压主题）

  • 三系统初始值各 -2（电力8 / 温度6 / 氧气7）
  • 事件堆加入全部4张选择事件，远征搜索结果-1
  • 胜利条件提高至 30 种
  • 适合：高层管理团队、强调抗压与极限资源管理的团建

❓ 常见问题

Q：一个系统归零就输了吗？ A：不是。单个系统归零只产生严重负面效果（如电力归零则所有行动+1AP）。只有2个及以上系统同时归零才判负——这正是设计意图：单个危机可补救，连环崩溃才致命。

Q：公共资源库里的资源怎么用？ A：任何玩家执行需消耗资源的行动时，可从个人手牌或公共库支付。公共库是团队共享的，由"传递资源"行动补充，也是最容易出现"占用 vs 共享"博弈的地方。

Q：远征搜到的种子要公开吗？ A：公开。搜索获得须正面朝上展示给全员，便于团队决策谁该入库哪类种子——合作游戏，信息透明利于整体最优。

Q：同名种子重复怎么办？ A：第二张可作"保险"（防被事件破坏），但计入物种总数只算1种。所以拿到重复种后优先去寻找新物种！

Q：没有骰子怎么办？ A：手机骰子APP，或准备1-6数字卡片代替。

Q：为什么要凑满"25种不同物种"才算赢？ A：模拟真实研发/资源项目的"多样化储备"——比起堆量，抗风险的关键是覆盖面广。这能自然引出复盘中的"广度 vs 深度"讨论。

📚 教练工具箱

引导话术

游戏前：

  • "记住，你们是一个团队。一个人的失误会拖垮所有人的系统。"
  • "别舍不得用资源修系统——及时维护是团队责任。"
  • "我鼓励你们大声讨论策略，但请留意系统告警。"

游戏中（适时提醒）：

  • "现在电力还剩多少？是否该优先修复而非继续外出？"
  • "后勤官，你对资源分配有什么建议？"
  • "安全主管，这次事件要不要动用『全面封锁』？"

复盘时：

  • "先安静30秒，回想一下守护过程。"
  • "我想听听[沉默玩家]的想法，你当时在判断什么？"
  • "谁在替大家做决定？这是效率还是隐患？"

安全与边界

  1. 心理安全：若团队因系统崩溃失败沮丧，教练应强调"这是游戏，失败是学习的机会"
  2. 包容性原则：对游戏不擅长的玩家提供额外指导，而非让其感到羞耻
  3. 时间管理：严格控制游戏与复盘时间，避免拖延
