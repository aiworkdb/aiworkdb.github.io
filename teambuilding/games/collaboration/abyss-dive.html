🎮 游戏概述

《深海探险》改编自同名合作桌游。2247年，一支精英深海探险队驾驶「蛟龙号」深潜器，穿越层层深海区域，寻找远古失落文明核心——深海之心。

海水越深，水压越凶、氧气越少、未知生物越多、洋流越不可控。探险队必须紧密合作——分配氧气、修理设备、对抗深海巨兽、破解古代谜题，才能抵达深海之心并安全返回水面。

🎯 团建改造重点

  • 合作而非竞争：所有玩家共享氧气、共享生命、共享胜负
  • 角色分工：5种专属职责，模拟真实团队职能
  • 共享资源管理：有限的氧气池考验共同决策
  • 压力管理：深度越深压力越大，模拟项目临近 deadline
  • 复盘框架：每层与返航后引导反思协作过程

🎯 团建目标

共享资源管理

在氧气有限下共同制定策略与优先级

角色分工

体验不同角色的职责边界与相互依赖

压力沟通

在紧迫与不确定中清晰表达、同步信息

危机决策

权衡风险与收益，学会"何时撤退"

🖨️ 无打印方案（临时团建）

  • 氧气：纸上写"氧气：30"，每回合用笔涂改
  • 卡牌：便签写名称与效果，抽签抽取
  • 地图：长条白纸从上到下画5区域
  • 环境事件：教练口述

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，模拟真实团队中的职能分工与相互依赖：

🧑‍🚀 潜航员

职责：把控下潜节奏与移动

被动：移动时可额外前进1区域｜主动：「紧急下潜」无视氧气消耗移动2层

🔧 工程师

职责：维护装备、修复损伤

被动：修理时额外+1恢复｜主动：「紧急修复」不消耗行动修复所有损坏装备

🔬 生物学家

职责：评估与应对生物威胁

被动：战斗判定+1｜主动：「生物安抚」使当前生物退回牌堆免战

🧭 导航员

职责：规划路线、规避洋流

被动：暗流事件中可自选方向｜主动：「精确导航」指定全队移动到已知区域

💊 医官

职责：关注团队生命与安全

被动：每回合恢复1名队友1点生命｜主动：「紧急抢救」恢复全队各1点生命

提示：3人局推荐 潜航员+工程师+医官；首轮自由选角，次轮可轮换角色体验不同职责。

🗺️ 游戏地图（5层垂直）

团队从第1层（阳光带）出发，逐层下潜，目标是抵达第5层「海底之心」并安全返回水面。

第1层
阳光带（0-200m）｜氧气消耗1点｜威胁★☆☆☆☆｜遗物1件｜无特殊规则，适合熟悉操作
第2层
暮光带（200-1000m）｜氧气消耗1点｜威胁★★☆☆☆｜遗物1件｜每2回合触发一次洋流事件
第3层
午夜带（1000-4000m）｜氧气消耗2点｜威胁★★★☆☆☆｜遗物1件｜黑暗惩罚：无探照灯则移动-1
第4层
超深渊（4000-6000m）｜氧气消耗3点｜威胁★★★★☆｜遗物1件｜生物遭遇不可逃逸，必须战斗
第5层
海底之心（6000m+）｜氧气消耗4点｜威胁★★★★★｜遗物0件｜终极BOSS战，击败守护者后拾取深海之心

🎲 游戏流程

阶段一：准备与下潜（10分钟）

  • 布置地图：深度指示器置于第1层，威胁等级1
  • 选角分工：每位玩家选择一个角色
  • 初始资源：氧气30点，每位玩家获得头盔+工具箱
  • 明确目标：收集3件遗物 → 抵达第5层 → 安全返航

阶段二：深海探索（35分钟）

玩家轮流行动，每回合含 3个行动点：移动 / 探索 / 修理 / 补给 / 战斗；回合末按深度消耗氧气并抽取环境卡。

战斗规则：掷2d6 + 装备 + 角色技能 ≥ 生物战力即击败；同区域或远程队友可支援（骰值取半，向上取整）。

阶段三：总结复盘（15分钟）

使用下方 4F 框架进行深度反思（事实→感受→发现→迁移）。

🤔 复盘框架（4F）

事实 Facts（发生了什么？）

  • 我们在哪一层损失最多氧气？最关键的决策是什么？
  • 资源分配是否共同商议？还是某人替大家决定？

感受 Feelings（体验如何？）

  • 你最紧张 / 最有安全感的时刻是什么？
  • 扮演[角色]让你感觉如何？是否被需要？

发现 Findings（学到了什么？）

  • 谁的意见被忽视了？面对失败我们怎么处理的？
  • 如果重来一次，下潜节奏和分工会怎么调整？

迁移 Future（接下来做什么？）

  • 这个游戏让你联想到工作中的哪个场景？
  • 我们可以做哪些改变？一件能立即改进的事是什么？

🔄 变体玩法

观察员模式

超6人时多出玩家任观察员，记录协作过程，复盘时提供第三方视角。

限时挑战

沙漏50分钟，时间内找到深海之心并返航即胜，增加紧迫感。

角色轮换

每下潜1层轮换角色，体验不同职能，强调换位思考。

沉默深潜

第3-4层不能说话，仅肢体/写字，凸显非语言沟通。

⚙️ 难度调整

简单模式

氧气40点、守护者战力5、第3层无黑暗惩罚。适合新手团队。

标准模式

氧气30点、守护者战力7。适合大多数团建场景。

困难模式

氧气22点、守护者战力9、每3回合多1只巡逻生物、下潜额外掉血。适合高层/抗压主题。

💡 设计思路

为什么选这个游戏？

  1. 高度合作：共享氧气与胜负，天然促进团队感
  2. 角色互补：5种职能卡模拟真实团队分工
  3. 压力渐进：越深越险，模拟项目推进中的风险累积
  4. 交付即终点：返航才算赢，呼应"上线≠成功"

与工作场景的映射

游戏要素工作场景
共享氧气预算、人力、时间等公共资源
深度/威胁等级项目临近 deadline 的压力累积
5种角色团队成员的职能专长
深海生物突发风险、竞争对手、技术难题
安全返航交付后的稳定性与回滚预案
