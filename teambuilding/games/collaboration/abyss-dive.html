🎯 游戏概述（团建版）

《深海探险》是一款合作类桌游，背景设定在 2247 年：一支精英深海探险队驾驶「蛟龙号」深潜器，穿越层层深海区域，寻找传说中的远古失落文明核心——深海之心。

海水越深，水压越凶、氧气越少、未知生物越多、洋流越不可控。探险队必须紧密合作——分配氧气、修理设备、对抗深海巨兽、破解古代谜题，才能抵达深海之心并安全返回水面。

团建改造重点

  • 合作而非竞争：所有玩家共享氧气、共享生命、共享胜负，强调团队一盘棋
  • 角色分工：每位玩家承担专属职责（潜航、工程、生物、导航、医疗），模拟真实团队职能
  • 共享资源管理：有限的氧气池需要团队共同决策，考验资源分配与优先级判断
  • 压力管理：深度越深压力越大，模拟项目临近 deadline 的高压协作
  • 复盘框架：每一层结束与最终返航后引导团队反思协作过程

📋 游戏信息

主题
深海探险 + 资源协作 + 危机应对

🎯 团建目标

  1. 共享资源管理：在氧气有限的情况下共同制定策略与分配优先级
  2. 角色分工：体验不同角色的职责边界与相互依赖
  3. 压力沟通：在紧迫与不确定中清晰表达判断、同步信息
  4. 危机决策：在风险与收益之间权衡，学会"何时撤退"
  5. 团队复盘：通过探索过程反思真实工作中的协作模式

🎲 游戏规则（团建版）

准备阶段

  1. 布置地图：将深海地图放在桌面中央，深度指示器放在第1层
  2. 分配角色（重要！）：每位玩家选择一个角色，详见下方"角色分工"
  3. 设置资源：共享氧气标记设为 30点，威胁指示器设为 1
  4. 分发起始物资：
    • 每位玩家获得 🤿潜水头盔×1、🔧修理工具箱×1、角色卡×1
    • 洗混装备/生物/遗物/环境四个牌堆
  5. 决定先手：掷骰子，点数最大者为「潜航队长」，顺时针轮流

角色分工（团建核心改造）

为加强团队协作，每位玩家需承担一个专属角色：

角色职责被动技能主动技能
潜航员 🧑‍🚀把控下潜节奏与移动移动时可额外前进1区域「紧急下潜」：无视氧气消耗移动2层
工程师 🔧维护装备、修复损伤修理时额外+1恢复「紧急修复」：不消耗行动修复所有损坏装备
生物学家 🔬评估与应对生物威胁战斗判定+1「生物安抚」：使当前生物退回牌堆（免战）
导航员 🧭规划路线、规避洋流暗流事件中可自选方向「精确导航」：指定全队移动到已知区域
医官 💊关注团队生命与安全每回合恢复1名队友1点生命「紧急抢救」：恢复全队各1点生命
💡 团建提示：3人局推荐 潜航员+工程师+医官 组合；首轮自由选角，第二轮可轮换角色体验不同职责。

游戏流程（每个回合）

每位玩家轮流行动，每个回合包含以下步骤：

1. 回合开始（恢复）

  • 检查共享氧气：若为 0，进入「紧急上浮」缓冲（见下）
  • 所有角色/装备的"每回合"被动生效（如医官治疗、头盔回氧）

2. 玩家行动（共3个行动点）

行动消耗说明
🚶 移动1点移动到相邻区域（同层或相邻层）
🔍 探索1点在当前区域探索，抽取生物卡或遗物卡
🛠️ 修理1点修复1件损坏装备
🫧 补给1点在补给点恢复2点团队氧气
⚔️ 战斗1点与遭遇的深海生物战斗（掷2d6+加成）
行动组合示例：移动 + 探索 + 战斗 = 3点；或 移动 + 补给 + 修理 = 3点

3. 氧气消耗

回合结束时，根据当前深度消耗氧气（见地图表：第3层2点、第4层3点、第5层4点）。

💡 氧气是团队共享资源。氧气为0时，全队各损失1点生命，并强制进入紧急上浮。

4. 环境事件

回合结束时从环境牌堆抽1张，执行效果（利好/挑战）。牌堆耗尽则洗混弃牌堆，威胁等级+1。

5. 回合结束

将回合传给下一位玩家（顺时针）。

战斗规则

当玩家探索或移动遭遇生物时触发战斗：

  1. 翻开1张生物卡，查看战力（如：热带水母群战力1，深海守护者战力7）
  2. 当前玩家掷2颗骰子，点数之和 + 装备加成 + 角色技能 ≥ 生物战力 = 击败
  3. 合作规则：同区域或远程支援的其他玩家可掷1颗骰子加入（支援骰值取一半，向上取整）
  4. 胜利：获得生物卡标注的战利品（修理点/装备/遗物进度）
  5. 失败：全队受到（生物战力 - 掷骰结果）的伤害，分配到各玩家生命值
💡 团建提示：鼓励战斗前简短讨论："谁去战斗？谁支援？谁用装备？"

胜利与失败

主胜利：收集任意 3 件遗物 → 携带遗物抵达第5层激活深海之心 → 安全返回水面。

副胜利：在第5层击败「深海守护者」（战力7）可直接获得深海之心（仍需返航）。

失败（任一即全队失败）：

  • 全员生命归零且无法施救
  • 氧气为0连续超过3回合
  • 威胁等级达到6
  • 回合数达到40仍未获胜
⚠️ 关键：找到深海之心 ≠ 胜利！必须带着它安全返回第1层以上才算最终胜利。

📖 完整游戏流程示例

示例：4人游戏第1-3回合

阵容：小明（潜航员）、小红（工程师）、小刚（生物学家）、小李（导航员）

第1回合 — 小明（潜航员）

  1. 行动：移动到「珊瑚礁」→ 探索翻出「热带水母群」🪼（战力1）→ 战斗掷2d6=6，轻松击败，获得1点修理点
  2. 补给：在珊瑚礁补给点恢复2点氧气
  3. 氧气：第1层消耗1点（30→29）；环境「温暖洋流」🌊 +2 → 氧气30

第2回合 — 小红（工程师）

  1. 移动到「鱼群区」，与小明相邻
  2. 探索抽到遗物「光之水晶」💎，遗物进度 1/3
  3. 交换将「医疗急救包」💊交给小明
  4. 氧气 30→29；环境「水压波动」📉 -2 → 氧气27

第3回合 — 小刚（生物学家）

  1. 移动至「海藻林」
  2. 探索遭遇「珊瑚礁鲨」🦈（战力2），使用被动「观察」免战，生物退回牌堆
  3. 氧气 27→26；环境「鱼群经过」🐟 利好，小红抽到「声呐探测仪」📡
💡 小结：3回合内氧气从30降至26，收集1件遗物，团队状态良好，准备向更深处进发。

💡 团建引导提示

游戏前（5分钟）

  1. 介绍主题："我们要一起驾驶蛟龙号，穿越5层深海，找到深海之心并安全返回——任何一个人撑不住，全队都危险。"
  2. 强调合作："氧气、生命、胜负都是共享的。你们是一个团队，不是5个竞争者。"
  3. 角色选择：让玩家自由选择角色，或教练按性格分配（如让平时少发言者选导航员，锻炼表达）
  4. 鼓励沟通："下潜越深越危险，请大声同步你们的判断！"

游戏中（观察要点）

教练或观察员应记录：

  1. 谁在做资源决策？ 是潜航队长，还是某位强势玩家？
  2. 谁很少发言？ 是否有玩家被边缘化？
  3. 氧气分配是否共同商议？ 还是某人替大家决定？
  4. 面对危机（氧气骤降/生物围攻）时，团队反应如何？ 互相指责还是共同求解？
  5. 是否知道"何时撤退"？ 还是硬撑到全员濒危？

游戏后（复盘框架 · 4F）

使用以下框架引导团队复盘（15分钟）：

1. 事实（Facts，3分钟）

"回顾刚才的探索：我们在哪一层损失最多氧气？最关键的决策是什么？"

2. 感受（Feelings，4分钟）

"游戏过程中你最紧张/最有安全感的时刻是什么？扮演[角色]让你感觉如何？"

3. 发现（Findings，5分钟）

"我们的资源分配公平吗？谁的意见被忽视了？面对失败时我们怎么处理的？
如果重来一次，下潜节奏和分工会怎么调整？"

4. 迁移（Future，3分钟）

"这个游戏让你联想到工作中的哪个场景（如临近上线的项目、预算紧张的周期）？
我们可以做哪些改变？"

🔄 变体玩法（团建专用）

变体1：观察员模式（适合大型团队）

人数超过6人时，多出的玩家担任观察员：

  • 记录团队协作过程（使用观察记录表）
  • 不打断游戏，复盘时提供第三方视角
  • 关注：主导者、沉默者、冲突时刻、协作亮点、改进建议

变体2：限时挑战（增加紧迫感）

  • 设置沙漏计时 50分钟，时间内抵达深海之心并返航即胜
  • 适合：时间有限的团建

变体3：角色轮换（深度体验换位思考）

  • 每下潜1层轮换一次角色，确保每位玩家体验不同职能
  • 适合：强调"理解他人职责"的团建主题

变体4：沉默深潜（沟通挑战）

  • 第3-4层玩家不能说话（仅肢体语言/写字）
  • 凸显非语言沟通与提前约定的重要性
  • 适合：沟通技巧培训

⚙️ 难度调整

简单模式（新手团队/第一次团建）

  • 共享氧气起始值提升至 40点
  • 深海守护者战力降至 5
  • 第3层无黑暗惩罚
  • 每位玩家起始多1张氧气瓶卡
  • 适合：刚组建的团队、非游戏爱好者

标准模式（推荐）

  • 共享氧气起始 30点
  • 深海守护者战力 7
  • 适合：大多数团建场景

困难模式（成熟团队/抗压主题）

  • 共享氧气起始降至 22点
  • 深海守护者战力提升至 9，且每3回合出现随机巡逻生物
  • 第4层及以上氧气消耗倍率+1
  • 增加"饥饿机制"：每下潜1层全队额外-1点生命
  • 适合：高层管理团队、强调抗压的团建

❓ 常见问题

Q：没有骰子怎么办？ A：使用手机骰子APP，或准备1-6数字卡片代替。

Q：氧气耗尽游戏立即结束吗？ A：不是。氧气为0后全队各损失1点生命并强制上浮，连续超过3回合仍无法恢复才失败。

Q：已收集的遗物能交换或丢弃吗？ A：遗物属于团队共有，放在团队面板上，不能丢弃也不能玩家间交换。

Q：角色生命归零会怎样？ A：进入「濒死」，可由医官或队友用医疗包施救；下回合可消耗3点氧气+1名队友1点生命复活（复活后1点生命）。

Q：不同区域玩家如何协作战斗？ A：同区域玩家可直接协助；其他玩家可远程支援（掷1d6，骰值取一半向上取整）。

Q：为什么要"安全返回水面"才算赢？ A：这正是设计意图——模拟真实项目"交付"不等于"成功上线"，返程的风险管理同样关键。

📚 教练工具箱

引导话术

游戏前：

  • "记住，你们是一个团队。一个人的失误就是所有人的失误。"
  • "不要舍不得用氧气瓶——及时补给是团队责任。"
  • "我鼓励你们大声讨论策略，但请留意时间。"

游戏中（适时提醒）：

  • "现在氧气还剩多少？是否该优先补给或考虑上浮？"
  • "导航员，你对路线有什么建议？"
  • "有没有人想尝试战斗？我们现在装备如何？"

复盘时：

  • "先安静30秒，回想一下下潜过程。"
  • "我想听听[沉默玩家]的想法，你当时在判断什么？"
  • "这个游戏让我们学到了什么关于资源协作的教训？"

安全与边界

  1. 心理安全：若团队因失败沮丧，教练应强调"这是游戏，失败是学习的机会"
  2. 包容性原则：对游戏不擅长的玩家提供额外指导，而非让其感到羞耻
  3. 时间管理：严格控制游戏与复盘时间，避免拖延
