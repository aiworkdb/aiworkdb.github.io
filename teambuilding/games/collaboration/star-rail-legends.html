🎮 游戏概述

《星穹列车 · 团建版》改编自合作策略桌游《星穹传说》。原作里，玩家扮演星穹列车的乘员，驾驶列车穿越 6 颗星球、在限定回合内收集 5 枚星核碎片、最终击败终焉之兽，拯救被星核危机笼罩的世界。

这正是跨团队接力交付项目的真实写照：一条主干道上串着多个"站点"（需求 / 模块 / 阶段），资源（精力 / 带宽 / 装备）在途流动，关键里程碑（星核碎片）必须对齐而非各自为政，而头顶始终悬着一根回合上限的绳子（交付期限 / 项目窗口）。任何一个站点脱节，列车就开不到终点。

团建版把"列车轨道"译成主干交付流水线、把"星球探索"译成各站点的子任务、把"星核碎片"译成关键里程碑 / 阶段交付物、把"能量 / 护甲 / 生命"译成团队精力 / 缓冲 / 健康度、把"终焉之兽"译成上线决战 / 大版本发布。

🎲 游戏流程（每回合 5 步）

每回合依次执行：

  1. 列车移动：掷骰，列车前进 1-6 站（= 项目推进）；抵达新站点即进入该站"子任务"
  2. 星球探索（可选）：在站点网格内移动、搜资源（🎒）、触发战斗（⚔️）、完成该站任务（📍）
  3. 战斗 / 风险（如触发）：合作击败敌人（= 解决阻碍 / 技术债 / 突发事故）
  4. 技能协同（可选）：消耗精力使用技能卡，互助 / 增益 / 治疗
  5. 回合结束：共享轨道结算；检查星核碎片（里程碑）是否集齐

核心机制 · 跨站接力（团建灵魂）

列车一站接一站往前开，后站依赖前站的交付物。任何一站"卡住"（战斗失败 / 资源耗尽），整列车就停在半路——多站协同必须无缝接力，绝不脱节。

核心机制 · 里程碑对齐（关键反转）

5 枚星核碎片 = 5 个关键里程碑。它们分散在不同站点，必须各自对齐、最终汇聚才能触发终战。胜利不靠单点猛冲，而靠"每站都交、对齐到终点"。

核心机制 · 资源在途调度

精力（行动力）、护甲（缓冲）、生命（健康度）是共享且有限的。前站猛花、后站就裸奔；必须在途调度——把资源留给最该用的人 / 最关键的站。

共享轨道与失败阈值

共享轨道初始警告 / 失败
团队精力（行动力）10每回合 -1；≤2 全队行动受限
缓冲（护甲）5受击先扣缓冲，归零才扣健康
健康度（生命）10任一玩家 =0 即"出局"（可复活但拖节奏）
回合上限20达 20 仍未集齐 5 碎片 = 项目窗口关闭，失败
星核碎片（里程碑）0集齐 5 枚触发终战；击败终焉之兽 = 胜利

⚠️ 关键：胜负不取决于"谁最猛"，而取决于"前站是否按时交、资源是否留给关键站、5 个里程碑是否对齐到终点"。

💡 团建引导提示

  • 游戏前（5 分钟）：定调——"你们是一趟接力列车，6 站连成一条主干交付线；星核碎片是关键里程碑，必须每站都对齐；回合上限是项目窗口。"
  • 游戏中（观察）：记录——资源是否集中在某人手里？哪站脱节了没人拉？是否有人猛冲单点忽略整体节奏？里程碑是否"各自为政"没汇聚？
  • 游戏后（4F 复盘）：事实 → 感受 → 发现 → 迁移，约 15-20 分钟；把"接力交付 / 资源在途 / 里程碑对齐"迁移到真实项目。
