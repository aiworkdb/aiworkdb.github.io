# 黄金结界 · 团队守护版（Huntrix: Golden Honmoon）

> 改编自合作桌游《猎魔女团：黄金结界 Huntrix: Golden Honmoon》（取材自 2025–2026 全球现象级动画音乐电影《KPop Demon Hunters / 猎魔女团 / HUNTR/X》）。

## 🎮 游戏概述

《黄金结界 · 团队守护版》把原作"偶像女团暗中守护人间"的内核，搬进了一支**高绩效团队的文化与心理资本守护**现场。

原作里，风靡全球的女子组合 HUNTR/X 其实是猎魔女团，她们用**歌声织起一道名为「Honmoon（结界）」的魔法屏障**，把深渊恶魔挡在人间之外；恶魔之王 Gwi-Ma 撕裂结界、五座结界节点失守、恶魔之门接连开启。玩家在 7×7 的都市棋盘上穿梭：登台应援、排练旋律、汲取灵能、装备术式、清扫恶魔之门、封印结界节点，最终正面击溃魔王，重新点亮「黄金结界」。这是一款**纯合作**游戏——所有人共享胜负。

团建版的关键反转在**两处**：

1. **「结界 = 团队的共享心理安全与信任」**。黄金结界是团队的隐形护盾，它亮着，团队就稳、就有底气；它裂开，各类"团队杀手"就钻进来——内耗、倦怠、信任裂痕、目标漂移、沉默螺旋。
2. **「结界是从内部裂开的」**（呼应原作：Rumi 的隐秘心结让屏障出现裂痕）。最危险的从不是外部攻击，而是**没被说出口的痛点、被压抑的张力、缺位的心理安全**。能被摆上台面讨论的裂痕会愈合，被掩盖的裂痕才会蔓延。

于是，本游戏聚焦一个和既有改造游戏都不同的团建视角：**团队文化与心理资本的"能量守恒"——你不能只"打怪"（救火），还必须靠登台表演（团队仪式、认可、充电）主动给结界续能；同时要把隐患摆上台面，别让它在沉默中啃噬团队。**

---

## 🎯 团建改造重点

- **能量守恒（核心反转）**：结界每整轮自然削弱（威胁 +1），须靠"登台表演/团队仪式"主动续能；映射到"高绩效需要刻意充电与认可，否则士气在沉默中流失"
- **5 团队健康支柱（5 结界节点）**：目标共识 / 心理安全 / 信任 / 成长 / 认可——每维护好一个，团队韧性 +1
- **把痛点摆上台面**：恶魔 = 内耗 / 倦怠 / 信任裂痕 / 目标漂移 / 沉默螺旋；它们生于"沉默"，靠"公开对话（共唱）"清除
- **角色互补**：凝聚Leader / 攻坚冲突管理 / 活力带动 / 资源统筹彼此依赖
- **合力决战（合力一击）**：大魔王 = 一场结构/文化级裂痕或重大危机，需 5 支柱齐亮、全队同步
- **复盘框架**：每局结束 4F 复盘，把"能量管理 / 心理安全 / 把隐患摆上台"迁移到真实团队

## 🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，映射高绩效团队的"凝聚 / 攻坚 / 活力 / 统筹"（可按性格由教练分配，超 5 人时加"守护者"）。

### 核心四人组（映射 HUNTR/X + 经纪人）

| 角色 | 团建映射 | 被动能力 |
| :--- | :--- | :--- |
| **🎤 主唱 · Rumi（凝聚Leader / 共同叙事）** | 把团队故事讲好、凝聚目标与意义感——"我们为什么在一起" | 封印节点时额外降低 0.5 威胁（更容易固化共识） |
| **🎤 Mira（说唱 · 攻坚 / 冲突管理）** | 啃硬骨头、把冲突摆上台面、直面棘手议题 | 对"凝视魔/信任裂痕"类恶魔伤害 +1 |
| **💃 Zoey（舞担 · 活力 / 新人带动）** | 带氛围、带动新人、把团队能量点燃 | 在主舞台登台额外 +1 应援（把气氛带起来） |
| **🎧 经纪人（资源统筹 / PMO）** | 调度资源、排期、对外争取、横向补位 | 每回合可多 1 个行动点用于"装备/补给" |

> **扩展角色（5 人局）**：**🛡️ 守护者 · 后方兜底 / HRBP**——为同伴挡一次风险或情绪冲击（结界护盾生效时 +1 生命），专门做"情绪缓冲 / 兜底"。

## 🎲 游戏规则

### 准备阶段

1. **布置地图**：7×7 都市网格放桌面，左上角 🎤 主舞台为全队 HQ，右下角 👑 魔王殿为决战点。
2. **选角归位**：每人选一个角色棋子，全部放在 🎤 主舞台。
3. **建库**：洗混应援⭐/旋律🎵/灵能💜 三套资源牌库（公共）、恶魔牌库、宝藏牌库；武器卡模板堆放 HQ 旁作"武器库"。
4. **分资源**：每人从应援牌库抽 6 张 ⭐；全员能量 ❤️×3，共享威胁 0，已维护支柱 0。
5. **放恶魔**：5 个恶魔棋子分别放在 5 个**结界节点 🛡️** 上（代表该健康支柱已被"团队杀手"占据，须先清后维护）。

### 每回合流程

玩家顺时针轮流行动，每人每回合含：

**① 表演 / 移动阶段（免费，每回合 1 次）**
- 掷 2 颗骰子，点数和 = 移动步数（2-12），只能上下左右走，停在触发格才生效。
- 在 🎤 主舞台可"登台表演"：不移动，改为抽 **2 张应援卡 ⭐**（= 团队仪式 / 认可 / 充电，主动给结界续能）。

**② 行动阶段（最多 2 个行动点 AP）**

| 行动 | 花费 | 效果 |
| :--- | :--- | :--- |
| **装备术式** | 1 AP + ⭐×2 或 🎵×2（停在 🎤） | 从武器库选 1 张协作术式入手牌 |
| **采集资源** | 1 AP（停在 ⭐/🎵/🌟） | 抽对应资源卡 1 张（带宝藏则 +1） |
| **清除恶魔** | 1 AP + 资源/术式（与恶魔同格或相邻） | 造伤害清除"团队杀手"（见恶魔表） |
| **维护节点** | 1 AP + 🎵×3 + 💜×1（停在已清空的 🛡️） | 放置封印标记，威胁 −1，已维护支柱 +1 |
| **疗愈** | 1 AP + 🎵×1（停在 💊 休息室） | 为自身或同伴恢复 1 点能量 |

**③ 恶魔结算（即时）**
- 在恶魔之门 🚪 停留 → 立即抽 1 张恶魔卡并结算。
- **节点泄漏**：回合结束，每个仍被恶魔占据的节点有概率再渗出 1 只低阶恶魔。

**④ 回合结束与威胁推进**
- 全员各行动 1 次后，共享**威胁值 +1**（结界自然削弱）。
- 威胁达到 **10** → 结界崩塌，**全员失败**。

### 胜负条件

- **共同胜利**：维护**全部 5 个**结界节点（已维护 = 5），魔王殿 👑 开启；全队集结与**恶魔之王 Gwi-Ma（团队结构性裂痕）**决战（魔王 HP 6，需合力用 ⭐/术式/💜 攻击）。魔王生命归零 → **黄金结界重新点亮，全员胜利！**
- **共同失败**：威胁值达 10（结界崩塌）；或所有成员能量同时归零（团队耗尽）。

## 🛡️ 五大团队健康支柱（5 结界节点）

维护好一个节点 = 团队为这一支柱建立了一项"显性的实践/公约"，威胁 −1。

| 结界节点 | 团队健康支柱 | 维护它的"实践"示例 |
| :--- | :--- | :--- |
| 🛡️ 共识节点 | **目标共识** | 把团队目标写下来、对齐优先级、周会过一遍 OKR |
| 🛡️ 安全节点 | **心理安全** | 容错文化、"可以问 dumb 问题"、复盘对事不对人 |
| 🛡️ 信任节点 | **信任** | 承诺必达、信息透明、不背后议论 |
| 🛡️ 成长节点 | **成长** | 1on1、带练机制、把复盘沉淀成资产 |
| 🛡️ 认可节点 | **认可** | 公开赞赏、登台表演（仪式感）、及时反馈 |

> 团建落点：游戏结束后，5 张节点卡可直接变成"我们团队健康度看板"——哪些支柱已经有实践（已维护），哪些还在被恶魔占据（待建设）。

## 💡 团建引导提示

| 阶段 | 要点 |
| :--- | :--- |
| **游戏前（5 分钟）** | 定调："我们守护的'黄金结界'就是团队的信任与心理安全。它会被内部裂痕（沉默、内耗、倦怠）啃噬，也会靠仪式与坦诚续能。先保住 5 大支柱，再合力打 Boss。" |
| **游戏中（观察）** | 记录：谁在"登台充电"（主动认可/仪式）？谁在掩盖裂痕（沉默不说话）？5 支柱有没有被维护？能量低的成员有人兜底吗？资源（应援/旋律/灵能）投到了消耗还是沉淀？ |
| **游戏后（4F 复盘 15-20分钟）** | 事实→感受→发现→迁移。重点迁移三件事：①能量守恒（团队需要刻意充电与认可）②把隐患摆上台面（沉默才是最大杀手）③5 大健康支柱哪些已有实践、哪些待建设。 |

## 🔄 变体玩法

| 变体 | 说明 |
| :--- | :--- |
| **观察员模式** | 超 5 人时多出玩家任观察员，专记"是否有人在掩盖裂痕 / 谁在主动充电 / 5 支柱覆盖了几个"，复盘给第三方视角。 |
| **限时挑战** | 设 60 分钟沙漏，强化"结界倒流"的压迫感。 |
| **角色轮换** | 每 3 回合轮换角色，体会凝聚/攻坚/活力/统筹不同职能，强化相互理解。 |
| **无声协奏** | 部分回合禁言分配/维护，凸显"提前约定、显性同步"对抗沉默螺旋的价值。 |
| **部门混编** | 拆散同部门到不同角色，强制"业务/技术/职能"跨界搭档，共守结界。 |
| **真实支柱叠加** | 把 5 张节点卡换成团队真实 5 个健康维度便签（如"反馈文化""成长路径"），游戏结束变"团队健康度看板"。 |
| **真实裂痕叠加** | 把恶魔卡换成团队真实痛点便签（如"跨团队墙""需求频繁变更"），清恶魔 = 把真实议题摆上台面讨论。 |

## ⚙️ 难度调整

| 模式 | 调整 | 适合 |
| :--- | :--- | :--- |
| **简单** | 威胁上限 12、恶魔牌库减半、只需维护 4 个节点 | 新团队 / 非玩家 |

| **困难** | 威胁上限 8、洗入 2 张魔王使者、魔王 HP 8 且每 2 轮对全队造成 1 能量伤害 | 文化 / 管理 / 高绩效团队 |
