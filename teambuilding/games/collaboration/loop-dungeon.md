# 轮回地下城 · 团队复盘迭代版 (Loop Dungeon)

## 🎯 游戏概述（团建版）

《轮回地下城 · 团队复盘迭代版》改编自合作桌游《轮回地下城 Loop Dungeon》（灵感来自《挺进地牢》《以撒的结合》等 Roguelike 地牢游戏）。玩家扮演被困在时间轮回里的冒险者：每当局势不利（全员阵亡），时间就倒流回地牢入口——但**上一次轮回里收集的"记忆碎片"会被保留**，用来购买永久升级。目标是在有限的轮回次数内，打通 5 层地牢、击败最终 Boss「轮回守护者」。

游戏以**合作为核心**——所有人共享胜负，共享精力与带宽；而最有魅力的机制是"**失败后带着记忆重启**"。在团建语境下，这座地牢就是一支在持续交付中反复迭代的团队：**每一轮轮回是一个冲刺（Sprint）**，打不过去就复盘、沉淀经验、带着更强的基线再战；那些跨轮回保留下来的"记忆碎片"，正是**复盘行动项的累积、组织过程资产（OPA）的沉淀**。

### 团建改造重点

- **复盘迭代而非一次定胜负**：阵亡不归零，记忆碎片永久留存，模拟"快速失败、安全试错、越战越强"的敏捷心智
- **知识沉淀**：记忆碎片 = 跨周期的复盘收获，让"组织过程资产"可见、可积累、可兑换成能力
- **共享资源管理**：全队共享精力（团队心力/信任）与带宽（产能/行动点），暴露"谁在透支、谁在囤力"
- **渐进式能力建设**：永久升级（精力+2 / 带宽+1 / 初始装备更好）映射"流程优化、工具沉淀、协作默契"带来的基线抬升
- **角色分工**：4-5 种专属职能（攻坚 / 兜底 / 修复 / 赋能 / 统筹），映射真实团队职能互补
- **复盘框架**：每轮轮回结束（无论成败）引导反思"这一轮我们学到了什么、下一轮改什么"

## 🎯 团建目标

1. **复盘心智建立**：体验"失败不是终点，而是带着记忆重启"，建立快速试错、安全失败的心理安全感

4. **渐进能力建设**：永久升级机制映射"流程/工具/默契"如何把团队基线一点点抬升
5. **团队复盘**：每轮轮回结束引导微复盘，把局内体感迁移到真实工作的持续改进

## 🗺️ 游戏地图（简化版）

地牢共 **5 层**，每层 5 个房间，从 1F 入口逐房探索、逐层深入。团建语境里，5 层对应**一个产品/项目从 0 到 1 的生命周期阶段**：

| 楼层 | 团建隐喻 | 怪物强度 | 奖励 |
| :--- | :--- | :--- | :--- |
| 1F 入口层 | 立项 / 需求澄清 | ⭐ | 基础装备（共识） |
| 2F 方案层 | 设计 / 方案规划 | ⭐⭐ | 不错装备（路线图） |
| 3F 执行层 | 开发 / 攻坚执行 | ⭐⭐⭐ | 稀有装备（里程碑） |
| 4F 验证层 | 测试 / 风险验证 | ⭐⭐⭐⭐ | 史诗装备（质量保障） |
| 5F Boss 层 | 上线 / 交付决战 | ⭐⭐⭐⭐⭐ | 传说装备 + 胜利（价值兑现） |

> 🌀 **核心张力**：每一层都在消耗团队精力、挤压带宽，而怪物房（风险/阻碍）和陷阱房（隐形坑）随时出现。**真正决定胜负的不是某一次打得漂亮，而是你从失败里攒下了多少记忆碎片**——这正像真实工作中"复盘沉淀"带来的复利。

## 🎲 游戏规则（团建版）

### 准备阶段

1. **布置地牢**：5 层网格置于桌面，玩家棋子放在 1F 入口；初始精力 10、带宽（行动点）2/轮、轮回计数 1
2. **分配角色**：每名玩家抽 1 张角色卡；初始发 2 张战利品卡（基础装备）
3. **设置追踪器**：精力置 10、轮回计数置 1（共 5 轮轮回）；永久升级板清空，记忆碎片归零

### 角色分工（团建核心改造）

为加强团队协作，每位玩家承担专属职能，映射真实团队中的角色：

| 角色 | 图示 | 团队职能映射 | 被动能力（团建视角） |
| :--- | :--- | :--- | :--- |
| **前锋探索者** | 🗡️ | 攻坚手 / 业务突破手 | 高攻击：把最硬的骨头啃下——团队的"攻坚手" |
| **盾卫守护者** | 🛡️ | 风险兜底 / 质量守护 | 高防御：承接风险、替队友挡伤害——"定海神针" |
| **治愈术师** | 💚 | 团队修复 / 情绪缓冲 | 治愈术：回精力、复活掉队者——HR/PMO/支持位 |
| **机关匠师** | ⚙️ | 工具赋能 / 流程优化 | 强化装备（流程）+ 群体增益——工程效能/中台 |
| **领航者** | 🧭 | 决策统筹 / 方向把控 | 定调、分配带宽、战略取舍——Leader/PM |

> 💡 **团建提示**：3-4 人局可由任意角色"兼任"两种职能；首轮自由选角，次轮可轮换体验（换位思考）。领航者的"定调权"恰恰是反思点——方向是不是总压在一个人身上？

### 游戏流程（每轮回多回合）

每位玩家每轮回有 **2 个行动点（AP）**，可选择：

| 行动 | 消耗AP | 说明 |
| :--- | :--- | :--- |
| 探索房间 | 1 AP | 抽取 1 张房间事件卡并执行效果 |
| 移动房间 | 1 AP | 前进到同层/下层下一个房间 |
| 装备/使用 | 1 AP | 装备战利品、用消耗品或技能 |
| 收集碎片 | 1 AP | 在记忆泉水/祭坛获取记忆碎片（经验） |
| 购买升级 | 1 AP | 用记忆碎片购买永久升级 |

#### 战斗规则

探索到怪物房（风险/阻碍）时触发战斗：先攻判定（骰≥4 先攻）→ 攻击（骰+武器 vs 怪物HP）→ 怪物反击（骰+攻击 vs 精力-防御）；直到一方清零。怪物 = 需求变更 / 线上故障 / 资源缺口，战斗消耗的是**团队共享精力**。

#### 层数推进

探索完本层 5 个房间后可进入下一层；第 5 层第 1 房为 Boss 房，击败即获胜。

#### 🌀 轮回机制（阵亡处理 · 团建灵魂）

当团队共享精力降为 0（全员阵亡）时：

1. 当前轮回结束
2. 保留**记忆碎片**（复盘沉淀的经验）
3. 其他装备与金币（当轮成果）丢失
4. 轮回计数 +1
5. 在新轮回中，从 1F 入口重启，精力恢复，但**用碎片购买的永久升级持续生效**

> 🔑 **团建密钥**：轮回 = Sprint 迭代；记忆碎片 = 复盘行动项；永久升级 = 组织过程资产。每一次"失败重启"都在让团队基线更强——这正是对"心理安全 + 持续改进"最直观的体感。

#### 胜利与失败

**主胜利**：在 5 轮轮回内打通 5 层、击败 Boss「轮回守护者」（价值兑现）。

**失败**（任一即全队失败）：
- **轮回耗尽**：轮回计数达到 5 仍未击败 Boss（持续改进窗口关闭）
- **精力崩盘**：团队共享精力降为 0 且已无碎片可兜底（心力枯竭，需警惕"过度透支"）

## 📖 完整游戏流程示例

### 示例：4 名玩家的第 1→2 轮回

**阵容**：前锋(攻坚)、盾卫(兜底)、治愈(修复)、领航(统筹)

#### 第 1 轮回 — 大多精力耗尽，触发重开

1. **前锋**：探索 1F 第2房抽「怪物·史莱姆」拼杀，得基础装备（共识达成），精力 10→8
2. **盾卫**：2F 主动挡下「精英·暗影刺客」的反击，护住前锋精力
3. **领航**：在 2F 决策"先下楼还是先攒装备"，选了冒进，触发 3F 强怪，精力被快速掏空
4. **结局**：到第 3 轮团队精力归 0 → **触发轮回**，但已通过「记忆泉水」攒下 **3 枚记忆碎片**

> 💡 **团建点**：冒进的决策代价被"安全地"承担——这正是敏捷"小步快跑、快速失败"的安全感来源。

#### 第 2 轮回 — 带着记忆重启，基线更强

1. **永久升级**：用 3 碎片买「初始精力+2」「额外行动点」，本轮回起步精力 12、带宽 3
2. **治愈**：每轮稳定奶住掉血的前锋，团队不再单点崩
3. **机关匠师**：强化了"流程装备"（等效+1 攻击），全队输出更稳
4. **结局前夜**：第 3 轮冲到 5F，集火击败轮回守护者，**通关**

> 💡 **小结**：第 1 轮的"失败"不是浪费，而是换来 3 枚碎片与一次真实的决策复盘——第 2 轮明显更稳、更准。**团队体感到了"经验复利"**。

## 💡 团建引导提示

### 游戏前（5分钟）

1. **介绍主题**："这座地牢就是一支在持续交付中迭代的团队。每一轮轮回是一个冲刺，打不过去就复盘、攒经验、带着更强的基线再战。"
2. **强调安全**："精力耗尽不丢人——你可以安全地失败、带着记忆重启。我们只看下一轮你改了什么。"
3. **角色分配**：自由选角，或教练按性格分配（让少发言者选治愈/机关，锻炼"托底与赋能"意识）
4. **鼓励记录**："抽到记忆碎片时，请大声说出'我学到了什么'——这就是你们的复盘。" 

### 游戏中（观察要点）

教练或观察员应记录：

1. **谁在做复盘？** 拿到碎片时，是有人主动总结，还是混过去？
2. **谁在透支？** 共享精力快速下降时，谁在默默扛、谁在囤力不输出？
3. **领航者是否单点决策？** 方向是不是总压在一个人身上（单点故障）？
4. **跨轮回有没有复用经验？** 上一轮的坑，这一轮绕开了吗？
5. **失败后团队情绪？** 是挫败，还是"哦又攒了几枚碎片"的轻松？

### 游戏后（复盘框架 · 4F）

使用以下框架引导团队复盘（15-20分钟），**并建议在每轮轮回结束也做一次 2 分钟微复盘**：

#### 1. 事实（Facts，4分钟）
> "哪一轮最险？最关键的取舍是什么？是谁提出先攒碎片还是先下楼？"

#### 2. 感受（Feelings，5分钟）
> "精力告急时你什么感受？掉队被治愈时呢？轮回重启时是挫败多一点，还是'又攒了经验'的轻松多一点？"

#### 3. 发现（Findings，6分钟）
> "我们的经验有没有真的被复用？哪些升级（流程/工具/默契）让我们第 2 轮更强？谁的声音被忽视？"

#### 4. 迁移（Future，5分钟）
> "这个游戏让你联想到工作中的哪个场景（如某项目反复踩同一个坑、复盘结论从没落地）？我们可以做哪些改变？一件能立即做的事是什么？"

## 🔄 变体玩法（团建专用）

### 变体1：观察员模式（适合大型团队）
人数超过 5 人时，多出玩家任**观察员**：记录每位成员的"复盘行为"（谁总结、谁托底、谁沉默），微复盘时提供第三方视角。

### 变体2：限时挑战（增加紧迫感）
设置沙漏 **45 分钟**，时间到即结算，以"是否打通 Boss"判胜负；适合时间有限团建。

### 变体3：角色轮换（换位思考）
每 1 轮轮回轮换一次角色，确保每位玩家都体验"攻坚"与"兜底/赋能"两类职能，强化相互理解。

### 变体4：无声回廊（沟通挑战）
部分轮回去除非语言沟通，凸显"提前约定、隐性默契"对协作的价值。

### 变体5：部门混编（跨部门磨合）
将同部门的人拆散到不同角色，强制跨部门搭档，专为"打破部门墙、训练横向补位"设计。

### 变体6：真实复盘叠加（知识管理主题 · 推荐）
每获得 1 枚记忆碎片，团队须在便签上写下一条**真实可落地的复盘行动项**（如"上线前加一条回归用例"），游戏结束后这些便签直接变成团队的改进看板。

## ⚙️ 难度调整

### 简单模式（新手团队/第一次团建）
- 轮回次数上限提高到 **7 轮**
- 所有怪物 HP **-1**，初始精力 12
- 初始额外获得 1 张消耗品卡
- **适合**：刚组建的团队、非游戏爱好者

### 标准模式（推荐）
- 轮回上限 5 轮，初始精力 10、带宽 2
- 默认怪物强度
- **适合**：大多数团建场景

### 困难模式（成熟团队/持续改进主题）
- 轮回上限降到 **3 轮**
- 怪物攻击 **+1**，陷阱房数量 **+2**
- 第 5 层前须"清零全部已知风险"方可挑战 Boss
- **适合**：管理层、强调知识管理与极限资源统筹的团建

## ❓ 常见问题

**Q：3个人怎么玩？**
A：选 3 名核心角色，其余职能标注"兼任"；共享轮回与精力机制不变，仍强调协作。

**Q：记忆碎片为什么要跨轮回保留？**
A：它模拟"复盘沉淀的经验不会随项目结束而消失"。设计意图是让团队体感：失败本身不亏，亏的是"失败了却没留下东西"。

**Q：队友精力掉到 0 怎么办？**
A：用治愈术/复活卷轴救回；"完全阵亡"可用碎片升级"不死鸟"实现首次自动复活。鼓励互保而非各自为战。

**Q：没有骰子怎么办？**
A：手机骰子 APP，或准备 1-6 数字卡代替。

**Q：为什么强调"第 1 轮失败也很正常"？**
A：它隐喻敏捷的"心理安全"——只有敢在低风险里快速失败，才不会在关键交付时一次性崩盘。

### 引导话术

**游戏前**：
- "记住，你们是一个团队。精力是大家的，掉的也是大家的。"
- "被怪打趴了没关系——我们带着记忆碎片重启，这就是复盘的力量。"
- "我鼓励你们大声说出'我学到了什么'，那是你们最值钱的东西。"

**游戏中**（适时提醒）：
- "现在精力是多少？谁在默默扛？"
- "机关/治愈，你对当前节奏有什么建议？"
- "拿到碎片了——这一轮我们学到了什么？"

**复盘时**：
- "先安静 30 秒，回想一下地牢里的那一轮。"
- "我想听听[沉默玩家]的想法，你当时在判断什么？"
- "我们的经验，下一轮真的用上了吗？还是又踩了同一个坑？"

### 安全与边界

1. **心理安全**：若团队因精力崩盘失败而沮丧，教练应强调"这是游戏，轮回就是为失败准备的"——把失败正常化
2. **包容性原则**：对游戏不擅长的玩家提供额外指导，而非让其感到羞耻
3. **知识落地**：变体6 的便签看板建议拍照留存，真的可能变成团队的改进项
4. **时间管理**：严格控制游戏与复盘时间，避免拖延
