🎯 游戏概述（团建版）

《星际拓荒者 · 从零到一版》改编自合作生存桌游《星际拓荒者 Star Pioneers》。原作里，玩家扮演开拓者号的探险队，降落在一颗完全未知的星球上——地图全被盖住，你们要一格格揭开迷雾、采集资源、建造基地、抵御威胁，并在氧气耗尽前完成星球勘测。所有人共享一格"团队氧气"，只有全员存活并达成目标才算赢。

这正是从 0 到 1 团队的真实写照：新业务、新产品、新市场——没有现成地图，只能边探索边试错；手里的资源既能一次性消耗换眼前进展，也能投资建造基础设施换长期复利；而头顶始终悬着一根有限的跑道（runway）——预算、时间窗口、老板耐心。团建版把"揭开探索卡"译成"调研 / 试错 / 验证假设"，把"氧气"译成"团队跑道 / 时间窗口 / 资金余量"，把"建造基地"译成"沉淀基础设施 / 组织能力"，把"3 个目标卡"译成"多个可能方向里必须聚焦取舍的战略目标"。

团建改造重点

  • 拓荒心态（核心反转）：地图全是迷雾，没有标准答案——体验"在未知里靠探索开路"，而非按图施工
  • 消耗 vs 投资：同一份资源，是一次性花掉换眼前进展，还是投进"建造基地"换长期复利——逼团队直面短期与长期的取舍
  • 有限跑道：共享氧气每回合流逝，是团队的"预算 / 时间窗口"——所有决策都在倒计时下做
  • 目标聚焦：开局翻出多个目标，资源有限做不完所有——练"选定主攻方向、砍掉次要"
  • 角色互补：队长 / 工程师 / 生物学家 / 战士 / 医生，映射真实团队的"统筹 / 建设 / 探索 / 攻坚 / 续航"
  • 复盘框架：每局结束 4F 复盘，把"探索、投资、聚焦、跑道管理"迁移到真实的 0→1 工作

📋 游戏信息

主题太空科幻 / 拓荒生存 / 探索未知 / 跑道管理

🎯 团建目标

  1. 拓荒者心态：体感"没有地图也要开路"，把面对未知的焦虑转成"多探一格就多一分信息"的行动力
  2. 消耗与投资的取舍：看见"一次性花掉资源"和"投资建基础设施"的差别，反思团队是不是只顾眼前不攒复利
  3. 跑道意识：共享氧气倒流让每个决策都带成本感——训练在有限预算 / 时间窗口下排优先级
  4. 目标聚焦：多目标里资源做不完，练"选主攻、砍次要"的战略取舍
  5. 角色互补：看见统筹 / 建设 / 探索 / 攻坚 / 续航彼此依赖，"没有谁是无用的位置"
  6. 团队复盘：每局引导 4F 复盘，把"探索 / 投资 / 聚焦 / 跑道"迁移到真实的 0→1 工作

💡 核心张力：原作里"每揭一格才知道下面是资源、是威胁还是空地"——团建版里"每一次探索都是一次带成本的试错，可能踩空、可能挖到宝"。而氧气（跑道）一直在流逝，逼团队在"多探一格"与"赶紧聚焦达标"之间抉择。

🎲 游戏规则（团建版）

准备阶段

  1. 铺开地图：8×8 网格全盖迷雾，仅露出中央 🚀 降落舱
  2. 设置跑道：氧气标记设为 20 点（3-4 人）或 30 点（5 人）——这是团队的总跑道
  3. 分配角色：每人选 / 抽 1 张角色卡，了解职能映射与被动
  4. 初始资源：每人获得 矿物×2 + 能源×1
  5. 翻开目标：从 5 张目标卡翻出 全部 5 张公开摆放，全队商量后圈定要主攻的 3 个（聚焦取舍）
  6. 决定先手：投骰点数大者先手

角色分工（团建核心改造）

每位玩家承担专属职能，映射 0→1 团队的"统筹 / 建设 / 探索 / 攻坚 / 续航"：

角色图示团队职能映射被动能力（团建视角）
队长🧭Leader / 统筹者所有玩家 +1 行动力——"提升全队节奏与协同"
工程师🔧基建 / 平台工程建造费用 -1 资源——"把基础设施投资做得更便宜"
生物学家🧬探索 / 研究 / 调研采集生物样本额外 +1——"更高效地挖信息、验假设"
战士⚔️攻坚 / 啃硬骨头武器攻击力 +1——"扫清阻碍、突破难关"
医生💊续航 / HRBP / 后勤氧气消耗 -1——"帮团队省跑道、防透支"
💡 团建提示：3-4 人局可让任意角色"兼任"两种职能；首轮自由选角，次轮轮换（换位思考）。工程师（投资建设）与战士（一次性攻坚）是"复利 vs 眼前"的两端——资源该投哪，正是复盘焦点。

游戏流程（每回合 4 阶段）

阶段一：事件阶段 ⚠️（必须）

翻 1 张事件卡立即执行（太阳风暴 / 陨石雨 / 氧气泄漏 / 外星袭击）——模拟 0→1 路上的突发风险。

阶段二：分配与行动 🎯（每人 3 行动点）

先全队商量本轮分工（谁探索、谁采集、谁建造、谁攻坚），再依次行动。每点可做任一操作：

行动消耗团建语义
🚶 移动1点/格向未知推进人力
🗺️ 探索1点揭开当前迷雾格（= 调研 / 验证假设）
⛏️ 采集资源1点在资源区收资源（= 攒弹药 / 积累筹码）
🏗️ 建造2点+资源在建造点投资设施（= 沉淀基础设施，效果持续）
⚔️ 战斗2点+武器清除外星生物（= 啃硬骨头 / 攻坚阻碍）
🔧 使用装备1点激活装备效果
🤝 交换资源0点与同格队友交换资源（免费，鼓励互补）
⚡ 协同提示：资源可自由交换、可存进大本营；基础设施（研究站 / 防御塔 / 仓库 / 医疗站）一旦建成惠及全队——这正是"投资复利"的体感。

阶段三：检查阶段 ✅（必须）

  1. 检查是否达成任一已圈定目标（达成 3 个即可胜利）；
  2. 检查氧气余量，若 ≤0 立即失败（跑道烧完）；
  3. 结算本回合探索揭示的地形效果。

阶段四：跑道结算 ⛽（必须）

  1. 团队氧气 -2（医生在场可减免，基础设施可回补）——跑道流逝；
  2. 手牌超 5 张需弃至 5 张；
  3. 回合 +1，先手权交给下一位。

共享轨道与危机

共享轨道初始警告 / 失败阈值
团队氧气（跑道）20 / 30 点每回合 -2；≤5 = 跑道告急；≤0 = 立即失败
迷雾探索度仅降落舱可见目标"勘测星球"需揭开 80% 地图
资源池每人矿×2+能×1手牌上限 5 张；可交换 / 存大本营
目标进度圈定 3 个达成 3 个 = 胜利

胜利与失败

主胜利（任意回合达成即赢）：

  • ✅ 在氧气耗尽前，完成圈定的 3 个战略目标，且全员存活。

失败（任一即全队失败）：

  • 团队氧气降至 0 或以下（跑道烧完 = 预算 / 时间窗口耗尽）
  • 任意玩家阵亡（生命值 ≤0）
  • 达到 15 回合仍未完成 3 个目标（可选限时模式 = 项目被砍）
💡 关键：胜负不取决于"探得最快"或"打得最猛"，而取决于"在有限跑道内，是否把资源投在了对的方向、达成了聚焦的目标"——探索过头会烧光氧气，只顾眼前消耗会攒不下复利。这正是 0→1 拓荒的平衡术。

📖 完整游戏流程示例

示例：5 名玩家的第 4 回合（拓荒拉扯）

阵容：队长（统筹）、工程师（基建）、生物学家（探索）、战士（攻坚）、医生（续航）。

当前状态：氧气 12（跑道过半）；已揭开约 40% 地图；圈定目标为「勘测星球」「收集样本」「建立基地」；建造点已建成 1 座研究站。

阶段一 · 事件：翻出 ☀️"太阳风暴"——全员本回合 -1 行动力。队长技能补回 +1，抵消。

阶段二 · 分配与行动

  • 生物学家（3点）：移动到未探索区 → 探索揭开一片生物区 → 采集生物样本（技能 +1，实得 2 个）
  • 工程师（3点）：到第 2 个建造点 → 建造"仓库"（矿物×2，技能 -1 只花 1 个）→ 手牌上限升至 7
  • 战士（3点）：清除挡在目标点前的外星生物👾（等离子刀，技能 +1 攻击力，一击解决）
  • 医生（3点）：移动到研究站旁 → 采集能源 → 使用氧气罐（团队氧气 +2）
  • 队长（3点）：移动到降落舱统筹资源分配 → 把多余能源交换给战士备用 → 预告"再两回合就得聚焦达标了"

阶段三 · 检查：探索度逼近 80%，「勘测星球」快达成；样本已够「收集样本」；基地建成 2 座，「建立基地」还差 1 座。三目标同时在望！

阶段四 · 跑道结算：氧气 -2，医生减免 1 → 实扣 1，剩余 12+2(氧气罐)-1 = 13。回合 +1。

💡 团建点：团队当场体感——"我们前几回合光顾着探索开图，氧气掉得飞快，是医生和那座研究站把跑道续了回来；而工程师早早建的仓库和研究站，现在每回合都在帮全队省力——当初那两点建造投入，正是现在的复利。要不是第 4 回合果断聚焦这 3 个目标、砍掉'击败威胁'，跑道根本不够。"正是"探索、投资、聚焦、跑道管理"的日常。

💡 团建引导提示

游戏前（5分钟）

  1. 拓荒定调："今天没有地图——地上全是迷雾，你们要边探边走，在氧气烧完前完成 3 个战略目标。"
  2. 跑道即预算："氧气是团队的跑道——预算 / 时间窗口 / 老板耐心，每回合都在流逝，所有决策都带成本。"
  3. 投资提醒："资源可以一次性花掉换眼前进展，也可以建成基础设施持续惠及全队——想想哪种更划算。"
  4. 聚焦提醒："5 个目标只需完成 3 个，资源做不完所有——开局就要商量主攻哪 3 个、砍哪 2 个。"

游戏中（观察要点）

教练或观察员应记录：

  1. 探索 vs 聚焦失衡了吗？ 是无限开图停不下来，还是过早收缩、信息不足就赌方向？
  2. 资源怎么花？ 全拿去一次性消耗（战斗 / 采集）了，还是舍得投建造攒复利？
  3. 谁在管跑道？ 有没有人盯着氧气余量提醒"该收了"？还是烧到告急才慌？
  4. 目标聚焦了吗？ 3 个目标是开局就定死主攻，还是三心二意每个都碰一点？
  5. 谁在续航兜底？ 医生 / 基础设施默默省跑道——这些"不显眼的底座工作"被看见了吗？

游戏后（复盘框架 · 4F）

使用以下框架引导团队复盘（15-20分钟）：

1. 事实（Facts，4分钟）

"哪一回合氧气最险？当时探索到几成、目标完成几个？是谁先说'该聚焦了'还是'再探一格'？"

2. 感受（Feelings，5分钟）

"面对全是迷雾的地图开局时什么感受？眼看跑道快烧完却还没达标时你急吗？被劝'砍掉那个目标'时甘心吗？"

3. 发现（Findings，6分钟）

"我们是探索上瘾还是过早收缩？资源是花在眼前还是投了复利？跑道是有人管着排优先级，还是烧到告急才反应？"

4. 迁移（Future，5分钟）

"这局让你想到工作里哪个场景（如新业务无限调研不落地、只顾眼前不攒能力、预算烧光才聚焦）？一件能立即做的事是什么？"

🔄 变体玩法（团建专用）

变体1：观察员模式（适合大型团队）

人数超 5 人时，多出玩家任 观察员：专门记录"探索/聚焦是否失衡、资源投在消耗还是复利、谁在管跑道"，复盘时提供第三方视角。

变体2：限时挑战（增加紧迫感）

设沙漏 60 分钟 / 15 回合即结算，以"是否达成 3 目标"判胜负；适合时间有限团建，强化跑道压迫感。

变体3：角色轮换（换位思考）

每 3 回合轮换角色，确保每人都体验"探索""建设""攻坚""续航"不同职能，强化相互理解。

变体4：无声拓荒（沟通挑战）

部分回合禁言分配 / 探索，凸显"提前约定探索边界、显性同步目标"对拓荒协作的价值。

变体5：部门混编（跨部门磨合）

将同部门的人拆散到不同角色，强制"业务 / 技术 / 职能"跨界搭档，专为打破部门墙、共探新领域设计。

变体6：真实目标叠加（战略聚焦主题 · 推荐）

把 5 张"目标卡"替换成团队 当前真实的 5 个候选方向 / OKR（便签上墙），开局圈定主攻 3 个；游戏结束便签直接变成"聚焦哪 3 个、砍哪 2 个"的战略取舍看板。

变体7：真实基建叠加（能力沉淀主题 · 推荐）

把"建造点设施"替换成团队 想沉淀的基础设施 / 组织能力（如自动化工具、知识库、复用组件），每建成 1 座 = 立一项能力资产；复盘直接盘点"哪些该投资建、哪些还在重复造轮子"。

⚙️ 难度调整

简单模式（新手团队 / 第一次团建）

  • 初始氧气 +10；外星生物生命值 -1；事件卡数量减半；只需完成 2 个目标即可获胜
  • 适合：刚组建的团队、非游戏爱好者

标准模式（推荐）

  • 氧气 20/30、每回合 -2、每人 3 行动力、圈定并完成 3 个目标即胜
  • 适合：大多数团建场景

困难模式（成熟团队 / 战略聚焦攻坚主题）

  • 初始氧气 -5；外星生物数量 +2、生命值 +1；每回合翻 2 张事件卡；需完成 4 个目标；增加"黑夜阶段"（每 3 回合已探索区重新盖雾，需复探）
  • 适合：战略 / 创新 / 0→1 团队，强调极限跑道下的取舍与韧性

❓ 常见问题

Q：3个人怎么玩？ A：选 3 名核心角色（如队长 / 工程师 / 生物学家），其余职能标注"兼任"；共享氧气、探索、聚焦机制不变，仍强调拓荒协同。

Q：为什么强调"资源可消耗也可投资建造"？ A：这是核心张力——真实 0→1 团队里，同一份预算 / 人力既能换眼前进展（消耗），也能沉淀成基础设施 / 能力（复利）。游戏把这种取舍具象化了。

Q：氧气为什么每回合都在掉？ A：隐喻"跑道有限"——预算、时间窗口、老板耐心都在流逝。它逼团队"带着成本感做每个决策"，区别于只强调救火的危机类游戏。

Q：5 个目标为什么只完成 3 个？ A：因为资源永远做不完所有事。这训练"选主攻、砍次要"的战略聚焦，而不是三心二意每个都碰一点。

Q：没有骰子怎么办？ A：手机骰子 APP，或准备 1-6 数字卡代替；行动点也可用抽卡数字决定。

Q：为什么把目标 / 基建和真实工作结合（变体6/7）？ A：游戏瞬间变成一次低风险的"战略聚焦会 / 能力沉淀盘点会"，让拓荒决策直接服务真实工作，复盘结论更易落地。

🧰 教练工具箱

引导话术

游戏前：

  • "今天没有地图——全是迷雾，边探边走，在氧气烧完前完成 3 个目标。"
  • "氧气是团队的跑道，预算 / 时间窗口在流逝，每个决策都带成本。"
  • "资源可以花掉换眼前，也可以建成设施攒复利——想清楚投哪。"

游戏中（适时提醒）：

  • "还在无限探索吗？该聚焦了没？"
  • "这份资源是一次性花，还是投去建基础设施？"
  • "谁在盯氧气余量？跑道还够几回合？"

复盘时：

  • "先安静 30 秒，回想一下氧气最险那一刻。"
  • "我想听听[沉默玩家]的想法，你当时在守哪块？"
  • "我们是不是探索上瘾 / 只顾眼前不攒复利？下次怎么平衡？"

安全与边界

  1. 心理安全：若因跑道烧完 / 方向选错失败而沮丧，教练应强调"这是游戏，拓荒本就充满试错"——把失败正常化
  2. 包容性原则：对游戏不擅长的玩家提供额外指导，而非让其感到羞耻
  3. 知识落地：变体 6 / 7 的便签看板建议拍照留存，真的可能变成团队的战略聚焦清单 / 能力沉淀路线图
  4. 时间管理：严格控制游戏与复盘时间，避免拖延
