🎮 游戏概述

《星际拓荒者 · 从零到一版》改编自合作生存桌游《星际拓荒者 Star Pioneers》。原作里，玩家扮演开拓者号的探险队，降落在一颗完全未知的星球上——地图全被盖住，你们要一格格揭开迷雾、采集资源、建造基地、抵御威胁，并在氧气耗尽前完成星球勘测。所有人共享一格"团队氧气"，只有全员存活并达成目标才算赢。

这正是从 0 到 1 团队的真实写照：新业务、新产品、新市场——没有现成地图，只能边探索边试错；手里的资源既能一次性消耗换眼前进展，也能投资建造基础设施换长期复利；而头顶始终悬着一根有限的跑道（runway）——预算、时间窗口、老板耐心。团建版把"揭开探索卡"译成"调研 / 试错 / 验证假设"，把"氧气"译成"团队跑道 / 时间窗口 / 资金余量"，把"建造基地"译成"沉淀基础设施 / 组织能力"，把"3 个目标"译成"多个方向里必须聚焦取舍的战略目标"。

🎯 团建改造重点

  • 拓荒心态（核心反转）：地图全是迷雾，没有标准答案——在未知里靠探索开路
  • 消耗 vs 投资：同一份资源，一次性花掉换眼前，还是投建基础设施换复利
  • 有限跑道：共享氧气每回合流逝，是团队的预算 / 时间窗口，所有决策都在倒计时下做
  • 目标聚焦：开局翻出多个目标，资源做不完所有——练选主攻、砍次要
  • 角色互补：统筹 / 建设 / 探索 / 攻坚 / 续航彼此依赖
  • 复盘框架：每局结束 4F 复盘，迁移到真实的 0→1 工作

🎯 团建目标

拓荒者心态

体感"没有地图也要开路"，把面对未知的焦虑转成"多探一格就多一分信息"的行动力

消耗与投资取舍

看见"一次性花掉"与"投资建复利"的差别，反思是不是只顾眼前不攒长期

跑道意识

共享氧气倒流让每个决策都带成本感，训练在有限预算/时间窗口下排优先级

目标聚焦

多目标里资源做不完，练"选主攻、砍次要"的战略取舍

🖨️ 无打印方案（临时团建）

  • 地图：白纸画 8×8 网格，中央标"🚀降落舱"，其余格贴便签当迷雾
  • 氧气：纸带写 0-30 刻度，硬币当指针，初始指 20（3-4人）/ 30（5人）
  • 资源：三色围棋子代表矿物🪨/能源⚡/生物样本🧬，放公共池
  • 卡牌：便签写名称 + 效果（🗺️/🔧/⚠️/🎯），分类面朝下抽
  • 骰子：手机骰子 APP，或 1-6 数字卡抽签

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，映射 0→1 团队的"统筹 / 建设 / 探索 / 攻坚 / 续航"（也可按性格由教练分配）：

🧭 队长 · Leader / 统筹者

被动：所有玩家 +1 行动力

团建映射：提升全队节奏与协同——"把节奏带起来"

🔧 工程师 · 基建 / 平台工程

被动：建造费用 -1 资源

团建映射：把基础设施投资做得更便宜——"攒复利的人"

🧬 生物学家 · 探索 / 研究 / 调研

被动：采集生物样本额外 +1

团建映射：更高效地挖信息、验假设——"在未知里开路"

⚔️ 战士 · 攻坚 / 啃硬骨头

被动：武器攻击力 +1

团建映射：扫清阻碍、突破难关——"啃最硬的骨头"

💊 医生 · 续航 / HRBP / 后勤

被动：氧气消耗 -1

团建映射：帮团队省跑道、防透支——"让大家跑得更久"

🎲 游戏流程（每回合 4 阶段）

每回合依次执行：① 事件阶段 → ② 分配与行动（每人 3 行动点） → ③ 检查阶段 → ④ 跑道结算（氧气 -2，回合 +1）。

核心机制 · 拓荒未知（团建灵魂）

地图全盖迷雾，每次探索都是一次带成本的试错——可能踩空、可能挖到宝。团队必须在"多探一格"与"赶紧聚焦达标"之间抉择。

资源 · 消耗 vs 投资（复利抉择）

同一份资源，一次性花掉换眼前进展，还是投进建造换持续复利——基础设施一旦建成惠及全队，这正是"短期 vs 长期"的取舍。

跑道 · 氧气 = 预算 / 时间窗口

团队氧气每回合 -2，是有限的跑道。烧到 ≤0 立即失败——逼团队"带着成本感做每个决策"。

共享轨道与危机

共享轨道初始警告 / 失败阈值
团队氧气（跑道）20 / 30 点每回合 -2；≤5 = 告急；≤0 = 立即失败
迷雾探索度仅降落舱可见目标"勘测星球"需揭开 80% 地图
资源池每人矿×2+能×1手牌上限 5 张；可交换 / 存大本营
目标进度圈定 3 个达成 3 个 = 胜利

⚠️ 关键：胜负不取决于"探得最快"或"打得最猛"，而取决于"在有限跑道内，是否把资源投在对的方向、达成聚焦的目标"——探索过头会烧光氧气，只顾眼前消耗会攒不下复利。

💡 团建引导提示

游戏前（5分钟）

拓荒定调："没有地图，边探边走，在氧气烧完前完成 3 个战略目标。"

游戏中（观察）

记录：探索/聚焦失衡？资源花在消耗还是复利？谁在管跑道？目标聚焦了吗？谁在续航兜底？

游戏后（4F复盘）

事实→感受→发现→迁移，约15-20分钟；把"探索/投资/聚焦/跑道"迁移到真实工作。

🔄 变体玩法

观察员模式

超5人时多出玩家任观察员，记录"探索/聚焦是否失衡、资源投消耗还是复利、谁管跑道"，复盘提供第三方视角。

限时挑战

设60分钟 / 15 回合沙漏，以"是否达成3目标"判胜负，强化跑道压迫感。

角色轮换

每3回合轮换角色，体验探索/建设/攻坚/续航不同职能，强化相互理解。

无声拓荒

部分回合禁言分配/探索，凸显"提前约定边界、显性同步目标"的价值。

部门混编

拆散同部门到不同角色，强制"业务/技术/职能"跨界搭档，共探新领域。

真实目标叠加

把5张目标卡换成团队真实5个候选方向/OKR便签，圈定主攻3个，游戏结束变战略取舍看板。

真实基建叠加

把建造设施换成想沉淀的基础设施/组织能力便签，每建成1座=立一项能力资产。
