# 岛屿求生（团建改造版）


> **原游戏**：岛屿求生（原桌游资料未随本库发布）


| **时长** | 45–75 min |
| **人数** | 建议 每组 4–8 人 |
| **场景标签** | 团建 / 培训 / 工作坊 |
| **难度** | ⭐⭐⭐ |
| **道具需求** | 有（打印地图 + 卡牌 + 标记物） |

**核心目标**：在资源有限、环境不确定的压力下，体验「团队协作决策」和「风险管理」——正是高效团队每天面对的挑战。

---

**团建核心价值**：
- 🌦️ 计划弹性：天气突变时的计划调整与预案启动
- 🧭 危机分工：探索、留守、采集的自发分工形成
- 🗼 共同目标：信号塔倒推关键路径与优先级

## 2. 团建改造要点

### 与原版的区别
| 原版规则 | 团建改造版 |
|---------|------------|
| 1–4 人游戏 | **4–8 人/组，每组有角色分工** |
| 自由分配行动 | **每轮有「角色讨论时间」（5 min）** |
| 胜利即结束 | **增加全程复盘节点**（每 3 天一次） |
| 单纯合作 | **增加「资源争夺」环节**（模拟部门墙） |

### 角色分工（每组 4–8 人）
| 角色 | 职责 | 领导力指标 |
|------|------|------------|
| **队长** | 最终决策（听取所有人意见后） | 决策力 |
| **资源官** | 管理食物/淡水/材料库存 | 精细化管理 |
| **探索员** | 探索新区域，汇报风险 | 信息收集 |
| **建造师** | 规划建造顺序和优先级 | 系统思维 |
| **天气预报员** | 分析天气卡，预警风险 | 风险管理 |



## 3. 改造后流程（60 min 标准版）

### 第一阶段：角色分配 + 规则讲解（10 min）
- 每组抽取/自荐角色
- 教练讲解核心规则（参考原游戏 README）
- **特别强调**：「每轮讨论 5 分钟，队长最终决策」

### 第二阶段：生存挑战（35 min）
- 每「天」= 5–7 分钟现实时间
- 第 3 天和第 6 天各暂停一次，做**迷你复盘**（2 min）
- 教练巡回观察，记录关键时刻

### 第三阶段：深度复盘（15 min）
- 按 4F 模型完整复盘
- 重点讨论：「你们组最危险的时刻是什么？怎么度过的？」

## 4. 引导要点

### 讲解时

> 「你们每组是一船遇难者，困在一座岛上。每天有一段固定时间做决策，队长负责最终拍板。
>
> 有一个设定你们要记住：**你们看不到明天会发生什么**。天气只预报一天，资源卡抽到才算数。
>
> 我要你们特别留意一件事——当队长的决定和你的判断不一样时，你会怎么做。」

### Feelings（感受）
- 当队长做出一个你不赞同的决定时，你是什么感受？
- 暴风雨来的时候，你是对队长有信心，还是想指责？

### Findings（发现）
- 你们组**最会未雨绸缪**的是谁？TA 做了什么？
- 如果重来，你们会在**第几天**做什么不同的事？
- 这个游戏和你们团队面对「项目危机」时有什么相似？

### Future（未来）
- 回到工作岗位，当你发现「资源（时间/预算）快不够了」，你会怎么做？
- 你们团队可以建立一个什么样的**「预警机制」**？

## 6. 变体适配

| 场景 | 调整方案 |
|------|---------|
| **人数少（4–6人）** | 去掉角色分工，每人自由行动，但每轮必须**全员同意**才能执行行动 |
| **时间紧（30 min）** | 改为「快节奏模式」——每天只有 3 分钟现实时间 |
| **培训深度版** | 增加「**部门墙**」环节——前 3 天每组独立，第 4 天宣布「现在可以交易资源了」 |
| **高管版** | 增加「**董事会压力**」——每 3 天教练宣布一个「总部指令」（额外限制或目标） |
| **线上场景** | 用 Tabletopia 或类似工具，视频会议讨论 |

## 8. 教练笔记

带过几场之后，我的体会是：这个游戏真正的战场不在岛图上，而在**每一轮讨论的那 5 分钟**。

最常见的画面是——三四个声音在抢，一个人低头算资源，队长在等大家「统一意见」，然后时间到了，仓促拍板。复盘时问一句「刚才那 5 分钟你们在干什么」，多数人说不清。

另一个高频现象是**灾难之后的追责**。暴风雨毁了仓库，第一句话往往是「谁说要建在那儿的」。这时候不要急着引导，让这句话落地，它自己会变成复盘的入口。

最后一个提醒：不要让游戏跑太久。第 6 天以后，资源和情绪都会进入重复模式，收益递减。抓在第 6–7 天的挫折点上收，效果最好。
