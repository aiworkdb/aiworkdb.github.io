# 非洲鼓（African Drum / 鼓舞飞扬 · 非洲鼓团建）

> **一句话**：一百个人打同一段节奏，只要有一个人快半拍，整片鼓声就"糊"了——而没人能听出是谁。

| **游戏名称** | 非洲鼓（African Drum / 鼓舞飞扬 / 非洲鼓团建） |
| **目的标签** | 节奏同步 · 声部协作 · 情绪释放 |
| **形式标签** | 室内 / 户外均可 · 分部落围圈 · 坐姿 |
| **人数** | 全场 50–300 人（分 2–8 个"部落"，每部落 20–40 人） |
| **时长** | 120–180 min |
| **难度** | ⭐⭐ 偏低（零基础可上手，合奏难） |
| **道具需求** | 有（非洲鼓 每人 1 面 + 部落图腾布 + 面部彩绘 + 音响） |
| **场景标签** | 年会开场 · 百人团建 · 女性占比高团队 · 文化型团建 · 减压 |
| **核心目标** | 让"不合拍"变成听得见的失败，而"合拍"变成身体的愉悦 |

---

**团建核心价值**：
- 🥁 节奏同步：所有人必须落在同一个拍点上
- 🎼 声部协作：高中低三个声部同时进行，谁都不能抢
- 🎭 角色代入：酋长、舞姬、歌姬——每个人都有位置
- 💥 情绪释放：鼓声是最直接的减压出口，不需要讲话

## 1. 游戏概览

全场分成若干"部落"，每个部落选酋长、定图腾、画彩绘，然后一起学鼓、编舞、斗鼓，最后全场围成同心圆合奏。

**它为什么在大场里特别好用**：

| 特征 | 说明 |
|---|---|
| 零基础 | 三个基本音（低音 bass / 中音 tone / 高音 slap）5 分钟学会 |
| 不靠体能 | 坐着打，年龄、体型、性别都不影响 |
| 不需要语言 | 全程靠听和模仿，跨语言团队也能玩 |
| 天然同框 | 300 人一起打，声浪本身就是高潮 |
| 情绪安全 | 不用发言、不用表演、不用社交，打鼓就行 |

**它的失败点也非常明确**：**一个人快半拍，整片声音就糊了。** 而且你听不出是谁——这正是它和"百人战鼓"的差异：战鼓的失败是"球掉了"（可见），非洲鼓的失败是"声音糊了"（只能听出来，找不到责任人）。

## 2. 核心规则

### 准备

- **鼓**：每人 1 面（或 2 人 1 面轮换）。**必须调好音**（松了打不出高音）
- **场地**：室内需空旷、有回响更好；户外需避风（风声盖过低音）
- **座位**：每部落围成一圈坐地上/椅子上，**鼓夹在两腿之间，鼓面朝外倾斜**
- **部落物料**：图腾布 1 面（画部落标志）、面部彩绘、部落名

### 三个基本音（开场必教）

| 音 | 打法 | 位置 | 音色 |
|---|---|---|---|
| **低音（Bass）** | 整个手掌平拍 | 鼓面中心 | 沉、闷、有震动感 |
| **中音（Tone）** | 四指并拢拍击 | 鼓面中圈 | 清、饱满 |
| **高音（Slap）** | 手指甩击，掌心不贴 | 鼓面边缘 | 脆、亮、穿透力强 |

### 规则

1. 每部落 **20–40 人**，选出 ① 酋长（统筹）② 王妃/歌姬（领唱）③ 舞姬（领舞）④ 鼓手长（定节奏）
2. 全程用**模仿法**教学：教练打一句，全员跟一句，**不用谱、不讲乐理**
3. 部落内部先统一一个"基础节奏"（如 `咚 - 哒 咚 -`），再叠声部
4. **声部分配**：部落内分 3 组，分别打低音声部 / 中音声部 / 高音声部
5. 斗鼓环节：各部落依次展示 60 秒，由全场"声浪"或教练评分
6. 终极合奏：全场围成**同心圆**（内圈高音、中圈中音、外圈低音），统一指挥合奏 3–5 分钟
7. **不许抢拍加速**：指挥手势是唯一速度依据

### 流程（三小时版 · 100 人 4 部落）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 分部落 + 图腾彩绘 | 25 min | 选酋长、起部落名、画图腾与彩绘 |
| 三个基本音教学 | 20 min | 逐个音模仿，直到全场整齐 |
| 基础节奏 | 25 min | 部落内统一一个 4 拍节奏 |
| 声部叠加 | 25 min | 分高中低三组，逐层叠加 |
| 编舞 + 领唱 | 20 min | 舞姬编 8 拍动作，歌姬领唱 |
| **部落斗鼓** | 25 min | 各部落 60 秒展示 |
| **终极合奏** | 20 min | 同心圆，全员合奏 |
| 复盘 | 20 min | 见第 4 节 |

## 3. 引导要点

### 讲解脚本（3 分钟）

> 今天不讲乐理。你们只需要学会三个声音：**低音、中音、高音。**
>
> 跟着我打——咚（低）……哒（中）……啪（高）。再来一次。
>
> 好。等一下你们会分成部落，每个部落有自己的酋长、自己的图腾、自己的节奏。
>
> 最后所有人围成一个圈一起打。我要提前说：**那时候只要有一个人快半拍，整片声音就糊了。** 你听得出糊了，但你听不出是谁。
>
> 所以那时候靠的不是听别人，是**看指挥**。

### 教练在场边做什么

- **教学必须"少而慢"**。一次只教一个音，确认全场整齐再教下一个。教快了，后面全乱
- **用身体示范，不用语言解释**。"这样打"比"用四指并拢拍击鼓面中圈"有效十倍
- **找"抢拍者"但不当众点名**。走到他旁边，用手压一下他的鼓面，让他自己听
- **斗鼓环节要制造声浪**：让其他部落当"观众"呐喊，这会把气氛推到最高
- **终极合奏前留 30 秒静场**，让所有人看着圆心
- **合奏结束时不要马上停**，让最后一个音自然消失——这个余韵是项目的情绪落点

### 三个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 越打越快 | 起手 60 BPM，30 秒后变 90 BPM | 兴奋驱动，没人看指挥 |
| 声部打架 | 三个声部都打重音，糊成一片 | 没有"谁让谁"的意识 |
| 部落内分裂 | 圈里明显分成两半，各打各的 | 没有鼓手长统一节奏 |

### 语言禁区

- ❌「你打错了」——鼓的错误是"不齐"，不是"错"
- ❌「大家跟紧一点」——"紧"不是指令，"看指挥"才是
- ✅「刚才那一段，声音是散的还是齐的？」
- ✅「谁在定速度？大家看的是谁？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 终极合奏时，速度比开场快了多少？（用手机节拍器可测）
- 有几个部落出现了"圈内分裂"？
- 斗鼓时，哪个部落的声音最齐？他们的鼓手长做了什么？
- 全场有几个人全程没打过鼓？

### Feelings（感受）

- 一百个人同时打鼓时，什么感觉？（胸口震动？耳鸣？兴奋？）
- 发现自己跟不上的时候，什么感觉？
- 合奏最后一个音消失的那一刻，什么感觉？

### Findings（发现）

- 为什么"越打越快"是必然的？（兴奋是加速度，同步需要刹车）
- 为什么"听不出是谁错了"这件事很重要？（现实里很多协作失效也找不到责任人）
- 声部叠加时，谁必须"让"？（高音让低音打底，中音填中间）
- 指挥的作用是什么？（不是打得好，是让所有人有同一个时间基准）

### Future（应用）

- 我们团队里，谁是"指挥"？大家真的在看他吗？
- 我们的工作节奏，是自己越干越快，还是有统一节拍？
- 出问题时我们找得到责任人吗？找不到的时候怎么办？
- 我们有没有"让"的意识？（谁该给谁打底）

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（30–50） | 2 部落，20 分钟教学足够；不设声部，只做齐奏 |
| 人数多（200–300） | 8 部落，每部落 25–35 人；终极合奏分三个同心圆层 |
| 鼓不够 | 2 人 1 面轮换（一人打 4 小节换手），或部分人改打"身体鼓"（拍腿拍手） |
| 只有 90 分钟 | 砍图腾彩绘与编舞，只做"教学 → 基础节奏 → 合奏" |
| 室内办公区 | 需确认楼下能否承受（100 面鼓的低频穿透力极强）；建议地下室/独立场地 |
| 想强化"文化" | 图腾必须画企业价值观的具象符号，酋长讲 1 分钟部落故事 |
| 想强化"领导力" | 鼓手长由部门负责人担任，复盘"指挥是否被服从" |
| 年会开场 | 合奏接领导上台/启动仪式，鼓声落点即开场信号 |
| 女性占比高团队 | 保持原样即可（这是本库最不受性别与体型影响的项目之一） |
