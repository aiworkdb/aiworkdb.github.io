🎮 游戏概述

《大圣西游》改编自中国古典名著《西游记》与热门游戏《黑神话：悟空》的合作桌游。玩家将化身唐僧师徒一行——孙悟空、猪八戒、沙悟净、白龙马（及可扩展的唐僧、二郎神），携手踏上西天取经的万里征程。

途中你们将共同面对"九九八十一难"：凶猛妖魔、险恶地形、诡异劫难与团队内部考验。只有团结协作、合理分工、共享信念，才能一路降妖伏魔、取得真经。取经团队正如一支企业团队——师徒四人的角色互补类比真实团队中的「攻坚手 / 补位 / 守护 / 协调」，妖魔劫难对应项目里的风险与困难。

🎯 团建改造重点

  • 合作而非竞争：共享里程与信念值、共享胜负
  • 角色分工：6种专属职责，模拟真实团队职能互补
  • 共享目标管理：两条共享轨道考验共同决策与取舍
  • 危机应对：劫难卡与 Boss 战不断施压，模拟 deadline
  • 复盘框架：每局结束引导反思前进与休整的权衡

🎯 团建目标

角色互补认知

体验攻坚 / 补位 / 守护 / 协调的职责边界与依赖

共享目标管理

在里程与信念轨道上共商节奏，平衡赶路与休整

压力沟通

在 Boss 连击的紧迫下清晰表达、同步信息

危机决策

权衡"硬闯巢穴 vs 先休整"，学会取舍撤退

🖨️ 无打印方案（临时团建）

  • 路线图：长条纸画 25 节点并连线，标注 4 个 Boss 节点
  • 生命/里程/信念：豆子=生命，硬币=里程站，彩纸=信念
  • 卡牌：便签写名称+数值，分类面朝下抽
  • 骰子：手机骰子 APP，或 1-6 数字卡抽签

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，模拟真实团队中的职能分工与相互依赖（也可按性格由教练分配）：

🐵 孙悟空 · 攻坚手 / 破局者

生命：5｜被动：七十二变（每回合额外行动1次）、火眼金睛（提前看1张妖魔卡）

主动：「大显神通」本回合战斗骰+2

🐷 猪八戒 · 万能补位 / 润滑剂

生命：6｜被动：天蓬元帅（战斗+1）、贪吃（营地额外恢复2生命）

主动：「化缘」全员各恢复1生命

🧑 沙悟净 · 守护者 / 兜底

生命：7｜被动：卷帘大将（替他人承1点伤害）、流沙河（水域优势）

主动：「舍身」本回合为任一队友挡下全部伤害

🐉 白龙马 · 协调者 / 连接器

生命：4｜被动：疾风步（移动+2）、龙族血脉（越任意地形）

主动：「飞驰传书」让两名队友交换位置并各+1行动

🧘 唐僧 · 领导者 / 凝聚者（5-6人）

生命：5｜被动：紧箍咒（令1妖魔跳过1回合）、信念守护（营地信念+1）

主动：「诵经凝神」团队信念直接+3

👁️ 二郎神 · 侦察 / 专家（6人）

生命：5｜被动：天眼（战前看Boss技能）、增援（援助战斗+1）

主动：「神目」本回合全体攻击+1

🎲 游戏流程（每回合5阶段）

阶段1 · 移动

当前玩家掷 2d6 取和移动；可自主选分支；白龙马+2步。

阶段2 · 地形事件

按站点类型执行：营地恢复 / 佛经宝地抽卡 / 妖魔巢穴战斗 / 劫难点抽卡 / Boss点全员战。

阶段3 · 战斗

掷 2d6 + 攻击 + 装备 ≥ 妖魔生命则击败，否则受伤害；其他玩家可在自身回合协助。

阶段4 · Boss战

全员依次攻击，Boss 每次反击对全员造成伤害，需团队策略应对。

阶段5 · 行动结束

用消耗法宝、检查佛经进度、推进共享里程，交回合给下家。

共享轨道与危机

共享轨道初始归零 / 满格后果
取经里程0 / 25站达25站触发"最终天劫"，通过则胜利
团队信念10归零立即失败（团队涣散）

⚠️ 关键：信念值由劫难、队友阵亡、放弃战斗等损耗，是团队状态的晴雨表——比起个人生命，它更考验"是否有人在乎全局"。

💡 团建引导提示

游戏前（5分钟）

介绍主题："妖魔劫难就是项目风险与 deadline"；强调里程与信念是团队的，不是某个人的。

游戏中（观察）

记录：谁在推进度？谁在兜底？信念谁在意？危机时互相指责还是共同求解？

游戏后（4F复盘）

事实→感受→发现→迁移，约15-20分钟，引导反思分工与英雄主义陷阱。

🔄 变体玩法

观察员模式

超6人时多出玩家任观察员，复盘提供第三方视角。

限时挑战

设75分钟沙漏，时间到以里程判胜负，适合时间有限团建。

角色轮换

每2回合轮换角色，体验"攻坚"与"兜底"两类职能。

无声取经

Boss战阶段禁言，凸显非语言沟通与提前约定。

部门混编

拆散同部门到不同角色，专为"打破部门墙"设计。
