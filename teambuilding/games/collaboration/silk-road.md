# 丝绸之路 · 团建协作版

> 改编自策略桌游《丝绸之路 Silk Road》（2-5 人贸易路线规划 / 资源管理）
> 团建视角：**供应链协同 / 路线规划对齐 / 资源共享降本 / 风险共担 / 局部最优 vs 全局最优**

---

## 🎯 一句话团建价值

原作是"各家商队沿丝路西行、比谁先攒够 80 金币"。团建版把它翻转为：**多支商队不是竞争对手，而是同一张贸易网络上的协作者**——共享"丝路繁荣指数"（组织协同健康度），谁短视囤货、谁路线脱钩，都会拉低整条商路的收益。它把"供应链上下游对齐、资源互通降本、风险共担、局部最优损害全局"这些组织协同难题，变成一场可以复盘的手感游戏。

**与其他改造游戏的差异化定位**：
- 区别于 mars-colony（星球生存 / 危机共治）、star-pioneers（从 0 到 1 拓荒 / 投资复利）、star-rail（接力交付 / 里程碑对齐）、future-city-builder（系统规划 / 技术债式冲突）
- 本作专攻：**贸易网络协同 / 路线规划对齐 / 库存与运力共享降本 / 风险沿路传导 / 局部压价 vs 全局繁荣**

---

## 👥 适用场景

- 供应链 / 跨部门协作工作坊
- 上下游对齐、资源调度与降本增效培训
- 新团队理解"局部决策如何影响全局结果"
- 项目管理中的风险共担与信息共享团建

**人数**：4-8 人（建议分 4-6 支商队，每队 1-2 人）  
**时长**：60-90 分钟（含 15-20 分钟复盘）  
**难度**：中等

---

## 🧩 核心机制（团建版）

### 1. 共享"丝路繁荣指数"（组织协同健康度）

- 初始值 **10**，范围 0-20
- 每回合结束按"全网协同度"调整：商队间有交易/拼队/共享情报 → +1~+2；出现脱钩（某商队孤立无协作）、恶性压价、运力浪费 → -1~ -2
- **≤ 0 即"商路断绝"**：全体失败，强制复盘"哪一步我们各自为战了"
- 繁荣指数高时，所有城市卖出价 +1（协同红利）；低时全城 -1（协同惩罚）

> **团建隐喻**：组织健康度不是某个人/某部门的事，是整张网络的共同资产。一个人偷懒或脱钩，全体收益缩水。

### 2. 路线规划与对齐（关键协同点）

- 地图 8 城线性分布：长安 → 敦煌 →（北路高昌 / 南路于阗）→ 撒马尔罕 → 波斯波利斯 → 巴格达 → 罗马
- 每支商队独立规划路线，但**相邻商队可在"驿站"节点交接物资与情报**
- 若两队规划撞车（同一路线同回合抢同一有限市场容量），触发"市场拥挤"：双方该城可交易商品数减半
- **对齐红利**：提前在群内同步各自路线，避免重复压价、错峰交易 → 繁荣指数 +1

> **团建隐喻**：上下游若不开会对齐路线，就会在客户端/资源池上撞车，双双受损。错峰与交接，是协同的基本功。

### 3. 资源共享降本（骆驼 / 水源 / 护卫池）

- 设立**共享商队池**：骆驼（运力）、水源（续航）、护卫（抗风险）三池，初始按人数发放
- 任一商队运力不足，可向池申请借用；有余力可捐回
- **共享收益**：池内资源被高效周转（借出→归还+1）时，繁荣指数 +1；长期闲置或某队独占 → -1

> **团建隐喻**：资源（人力/算力/预算）在部门间打通流转，比各自囤积更降本。囤货型团队拖累全局。

### 4. 风险沿路传导（事件卡共担）

- 移动时抽事件卡：沙暴🌪️ / 强盗🗡️ / 疾病🤒 / 商品变质📦 / 迷路🧭（负面）；绿洲🌴 / 商旅🤝 / 王室使者👑 / 驿站🏨（正面）
- **负面事件可"共担"**：受击商队可发起求助，其他商队用护卫/水源替其抵消，代价由帮者承担、繁荣指数 +1（互助红利）
- 不互助、各自逃跑 → 受击者损失加倍，且繁荣指数 -1

> **团建隐喻**：风险在供应链上会传导。一个环节爆雷，隔壁不拉一把，最终反噬自己。

### 5. 胜利条件（反转）

- **团队胜利**：全体商队累计"丝路总财富"达到目标（如 200 金币）**且**繁荣指数 ≥ 8
- **特殊胜利**：任一商队单独囤到 80 金但繁荣指数 < 5 → 判定"富了个人、垮了商路"，**不计胜，触发复盘**
- 15 回合上限，到时按"总财富 × 繁荣系数"评级（A级 = 协同型繁荣）

## 🎭 角色分工（6 类职能，映射组织视角）

| 商队职能 | 团建映射 | 核心职责 |
|---------|---------|---------|
| 🧭 领航商队（总调度） | PMO / Leader | 统筹全网路线、推动错峰对齐、盯繁荣指数 |
| 🏺 货源商队（供给） | 供应链 / 中台 | 保障商品供给、驼运与库存周转 |
| 💰 市集商队（业务） | 业务 / 销售 | 在城市卖出获利、捕捉价差机会 |
| 🛡️ 护卫商队（风控） | 质量 / SRE | 持有护卫、替全网抵风险、保交付 |
| 🌿 驿路商队（联勤） | 运营 / HRBP | 管理水源续航、驿站交接、补给协调 |
| 📜 情报商队（信息） | 架构 / 战略 | 探路事件牌堆、共享路线情报、降不确定性 |

> 每队可 1 人兼任 2 职能；4 人局可合并为 4 职能。

## 🔄 回合流程（每队每回合三阶段）

**阶段一 · 城市行动**（在所在城）
- 交易：买卖商品（受市场容量限制，全网共享容量）
- 建设商队：花金币升级运力/护卫（利己也利池）
- 城市特殊能力：如敦煌招募护卫、巴格达大批量出货

**阶段二 · 旅途移动**
- 选路线 → 付水源 → 移动 → **抽事件卡结算**
- 可发起/接受"驿站交接"（与邻队互换物资情报）

**阶段三 · 回合结束**
- 补充城市市场；结算繁荣指数增减
- 检查"商路断绝"（≤0）或团队胜利条件

## 📋 4F 复盘框架（必做，15-20 分钟）

| F | 提问 | 留意信号 |
|---|------|---------|
| **Facts 事实** | 哪几回合繁荣指数掉得最狠？当时发生了什么？ | 撞车、孤立、囤货、拒援 |
| **Feelings 感受** | 作为某职能商队，什么时候最焦虑 / 最被托住？ | 资源卡脖子、被邻居拉一把 |
| **Findings 发现** | 我们的"局部最优"决策，怎样损害了全局？ | 压价互耗、运力闲置、信息黑箱 |
| **Future 行动** | 回到真实工作，哪条链路该先开对齐会？ | 供应链例会、共享资源池、风险共担机制 |

## 🎲 变体玩法

1. **观察员模式**：1 人不出队，只记录"协同断点"并在复盘呈现
2. **限时决策**：每阶段 90 秒，逼出"先对齐还是先开干"的真实习惯
3. **角色轮换**：每 5 回合换职能，体会供需/风控/信息不同视角的难
4. **无声商路**：移动阶段禁语，只能写便签——练"异步协同"与信息沉淀
5. **部门混编**：跨真实部门组队，打破本位
6. **真实目标叠加**：把团队当前一个真实 OKR 作为"罗马终极市场"的额外奖励条件
7. **断链演练**：故意抽掉共享池，让各队回归各自为战，对比繁荣指数崩塌速度
