🎮 游戏概述

《猎人小队 · 协同升级版》改编自合作桌游《独行猎人 Solo Leveling Hunters》（改编自动漫《我独自升级》）。原作里每位玩家都是独自刷副本、靠击杀升级的个人英雄；团建版里，玩家组成一支猎人小队，组队深入 5 层地下城，分工清怪、共享经验与装备、搭伙打 Boss，把"我独自升级"彻底改写成"团队一起升级"。

在团建语境下，地下城就是一支正在爬坡 / 攻坚的团队：怪物是业务风险与能力短板，Boss 是那个绕不过去的里程碑；能不能让全员一起升起来、而不是只有少数人在扛，正是真实工作中"共同成长 vs 能者多劳"的缩影。原作最迷人的"升级系统"，恰是团队里"能力成长"的绝妙隐喻——只不过我们把它反转为：你的成长不是孤立的，团队的传帮带、经验共享、搭子制度，会把每个人的成长曲线都拉得更陡。

🎯 团建改造重点

  • 协同升级（核心反转）：经验入团队池、按需分配——"传帮带让成长更陡"
  • 角色互补：兜底 / 攻坚 / 点杀 / 补给 / 统筹，映射真实团队的攻守与调度
  • 资源流向：把好装备 / 经验给最需要的人，而非囤积
  • 搭子带练：新手绑资深搭子经验加成——还原师徒 / buddy 系统的价值
  • 复盘框架：每局结束 4F 复盘，把"升级与成长"迁移到真实工作的能力建设

🎯 团建目标

协同升级观

体验"经验共享 + 传帮带"比"各练各的"成长更快，反思是否总靠少数人在扛

角色互补

看见兜底 / 攻坚 / 补给 / 统筹的相互依赖，体感"没有谁是无用的位置"

资源流向

把好装备 / 经验给最需要的人，训练"资源去到最产生价值的地方"

带练文化

搭子模式下新手持资深搭子加成——体感师徒 / buddy 系统是加速器

📦 物料准备

物品名称数量用途
地下城地图1张5 层网格，标注怪物 / 事件 / 宝藏 / 休息点
经验池轨迹1张团队共享经验值（每 100 升 1 级）
士气轨迹1张队伍士气值（初始10，低则崩）
角色卡 / 骰子5张 / 1-2颗职能分工；战斗 / 事件判定

🖨️ 无打印方案（临时团建）

  • 地图：白纸分 5 段（入门→进阶→熟练→精通→突破），各段摆"怪"便签
  • 经验/士气：纸条写经验 0-300、士气 0-10 当轨迹
  • 卡牌：便签写名称 + 效果（👹/⚔️/✨），分类面朝下抽
  • Boss：第 5 段中心写"🐲 Boss（300 血）"
  • 骰子：手机骰子 APP，或 1-20 数字卡抽签

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属角色，模拟真实团队中的"攻守与调度"分工与相互依赖（也可按性格由教练分配）：

🛡️ 剑士 · 质量 / 中台 / 风险兜底

被动：承受伤害+1、替队友挡刀

团建映射：稳底盘、兜底——"风险兜底与系统守护"

🔮 法师 · 业务攻坚 / 技术突破

被动：范围伤害、群体秒怪

团建映射：主攻手、攻坚——"业务突破手"

🏹 弓箭手 · 精准突破 / 要事第一

被动：必中弱点、点杀关键

团建映射：抓关键窗口——"要事第一"

✨ 牧师 · 情绪补给 / 资源协调

被动：群体治疗、共享 MP

团建映射：心理安全与补给——"PMO / 后勤"

📜 战术指挥 · 统筹 / PMO / Leader

被动：预看事件、分配经验

团建映射：调度与传帮带——"谁在负责让大家一起成长"

🎲 游戏流程（每回合 4 阶段）

每回合依次执行：① 事件阶段 → ② 行动阶段（每人 2 行动点） → ③ 结算阶段（经验入池！） → ④ 结束阶段（回合 +1）。

核心机制 · 协同升级（团建灵魂）

击败怪物获得经验进入团队池，而非个人；每 100 经验可升 1 级，按需分配给最该成长的人。没有人把经验独吞、没有新人被晾着，全员才升得起来——这正是"传帮带让成长更陡"的体感。

地图 · 5 层地下城 = 能力进阶五阶段

入门→进阶→熟练→精通→突破；越深层怪物越强，必须靠角色互补 + 经验共享才打得过。一个人再强也顶不住 Boss——"团队成长 > 个人英雄"。

危机 · 队伍士气 = 团队状态 / 离职潮

光催进度不打气，士气归零团队就崩。游戏逼团队在"催里程碑"与"养人"之间找平衡。

共享轨道与危机

共享轨道初始警告 / 失败阈值
团队经验池0每 100 升 1 级（能力基线）；全员满级即"团队出师"
队伍士气10≤3 低迷警报；≤0 即失败（离职潮 / 团队崩）
副本深度第1层清完 5 层 + 击败 Boss = 胜利
回合计数器0达 30 塌陷 = 失败（交付期限到了）

⚠️ 关键：胜负不取决于"谁杀怪最多"，而取决于"经验有没有共享、装备有没有给对人、新人有没有被带起来、士气有没有守住"。

💡 团建引导提示

游戏前（5分钟）

反转主题："今天不玩《我独自升级》，玩《我们一起升级》——经验进团队池，谁最需要就分给谁。"

游戏中（观察）

记录：经验流向了谁？谁在兜底？装备去哪了？新人怎样？士气几了（养人 vs 催进度）？

游戏后（4F复盘）

事实→感受→发现→迁移，约15-20分钟；把"升级与成长"迁移到真实工作的能力建设。

🔄 变体玩法

观察员模式

超5人时多出玩家任观察员，记录"经验流向、谁在兜底、新人是否被带"，复盘提供第三方视角。

限时挑战

设60分钟 / 30 回合沙漏，以"是否清完 5 层 + 击败 Boss"判胜负，适合时间有限团建。

角色轮换

每2回合轮换角色，体验"兜底"与"攻坚 / 补给 / 统筹"几类职能。

无声副本

部分回合禁言，凸显"提前约定、显性同步"对配合型协作的价值。

部门混编

拆散同部门到不同角色，专为"打破部门墙"设计。

真实能力短板叠加

把怪物换成当前能力短板/待提升项便签，每击败1只=突破一项，便签变能力改进看板。

新人带练

标1-2名新人与资深绑搭子（经验+20%、共享MP），复盘重点："怎么让新人最快成长"。

⚙️ 难度调整

模式调整适合
简单怪物减半、士气12、经验80/级、回合上限40新团队/非玩家
标准（推荐）怪物标准、士气10、经验100/级、回合上限30、Boss300血大多数团建
困难怪物×1.5、士气8、回合上限22、Boss450血、禁囤装备业务攻坚/冲刺团队
