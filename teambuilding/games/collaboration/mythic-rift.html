🎮 游戏概述

《神话裂隙》改编自合作桌游《Mythic Rift》。玩家扮演来自不同神话世界的"神话猎人"——孙悟空、赫拉克勒斯、托尔、拉、须佐之男，联手探索连接各神话世界的神秘裂隙，收集远古神器，合作封印企图入侵的远古邪神"混沌之主"。

游戏以合作为核心——所有人共享胜负，只要团队"理智值"见底、全队在混沌侵蚀中崩溃，任务即刻失败。三条章节层层推进、三位 Boss 逐一降临、神器与技能需要跨角色组合，每一刻都在考验团队的角色互补、信息共享与协同决策。这片裂隙正如一支面临复杂挑战的团队——持续下降的理智值是团队心智水位与心理安全的晴雨表，三位 Boss 是项目里程碑上接连出现的硬骨头，而"混沌之主"正是那道必须合力攻克的核心难题。

🎯 团建改造重点

  • 合作而非竞争：共享理智值、共享裂隙能量、共享胜负
  • 角色互补：5种神话职能，模拟真实团队角色互补
  • 心智韧性：理智值引导团队觉察"谁在照顾全局状态、拉回崩溃同伴"
  • 信息共享：神器效果与 Boss 弱点全队公开，别让队友蒙在鼓里
  • 阶段推进：三条章节对应项目里程碑，觉察"冲刺 vs 透支团队"

🎯 团建目标

角色互补认知

体验攻坚 / 守护 / 范围 / 疗愈 / 控制五类职能的边界与依赖

心智韧性

理智持续下降时，团队是否有人主动"补位"、拉回崩溃或沉默的同伴

信息共享

神器与 Boss 弱点全队可见，训练主动同步情报、别让队友硬扛

节奏管理

在"推进章节"与"回复理智"间权衡，觉察团队能量水位

🖨️ 无打印方案（临时团建）

  • 地图：白纸画六边形或九宫格当需要裂隙，放下能量/神器/裂隙/营地标记位
  • 理智/能量：纸条写 0-10 刻度当轨道，硬币当标记
  • 卡牌：便签写名称+效果，分类面朝下抽
  • 棋子：硬币=玩家、骰子=Boss；骰子可用手机 APP

🧑‍🤝‍🧑 角色分配（团建核心）

每位玩家承担一个专属职能，映射真实团队中的角色分工（也可按性格由教练分配）：

🐵 孙悟空 · 攻坚 / 破局者

被动：高攻击近战 —— 团队里的"主攻手"，把硬骨头啃下来。

💪 赫拉克勒斯 · 守护 / 稳定者

被动：高防御 + 复活 —— 团队承压时的"定海神针"，稳住基本盘。

⚡ 托尔 · 范围 / 催化剂

被动：雷电范围伤害 —— 团队里的"扩散破壁者"，一次撬动全局。

☀️ 拉 · 疗愈 / 增益者

被动：治疗与增益 —— 团队的"充电宝"，提振状态与士气。

🌊 须佐之男 · 控制 / 调度者

被动：水系控制场地 —— 团队的"节奏掌控者"，安排进退与时序。

🎲 游戏流程（每回合 4 阶段）

阶段1 · 恢复

所有玩家恢复行动点、抽 1 张技能卡。

阶段2 · 行动

按行动点顺序：移动 / 探索神器遗迹 / 采集能量 / 战斗 / 使用技能卡 / 装备神器 / 传递卡牌（相邻互传免费）。

阶段3 · 事件

停留在混沌裂隙时抽事件卡并执行效果（利好或危机）。

阶段4 · 结束

检查理智值（团队理智降为 0 即崩溃）；检查胜利条件；章节标记推进。

共享轨道与危机

共享轨道初始失败阈值
团队理智值10 / 10达到 0 即全队因"集体倦怠 / 心智崩溃"失败
裂隙能量共享池资源枯竭将无力合成神器、僵局难破
推进章节3 章章节失败条件触发（累计折损过多）即全队失败

⚠️ 关键：理智值是团队状态的晴雨表——比起个人战力，它更考验"是否有人在乎全局状态"。能量节点提醒：资源要共享、要有人统筹，别让攻坚手"弹尽粮绝"。

💡 团建引导提示

游戏前（5分钟）

介绍主题："混沌与理智值就是项目压力与 deadline"；强调理智值与能量是团队的，不是某人的。

游戏中（观察）

记录：谁在采资源统筹？谁在兜底？理智值谁在意？有人崩溃时团队反应？

游戏后（4F复盘）

事实→感受→发现→迁移，约15-20分钟，引导反思分工与心智韧性。

🔄 变体玩法

观察员模式

超5人时多出玩家任观察员，复盘提供第三方视角。

限时挑战

设90分钟时间盒，时间到以是否封印混沌之主判胜负，适合时间有限团建。

角色轮换

每封印一位 Boss 轮换角色，体验"攻坚"与"疗愈/守护"两类职能。

无声裂隙

部分章节推进禁言，凸显非语言沟通与提前约定。

部门混编

拆散同部门到不同角色，专为"打破部门墙"设计。
