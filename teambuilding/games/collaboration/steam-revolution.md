# 蒸汽革命 · 效能引擎（团建协作版）

> 改编自策略桌游《蒸汽革命 Steam Revolution》（2-5 人引擎构建 / 铁路网络 / 资源转化）
> 团建视角：**端到端交付流水线贯通 / 平台基建复利 / 短期交付 vs 长期效能投资 / 效能健康度可运营**

---

## 🎯 一句话团建价值

原作是"各自建造工业帝国、比谁分数最高"。团建版把它翻转为：**多个车间（部门）不是竞争对手，而是同一条端到端价值流上的共谋者**——矿山（原料/需求）→ 工厂（研发加工）→ 铁路（构建部署流水线）→ 城市（上线营收），四段链路任何一段断掉，订单就烂在路上。它把"业务需求 vs 效能投资抢同一池资源、平台团队的价值如何被看见、透支式繁荣的代价"这些研发组织的经典难题，变成一场可以复盘的手感游戏。

**与其他改造游戏的差异化定位**：
- 区别于 silk-road（供应链网络协同 / 风险共担）、future-city-builder（系统规划 / 技术债式冲突）、lychee-express（极限 deadline / 质量 SLA）
- 本作专攻：**端到端价值流贯通 / 共享基建复利（投资方 vs 复用方） / 赚快钱 vs 投效能的经典冲突 / 效能是运营出来的不是喊出来的**

---

## 👥 适用场景

- 研发 / 工程团队的 DevOps 与效能文化工作坊
- 业务与技术的"需求排期 vs 技术改造"冲突调解
- 平台 / 中台团队价值呈现（让业务方亲身体验基建复利）
- 项目管理中的交付流水线与瓶颈识别培训

**人数**：4-8 人（建议分 4-6 个车间，每队 1-2 人）
**时长**：60-90 分钟（含 15-20 分钟复盘）
**难度**：中等偏难

---

## 🧩 核心机制（团建版）

### 1. 共享"引擎热力指数"（组织效能健康度）

- 初始值 **10**，范围 0-20
- 每回合结束按"链路健康度"调整：订单端到端贯通交付 → +1~+2；出现断链（原料断供 / 成品积压运不出去 / 订单逾期）→ -1~-2
- **≤ 0 即"锅炉熄火"**：全体失败，强制复盘"哪一段链路被我们饿死了"
- 热力指数高时，全团每回合 +1 行动点（效能红利）；低时所有工厂产能 -1（效能惩罚）

> **团建隐喻**：效能是全团的公共资产。某个车间天天救火、某个环节常年断供，全团都在为低效买单。

### 2. 端到端价值流（四段链路贯通）

- 地图三带布局：🏔️ 矿山带（原料）→ 🏭 工厂带（加工）→ 🏙️ 城市带（订单/营收），铁路🛤️ 贯穿其间
- **订单必须四段贯通才能交付**：城市订单 → 需要工厂成品 → 需要矿山原料 → 需要铁路运力
- 任一段断链（如工厂有产能但矿山没原料、成品造好了但铁路运力不足），订单进入"逾期倒计时"，2 回合内未打通 → 订单作废、热力 -2
- **对齐红利**：行动阶段开始前，各车间同步本轮原料/产能/运力状态再分工 → 热力 +1（不许对齐则正常行动）

> **团建隐喻**：交付周期不是最忙的车间决定的，是被"卡住的那一段"决定的。瓶颈不汇报，全团瞎忙。

### 3. 共享基建复利（铁路 = 内部平台）

- 铁路一旦铺设，**全团免费复用**（核心反转：原作中铁路向他人收 1 金/次通行费，团建版删除）
- 铺设成本由发起车间独自承担（2 行动点 + 3 金）——"我出钱修的路，全公司都在跑"
- 每回合结算"复用率"：一条铁路被 ≥ 2 个车间使用 → 热力 +1（平台复利）；铺了没人用 → 热力 -1（过度建设）
- 城市订单奖励与"铁路连通度"挂钩：连通城市越多，订单奖励越高

> **团建隐喻**：平台/中台的价值藏在所有人的效率里，而不在自己的产出报表里。讨论点：平台团队的功劳怎么被看见？

### 4. 短期交付 vs 长期效能投资（技术卡 = 效能工具）

- 技术卡不产出即时金币，但**永久提升全团产能**：
  - ⚙️ 机床革新（4 金）：所有工厂产出 +1 —— 研发效能工具
  - 🚂 蒸汽机改良（3 金）：铁路运输效率 +1 —— 流水线提速
  - 🤖 工厂自动化（6 金）：工厂无需占用行动点即可运行 —— CI/CD 自动化
  - 📡 铁路电报（3 金）：可远程完成订单（不必移动棋子）—— 异地协同/远程评审
  - 💨 蒸汽涡轮（5 金）：所有产出 +1 —— 全局架构升级
- **经典冲突**：每回合只有 3 行动点、一池金币——多接一单赚快钱，还是研发一项技术吃复利？逼真还原"业务需求 vs 技术改造"的资源争夺
- 前 6 回合未研发任何技术的车间，第 7 回合起每回合产能 -1（低效债务）

> **团建隐喻**：效能投资永远"看起来可以再等等"，直到低效的利息找上门。

### 5. 事件卡（组织风险）

- 每回合事件阶段翻 1 张，影响全团：
  - ✊ 工人罢工：所有工厂产能 -1（1 回合）—— 人员流失 / 士气下滑
  - 💥 矿难：1 座矿山本回合无产出 —— 线上事故 / P1 故障
  - 📉 金融危机：全团 -3 金 —— 预算缩减
  - 📈 经济繁荣：订单奖励 +2 金（1 回合）—— 业务旺季窗口
  - 🎪 技术博览会：研发费用 -2 金（1 回合）—— 行业机会窗口（该投技术了）
  - 👑 皇室订单：出现 1 个高价值紧急订单 —— 大客户插单
- 罢工/矿难发生后，可消耗 2 金"抚恤/检修"提前恢复 —— 事后复盘 vs 事前预防的成本差

### 6. 胜利条件（反转）

- **团队胜利**：12 回合内完成 **15 张订单** 且热力指数 ≥ 8 且全团累计研发 ≥ 4 项技术
- **特殊失败**：疯狂接单攒金币、但技术投资为 0 且热力 < 5 → 判定"透支式繁荣"，**不计胜，触发复盘**
- 到时未达标，按"订单数 × 热力系数 + 技术数 × 2"评级（A级 = 健康的引擎）

## 🎭 角色分工（6 类职能，映射组织视角）

| 车间职能 | 团建映射 | 核心职责 |
|---------|---------|---------|
| 🏔️ 矿务督办（原料供给） | 数据 / 需求方 | 保障原料供给、预警断供、管理矿山产能 |
| 🏭 车间厂长（加工生产） | 研发 | 原料→成品转化、产线切换、产能排程 |
| 🚂 铁路总办（基建平台） | 平台工程 / DevOps | 铺设共享铁路、维护运输效率、承受"投资无产出"的评判 |
| 💰 订单商会（业务） | 业务 / 客户成功 | 接订单、排优先级、管理交付承诺与逾期 |
| 📡 皇家学会院士（技术） | 架构 / 效能 | 研发技术卡、论证长期效能投资 |
| 🔧 总工程师（统筹） | PMO / Leader | 盯热力指数、协调四段链路贯通、仲裁"接单 vs 投资" |

> 每队可 1 人兼任 2 职能；4 人局可合并为 4 职能（建议保留铁路总办——他是本作冲突的引爆点）。

## 🔄 回合流程（每回合四阶段）

**阶段一 · 对齐速报**（2 分钟）
- 各车间亮出当前原料 / 产能 / 运力 / 订单状态；选择"对齐"则热力 +1

**阶段二 · 收入阶段**
- 运行中的工厂产出资源；矿山自动产出；铁路按复用率结算热力增减

**阶段三 · 行动阶段**（每车间 3 行动点）
- 采集原料 / 工厂加工 / 铺设铁路 / 建造工厂 / 交付订单 / 研发技术 / 移动（详见原作行动表）

**阶段四 · 事件与结算**
- 翻事件卡执行；补充城市订单；结算热力指数增减
- 检查"锅炉熄火"（≤0）、订单逾期、或团队胜利条件

## 📋 4F 复盘框架（必做，15-20 分钟）

| F | 提问 | 留意信号 |
|---|------|---------|
| **Facts 事实** | 哪几回合热力掉得最狠？哪张订单逾期了？链路断在哪一段？ | 原料断供、成品积压、运力闲置 |
| **Feelings 感受** | 铁路总办"投资修路全团白用"时什么感受？业务方"订单烂在路上"时呢？ | 平台价值不被看见、被卡脖子的愤怒 |
| **Findings 发现** | "赚快钱 vs 投效能"我们怎么权衡的？回头看哪次投资太晚？ | 一直说"下回合再投技术"、透支式繁荣 |
| **Future 行动** | 回到真实工作，我们的"铁路"（平台/工具/自动化）还缺哪几条？谁发起？ | 效能看板、内部平台共建、需求与技术改造的固定配比 |

## 🎲 变体玩法

1. **观察员模式**：1 人不出队，只记录"链路断点与投资时机"并在复盘呈现
2. **限时决策**：行动阶段 90 秒，逼出"先对齐还是先开干"的真实习惯
3. **角色轮换**：每 4 回合换职能，特别是让业务方当一次铁路总办
4. **无声工厂**：行动阶段禁语只写便签——练异步协同与信息沉淀
5. **部门混编**：跨真实部门组车间，打破本位
6. **真实效能看板叠加**：把团队真实的 CI 时长 / 部署频率 / 需求周期作为"热力指数"额外计分项
7. **通行费模式**（还原原作）：铁路可收 1 金/次——对比"平台收费 vs 平台免费"两局的热力曲线，讨论内部结算与成本分摊
