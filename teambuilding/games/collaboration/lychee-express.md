# 长安荔枝 · 极限转运 团建协作版

> 改编自策略桌游《长安荔枝：转运使之争 Lychee of Chang'an》（2-4 人路线规划 / 易逝资源管理，灵感自马伯庸小说《长安的荔枝》）
> 团建视角：**极限 deadline 下的实验迭代 / 交付质量随时间衰减 / 分段接力与信息交接 / 组织成本约束（不靠压榨取胜）**

---

## 🎯 一句话团建价值

原作是"各转运使抢功互坑、比谁的贡品分高"。团建版把它翻转为：**所有人同属一个荔枝使团**——面对"荔枝一日色变、二日香变、三日味变"和贵妃生辰的极限 deadline，靠分段接力、保鲜实验和沿途资源整合，把不可能任务变成可交付的项目。它把 **"交付物到手会烂（质量衰减）、技术方案要靠实验验证（保鲜器具）、交接不同步就掉鲜（信息损耗）、加班压榨有隐性代价（民力）"** 这些项目管理难题，变成一场可以复盘的手感游戏。

**与其他改造游戏的差异化定位**：
- 区别于 silk-road（贸易网络协同 / 供应链对齐）、star-rail（接力交付 / 里程碑）、mars-colony（长期主义 / 危机共治）
- 本作专攻：**极限 deadline 下的"算学与实验"（把不可能拆成可解的题）/ 交付质量 SLA 衰减管理 / 分段转运的信息交接损耗 / 民力（组织成本）红线——赢了交付不能输掉团队**

---

## 👥 适用场景

- 项目管理培训：deadline 极限、范围固定、资源不足的"不可能任务"工作坊
- 研发团队：技术方案选型与实验验证（保鲜器具 = 基础设施投资）
- 跨部门协作：分段交接、信息同步质量的显性化
- 管理层培训：交付节奏 vs 组织成本的平衡（一骑红尘的背后是什么）

**人数**：4-8 人（建议分 4-6 支转运队，每队 1-2 人）
**时长**：60-90 分钟（含 15-20 分钟复盘）
**难度**：中等偏难

---

## 🧩 核心机制（团建版）

### 1. 新鲜度 = 交付质量 SLA（会衰减的核心资产）

- 每担荔枝新鲜度 **0-10**，从装担起**每回合 -1**（荔枝天然腐坏）
- 抵达长安时，新鲜度即为该担的"圣心评价"：≥8 圣心大悦、6-7 尚可、4-5 勉强、≤3 贵妃皱眉（计 0 分）
- 新鲜度归 0 = 该担全损，之前所有的赶路、投资全部沉没

> **团建隐喻**：交付物是有保质期的。用户到手时的体验才算数，不是你出发时有多好。为了速度牺牲质量的债，在路上每一站都在滚利息。

### 2. 保鲜实验（技术方案验证与基建复利）

- 市集/驿站可花资源建造 8 种器具：竹筒水藏（腐坏 -1/回合）、冰窖车（资源增产）、快马加鞭（提速）、盐渍古法（进贡视为 +2）等
- **团建版关键改动：器具效果对全团共享**——你造的竹筒水藏，所有转运队的担都减缓腐坏。一次实验成功，全团复利
- 器具槽有限（每队 3 件），逼迫团队做**方案优先级排序**：先保命（竹筒）还是先提速（快马）？

> **团建隐喻**：李善德赢在"做实验"——竹筒、盐渍、分枝植瓮都是一次次试出来的。技术方案靠小成本验证、再放大投入；基础设施投资是全团队共享的复利。

### 3. 分段接力转运（交接即信息同步）

- 五千里路分 5 段：岭南荔园 → 梅关道 → 赣江水路 → 汉水官道 → 商山道 → 长安兴庆宫
- 每段一支转运队负责，担在驿站**交接**：
  - 交接时须**完整同步**：当前新鲜度、剩余资源、已知前方风险、建议方案
  - 交接合格：担照常推进
  - **交接敷衍**（信息没说全/没记录）：新鲜度 **-2**，且接收队本回合行动受限
- 前段省下的冰藏/脚力资源，可留在驿站传给后段（接力资产）

> **团建隐喻**：项目交付的质量损耗，大头不在干活，在交接。上一棒不把上下文讲清楚，下一棒就要用交付质量来还。

### 4. 民力值（组织成本红线）

- 全团共享**民力值 10**（0-15 轨道）
- 每次"强行军"（加班冲刺：额外 +2 移动）→ 民力 -1
- 民力 ≤ 3 触发"民怨"：全团每回合额外腐坏 -1（疲惫让质量下滑）
- 民力 = 0 → **天怒人怨**：即便荔枝送到，也判定任务失败

> **团建隐喻**：靠压榨换速度是有账单的，账单晚到但必到。"一骑红尘妃子笑"的背后是沿途驿卒的透支——团建版把这个隐藏成本摆在桌面上。

### 5. 风险卡（匪患由环境触发，不再互坑）

- 主持人每回合翻 1 张风险卡：山贼剪径⛰️ / 酷暑蒸腾☀️ / 官道塌方🪨 / 马瘟倒毙🐴 / 贡期提前⏰（deadline 突然提前！）
- 全团须即时协商应对：花护卫抵消、绕路、还是硬扛损失
- 原"同行互坑"的匪患卡全部转为环境压力——**对手是任务本身，不是队友**

### 6. 胜利条件（反转）

- **团队胜利**：第 10 回合（贵妃生辰）前，累计成功进贡 **3 担** 且 **平均新鲜度 ≥ 6** 且 **民力 ≥ 4**
- **特殊失败一（送达但烂了）**：担数够但平均新鲜度 < 6 → "红尘虽至、荔枝已馊"，不计胜
- **特殊失败二（赢了交付输了团队）**：担数与新鲜度都够但民力 < 4 → "一骑红尘、十室九空"，不计胜，强制复盘
- 到时未达 → 按已达成的担数/新鲜度/民力综合评级（A级 = 又快又鲜又不伤民）

## 🎭 角色分工（6 类职能，映射组织视角）

| 使团职能 | 团建映射 | 核心职责 |
|---------|---------|---------|
| 🧮 荔枝使（李善德） | PMO / Leader | 全局算学统筹、分段调度、盯三线指标（担数/鲜度/民力） |
| 🕌 胡商司马（苏谅） | 商务 / 供应商管理 | 银钱调度、外部资源谈判、以钱换时间 |
| 🌿 荔园峒女（阿僮） | 业务 / 源头品控 | 装担质量把控、荔枝品种选择、源头最优 |
| 🏯 驿丞 | 运维 / 中台 | 驿站运营、器具建造与维护、交接调度 |
| 🛡️ 护卫都尉 | 质量 / SRE | 持有护卫、替全团抵风险卡、保路线安全 |
| 📜 算房书吏 | 数据 / 效能 | 每回合记录三线指标、微复盘、给荔枝使出算法 |

> 每队可 1 人兼任 2 职能；4 人局可合并为 4 职能。书吏是本作灵魂角色——没有记录就没有迭代。

## 🔄 回合流程（每回合四阶段）

**阶段一 · 掷骰与调度**
- 各队掷骰前进（可花脚力加速、可选择强行军：+2 移动但民力 -1）

**阶段二 · 结算与交接**
- 停资源格抽卡（冰藏/脚力/银钱）；停市集可造器具（全团共享）
- 驿站交接：交接队须完整同步信息，敷衍交接鲜度 -2

**阶段三 · 风险与协商**
- 主持人翻风险卡，全团即时协商应对方案

**阶段四 · 腐坏与对账**
- 所有在途担新鲜度 -1（有共享竹筒水藏则不减）
- 书吏记录三线指标（担数/鲜度/民力）；检查民怨与终局条件

## 📋 4F 复盘框架（必做，15-20 分钟）

| F | 提问 | 留意信号 |
|---|------|---------|
| **Facts 事实** | 我们的民力在哪几个回合掉得最快？交接掉鲜发生在哪几段？ | 连续强行军、敷衍交接、器具投资排序失误 |
| **Feelings 感受** | 作为后段转运队，接到一个"信息不全的担"是什么感受？ 作为被要求强行军的队呢？ | 信息黑箱的愤怒、被压榨的沉默 |
| **Findings 发现** | 我们把"快"和"好"对立起来了吗？保鲜实验和赶路，哪个是杠杆？ | 先投资基建的团后期鲜度反超、纯赶路的担半路全损 |
| **Future 行动** | 回到真实项目，哪里该先做"保鲜实验"？哪次交接最该补信息同步？ | 技术预研排期、交接清单模板、加班红线机制 |

## 🎲 变体玩法

1. **观察员模式**：1 人不入队，只记录"强行军次数"与"交接质量"，复盘时呈现隐藏账单
2. **贡期提前演练**：第 5 回合强制翻"贡期提前⏰"，deadline 从 10 回合砍到 7——练范围裁剪
3. **角色轮换**：每 3 回合换职能，体会源头品控和末端交付的不同焦虑
4. **无声转运**：交接阶段禁语、只能写交接单——把"口头同步"逼成"文档沉淀"
5. **部门混编**：跨真实部门组队（前段研发、后段业务），暴露真实交接断点
6. **真实项目叠加**：把团队当前一个真实 deadline 项目映射为"这担荔枝"，游戏结束后开真实排期会
7. **压榨式管理演练**：进阶场故意允许无限强行军，观察民力崩塌与质量雪崩的联动，复盘组织成本
