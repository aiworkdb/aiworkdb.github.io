# 扬帆起航（Build a Ship / 百人造船 · 共造巨舰）

> **一句话**：三个组分别做船头、船身、船尾——三段的龙骨高度只要差 5 厘米，中间那条接缝就永远补不上。

| **游戏名称** | 扬帆起航（Build a Ship / 百人造船 / 共造巨舰 / 同舟共济） |
| **目的标签** | 分段建造 · 曲面延续 · 共同载体 |
| **形式标签** | 室内大场地 / 户外广场 · 三段并行 · 站/蹲姿 |
| **人数** | 全场 100–400 人（分 3 大段 × 若干小组，每组 8–15 人） |
| **时长** | 210–270 min |
| **难度** | ⭐⭐⭐ 中等偏高（骨架能搭，曲面接不上） |
| **道具需求** | 有（瓦楞纸板 + PVC 管 + 扎带 + 热熔胶 + 颜料 + 美纹胶带） |
| **场景标签** | 年会 · 周年庆 · 战略发布 · 百人共创 · 企业文化 |
| **核心目标** | 用"外皮曲面接不上"这件事，暴露"同时开工但没定接口"的代价 |

---

**团建核心价值**：
- 🚢 分段建造：船头、船身、船尾三队同时开工，进度快但接口风险高
- 〰️ 曲面延续：最难的不是搭骨架，是让三段的船舷弧线连成一条
- 🏋️ 真实承载：成品要能被全队抬起来走一圈，纸糊的骗不过去
- 🎯 共同载体：船是"我们"的隐喻，不是比喻，是能摸到的东西

## 1. 游戏概览

全场分成三大段：**船头队、船身队、船尾队**，各段内部再分小组（骨架组、外皮组、涂装组）。三段同时开工，最后合体成一艘长 4–6 米的巨船，全员抬着它走一圈，举行"启航仪式"。

**它和多米诺、过山车属于同一族——"分段建造 + 最终合体"。但难点完全不同：**

| 项目 | 合体难点 | 误差形态 |
|---|---|---|
| 多米诺连锁 | 间距与方向 | 一维（前后） |
| 超级过山车 | 轨道高度与坡度 | 二维（前后 + 高低） |
| **扬帆起航** | **船舷曲面的连续 + 龙骨对齐** | **三维（前后 + 高低 + 左右曲面）** |

所以它是这一族里**合体最难**的一个。三段各自做出来都很像船，合起来会出现：

- 船头高、船身低 → 中间一个台阶
- 三段船舷弧度不一致 → 接缝处鼓起或凹陷
- 外皮包覆方向相反 → 接缝处纸板互相顶住，合不拢
- 龙骨（底部长梁）不在一条线上 → 船体整体扭曲

**为什么它适合百人以上**：它需要"至少三个人数相当的段"才能成立。50 人做会显得局促，100 人刚好，200 人以上要分成"多艘船"比赛。

## 2. 核心规则

### 准备

- **成品规格**（建议）：长 4–6 m × 宽 1.5–2 m × 高 1.2–1.5 m（含桅杆可到 2.5 m）
- **材料**：
  - 五层瓦楞纸板（主要外皮与装饰）
  - PVC 管（直径 20–25 mm，做龙骨与肋骨）
  - 尼龙扎带、美纹胶带、热熔胶枪（骨架固定）
  - 丙烯颜料 + 滚筒 + 画笔（涂装）
- **场地**：室内需至少 8 m × 12 m 的空地（含三段各自的作业区 + 合体区）；户外需无风（纸板遇风会掀）
- **三段划分**：按长度 1:1:1 均分。**每段人数必须相当**（否则进度差太大，先完成的段会来"指导"别人）
- **合体区**：提前在地面用胶带标出船的**总外轮廓**（长 × 宽），三段都在这个轮廓里作业，合体时直接推到位置

### 规则

1. 三段**同时开工**，各自领取等量材料
2. 每段只负责自己的部分，**不许提前去别的段"帮忙"**（这是硬规则，否则会变成一队人在做，其他人在看）
3. 合体前，三段**必须共同开一次"接口会"**（至少 10 分钟，每段派 3 人参加）
4. 接口会必须确定三件事：**龙骨高度、船舷弧线的三个控制点、外皮包覆方向**
5. 合体时按地面轮廓就位，由教练逐项验收：龙骨对齐 / 曲面连续 / 接缝无空隙
6. 验收通过后，**全员抬船走 20 米**（真实承重测试，抬不起来就是没过）
7. 抬船回到"启航区"，举行启航仪式（推入蓝布"水面"/撒花/鸣笛/合影）

### 流程（四小时版）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 讲规则 + 分段 | 20 min | 分三段、发材料、公布成品规格与地面轮廓 |
| 各段设计 | 25 min | 段内出草图，确定骨架方案 |
| **接口会（必须）** | 15 min | 三段共同定龙骨高度、弧线控制点、包覆方向 |
| 分段建造 | 90 min | 骨架 → 外皮 → 初检 |
| 段内涂装 | 40 min | 融企业文化/队名/口号 |
| **合体** | 25 min | 推到位、对齐、补缝 |
| 承重抬船 | 10 min | 全员抬行 20 米 |
| 启航仪式 | 15 min | 仪式 + 合影 |
| 复盘 | 20 min | 见第 4 节 |

> ⚠️ **接口会必须在"分段建造"之前开，不能等到合体前。** 很多执行方把它放在合体前 10 分钟，那时骨架已经定型，只能现场锯、现场补，效果差十倍。

### 接口会必须产出的三条约定（写在白板上，全场可见）

| 约定项 | 具体要求 | 不定会怎样 |
|---|---|---|
| **龙骨高度** | 底面到龙骨顶的绝对高度，精确到厘米（如 25 cm） | 三段船底不在一个平面，整船扭曲 |
| **船舷控制点** | 在总长 0 / 1/3 / 2/3 / 1 四个位置，标出船舷上沿的高度 | 曲面接不上，出现台阶或凹陷 |
| **包覆方向** | 外皮纸板统一"从头往尾"叠压（像鱼鳞） | 接缝处纸板互顶，合不拢 |

## 3. 引导要点

### 讲解脚本（3 分钟）

> 你们三个队，一队做船头，一队做船身，一队做船尾。同时开工。
>
> 做完要合起来，然后**全队把这艘船抬起来，走 20 米**。抬不起来，就是没过——所以别做一艘只能拍照的船。
>
> 我只提醒一件事：**你们现在看不到另外两个队在做什么。** 等你们做完再合，如果龙骨高度不一样、船舷弧度不一样、纸板叠压方向反了，那时候就改不了了。
>
> 所以等一下会有一个"接口会"。**那个会不是走流程，那是你们唯一一次能对齐的机会。**

### 教练在场边做什么

- **接口会必须盯三件事**：有没有真的写数字（"大概 25 厘米"不算）；有没有人在会上不说话（通常是船身队，因为船身"最没特色"）；有没有人当场反对但被压下去
- **不允许"跨段帮忙"**。这是最容易破的规则，一旦破了，"分段"就失去意义
- **控制材料发放**：每段材料**等量**。如果某段多拿了胶带，合体时就会来"收买"别人
- **合体时不帮忙**。让他们自己发现合不拢，教练只做验收
- **抬船环节必须真的抬**。这是全项目最真实的检验：纸板船一抬就变形，所有"看起来对齐"的地方都会露馅
- **启航仪式要给足仪式感**：音乐、口令、撒花、合影。这一分钟是所有人记住这个项目的原因

### 四个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 三段各做各的 | 每段都好看，合起来像三截拼的 | 接口会走过场，没定数字 |
| 船身队边缘化 | 船头船尾有造型，船身是块平板 | 船身"没特色"，资源与注意力都被两端吸走 |
| 外皮互顶 | 接缝处鼓包、翘边 | 包覆方向相反 |
| 抬不起来 | 一抬就散架、扭曲 | 骨架只做了"看着像"，没做受力结构 |

### 语言禁区

- ❌「你们三段要多多沟通」——"多多沟通"不是指令
- ❌「船身队辛苦了，虽然看不出什么」——当众定性，船身队立刻散
- ✅「龙骨高度写在黑板上了吗？是多少？」
- ✅「这条缝，是哪两段的责任？谁负责补？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 接口会开了多久？有没有当场写下三个数字？
- 合体时，第一处不合的地方在哪？（龙骨 / 曲面 / 包覆方向）
- 三段的人数、材料、完成时间，差多少？
- 抬船时，船体出现了哪些变形？

### Feelings（感受）

- 接口会上，你有没有想法但没说？
- 看到另外两段的成品时，第一反应是什么？
- 船被抬起来那一刻，什么感觉？

### Findings（发现）

- 为什么"同时开工"效率高，但风险也高？（并行意味着信息不同步）
- 接口会为什么必须**写数字**？（"差不多"在接口处会放大成"差很多"）
- 为什么船身队容易边缘化？现实里哪个部门最像"船身"？
- 为什么必须"抬起来走 20 米"？（不能被检验的成果，等于没有成果）

### Future（应用）

- 我们有没有过"三个团队并行开发，最后集成炸了"的项目？
- 我们的"接口会"在哪？有没有？开了是不是只对了个时间点？
- 我们团队里，谁在做"船身"（重要但看不见）？他们被怎么对待？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（50–80） | 只分**两段**（船头+船尾），或做一艘小船（3 m）；接口会缩到 8 分钟 |
| 人数多（200–400） | **多艘船比赛**：分 2–3 队，每队独立造一艘，最后并排"下水"评比 |
| 只有 3 小时 | 砍涂装（20 min），骨架用预裁好的 PVC 件（省 30 min） |
| 室内层高不足 | 取消桅杆，只做船体；或桅杆改为可拆卸 |
| 想让成品能"下水" | 底部加泡沫板 + 防水膜，可在浅水池浮 1 分钟（需另备防水材料，成本上升） |
| 想强化"文化落地" | 船身必须画出企业价值观的**具体事件**（不是口号），每队讲 1 分钟 |
| 想强化"领导力" | 设 1 名"总设计师"（可跨段指挥但不许动手），复盘"指挥与执行" |
| 年会 / 周年庆 | 船做成"年度主题"造型；启航仪式配合灯光、干冰、音乐 |

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 五层瓦楞纸板 | 按船体表面积 ×1.5 | 外皮 + 装饰；必须五层，三层抬不起来 |
| PVC 管（Φ20–25 mm） | 每段 8–12 根（2 m/根） | 龙骨、肋骨；配 PVC 剪/锯 |
| 尼龙扎带 | 500 根以上 | 骨架主力固定件 |
| 美纹胶带 | 每段 4 卷 | 临时固定、贴边 |
