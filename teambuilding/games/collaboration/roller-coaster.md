# 超级过山车（Roller Coaster / 疯狂过山车）

> **一句话**：每组造一段轨道，球从最高点滚下去——只要有一段的坡度不对，球就停在那里，永远到不了终点。

| **游戏名称** | 超级过山车（Roller Coaster / 疯狂过山车 / 团队过山车） |
| **目的标签** | 分段建造 · 接口协议 · 资源统筹 |
| **形式标签** | 室内挑高场地 / 户外 · 分段并行 · 站/蹲姿 |
| **人数** | 全场 50–200 人（分 4–10 段，每组 8–15 人） |
| **时长** | 150–200 min |
| **难度** | ⭐⭐⭐ 中等偏高（段内简单，贯通极难） |
| **道具需求** | 有（PVC 半管/纸板槽 + 支架 + 大量胶带 + 篮球/弹珠） |
| **场景标签** | 百人共创 · 跨部门协作 · 工程/研发团队 · 年会 |
| **核心目标** | 用"球停在你们段起点"这个画面，让"接口由谁负责"变成必须回答的问题 |

---

**团建核心价值**：
- 🔗 接口协议：高度、坡度、管径三个数字必须全场统一
- 📉 能量管理：整条轨道只能靠重力，高度必须精密递减
- 🧪 反复试错：球每次停下只花 10 秒，可以高频迭代
- 🎯 全局视角：每段都只看得见自己那三米

## 1. 游戏概览

全场分若干段，每段负责 3–5 米轨道。所有段首尾相接，形成一条几十米长的"过山车"。球从最高点释放，靠重力一路滚到终点，中途不能停、不能脱轨。

**它和多米诺连锁、扬帆起航属于"分段合体"这一族，但难度维度不同：**

| 项目 | 接口要约定什么 | 误差维度 |
|---|---|---|
| 多米诺连锁 | 间距、方向 | 一维（前后） |
| **超级过山车** | **高度、坡度、管径、接头缝隙** | **二维（前后 + 高低）** |
| 扬帆起航 | 龙骨、曲面、包覆方向 | 三维（含左右曲面） |

**为什么它特别适合 50 人以上的工程型团队**：它把"接口"从抽象概念变成了四个可以量的数字。而且失败点**极其直观**——球停在你们段的起点，全场都看得见，赖不掉。

## 2. 核心规则

### 准备

- **材料**：
  - **轨道**：PVC 半管（直径 75–110 mm，纵向剖开）最佳；替代方案：纸板折成 U 型槽、铝箔保温管、硬质塑料排水槽
  - **支架**：PVC 管 / 纸筒 / 椅子 / 桌子 / 纸箱（高度可调）
  - **固定**：美纹胶带（大量）、扎带、热熔胶
- **球**：篮球（直径 24 cm，最稳、最出片）；小场地可用网球/弹珠（但接口容差要求陡增）
- **场地**：
  - 室内需**挑高 ≥ 4 米**、长度 ≥ 25 米（50 人分 6 段 × 4 米）
  - 户外需避开风口（风会吹停轻球）
  - **地面必须水平**（否则"高度递减"会失效）
- **段数计算**：段数 = 总人数 ÷ 12（约）。100 人 → 8–9 段

### 规则

1. 每段负责 **3–5 米**轨道，段长由教练统一规定（必须一致，否则总长不可控）
2. 起点高度由教练指定（如 3 米），**终点高度必须为 0.5 米以下**
3. 全程只能靠重力，**不许用手推球、不许加电机、不许用弹射装置**
4. 段与段之间必须**物理连通**：球离开上一段时，必须能自然落入下一段
5. 每段可自由设计（直道、弯道、螺旋、小坡都可以），但**出入口的高度和坡度必须符合协议**
6. 完成后，由教练在起点释放球，**一次机会**；球停在某段，该段不计分，其余段仍计分
7. 全程贯通时间**不得少于 15 秒**（防止有人用陡坡"作弊"）
8. 评分维度：贯通（权重最高）/ 全程时间（越接近 15–40 秒越好）/ 结构美观 / 团队讲解

### 流程（三小时版）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 讲规则 + 分段 | 15 min | 分段、发材料、公布起点与终点高度 |
| **协议会（必须）** | 15 min | 全场定 4 个数字：段长、入口高度、出口高度、管径 |
| 各段设计建造 | 75 min | 支架 → 轨道 → 段内试滚 |
| **相邻对接** | 20 min | 相邻两段拼接，实物试滚 |
| 全线调试 | 20 min | 只允许分段试滚，不许提前放全程 |
| 总放球 | 10 min | 一次机会 |
| 评分 + 复盘 | 25 min | 见第 4 节 |

### 协议会必须定下的四个数字（写在白板，全场可见）

| 数字 | 含义 | 典型值 | 不定会怎样 |
|---|---|---|---|
| **段长** | 每段轨道的水平长度 | 4.0 m（全场统一） | 总长与总落差失控 |
| **入口高度** | 球进入本段时轨道底面的离地高度 | 按段序递减，如 300/270/240…cm | 上段出口高于下段入口，球倒灌或断流 |
| **出口高度** | 球离开本段时的高度 | 同下一段的入口高度 | 接缝处出现台阶，球停住 |
| **管径/槽宽** | 轨道内宽 | 全场统一（如 90 mm） | 窄段卡球，宽段脱轨 |

> 💡 最实用的做法：**把"高度表"直接贴在墙上**，每段自己查自己的入口/出口高度，不用互相商量。这样能省掉大量扯皮，也能让"有人不按表做"这件事变得一目了然。

### 评分（百分制）

| 维度 | 分值 | 说明 |
|---|---|---|
| 全程贯通 | 50 | 球一次滚到终点 |
| 中途不停（含短暂停滞） | — | 停住即该段 0 分，其余段保留 |
| 全程时间 15–40 秒 | 20 | <15 秒视为陡坡作弊，扣分 |
| 结构稳定性 | 15 | 放球过程中不倒、不塌 |
| 设计与美观 | 10 | 有主题、有装饰、有讲解 |
| 团队讲解 | 5 | 1 分钟说明设计思路 |

## 3. 引导要点

### 讲解脚本（3 分钟）

> 你们每组一段，三到五米。全部接起来，球从最高点滚到终点。
>
> 只能用重力。不许推、不许弹、不许装电机。
>
> 起点三米，终点半米以下，全程不能少于 15 秒。
>
> 我现在说一句最重要的：**球停下来的时候，永远停在某一段的最开头。** 那一段的人会觉得"不是我，是上一段没给够速度"。上一段的人会觉得"我出口高度是对的，是你们入口太高"。
>
> 所以等一下会有一个协议会。**把四个数字定下来，写在墙上。** 定完就不许改。

### 教练在场边做什么

- **协议会必须逼出数字**。听到"大概三米""差不多"就打断，要求写具体数值
- **地面必须验平**。地不平，高度递减全废，而且没人会想到是地面的问题
- **盯住"抢材料"**：胶带消耗极快，前 20 分钟就会有人囤积。提前按段均分
- **段内试滚时不要干预**，但要记录：哪一段从来没人试滚过（通常是最自信的那段，也是最后出问题的那段）
- **总放球前留 60 秒静场**，让所有人退到轨道两侧
- **球停下时不要马上让人去修**。先让全场安静看 10 秒——看球停在哪里、看那一段的人第一句话说什么

### 四个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 台阶断流 | 球到接缝处停住或弹回 | 上段出口低于下段入口 |
| 卡球 | 球滚到某段卡住不动 | 该段槽宽小于球径，或接头处有胶带凸起 |
| 脱轨 | 球在弯道飞出 | 弯道外侧没有挡边，或弯道速度过快 |
| 抢跑作弊 | 全程只用了 8 秒 | 有人把段做得极陡，牺牲了后面段的高度预算 |

### 语言禁区

- ❌「你们这段太陡了」——单段指责，下一轮他会做成缓坡，球又滚不动
- ❌「早就说了要对高度」——事后诸葛亮
- ✅「球停在哪一段的哪个位置？那个位置的轨道底面高度是多少？」
- ✅「这个接缝，谁量的？量出来多少？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 球停在了第几段？停的位置离接缝多远？
- 协议会定了几个数字？有几个数字是当场写下来的？
- 有几段在"相邻对接"环节真的做了实物试滚？
- 全程用了多少秒？最陡的那一段是谁做的？

### Feelings（感受）

- 球停在你们段起点时，第一反应是什么？
- 有人说是"上一段的问题"时，你认同吗？
- 球一路滚到终点那一刻，全场什么反应？

### Findings（发现）

- 为什么"每段都合格"还是贯通不了？（因为合格的标准是"段内"，不是"接口"）
- 高度表贴在墙上，为什么比"大家商量一下"有效？
- 为什么不允许提前放全程？（提前放会把"一次机会"的紧张感消耗掉，也会让人反复微调而不去解决结构问题）
- 为什么限制"不得少于 15 秒"？（防止有人用牺牲全局的方式换取局部通过）

### Future（应用）

- 我们的项目里，接口标准是谁定的？有没有"贴在墙上的高度表"？
- 我们的考核，是奖励"我这块做得快"还是"整条链能跑通"？
- 出了问题，我们第一反应是查自己的出口，还是先怀疑上一段？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（50 以下） | 4–5 段；或分两队各造一条短轨道比赛 |
| 人数多（200） | 分 2 条独立轨道（各 8–10 段），最后对比贯通率 |
| 室内层高不足（<3 m） | 起点降到 2 m，用弹珠代替篮球（容差要求更高，可当难度升级） |
| 想降低难度 | 提供"预制接头"（统一规格的连接槽），把接口问题从"设计"降为"安装" |
| 想提高难度 | 强制"必须有一个 360° 回环"或"必须穿过一个 1 m 高的门洞" |
| 只有 2 小时 | 砍设计（10 min），协议会缩到 10 min，建造 60 min，对接 20 min |
| 想强化"资源" | 材料用"积分购买"，各段起始积分相同，可交易（会出现囤积与抬价） |
| 年会 / 大型场 | 轨道沿会场四周布置，球滚完全场，终点触发灯光或启动装置 |

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| PVC 半管（Φ75–110 mm） | 每段 4–6 根（2 m/根） | 纵向剖开；或用纸板折 U 型槽替代 |
| 支架（PVC 管/纸筒/纸箱） | 每段 8–15 个 | 高度需可调；椅子可作高点支撑 |
| 美纹胶带 | 每段 3–5 卷 | **消耗最大，必须足量** |
| 尼龙扎带 | 每段 100 根 | 固定支架 |
| 热熔胶枪 + 胶棒 | 每段 1–2 把 + 30 根 | 接头加固 |
| 篮球（或网球/弹珠） | 3–5 个 | 备用必须现场就有 |
| 卷尺 / 激光测距仪 | 每段 1 把 | 量高度，**必须有** |
| 高度表白板 | 1 块 | 贴在墙上，全场可见 |
| 标志桶 / 胶带 | 若干 | 标段界、标起点终点 |
| 梯子 | 2 把 | 架设高点、放球 |
| 计时器 | 1 个 | 计全程时间 |
| 医药包 | 1 个 | 割伤、砸伤应急 |
