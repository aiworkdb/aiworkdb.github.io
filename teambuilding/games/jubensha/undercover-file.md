# 卧底档案 (Undercover File)

> **剧本杀 · 身份推理 · 轻量烧脑**  
> 适合：午休快闪 / 新老融合 / 综艺感强的小场

---

## 🎯 游戏目标

「谁是卧底」的剧本杀升级版：一场「公司内部调查」中，大多数人拿到底牌（普通员工），少数人拿到卧底牌（带暗语），还有一人是「双面人」。通过描述、投票、处决，找出所有异类。规则 3 分钟讲清，一局 30 分钟，是下午茶时间的最佳燃料。

**团建核心价值**：
- 🥷 表达艺术：同样的词，有人一说就露馅
- 🕵️ 观察倾听：从别人的描述里找逻辑裂缝
- 😈 演技释放：拿了卧底牌的人，演技是藏不住的
- ⚡ 快速破冰：一局下来，全组笑点共享

## 🥷 核心机制

### 牌型配置（12人局示例）

| 牌型 | 人数 | 胜利条件 |
| :--- | :--- | :--- |
| 普通员工 | 9人 | 投出所有卧底和双面人 |
| 卧底 | 2人 | 存活到最后2人 |
| 双面人 | 1人 | 被误投出（即卧底赢他才赢） |

### 玩法循环

1. **发牌**：每人暗抽一张牌，只有自己知道
2. **描述**：从主持人开始顺时针描述自己的「底牌」（卧底拿到的是近似词，如别人是「打印机」卧底是「复印机」）
3. **投票**：全员举手表决，得票最高者「出局」并亮牌
4. **平票PK**：平票者各用一句话自辩，重新投票
5. **循环**直到任一方胜利条件达成

## 🎮 游戏流程

### 准备（3分钟）

- 主持人抽词对，宣布人数配置
- 每人私抽词卡，默读 10 秒

### 游戏进行（20-25分钟）

- 描述→投票→亮牌，循环约 5-7 轮
- 被投出者就「处刑台」围观，禁止剧透（违者下一局发牌无效）

### 结算（5分钟）

- 公布阵营胜负
- 特色颁奖：最强卧底（藏得深）/ 最快露馅（第一轮就被投）/ 灵魂描述（金句王）

## 💡 教练引导指南

**控场要点**：
- 描述限一句话，超时过（防长篇大论拖节奏）
- 有人描述太明显（直接报词）：主持人提醒「请用特征描述，不要直接念出来」
- 首票无人被投：强制平票PK或「本轮无人出局，直接进入下一轮描述」

**复盘三问（快速版）**：
1. 你抽到卧底时，第一反应是「装傻」还是「带节奏」？工作中你遇到质疑时是哪一种？
2. 全场最高票出局的人，是「最可疑」还是「最不会说话」？——冤枉好人的成本
3. 双面人「求被投出」的策略，现实里有对应场景吗？（比如主动背锅）
### 🎬 游戏后深度复盘（4F 框架 · 正式团建 10–15 分钟）

> 时间紧用上面三问快速带过；新团队信任建设/沟通训练建议用完整框架。

| 步骤 | 时长 | 引导问题 |
| :--- | :--- | :--- |
| **1️⃣ 事实回顾** | 2–3分钟 | 第一轮谁被投出去了？ta 真的是卧底吗？整场冤案率多少？双面人得逞了吗？ |
| **2️⃣ 感受分享** | 2–3分钟 | 拿到卧底牌时心跳加速了吗？被最高票投出而你是好人时，什么感受？ |
| **3️⃣ 学习洞察** | 4–6分钟 | 关于表达：最强卧底的描述强在哪？最冤的好人漏在哪？「一句话信息量」怎么练？<br>关于判断：最高票=最可疑，还是最不会说话？我们有多容易跟风？<br>关于信任：双面人「求被投出」的策略，现实里对应什么场景？ |
| **4️⃣ 行动迁移** | 3–5分钟 | 回想最近一次「冤枉」同事或被「冤枉」的经历——下次投票/表态前，多问一个为什么。 |

## 🔄 变体玩法

### 变体1：全员卧底版（混乱中立）

除了1个平民全是卧底，每个人都在演。考验「从众中的独立思考」。

### 变体2：档案模式（剧情向）

把词卡换成「身份档案」：卧底的任务从「隐藏」变成「完成一个动作」（如偷拍某人照片），被抓住才出局。综艺感拉满。

### 变体3：三轮马拉松版

每人只有3条命，三局累计积分，适合部门联赛。

## ⚠️ 参与限制与安全

- **零身体接触**：围坐即可，轮椅使用者可直接加入圈内
- **零表演压力**：只需要说一句话，不想说「过」也允许（但会被怀疑，这本身就是游戏）
- **反霸凌条款**：禁止「上轮流他就投他」的跟风霸凌；主持人发现抱团投票需干预
- **内容红线**：词库禁止涉及薪资、职级、地域等敏感对比，全部用中性职场物品
- **自愿退出**：任何一轮后可申请「辞退调查」安全退场，不扣分不追问

## 🎯 适合的培训主题

### 1. 精准表达与信息压缩

**关键词**：一句话信息量 · 特征描述 · 避免歧义

**适用场景**：汇报与沟通训练 / 主持人选拔 / 商务谈判

**迁移重点**：描述环节每人只有一句话，是「一句话说清一件事」的极限训练，可直接迁移到汇报开场白。

### 2. 独立思考与反从众

**关键词**：质疑跟风 · 证据意识 · 逻辑倾听

**适用场景**：评审文化建设 / 头脑风暴 / 决策会议改进

**迁移重点**：「上轮流他就投他」的抱团现象会在游戏中真实复现，复盘时讨论从众成本，比讲「批判性思维」概念更戳人。

### 3. 信任建立与误判成本

**关键词**：冤枉成本 · 包容试错 · 团队信任

**适用场景**：新团队信任建设 / 复盘会 / 跨文化团队

**迁移重点**：冤案率是这款游戏的隐藏指标——团队越是「宁可错杀」，越说明信任账户余额不足，值得管理层重视。

## 📝 常见问题

**Q：有人总第一轮被投出，挫败感强？**
A：设置「最快露馅奖」把出局变成荣誉；私下沟通「这是游戏机制不是对你的判断」。

**Q：词太难，大家都描述得像？**
A：换差异更大的词对（打印机/复印机 →  coffee/tea），先从「一听就懂」开始。

**Q：卧底太强把把赢？**
A：加入「双面人」机制稀释卧底胜率；或平民词给得更有区分度。
