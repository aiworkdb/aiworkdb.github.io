# 藏宝密令 (Treasure Code)

> **剧本杀 · 寻宝解谜 · 全场竞技**  
> 适合：大型团建 / 定向越野 / 午休快闪

---

## 🎯 游戏目标

把剧本杀的「线索链」装进一场公司寻宝：一份藏宝图被撕成碎片散落在办公区/园区，每枚碎片都藏在一道谜题、一个挑战或一次「与人对话」背后。小组顺藤摸瓜，最先拼出完整藏宝图并找到「宝藏」的队伍获胜。

**团建核心价值**：
- 🗺️ 目标拆解：大目标切小线索，像做项目一样做游戏
- 🧩 跨组协作：关键碎片需要交易或合作才能获得
- 🏃 全场流动：把整个公司变成游戏场，午休也能燃
- 🎯 策略选择：直冲宝藏还是先囤线索，考验判断

## 🗺️ 游戏结构

### 三层线索体系

```
第一层：谜题点（8-12个）
  ├─ 解谜型：办公区张贴的谜语/二维码/密码箱
  ├─ 挑战型：完成一个小挑战（如全组合影比心、找到某物）
  └─ 人肉型：找到指定「NPC」（如财务姐姐、戴红帽子的同事）
       ↓ 获得
第二层：地图碎片（每队持3-5片，单队拼不齐）
       ↓ 需要
第三层：交易/结盟（碎片互补的队伍必须谈判）
       ↓ 集齐
终局：完整藏宝图 → 指向「宝藏」位置（如天台/茶水间/CEO办公室）
```

### 宝藏设计

实体宝箱里放：冠军大奖（带薪假/购物卡）+ 安慰奖每人一份。**让最后一名也有奖**，是这类游戏不挨骂的关键。

## 👥 分组与角色

每组 4-8 人，队内自然分化三种角色（无需指派，观察即可）：

- **侦察兵**：跑得快，负责满场找点位
- **解码员**：坐得住，负责解谜题
- **外交官**：敢开口，负责碎片交易谈判

> 复盘时公布：三种角色的比例，正好对应项目里的执行、策划、商务。

## 🎮 游戏流程

### 开场（5分钟）

- 发第一枚「引路碎片」：上面写着谜题一的位置
- 宣布规则：碎片可交易可结盟可「诈骗」（口头承诺允许反悔，增加戏剧性）

### 寻宝进行（30-40分钟）

- 各组自由行动，解谜→拿碎片→找下一谜
- **突发事件**（主持人第20分钟投放）：「风暴来袭！所有队伍停止解谜3分钟，只能交易」——强制社交
- **防挂机机制**：30分钟后未拿到任何碎片的队伍，主持人私信「神秘援助」送一片

### 终局冲刺（10分钟）

- 第一支集齐碎片拼出藏宝图的队伍获得「先知权」：可独自去开宝箱
- 但宝箱有锁：密码=某道谜题的答案，没解过这题的队伍还得回头补课
- 其余队伍继续拼图追击，按完成顺序排名

### 结算（5分钟）

按名次颁奖+「最佳交易奖」「最快解码奖」「最惨路人奖」（气氛奖）。

## 💡 教练引导指南

**谜题设计三原则**：
1. **2分钟内能解**：谜题是调料不是主菜，卡住10分钟的题=坏题
2. **利用环境**：「找到工位上有仙人掌的人」比「字谜」更有参与感
3. **留交易口**：至少2枚碎片只能靠交易获得，否则社交机制空转

**控场信号**：微信群/广播统一口令。出现争执（如抢NPC）时主持人秒判「先到先得」。

**复盘三问（快速版）**：
1. 你们队什么时候决定「停止解谜去交易」的？现实工作中你敢做这个决定吗？
2. 「诈骗」成功的队，后来怎么修复信任的？
3. 如果重来一次，先囤碎片还是先找交易对象？
### 🎬 游戏后深度复盘（4F 框架 · 正式团建 10–15 分钟）

> 时间紧用上面三问快速带过；大型团建/规划类工作坊建议用完整框架，把「寻宝体验」对接「目标管理」。

| 步骤 | 时长 | 引导问题 |
| :--- | :--- | :--- |
| **1️⃣ 事实回顾** | 2–3分钟 | 第一个碎片怎么拿到的？决定「停止解谜去交易」发生在第几分钟？最终名次和策略有关吗？ |
| **2️⃣ 感受分享** | 2–3分钟 | 被「诈骗」/换到假碎片时什么感受？终局差一步时团队气氛如何？ |
| **3️⃣ 学习洞察** | 4–6分钟 | 关于目标管理：大目标怎么切成小线索的？有没有队一开始就想直奔宝藏？<br>关于谈判：哪次交易最成功？你们让渡了什么、换到了什么？<br>关于分工：侦察/解码/外交三种角色自然形成了吗？和项目里的分工像不像？ |
| **4️⃣ 行动迁移** | 3–5分钟 | 把现在的季度目标画成一张「藏宝图」：哪几块关键碎片在别人手里？去找谁交易？ |

## 🔄 变体玩法

### 变体1：剧本杀模式（剧情向）

不拼地图，拼「案情时间线」：碎片是「谁几点做了什么」，集齐后推理出「内鬼」。适合偏好烧脑的团队。

### 变体2：城市定向版（全天Outing）

把点位放到城市地标/公园/商圈，结合地铁+步行，每组发固定「交通基金」，超支扣分。**必须配安全员和应急联系人**。

### 变体3：线上版（远程团队）

点位=公司内网页面/群文件，碎片=网盘链接，交易=私聊交换。全程线上可玩。

---

## ⚠️ 参与限制与安全

- **运动强度可控**：谜题点均匀分布，不需要冲刺奔跑；「走完全程」即可完成
- **坐姿/少动替代**：每组指定1名「军师」可留守基地（微信群）专职解码交易，不强制跑动
- **办公区安全**：提前清场确认，禁止进入机房/仓库等禁区；奔跑路段避开玻璃门和湿滑地面
- **身体接触**：无强制接触；合影比心等挑战可用「隔空比心」替代
- **户外版必须**：购买短期意外险、指定安全员、设定「掉队即上车」规则

## 🎯 适合的培训主题

### 1. 目标拆解与路径规划

**关键词**：里程碑 · 分兵策略 · 资源盘点

**适用场景**：项目管理工作坊 / 季度规划会 / 战略解码

**迁移重点**：三层线索体系就是「总目标—里程碑—执行动作」的游戏化投影，复盘时可直接对照真实项目的 WBS。

### 2. 跨团队谈判与资源协作

**关键词**：交易思维 · 共赢谈判 · 信息换资源

**适用场景**：跨部门协作 / 矩阵型组织 / 商务与供应链团队

**迁移重点**：碎片必须交易才能集齐的设定，让「和别人合作」从口号变成刚需，复盘谈判得失比讲谈判技巧更有效。

### 3. 团队角色认知与自组织

**关键词**：执行/策划/商务 · 角色分化 · 无授权领导

**适用场景**：新团队磨合 / 人才盘点 / 管理培训

**迁移重点**：侦察兵、解码员、外交官的自然分化，是团队角色认知的活教材，适合衔接贝尔宾/BELBIN 类测评解读。

## 📝 常见问题

**Q：有人抱怨「这不就是跑步吗」？**
A：那他是没体验到交易和推理。把突变事件提前，强制停下来动脑。

**Q：队伍实力悬殊，一路领先没悬念？**
A：给末位「神秘援助」+设置「金币机制」：落后队伍可用积分购买线索。

**Q：点位被其他部门同事无意破坏？**
A：提前和行政报备，海报用「活动预告」样式张贴，附上「请勿拆除」便签。
