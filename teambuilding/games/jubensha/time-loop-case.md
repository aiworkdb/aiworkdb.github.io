# 时间循环案 (Time Loop Case)

> **剧本杀 · 循环推理 · 极限烧脑**  
> 适合：高学历团队 / 程序员群体 / 深度团建

---

## 🎯 游戏目标

一个只有 10 分钟的「案发夜晚」，团队要重复经历 5 次。每一轮结束，主持人补充一条新线索，之前轮次的「错误记忆」会被推翻。团队必须在循环里找出那条「唯一被改变的细节」，才能跳出循环。专为喜欢烧脑的团队设计，盘出来的瞬间全场炸裂。

**团建核心价值**：
- 🔁 迭代思维：承认「上一轮错了」是通关前提
- 🧠 信息管理：5轮信息不断叠加，考验笔记和归因
- 💬 高压沟通：时间压力下的信息同步与说服
- 🎯 细节敏感：训练「注意到什么没发生」

## 🔁 核心机制

### 一个10分钟案发夜晚（剧本）

固定剧本：公司停电夜，六名留宿员工中，「核心硬盘」在 22:00-22:10 之间失窃。每个人的时间线、动作、对话都是固定的。

### 五轮循环（每轮重放同一晚）

- 每轮开始时，所有人「回到」22:00
- 每轮自由询问、搜查（每轮限8分钟，讨论2分钟）
- 每轮结束，主持人揭示一条「本轮新线索」
- 第5轮必须给出最终答案

### 关键设计：每条新线索都会推翻上轮结论

| 轮次 | 揭示的新线索 | 效果 |
| :--- | :--- | :--- |
| 第1轮后 | 门禁记录显示22:03有人刷卡出门 | 推翻「内贼」假设 |
| 第2轮后 | 监控在22:05拍到「失主本人」进了机房 | 推翻「盗窃」假设 |
| 第3轮后 | 硬盘里有自动备份脚本 | 推翻「数据丢失」假设 |
| 第4轮后 | 备份的目标地址是外部邮箱 | 真凶动机浮现 |
| 第5轮 | 必须指认：谁、何时、用什么手法 | 终局 |

> 每一轮都有人喊「稳了」，然后被下一条线索打脸——这个体验本身就是复盘素材。

## 🎒 物料准备

| 物品名称 | 数量 | 用途 |
| :--- | :--- | :--- |
| 角色时间线卡 | 每人1张 | 写死每人在10分钟内的动作 |
| 线索揭示卡 | 5张 | 每轮结束由主持人亮出 |
| 笔记纸 | 每人2张 | 鼓励做时间线笔记 |
| 白板 | 1块 | 团队共用「案情板」 |
| 计时器 | 1个 | 严格卡8分钟 |

### 主持人准备（最关键）

写死一张「真相表」：谁在哪个时间点做了什么。所有线索必须能从真相表推导，**不能为了反转而反转**。参考结构：

```
22:00 全员在大厅（可互证）
22:01 A说去洗手间（无人证）
22:02 停电，所有人原地
22:03 门禁：B刷卡出门（监控盲区）
22:05 监控：失主本人进机房（自称找手电）
22:07 供电恢复
22:09 B返回
22:10 发现硬盘失踪
```

## 🎮 游戏流程

### 准备（5分钟）

发时间线卡，宣布「循环规则」：每轮信息量会变，**以上一轮的结论为基础，但允许被推翻**。

### 循环进行（45-50分钟）

每轮 10 分钟：8分钟询问+搜查，2分钟团队陈述「本轮结论」。

### 终局（5分钟）

第5轮结束，公布最终答案。指认正确=通关。

### 复盘（10分钟）

重点不在「盘得准不准」，在「你们怎么处理被自己推翻的结论」。

---

## 💡 教练引导指南

**控场要点**：
- 严格计时：时间压力是游戏体验的一半
- 有人记性差：鼓励把时间线画在白板上，公开透明
- 有人固执己见：让ta用「如果我是凶手，我会怎么……」句式重述

**复盘三问（快速版）**：
1. 哪一轮被推翻时最难受？现实工作中你的「方案」被推翻时是什么感受？
2. 团队有没有一条「共享案情板」？信息在谁脑子里？
3. 如果这是真实项目，第几条线索出现时你就该止损换方向？
### 🎬 游戏后深度复盘（4F 框架 · 正式团建 10–15 分钟）

> 时间紧用上面三问快速带过；研发/产品团队建议用完整框架——这款游戏的复盘价值高于游戏本身。

| 步骤 | 时长 | 引导问题 |
| :--- | :--- | :--- |
| **1️⃣ 事实回顾** | 2–3分钟 | 第几轮接近过正确答案？最终结论和第 1 轮差多少？每条新线索是哪轮出现的？ |
| **2️⃣ 感受分享** | 2–3分钟 | 结论被推翻的那一刻，你是「兴奋」还是「防御」？谁当时最难受？ |
| **3️⃣ 学习洞察** | 4–6分钟 | 关于迭代：哪条线索出现时你就该换方向？是什么让你舍不得放弃旧结论？<br>关于信息：案情板是谁在维护？信息在共享看板上，还是在个人脑子里？<br>关于决策：第 5 轮的答案是共识，还是嗓门大的人赢了？ |
| **4️⃣ 行动迁移** | 3–5分钟 | 工作中哪个「上一轮的结论」已经三个月没复查了？本周约一次复盘会。 |

## 🔄 变体玩法

### 变体1：三重循环版（轻量）

只循环3轮，总时长压到40分钟，适合普通团队试水。

### 变体2：无限循环版（硬核）

不限制轮次，直到团队自愿「放弃并复盘」——体验「沉没成本」的杀伤力。

### 变体3：循环会议版（职场向）

把案件改成「一次搞砸的发布」：每次循环 = 一次复盘会，找出真正的根因。适合技术团队。

---

## ⚠️ 参与限制与安全

- **纯脑力活动**：全程坐姿，零身体接触，零表演要求
- **认知负荷提示**：难度偏高，建议提前告知参与者「需要动脑和记笔记」；不愿深度参与者可担任「记录员」（重要且轻松的角色）
- **防内让机制**：规则写明「可以质疑结论，不能指责人」；主持人有权叫停人身攻击
- **时间红线**：75分钟封顶，超时强制进入复盘，不许「再来一轮」

## 🎯 适合的培训主题

### 1. 迭代思维与复盘文化

**关键词**：承认错误 · 结论可推翻 · 快速修正

**适用场景**：研发团队复盘会 / 产品迭代训练 / 持续改进工作坊

**迁移重点**：「每轮结论都被下一条线索推翻」的机制设计，让「被证明错了」变成游戏内的正常事件，是建立心理安全的复盘文化的最佳入口。

### 2. 团队知识管理

**关键词**：共享看板 · 信息沉淀 · 集体记忆

**适用场景**：信息孤岛改善 / 交接班机制 / 远程团队

**迁移重点**：五轮信息不断叠加，没有共享案情板的团队必然崩盘——用体验说明「知识不沉淀=反复交学费」。

### 3. 高压共识与决策质量

**关键词**：证据链 · 时间压力 · 说服艺术

**适用场景**：管理层决策训练 / 危机演练 / 评审会改进

**迁移重点**：8 分钟限时询问+2 分钟团队陈述的结构，是高压下「形成共识」的微缩演练，适合管理干部决策训练。

## 📝 常见问题

**Q：参与者觉得「被主持人耍了」？**
A：开场就讲清「线索会推翻结论」是机制不是陷阱，并强调「被推翻恰恰说明你在靠近真相」。

**Q：团队太强，两轮就通关？**
A：加第6条线索或换「双凶手」设定。强队值得更强的题。

**Q：有人全程不发言？**
A：每轮指定1人做「本轮结论陈述人」，轮换制，强制参与但不强迫精彩。
