# 八仙渡海 · 回渡与结缆（团建信任建立版）

> 原作：《八仙渡海：打工人成仙记》（3-8 人派对竞速 + 互坑桌游，掷骰前进 + 结算格子 + 天雷卡坑人，20-40 分钟，先凑够 3 点渡海值并抵达终点者单赢）
> 改造：把"甩锅抢跑、一个人上岸"翻转成"**先上岸的人必须掉头回来接人，而接人的方式决定了团队还剩多少信任**"——领先不是特权，是义务

---

## 一句话团建价值

**大多数团队里，能力强的人不是不帮忙，而是帮得太"干净"——给资源、给答案、给方案，唯独不给对方"自己走完最后一段"的机会。**

本作把三件事摆到桌面上：领先者愿不愿意回头、托付时说不说清楚"我指望你拿它做什么"、被托付的人有没有把别人的东西当自己的用。

## 适用场景

- 团队里存在明显的"能力强者 vs 跟不上的少数人"，且强者已经有点不耐烦
- 老带新 / 师徒制 / 后备人才培养的能力落差议题
- 跨部门协作中"我把东西交给你之后就没下文了"的交接困境
- 管理者培训：强者的责任边界在哪里，帮忙和接管的区别是什么
- 团队经历过"能人扛全场、其他人打酱油"，需要重新分配参与感

## 四处关键改造

| 原作 | 团建版 | 为什么这么改 |
|------|--------|------------|
| 先凑够 3 点渡海值到终点者**单赢** | **全员上岸才算渡海成功**；判定看"所有人渡海值的**最小值**" | 真实项目里没有"我先到了就算完成"，只有"最后一个人的进度" |
| 天雷卡：指定 1 名玩家后退 3 格 | **风浪卡：外部事件**，只作用于"当前最靠前的人"或全场，**任何人可以喊「我来拉」替他扛** | 原作把压力设计成"人对人"，改成"事对人"后，才可能长出托付 |
| 「助人成仙」是攒渡海值的边角手段 | 升格为**核心动作「回渡」**：先到终点者必须反向往回走，去接最后一名 | 领先者的责任必须写成硬规则，否则它永远只是一句号召 |
| 送 3 张牌换 1 点渡海值，无附加条件 | **「托付」**：给资源时必须说清"我指望你拿它做什么"，对方复述才生效 | 只给不说 = 施舍；说清楚 = 托付。团队里大量的交接失败都卡在这一句 |

## 核心机制

### 1. 全员上岸判定（团队渡海值 = 最小值）⭐

- 每人各有自己的渡海值（0–3），但团队的渡海进度取**所有人的最小值**。
- 只要还有 1 个人是 0，团队渡海值就是 0 —— **先跑的人再快也没有用**。
- 终局条件：全员渡海值 ≥ 3 **且**全员棋子都抵达第 49 格。

> 观察点：什么时候开始有人算这笔账？是第一个人到第 49 格那一刻，还是教练提醒之后？

### 2. 回渡机制（本作灵魂）⭐

先抵达第 49 格的人**不能结束回合**，从下一轮起必须**反向往回走**（蛇形路线倒着走）。

| 回渡者可做的事 | 效果 |
|------|------|
| 走到落后者所在格或相邻格 | 可发起一次**托付**（见 3） |
| 每往回走 6 格 | 可把自己的 1 点渡海值**结缆**给任意一名落后者（自己 −1，对方 +1） |
| 拒绝回渡（到终点后原地等） | 信任 **−2**，且本轮不能掷骰 |

> **关键**：结缆是"把我的渡海值给你"，不是"我帮你把路走完"。回渡者永远不能替别人掷骰、替别人做格子结算。
> 现实中"我替你做了"和"我把资源给你，你自己做"是两件事，本作把它们做成了两种规则。

### 3. 托付三步（给资源必须说清用途）⭐

托付不是"送你 3 张牌"，而是一个**三步动作**，缺一步即无效（信任 +0，且牌照给）：

1. **给出**：托付方把资源推到对方面前。
2. **说明**：托付方必须说一句"**我指望你拿它做 \_\_\_**"（必须是具体动作，不能是"你看着办"）。
3. **复述**：接收方复述"**我听到的是，你指望我 \_\_\_，我打算这样做**"，托付方点头才算生效。

| 结果 | 信任变动 |
|------|---------|
| 三步齐全，且对方后续确实用在该用途 | **+1** |
| 三步齐全，但对方没用在该用途（且没解释） | **−2**（别人的东西被随手花了） |
| 省掉第 2 步或第 3 步（只给不说 / 说了不复述） | **+0**，牌照给 |
| 接收方主动说"我可能做不到，我只能做到 \_\_\_" | **+1**（提前校准预期） |

### 4. 风浪卡与「我来拉」

- 每 3 轮翻 1 张风浪卡，作用于**当前最靠前的人**（后退 3 格 / 弃 2 张功德卡 / 停一回合）。
- 翻开的瞬间，任意其他玩家可以喊「**我来拉**」，替他承受全部效果 —— 自己受罚，对方无事。
- 替人扛一次 → 得 1 个**结缆标记**，信任 **+1**。

> 观察点：喊"我来拉"的人，是领先者还是落后者？整局无人喊会怎样？

### 5. 结缆标记（终局门槛）

- 全船结缆标记 **≥ 3** 才允许判定"渡海成功"。
- 结缆标记来源：① 替人扛风浪；② 回渡时结缆渡海值；③ 三步齐全的托付生效。
- 结缆 **≤ 1** 而全员上岸 → 触发特殊失败「各漂各的」。

### 6. 信任账户（0–12，起始 7）

- 起始 **7**（"能一起干活，但还没托付过东西"）。
- **信任 ≤ 0** → 「船散了」，游戏立即结束，全员进复盘。
- 每次变动，全船必须**当场说出理由**（"为什么 −2？因为他给出去的牌被拿去换了法器，而他说的是换渡海值"）。

| 事件 | 信任变动 |
|------|---------|
| 三步齐全的托付生效 | **+1** |
| 托付的资源没被用在该用途（且无解释） | **−2** |
| 有人喊「我来拉」替人扛风浪 | **+1** |
| 抵达终点后拒绝回渡 | **−2** |
| 有人公开说"我这轮撑不住了，需要谁帮我一下" | **+1** |
| 一轮内无人掷骰（全船卡住） | −1 |

### 7. 八张岗位卡（原作仙格卡改造）

每人开局随机 1 张，**每 3 轮整体轮换一次**。缺点映射真实协作短板，卡面写"你的习惯是……"：

| 岗位卡 | 原作缺点 | 团建映射 |
|--------|---------|---------|
| 囤积者（铁拐李 · 贪杯） | 停酒摊多抽 | 资源先攥在手里，等"更安全的时候"再给 |
| 回避者（汉钟离 · 摆烂） | 可不掷骰改抽牌 | 遇到冲突先退一步，用沉默代替表态 |
| 返工者（张果老 · 倒着走） | 可倒退移动 | 做完又推翻，习惯性回头改方案 |
| 抢答者（吕洞宾 · 好为人师） | 替人挡雷换牌 | 别人还没说完就接话、抢着给答案 |
| 老好人（何仙姑 · 心太软） | 要牌必须给 | 不敢拒绝，什么都答应，然后做不到 |
| 抢话者（蓝采和 · 嘴碎） | 预测骰点 | 表达欲强，会议里说话最多的人 |
| 自嗨者（韩湘子 · 沉迷吹笛） | 移动 ×2 但不结算 | 埋头做自己喜欢的部分，不看全局 |
| 守财者（曹国舅 · 抠门） | 费用省 1 张 | 严守自己的资源边界，不轻易外借 |

> **轮换的意义**：最爱给答案的人一定会轮到"只能被给"的位置；最不愿开口的人一定会轮到"必须说明用途"的位置。

## 流程（每轮 4 步，共 8–12 轮）

1. **掷骰前进** — 按顺序每人掷 1 颗 D6 沿蛇形前进；已到终点者**反向回渡**。法器卡可 +1 移动或重掷。
2. **结算格子** — 停在资源格抽功德卡；停在法器铺可建 1 件法器；停在蟠桃点抽 1 张蟠桃卡。
3. **行牌与托付** — 可发起**任意次托付**（三步齐全才生效）；可喊「我来拉」；每 3 轮翻 1 张风浪卡。
4. **结算** — 记渡海值 / 结缆标记 / 信任变动，全船用一句话说出"这轮信任为什么变了"。

**每 3 轮**：岗位卡整体轮换 + 翻 1 张风浪卡。

## 胜负条件（须同时满足）

| 条件 | 要求 |
|------|------|
| 全员渡海值 | 每人 ≥ 3（取最小值判定） |
| 全员棋子 | 都抵达第 49 格 |
| 结缆标记 | ≥ 3 |
| **信任账户** | **≥ 7**（不能低于起始值） |

**信任 ≤ 0** → 「船散了」，游戏立即结束。
**12 轮结束仍未全员上岸** → 渡海失败，进复盘。

### ⚠️ 双重特殊失败（到了对岸，但没到彼此心里）

| 名称 | 触发条件 | 说明 | 复盘方向 |
|------|---------|------|---------|
| **各漂各的** | 全员上岸，但托付生效 ≤ 2 且结缆标记 ≤ 1 | 每个人都自己攒够了，谁也没靠谁 | "谁的渡海值是一路自己攒的？回到岗位，他是不是也这样——宁可自己扛也不开口？" |
| **缆绳疲劳** | 托付生效 ≥ 6，但**最后一名全程没有主动托付过任何一次**，且是靠结缆硬拖上岸 | 有人一直在被照顾，从没把自己交出去 | "被接住的那个人，他自己怎么想？我们是在帮他，还是在替他？" |

## 4F 复盘框架

| 维度 | 引导问题 |
|------|---------|
| **Facts 事实** | 团队渡海值最后是多少？结缆标记几个？托付生效几次、失效几次？有没有人拒绝回渡？有没有人喊「我来拉」？ |
| **Feelings 感受** | 你第一个到达终点、却被要求掉头往回走时，心里是什么？你被托付时，是松了一口气还是有压力？你把牌给了别人、发现他没按你说的用时，你说了吗？ |
| **Findings 发现** | "给资源"和"托付"的区别，我们是在哪一轮体会到的？托付失效的那几次，是没说清楚，还是说了对方没听？谁从来没主动托付过？为什么？ |
| **Future 行动** | 回到岗位，**下次把一件事交给别人时，我们会多说哪一句**？当我们是那个"先到终点的人"，我们会用什么方式回头？ |

### 教练落点（挑 1–2 条即可）

1. **盯住第一个到终点的人** —— 他掉头的那一瞬间是全作最重要的观察点。有人主动往回走，有人要等规则逼他。
2. **托付失效要当场点名** —— "他给的是换渡海值，你拿去换了法器，当时你怎么想的？"这句话的冲击力远大于泛泛讲"要重视交接"。
3. **拒绝回渡不要拦** —— 让它发生，信任账户会替你说话；复盘时再问那个人的感受。

| 变体 | 做法 | 适用 |
|------|------|------|

## 教练注意事项

1. **"回渡"一定要在开局就讲清楚** —— 这是全作最反直觉的规则，如果有人不知道，他到终点后会以为自己赢了。
2. **托付三步不要简化** —— 团队会本能地跳到第 3 步（"别废话了直接给"）。这时候教练只说一句："按规则，第 2 步还没做。"
3. **"我来拉"不能变成轮流坐庄** —— 如果出现"这次你替我、下次我替你"的默契记账，复盘时要指出来：那是交换，不是托付。
4. **落后者要被看见，但不要被施舍** —— 若最后一名是被硬拖上岸的，复盘必须问他本人的感受，而不是让全队替他回答。
5. **能力落差不要点破** —— 骰子带来的领先是随机的，教练不要说"能力强的人应该……"，让规则自己说话。

## 差异化定位

- 区别于 **信任背摔**（身体层面交出控制权）与 **盲行**（一对一引导与责任）：本作是**领先者的托付义务**——信任分类里唯一一款竞速骨架，也是唯一把"强者的责任"写成硬规则的一款。
- 区别于 **间谍过家家 · 真心之家**（自我暴露—承接回应的闭环）与 **信任厨房 · 隐患与澄清**（怀疑的成本）：那两款练的是**开口**（敢不敢说真话 / 敢不敢先承认），本作练的是**出手**——敢不敢把资源交出去，肯不肯掉头回来。
- 区别于协作类的 39 款改造桌游（主打危机下的分工与交付）：本作刻意制造**能力落差**（骰子决定谁领先），且领先**不带来任何个人收益**，唯一可做的是回头。

## 🔐 信任挑款：这一款托付出去的是什么

🔐信任 6 款按「托付出去的是什么」分成 3 组，它属于 **🤝 交出一件事的成败（2 款）**：

> 这两款托付的是「结果」：八仙渡海里先上岸的人必须掉头回来接人，给资源时必须说清「我指望你拿它做什么」并等对方复述才生效，全员渡海值取最小值；三猿拆弹里操作手永远看不到手册原文，只能选择信，或者付代价重传 —— 而要求验证这件事，本身就在记账。

**这一款托付出去的是什么**：领先者的优势要不要交出去

- [信任挑款指南 · 🤝 交出一件事的成败这一组](../../trust.html#g-outcome) —— 同组另外 1 款，附「什么情况下选它 / 什么时候别选它 / 拿不准就先拿」
- [挑款指南首页（30 秒决策表）](../../trust.html) —— 按你现在的麻烦直接对组，不用先读完 6 张卡

> 上面是**建议**不是既有收录：这些流程的原表里没有它，塞进去时前后各留 5 分钟交接；塞之前先核一遍人数和时长，别看标题。
