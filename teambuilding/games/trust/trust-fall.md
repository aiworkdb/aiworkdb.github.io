# 信任背摔（Trust Fall）



| **时长** | 中篇 20–40 min（含复盘） |
| **人数** | 建议 每组 8–15 人（全场 8–20 人） |
| **难度** | ⭐⭐ 中等（对安全意识要求高） |
| **场景标签** | 团建 · 培训 · 通用 |
| **核心目标** | 体验"交出控制权"的感受，建立团队信任基础 |

---

**团建核心价值**：
- 🤝 信任交付：向后倒的瞬间心理建设
- 🫂 责任承接：接的人的责任意识
- 🛡️ 团队安全感：每一次稳妥接住都在积累信任

## 2. 核心规则

### 安全前提（必须宣读）

```
"这个游戏需要大家高度专注和负责。
背摔的人完全信任接住他的人。
接的人肩上扛着别人的安全。
所以：不参与 = 可以，开玩笑 = 不可以。
我会在整个过程监控安全。"
```

### 流程

```
1. 所有人站成一个"接人阵型"：
   - 两排人面对面站，伸出双臂，掌心朝上
   - 两排间距约 30–40 cm（背摔者刚好能站进去）
   - 第一排人肩膀顶住第二排人的肩膀（增加稳定性）

2. 背摔者站到阵型一端的高处（椅子/台阶，约 50–80 cm）
   （初次体验建议从地面开始，不用高处）

3. 背摔者动作：
   - 双脚并拢，身体直立
   - 双手交叉放在胸前（或让队友用丝带轻绑手腕）
   - 大声说："我准备好了，你们准备好了吗？"
   - 团队齐声回答："准备好了！"
   - 身体笔直向后倒（不要跳、不要弯腰）

4. 接人阵型的人：
   - 用双臂接住背摔者，平稳地传递到大腿高度
   - 确认安全后，大家一起说："我们接住你了！"

5. 每个人轮流完成一次
```

### 胜负判定

- **合作模式**（推荐）：不设胜负，每个人的安全完成就是全组成功
- **可以加入"无声背摔"变体**：接人阵型不能说话，只能靠默契

## 3. 引导要点

### 如何讲解（3 分钟讲完）

```
第一步：说意义（1 分钟）
  "信任这个词，我们说了无数次。
  但真正把后背交给别人，是另一回事。
  今天这个游戏，就是让你体验：'我相信你'到底是什么感觉。"

第二步：讲安全规则（1.5 分钟）
  "接人的人：你们的动作是——双臂伸直，掌心朝上，
   接到人后，先托住肩膀和腰部，再慢慢放下。
   不要只接手，要接整个身体。
   背摔的人：身体笔直，像一块木板一样倒下来。
   不要跳，不要弯腰，不然接的人会受伤。"

第三步：示范（30 秒）
  "我找一个志愿者，我们演示一次——"
```

### 关键把控

| 情况 | 处理方式 |
|------|---------|
| 有人不敢尝试 | **不要强迫**。让他/她先当接人的人，观察别人，再决定是否尝试 |
| 接的人阵型不稳 | 立即喊停，重新整理阵型，教练站在旁边监控 |
| 有人开玩笑/不认真 | 立即喊停，严肃说明："这不是游戏，这是安全训练" |
| 背摔者身体弯曲 | 喊停，让团队给他/她反馈，重新尝试 |

### 教练站位

- 站在背摔者正后方，随时准备保护性接住（双重保险）
- 眼睛全程盯着背摔者的身体姿态

## 4. 复盘问题（4F 模型）

安全类活动的复盘有个原则：**先讲身体感受，再讲心理感受，最后才讲工作**。跳过前两步，后面的回答都会变成场面话。

### Facts（事实）

- 你摔了几次？每次摔之前，你往后看了几眼？
- 接你的人是什么阵型？有没有人对不上位置？
- 教练喊「准备」到你说「我倒了」，中间隔了多久？

### Feelings（感受）

- 站在台子上往后看的那一秒，你心里在算的是什么？
- 身体交出去的一瞬间，是害怕多一点，还是放心多一点？
- 有人在下面笑了吗？那个笑对你的影响是什么？
- 轮到你接人的时候，你的手臂是紧张还是放松的？

### Findings（发现）

- 是什么让你最终决定「倒下去」？是队友说了某句话，还是你自己数了个数？
- 如果你想再等一会儿，团队会不会催你？他们是怎么表达的？
- 「信任」在这个活动里，具体是由哪几件事构成的？
- 回到工作中，你的同事要把一件事「交到你手上」时，你需要什么才会接？

### Future（未来）

- 回到团队里，你愿意把哪一件「真正重要的事」交出去？交给谁？
- 你希望团队为你做什么，才能让你更敢放手？
- 你们可以建立一个什么样的机制，让「托付」不靠勇气，而靠流程？

## 5. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 软垫 | 1 块 | 厚度 5 cm 以上，或选草地/榻榻米；水泥地必须铺 |
| 接人阵容 | 至少 6 人 | 两排面对面、手臂交错成网；体重较大者再加人 |
| 绑手带 | 若干 | 可选，把接人者手腕交叉绑住，防止手臂被撞开 |
| 口哨 | 1 个 | 教练专用，喊停用 |
| 高台 | 1 个 | 可选，0.8–1 m 的稳固平台；平地背摔同样有效 |
