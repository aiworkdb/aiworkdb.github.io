# 三猿拆弹 · 无声引信（团建信任建立版）

> 原作：《三猿拆弹：无声引信 Three Monkeys Defuse》（3-6 人派对合作竞速桌游，读册师看得见手册却不能说话、聋师听不见、盲师看不见，指令沿人链传递，操作手在末端剪线，个人计分）
> 改造：把"传歪了很搞笑"翻转成"**你永远无法回头核对源头，只能选择信，或者付代价重来**"——而要求验证这件事，本身就在记账

---

## 一句话团建价值

**真实工作里绝大多数信任，都是"不可验证的信任"：你能看到结果，却永远看不到中间那几环发生了什么。**

本作用一条人链把这件事做成物理事实——末端的操作手握着剪刀，他对世界的全部认知来自前一个人，而那个人又信着更前面的人。你可以要求重传一次，但代价是引信继续烧，而且**这个代价由提出验证的人付**。

## 适用场景

- 长流程协作（产研交付、供应链、跨部门审批）：每个人只看到自己那一环
- 授权与放权的边界：管理者看不见执行细节时，选择信还是反复确认
- 新团队磨合期的"我该不该再问一遍"困境
- 心理安全感建设：出错后是认领还是沉默
- 复盘文化导入：能不能做到"看见失真，但不追责个人"

## 四处关键改造

| 原作 | 团建版 | 为什么这么改 |
|------|--------|------------|
| 个人计分，看谁剪对的多 | 共享**「引信余量」（起始 12）**，剪错一次 −3，归零则引爆、全链一起结束 | 真实交付里没有个人名次，只有一个共同的下场 |
| 传歪了大家一起笑，下一轮重来 | **不可验证**：操作手**永远看不到手册原文**，只能选择"信"或"付代价重传" | 可核对的信任不叫信任，叫验收；真实的信任都发生在看不见的地方 |
| 没有"我没听清"这个选项 | 新增**「我没把握」标记**：传递者可明说，下游获知后可选择先复述再传；整局无人标过则触发特殊失败 | 示弱是有成本的，但成本必须**低于**出错的成本，才有人愿意示弱 |
| 操作手只能凭前一位的信息剪 | 新增**「复述权」**：可要求整链重传一次，代价是引信 −1 且沙漏继续走 | 要验证是合理权利，但它不是免费的——这就是现实中的"再确认一次" |

## 核心机制

### 1. 不可验证（本作地基）⭐

- **操作手永远看不到手册卡原文**，剪完之后也不许看（要看只能等全链公开译码板那一刻）。
- 手册卡由教练在**回合结束后收回**，不进弃牌堆、不可复查。
- 因此本作**不存在"谁错了"的客观答案**——只有"这一段传递后，内容变成了什么"。

> 这一条是所有其他机制的前提。教练必须在开局明确宣布，否则整局会退化成一次普通的传话游戏。

### 2. 「我没把握」标记（本作灵魂）⭐

任一传递者在把指令交出前，可以公开说一句：「**这一手我没把握。**」

| 效果 | 说明 |
|------|------|
| 下游立即获知 | 下游可以选择"先复述一遍再往下传"（不消耗引信） |
| 信任 **+1** | 主动示弱是可观测的诚实，当场记账 |
| 该轮效率 −0.5 回合 | 示弱是有成本的，否则它会变成廉价的免责声明 |
| 整局无人使用 | 触发特殊失败「全链沉默」 |

> 观察点：第一个说"我没把握"的人是谁？是新人还是资深？他说完之后，下游是更认真地传了，还是更紧张了？

### 3. 复述权（信任是有成本的）⭐

操作手在剪线之前，可以举手说：「**请整链重传一次。**」

- 全链从读册师开始**重新传递一遍**（读册师重看手册，重新做手势/语音）。
- 代价：引信 **−1**，沙漏继续走（不暂停）。
- 信任 **−1**（每次）——要求验证是合理权利，但它表达了不信任，必须记账。

> **关键设计**：成本由提出验证的人付，而不是由被怀疑的人付。现实中很多团队反过来——被追问的人承担了全部不适，于是没人再敢追问，也没人再敢被追问。

### 4. 引信余量（0–12，起始 12）

| 事件 | 引信变动 |
|------|---------|
| 剪对 | **+1**（上限 12） |
| 剪错 | **−3** |
| 使用复述权 | **−1** |
| 一轮超时（沙漏走完仍未剪） | **−2** |

**引信 ≤ 0** → 引爆，游戏立即结束，全员进复盘。

### 5. 信任账户（0–12，起始 8）

- 起始 **8**（"能一起干活，但还没在看不见的地方信过谁"）。
- **信任 ≤ 0** → 「链条断掉」，游戏立即结束。
- 每次变动，全链必须**当场说出理由**。

| 事件 | 信任变动 |
|------|---------|
| 有人主动标「我没把握」 | **+1** |
| 无人标记的情况下，操作手选择"一次就信"并剪对 | **+1**（该信的时候敢信） |
| 使用复述权 | **−1** 每次 |
| 剪错后 60 秒内有人说"是我这环传歪的" | **+1** |
| 剪错后 60 秒内**无人认领** | **−2** |
| 有人公开质疑"是不是前面就没传对"（具体到人） | **−1**（指向人 ≠ 指向环节） |

### 6. 全链轮换（每人都要站末端）

每完成一颗炸弹（无论对错），全链**整体后移一位**：

```
读册师 → 聋师 → 盲师 → 操作手 →（回到）读册师
```

- 保证每个人在整局中都至少站过一次**末端**——那个"只能信别人、且无法验证"的位置。
- 也保证最健谈的人一定会轮到**不能说话**的读册师位。

## 流程（每颗炸弹 4 步，共 5–7 颗）

1. **布弹（90 秒）** — 教练抽取手册卡放在读册师面前（只有他能看），6 根彩线插入线槽，沙漏翻过来。
2. **传递（沙漏计时）** — 指令沿人链逐环传递：读册师（不可说话，只能手势/画图）→ 聋师（不可听，只能看）→ 盲师（不可看，只能听）→ 操作手。每环可标「我没把握」。
3. **决策** — 操作手宣布剪几号线，或行使**复述权**要求重传（引信 −1、信任 −1）。
4. **开牌与记账** — 全链同时翻开各自的**译码板**（每人事先写下自己收到的指令），教练公开手册原文；记引信与信任变动，然后全链轮换。

> **译码板的作用不是追责** —— 它是为了让所有人亲眼看见"剪 3 号红线"是怎么变成"剪 8 号蓝线"的，以及**它到底在哪一环崩掉**。教练必须反复强调这一点。

---

## 胜负条件（须同时满足）

| 条件 | 要求 |
|------|------|
| 拆弹 | 5 颗中剪对 **≥ 4 颗** |
| 引信余量 | **≥ 4**（结束时） |
| 信任账户 | **≥ 8**（不能低于起始值） |

**引信 ≤ 0** → 引爆，游戏立即结束。
**信任 ≤ 0** → 链条断掉，游戏立即结束。

### ⚠️ 双重特殊失败（拆掉了炸弹，没拆掉那堵墙）

| 名称 | 触发条件 | 说明 | 复盘方向 |
|------|---------|------|---------|
| **全链沉默** | 整局无人标过一次「我没把握」，且剪错 ≥ 2 次 | 没人示弱，也没人因此被保护——大家都在硬扛 | "你其实有几次是没听清的？为什么没说？说了会怎样？" |
| **全线复述** | 复述权使用 ≥ 4 次，炸弹拆掉了但引信 ≤ 4 | 流程上赢了，关系上全靠末端一个人反复自证 | "一直要求重传的那个人，他付出的引信是谁的？回到岗位，谁在反复确认？" |

## 4F 复盘框架

| 维度 | 引导问题 |
|------|---------|
| **Facts 事实** | 剪对几颗、剪错几颗？引信从 12 走到多少？信任从 8 走到多少？复述权用了几次？「我没把握」标了几次？谁标的？ |
| **Feelings 感受** | 站在末端握着剪刀、什么也看不见时，你身体的感觉是什么？你按下"请重传"的那一刻，犹豫了吗？有人说"是我这环传歪的"时，你松了口气还是更紧张？ |
| **Findings 发现** | 我们是在哪一环失真的？那个环节的人，当时知道的比现在多还是少？"我没把握"说出之后，团队变慢了还是变准了？我们是不是把"再确认一次"当成了对别人的否定？ |
| **Future 行动** | 回到岗位，**当我们看不见中间环节时，我们的默认动作是"信"还是"再问一遍"**？下一次有人说"这块我没把握"，我们的第一个反应会是什么？ |

### 教练落点（挑 1–2 条即可）

1. **拿译码板做证据，不要拿人做证据** —— 复盘时把 4 张译码板并排放，问"它是在哪一环变的"，而不是"谁传错了"。这个动作本身就是一次示范。
2. **第一个标「我没把握」的人是全场最重要的人** —— 无论他对错，复盘都要回访他："你当时在犹豫什么？"
3. **复述权的使用次数是一个硬指标** —— 用 0 次说明没人敢验证，用 ≥ 4 次说明链条事实上已经不工作了。两种都要谈。
4. **不要提供"正确答案"之外的评判** —— 教练只念手册原文，不评价任何一环。

## 变体玩法（6 种）

| 变体 | 做法 | 适用 |
|------|------|------|
| 双链对照 | 2 条链接收同一份手册，比对的不是对错，是"失真的位置是否相同" | 人多、想做对照实验 |
| 加长链 | 人链扩到 6–7 环（增加两个"中转师"） | 流程确实很长的团队（如供应链） |
| 静默复盘 | 开牌后前 3 分钟不许说话，只能看译码板 | 情绪激动、容易互相指责的团队 |
| 无复述权局 | 全程禁止重传，只能选择信 | 想放大"不可验证"的体验本身 |
| 实名认领局 | 剪错后必须有人说"是我这环"才允许进入下一颗（否则引信 −1） | 认领文化缺失的团队 |
| 真实议题版 | 手册卡换成团队真实的流程文档，彩线换成真实待办 | 有明确议题的工作坊 |

## 教练注意事项

1. **"不可验证"必须开局宣布三次** —— 操作手不许回头看手册、手册回合结束即收回。这一条破了，全作就退化成普通传话游戏。
2. **手册卡用符号不用文字** —— 文字会让链路变成"读字比赛"，符号才逼出真正的理解与转述。
3. **剪错后必须留 60 秒沉默** —— 不要立刻追问"谁传错了"。给认领留出空间，这 60 秒本身就是训练。
4. **引信归零就真的结束** —— 不要通融、不要"再来一次"。引爆的后果越真实，"我没把握"的价值才越高。
5. **生理限制要照顾** —— 盲师全程戴眼罩会不适，可改为"闭眼 + 不许偷看"；有幽闭或听力敏感的参与者可申请固定在不需要眼罩/耳塞的位置。

## 差异化定位

- 区别于沟通表达分类的 **谣言工厂 / 传话游戏**：那两款可以核对原文、可以追责，练的是"信息为什么会失真"；本作**永远无法核对**——练的是"**不可验证时，你选择信，还是付代价重来**"。
- 区别于 **信任背摔**（身体交出控制权）与 **盲行**（一对一引导）：那两款的信任是**可感知、可即时纠错**的；本作是**链式信任**——你信的那个人，自己也在信别人，且全链无人掌握真相。
- 区别于 **信任厨房 · 隐患与澄清**：厨房里信息是充分的，缺的是开口的勇气；本作里信息天然不足，缺的是**在不确定中做出选择并承担成本的担当**。
- 区别于 **八仙渡海 · 回渡与结缆**（同分类）：本作是**信息维度**的信任（看不见只能信），八仙渡海是**资源维度**的信任（敢不敢把东西交出去）。

## 🔐 信任挑款：这一款托付出去的是什么

🔐信任 6 款按「托付出去的是什么」分成 3 组，它属于 **🤝 交出一件事的成败（2 款）**：

> 这两款托付的是「结果」：八仙渡海里先上岸的人必须掉头回来接人，给资源时必须说清「我指望你拿它做什么」并等对方复述才生效，全员渡海值取最小值；三猿拆弹里操作手永远看不到手册原文，只能选择信，或者付代价重传 —— 而要求验证这件事，本身就在记账。

**这一款托付出去的是什么**：一个看不到源头、只能选择信的判断
