# 信任圈（Willow in the Wind）

> **一句话**：闭眼、直挺挺往后倒，身后是一圈手——倒下去的那 1.5 秒，是「我说我信你」和「我真的信你」之间的距离。

| **游戏名称** | 信任圈（Willow in the Wind / Trust Circle） |
| **目的标签** | 信任建立 · 责任承接 · 身体觉察 |
| **形式标签** | 室内 · 全员 · 站姿 |
| **人数** | 建议 每组 6–10 人（围圈人数决定安全余量） |
| **时长** | 40–55 min |
| **难度** | ⭐⭐ 中等（动作简单，心理门槛高） |
| **道具需求** | 无（空场地即可，建议铺软垫） |
| **场景标签** | 团建 · 培训 · 新团队融合 |
| **核心目标** | 在可控的身体风险里，让「托付」和「接住」都变成具体动作，而不是口号 |

---

**团建核心价值**：
- 🤲 交付控制权：信任的第一步是放弃控制
- 🛡️ 责任承接：接的人比倒的人更需要专注
- 👀 无声协同：靠手感而不是喊话配合
- 🧭 边界感：每个人对「能倒多少」的判断都不同

## 1. 游戏概览

信任背摔很多人都听过，但它的门槛偏高——从高处倒下，心理压力和身体风险都大。**信任圈是它的低门槛版本**：不倒向地面，倒在人墙上；不闭眼从台上掉，站直了往圈里倾。

做法很简单：一个人站在中间，双脚并拢、身体绷直、双手抱在胸前，闭眼；周围 6–10 人围成一圈，双手抬起、掌心朝内、一前一后站成「缓冲带」。中间的人慢慢往后倾，圈上的人把他轻轻推回来，然后他再往另一个方向倾。

这个动作的关键在于：**它不是「倒下」，而是「倾斜后被推回」**。听起来温和，但真正闭眼往后倾的那 1.5 秒，绝大多数人会本能地缩腰、迈腿、睁眼——身体比嘴诚实得多。

教练的价值就在这 1.5 秒里：你要让他在被接住之后，**还有机会再试一次**，直到身体也相信了。

## 2. 核心规则

### 准备

- 场地：平整、干燥、无障碍物的地面，人均 2 平方米以上
- 每组 6–10 人（少于 6 人不做，安全余量不够）
- 中间的人**摘掉眼镜、口袋清空、不戴尖锐饰品**
- 圈上的人**摘手表、手链**，指甲不过长
- **必须**：地面铺软垫（瑜伽垫、爬行垫均可），没有垫子不做

### 站位（这一步错了就全错）

围圈的人按「一前一后、交错站」：

- 前排在中间人的左右和正后方，**双掌张开，掌心朝向中间人，手掌距其肩背约 10 厘米**
- 后排站在前排队友的斜后方，双手托在前排队友的腰侧（防止前排被推倒）
- 所有人**屈膝、重心下沉**，脚一前一后踩稳
- 圈上人**全程不许说话**（说话会分散中间人的注意力）

### 流程

1. **示范**：教练先做一次中间人，让所有人看清动作幅度
2. **空转**：不闭眼、不倒，只做「圈上人推回」的动作，确认力度
3. **第一位志愿者**：通常选一个主动举手的，不要点名
4. **每人 3 次**：第一次往后倾、第二次往左倾、第三次自选方向
5. **轮转**：换人，直到所有人做过一次中间人（**自愿原则，可以只做圈上人**）

### 中间人的动作要领

- 双脚并拢，**膝盖锁直不弯**（弯了就是准备自己救自己）
- 双手交叉抱在胸前（不要伸手去扶）
- **闭眼**（睁眼就等于在做计算，不是信任）
- 身体像一块板，从脚踝开始整体倾斜，**不是弯腰**
- 感觉被接住就停，不用倒到底

### 圈上人的动作要领

- 手掌**接住**，不是**推倒**
- 接住后**缓慢推回中间位置**，不要猛推
- 全程注视中间人的身体重心，不看脸

### 安全红线（不可妥协）

| 情况 | 处理 |
|---|---|
| 有人体重明显超出圈上人的承接能力 | 增加圈上人数，或改为坐姿版本 |
| 有腰颈椎伤病史 | 不做，改为观察员（观察员也有复盘任务） |
| 中间人出现脸色发白、呼吸急促 | 立即停止，坐下休息，不追问 |
| 圈上有人笑场、松手 | 立即叫停，重来；笑场是安全的最大敌人 |

## 3. 引导要点

### 讲解脚本（2 分钟）

> 我想先问一句：**你觉得你相信你旁边这个人吗？** 大多数人会说相信。
>
> 好，那我们试一件很小的事。你站到中间，闭上眼，身体绷直，慢慢往后倾。后面有人接着你。
>
> 我要提醒一句：**你大概会在最后一刻睁眼，或者偷偷弯一下膝盖。** 那不是你的错，那是身体的自我保护。我们今天只是看看，那一下会发生什么。

### 教练在场边做什么

- **盯手不盯人**：始终看圈上人的手掌位置，有人手放下去了立刻提醒
- **控节奏**：中间人准备倾的时候，说一句「准备好了就说『我倒了』」，圈上人回「我们接住你」——这个口令不是仪式，是给身体一个明确的信号
- **第一位志愿者做完后，先问他感受，不要先问大家**。他的回答会决定后面谁敢上
- 有人拒绝做中间人，**当场就让他做观察员，并且给他一个任务**（记录谁的手最稳、谁在什么时候松了），不要让他闲着，闲着会被解读成「被排除」

### 语言禁区

- ❌「别怕，这有什么好怕的」——否定感受，会让人更紧张
- ❌「你要相信你的队友」——这是道德绑架
- ✅「你可以只做圈上人，这完全没问题」
- ✅「刚才那一下你缩了一下，是身体在保护你，很正常」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 有多少人做了中间人？多少人选择了只做圈上人？
- 有几个人在倾倒时睁眼或弯膝？大概在第几次消失的？
- 圈上有没有出现过手放下去、或者笑场的时候？

### Feelings（感受）

- 闭眼往后倾的那一秒钟，你脑子里第一个念头是什么？
- 被接住的那一下，身体是什么感觉？
- 做圈上人的时候，注意力在哪里？累不累？

### Findings（发现）

- 「我说我信你」和「我敢往后倒」差在哪？
- 为什么做圈上人时反而更紧张？（因为责任比托付更重）
- 团队里，谁经常是「倒的人」，谁经常是「接的人」？

### Future（应用）

- 工作里，我们要求别人「信任我们」的时候，有没有先证明自己「接得住」？
- 什么情况下你会不敢把后背交给同事？那个情况能改吗？
- 我们团队里，有没有人一直只做「接的人」但从来没被托付过？为什么？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 有人身体条件不适合 | 坐姿版：坐椅子上，向左右轻靠，圈上人扶肩 |
| 团队规模大（>30） | 分 4–5 个圈同时进行，教练巡回，每圈配 1 名安全员 |
| 新团队 / 信任度低 | **先做「背对背靠」**：两人背靠背坐下互相借力站起，零风险建立第一层信任 |
| 管理层团队 | 做完直接接「授权与兜底」的议题讨论：谁是团队的缓冲带 |
| 线上 / 远程 | 不做身体版，改为「承诺卡」：写下愿意为团队兜底的一件事，公开读出 |
