# 盲人排队（Blind Line-up）

> **一句话**：全员蒙眼、不许说话，把一队人按生日排成一列——你会发现，没有语言的时候，信任是靠「碰一下」建立的。

| **游戏名称** | 盲人排队（Blind Line-up / Silent Line-up） |
| **目的标签** | 非语言协作 · 信任建立 · 身体边界 |
| **形式标签** | 室内外均可 · 全员 · 站姿 |
| **人数** | 建议 8–60 人（本轮 8–16 人一场，人多可分多轮） |
| **时长** | 20–30 min |
| **难度** | ⭐ 偏低（门槛低，但第三轮会突然变难） |
| **道具需求** | 有（眼罩每人 1 个） |
| **场景标签** | 团建 · 新团队融合 · 破冰后的第一课 |
| **核心目标** | 在完全失去视觉和语言的情况下，验证「一个动作也能传递一条信息」 |

---

**团建核心价值**：
- ✋ 非语言传递：拍肩、握手、拉袖子，每一个动作都在传信息
- 🧍 身体边界：被陌生人触碰的舒适度，人和人差得很远
- 🕐 耐心：信息一次只能过一个人，急就错
- 🎯 精确定义：什么叫「排序」？生日按年月日还是只按日？

## 1. 游戏概览

这是最便宜也最好用的一款信任游戏：**零道具成本（除眼罩）、零场地要求、零体能门槛**，却能在 20 分钟里把一群人从「客气」推到「必须合作」。

规则就一句话：蒙上眼，不许说话，按某个维度排成一列。

难点不在排序本身，在于**信息怎么流动**。你只知道自己的生日，不知道别人的；你也不能问。所以你唯一的手段是：找到一个人，用动作交换信息，然后把他放到正确的位置上。

三轮递进设计是这个游戏的关键：

- **第一轮**：可以摸（允许任何身体接触）
- **第二轮**：只能用肩膀碰（接触面积缩小，信息量骤降）
- **第三轮**：全程不许接触（只剩下拍手、跺脚、发出声音）

每加一道限制，团队的策略就必须重写一次。而**第三轮几乎必然出现「没人敢动」的僵局**——那个僵局，才是这个游戏真正的教学点。

## 2. 核心规则

### 准备

- 场地：10 × 10 米平整空地，无障碍物（蒙眼后会乱走，必须清场）
- 眼罩：每人 1 个，**必须真的遮光**（用手试一下能不能看到脚下）
- 站位：所有人先站成一个松散的圈，间隔一臂
- 安全：场地边界用胶带标出，教练站在圈外，配 1 名安全员

### 第一轮：可自由接触

1. 全员戴眼罩，教练确认无人能看到
2. 宣布排序维度：**按生日（1 月 1 日到 12 月 31 日）从早到晚排成一列**
3. 规则：**不许说话、不许发出有意义的音节**，可以用手触碰、握手、拍肩
4. 限时 8 分钟
5. 时间到，**保持站位不动**，摘下眼罩，从队首走到队尾核对

### 第二轮：只能用肩膀

1. 换一个维度：**按入职时间（或加入团队的时间）**
2. 规则升级：**只能碰肩膀**，不许握手、不许碰手、不许拉衣服
3. 限时 8 分钟

这一轮的策略会完全变。信息传递带宽变小了，团队通常会自动发明出一套「拍左肩=更早、拍右肩=更晚」的编码——**这个自发的编码行为，就是复盘的核心材料**。

### 第三轮：零接触

1. 再换维度：**按手机号最后一位，0 到 9**
2. 规则升级：**全程不许有任何身体接触**，只能拍手、跺脚、吹口哨等声音
3. 限时 8 分钟

第三轮通常卡住。卡住是正常的，**不要给提示，让它卡满时间**。

### 判定与计分

| 轮次 | 判定方式 | 计分 |
|---|---|---|
| 第一轮 | 从队首核对，每错一个位置 | −1 分 |
| 第二轮 | 同上 | −1 分 |
| 第三轮 | 同上 | −1 分 |
| 加速完成 | 每提前 1 分钟完成 | +1 分 |

满分不设，重点看三轮的错误数变化。

### 安全底线

- 有人对肢体接触明显抗拒：**事先声明可以申请「只碰手臂」**，不公开说明理由
- 场地必须清空，蒙眼状态下任何凸起物都是风险
- 教练必须能随时喊停，口令用一句话：「全体停，手放下」

## 3. 引导要点

### 讲解脚本（1 分钟）

> 接下来 20 分钟，你们会失去两样东西：**眼睛和嘴**。
>
> 但你会多出一样：**手**。
>
> 任务是排序。怎么排、用什么办法排，我不管。我只定一条规矩：**不许说话。**
>
> 提醒一句：你旁边那个人，可能不太习惯被陌生人碰。所以**动作轻一点，慢一点**，别一把拽过去。

### 教练在场边做什么

- **第一轮不要干预**，哪怕他们排得很乱。乱是必然的，前 3 分钟基本是瞎摸
- **观察谁第一个建立起「两人一组核对」的模式**——这个人往往是团队里真正的组织者
- **第二轮注意编码的诞生**：谁发明的？怎么传播开的？传播时有没有失真？
- **第三轮卡住时不要提示**，但可以给一句中性的话：「你们还有 4 分钟」
- **有人在第三轮主动退出**（站着不动）：记录下来，复盘时问「当时为什么放弃」

### 观察重点（提前发给观察员）

| 观察项 | 看什么 |
|---|---|
| 组织者 | 谁第一个开口之外的方式把人组织起来 |
| 编码 | 有没有出现固定的手势/拍法，传播了几个人 |
| 放弃者 | 谁在中途站着不动了，是被排除还是主动退出 |
| 边界 | 有没有人明显在躲避接触，别人有没有察觉 |

### 语言禁区

- ❌「你们怎么这么慢」——第三轮本来就慢
- ❌「试试拍手啊」——给方案等于毁掉这一轮
- ✅「动作轻一点，别拽」
- ✅「时间到，保持站位，先别动」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 三轮各错了几个人？哪一轮错得最多？
- 第二轮你们发明了什么信号？谁发明的？传播到第几个人时开始失真？
- 第三轮有多少人最后站着没动？他们是被排除，还是自己停下的？

### Feelings（感受）

- 蒙上眼的第一分钟，你最想做的事是什么？（睁开眼？说话？）
- 被人碰到的时候，你舒服吗？哪一次让你不舒服？
- 第三轮完全不能碰，你心里是什么感觉？（无力？还是松了口气？）

### Findings（发现）

- 为什么第一轮反而最容易成？（因为带宽最大，容错最高）
- 「拍左肩=更早」这个编码，是谁想到的？他有没有告诉所有人，还是只用在自己那一小段？
- 团队最后是按「一条信息从头传到尾」在排，还是「每个人只跟旁边的人核对」？（后者快得多，也更准）

### Future（应用）

- 我们平时开会，有多少信息是靠「说」传的，有多少是靠「做」传的？
- 团队里有没有人一直没接收到关键信息，但没人发现？（第三轮站着不动的那些人）
- 如果明天开始只能用一种沟通方式，我们会选哪种？为什么？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（< 8） | 降为 6 人也能玩，但要缩到 2 轮，第三轮改「只能用手指敲地面」 |
| 人数多（> 30） | 分 3–4 队同时进行，每队各排各的，最后比错误数 |
| 想让第一轮更难 | 排序维度改成「按体重」，身体接触更敏感，需提前说明可拒绝 |
| 想降低身体接触门槛 | 第一轮改为「手上拿一张写着自己信息的纸条」，用传递纸条代替触碰 |
| 领导力主题 | 指定一人为「唯一可以说话的人」，观察信息如何经过他 |
| 线上 / 远程 | 改为「文字版」：每人只知道自己的数字，只能两两私聊，最后报出完整顺序 |
| 儿童 / 家庭场 | 不用眼罩，改为「闭眼」+ 允许说话，只禁「说出自己信息」 |
