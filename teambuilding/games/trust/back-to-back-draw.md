# 背对背画画（Back-to-Back Drawing）

> **一句话**：我看不见你的图，你也看不见我的——只能靠问。而敢不敢问「你刚才那句是什么意思」，就是信任的起点。

| **游戏名称** | 背对背画画（Back-to-Back Drawing） |
| **目的标签** | 信任建立 · 精准沟通 · 主动澄清 |
| **形式标签** | 室内 · 两人一组 · 坐姿 |
| **人数** | 建议 每组 2 人配对，可多组并行 |
| **时长** | 30–40 min |
| **难度** | ⭐ 简单（零门槛，但「不敢问」会立刻暴露） |
| **道具需求** | 有（纸 + 笔 + 图卡） |
| **场景标签** | 团建 · 培训 · 跨部门沟通工作坊 |
| **核心目标** | 让「假设对方懂了」这件事付出可见代价，练习主动确认与承认不懂 |

---

**团建核心价值**：
- 🗣️ 主动澄清：不懂就问，而不是猜
- 🧠 假设觉察：「我以为他说清楚了」
- 🤝 承认不懂：示弱的成本有多高
- 🔁 反馈闭环：说—确认—修正

## 1. 游戏概览

两人一组，背对背坐。A 拿到一张图（几何图形组合），B 拿纸笔。A 只能用嘴描述，B 只能听和画，**不许回头看**。

规则里最狠的一条是：**B 可以随时提问，但 A 只能说「是」「不是」或「我不能说」**（部分版本允许自由回答，见变体）。

游戏结束时把原图和画出来的图并排一放，全场会笑。但笑完之后的那个问题才是重点：

> 刚才你有几次想问「你说的『左边』是哪一边」，但是没问？

这个游戏几乎必然暴露同一个现象：**画的人不敢问，说的人不问「你听懂了吗」**。双方都在假设，直到最后对不上。

放在工作里，这就是需求评审、跨部门对接、上级交办任务时最常见的那道裂缝。

## 2. 核心规则

### 准备

- 打印图卡：每张图由 5–8 个几何元素组成（圆、三角、矩形、线段），位置关系明确但不直观
- 难度分三档：简单（3 个元素）/ 中等（5 个）/ 困难（8 个且有重叠、对称）
- 每组两人，背对背坐，中间有隔板或直接背靠背
- 每人一张白纸 + 一支笔（A 也需要纸笔画不了，只能描述，可给 A 一支笔做手指比划用）

### 流程（三轮递进）

**第一轮：单向描述（5 分钟）**

A 描述，B 画，**B 不许提问**。

结果通常惨不忍睹。这一轮的目的是建立「基线」——看看纯单向沟通能做到什么程度。

**第二轮：允许提问（5 分钟）**

换一张新图，规则改为 B 可以随便问，A 必须如实回答。但**A 不许主动补充**（不能自己加说明，只能回答被问到的）。

这一轮会出现一个关键现象：**提问的人很少**。多数人宁愿猜。

**第三轮：双向确认（5 分钟）**

允许 A 主动问「你现在画到哪了」「这个位置你觉得对吗」，也允许 B 要求 A 复述。

三轮结束后，三张画并排对比。

### 胜负判定

不排名次。只做一个统计：**三张画的「元素位置正确率」分别是多少**。通常第一轮 40%、第二轮 65%、第三轮 85%。这个数字本身就是复盘材料。

## 3. 引导要点

### 讲解脚本（1.5 分钟）

> 你们俩背对背坐。A 手里有一张图，B 手里有纸笔。
>
> A 只能说话，不能回头、不能用手比划给 B 看。B 只能听和画。
>
> 第一轮：B 不许问任何问题。就照着听来的画。
>
> 好，开始。

（第一轮「不许问」这条，说完就走开，别解释。他们的困惑本身就是体验。）

### 教练在场边做什么

- **第一轮全程沉默**，看着他们卡住、猜、画错，不要提示。
- 第二轮开始前只说一句：「这一轮你可以问，随便问。」然后就闭嘴——**看谁真的问了**。
- 记录：哪一组在第二轮问了 5 个以上问题？哪一组一个都没问？
- 第三轮前提醒 A：「你也可以问。」

### 收尾的关键一问

三轮结束后，先不说话，把三张图并排贴墙上。等大家笑完，问一句：

> 第二轮允许提问的时候，你有几次想问，但最后没问？

（这一问通常会安静下来。沉默的长度，就是这个游戏的价值。）

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 三轮的元素位置正确率大概是多少？
- 第二轮你问了几个问题？第一轮你想问几个？
- 有几次是「听懂了但其实理解错了」？

### Feelings（感受）

- 不敢问的时候，你在担心什么？（怕显得笨？怕打断对方？）
- 发现画错的时候，第一反应是怪自己还是怪对方？
- 对方主动问「你听懂了吗」的时候，你什么感觉？

### Findings（发现）

- 为什么「允许提问」之后，提问还是很少？
- 说的人以为自己说清楚了，这个「以为」从哪来？
- 我们的工作里，哪一类信息最容易出现「我以为他懂了」？

### Future（应用）

- 下次接需求，你能不能在开始做之前先复述一遍？
- 团队里能不能约定一个「澄清不扣分」的规则？
- 你自己当「说的人」时，会主动问「你复述一下我听听」吗？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 时间紧（15 分钟） | 只做第一轮和第三轮，对比效果最强烈 |
| 大团队 | 多组并行，最后每组挂一张「最离谱的图」出来投票 |
| 跨部门工作坊 | 图卡换成「我们部门的工作流程图」，由一方描述给另一方画 |
| 上下级配对 | 让上级当 B（画的人），体验「不敢问老板」的压力 |
| 线上 | 用共享白板，A 语音描述，B 画在共享画布上 |
