# 🕵️ 间谍过家家 · 真心之家（团建信任版）

> 原作：SPY FAMILY PARTY（间谍家庭派对，4-8 人隐藏身份 / 推理派对桌游，灵感《间谍过家家》）
> 改造方向：**信任建立**
> 一句话：**把"藏住秘密才算赢"翻转成"秘密被安全接住才算赢"。**

---

## 📋 基本信息

| 项目 | 内容 |
|------|------|
| 人数 | 6-16 人（每 5-8 人组成一个"临时家庭"；超过 8 人分 2 组并行） |
| 时长 | 60-90 分钟（含 20-25 分钟复盘） |
| 场地 | 室内，围坐一圈，每组一张桌 |
| 类型 | 信任建立 · 心理安全感 · 深度自我暴露 |
| 强度 | 情绪中高（涉及真实自我暴露，**需提前做心理安全约定**） |
| 物料 | 打印卡牌 + 便签 + 笔（见物料清单） |

## 🎯 团建价值

大多数"信任游戏"练的是**行为层面的信任**——敢不敢把后背交出去（信任背摔）、敢不敢蒙眼跟着走（盲行）。
这一款练的是更难的一层：**情感层面的信任**——我敢不敢说出一个真实的、有点脆弱的想法，以及团队接不接得住它。

真实团队里的信任崩塌，几乎都不是因为"不敢把后背交给对方"，而是这几件小事：
- 我说了我的难处，没人接话，话题就过去了；
- 我提了个顾虑，被一句"这个不用你操心"堵回去；
- 会议上大家都说"没问题"，散会后各自吐槽。

这款游戏把这些瞬间**做成规则**：坦白有收益，但被无视会扣分；沉默能完成任务，但会触发特殊失败。

**差异化定位**：区别于 `trust-fall`（行为信任 / 体力托付）、`blind-walk`（交出控制权 / 责任感），本作专攻**「自我暴露—承接回应」的信任闭环 / 心理安全感的可观测化 / 表面和睦与真实信任的区分**。

## 🔄 四处关键改造（对照原作）

| # | 原作 | 团建版改造 | 为什么这么改 |
|---|------|-----------|-------------|
| 1 | 隐藏身份，被猜中扣分 | **坦白机制**：每人 1 张「真心卡」（写自己一个真实的职场顾虑/诉求），初始暗置；**主动坦白并获回应才得分** | 原作奖励"藏"，团建要奖励"露" |
| 2 | 个人积分，分数最高者获胜 | 全团共用**「家庭默契指数」**（0-10），≤0 → 家庭解体，**全体失败** | 消除零和，强制共同命运 |
| 3 | 攻击 / 偷窃 / 淘汰玩家 | 全部移除，改为**外部压力事件卡**（甲方催单、需求变更、骨干离职、预算削减） | 团队内部不该互坑，压力来自外部 |
| 4 | 相互猜疑、投票驱逐 | 改为**「接住 / 没接住」判定**：坦白后队友必须回应，由坦白者本人判定是否被接住 | 把"被听见"变成可判定的动作，而不是感觉 |

## 🧩 核心机制

### 1. 共享指标：家庭默契指数（0-10）

- 起始 **3 分**（默认礼貌性默契，不是真信任）
- **目标**：结束时 ≥ 8 分
- **归零**：≤ 0 →「家庭解体」，全体失败，直接进入复盘
- 每分变动都要**当场说明理由**（不许默默改分）

| 变动 | 触发条件 |
|------|---------|
| **+2** | 一次坦白被**明确接住**（坦白者判定成立） |
| **+1** | 共同任务成功完成 |
| **+1** | 有人使用「掩护」帮队友扛下一次危机 |
| **-1** | 共同任务失败 |
| **-1** | 一次坦白**没被接住**（沉默、敷衍、或变成说教） |
| **-1** | 有人打断他人发言、或抢话替别人把话说完 |
| **-2** | 外部危机卡未被处理，进入下一轮 |

### 2. 共同任务（原「家庭任务」改造）

每轮抽 1 张任务卡，**必须至少 2 名不同角色协作**才能完成，限时 3-5 分钟。
大众投票容易变成"客客气气全通过"，因此判定改为：**由观察员（管家）+ 任务之外的成员共同判定**，需 2/3 通过。

任务卡示例：
- 🍳 **一顿晚餐**：3 人用肢体+语言合演一个"团队加班到深夜"的 30 秒场景，另 1 人旁白
- 📸 **全家福**：全组在 60 秒内摆出一个能表达"我们团队现在的状态"的造型，并各说一句解说
- 🎁 **生日惊喜**：组内某人不说话，其余人猜他最近在工作上最想要什么支持（猜对被 +1）
- 🧹 **大扫除**：列出团队当前 3 个"没人愿意碰的脏活"，当场认领
- 🐕 **遛狗**：两人一组，一人蒙眼一人语言引导，绕过 3 个障碍（与 `blind-walk` 联动彩蛋）

### 3. 坦白机制（游戏核心）

**流程**（每轮每人最多坦白 1 次）：

```
① 举手 → ② 读出真心卡 → ③ 静默 3 秒（不许立刻接话）
   → ④ 队友依次回应（每人 ≤ 30 秒）→ ⑤ 坦白者宣布"接住 / 没接住"
```

**「接住」的判定标准**（坦白者自己说了算，写在卡背面）：
- ✅ 复述了我真正在意的那一点，而不是复述我的原话
- ✅ 给出了一个具体的支持动作（"我这周帮你顶掉 X"），而不是"加油"
- ✅ 有人分享了自己类似的经历（共鸣 > 建议）
- ❌ 立刻给建议 / 说教 / "我以前比你还惨"
- ❌ 沉默、转移话题、或者把话题拉回自己身上

**收益与代价**：
- 被接住 → 默契 **+2**，坦白者获得 1 张「共鸣卡」（可抵 1 点行动力或换来一次掩护）
- 没接住 → 默契 **-1**，该真心卡**永久翻面为「冰封卡」**（本局不可再坦白同主题）

> 💡 设计意图：「冰封卡」是全场最重要的信号。被冰封的主题，就是复盘时最该谈的东西。
> 教练请默默记下所有被冰封的主题。

### 4. 外部压力事件卡（原「攻击卡 / 事件卡」改造）

每轮结束翻 1 张，团队须在下一轮消耗行动力处理，未处理则默契 -2。
压力来自**外部**，团队只能共同承受——这是刻意设计：让团队体验"一致对外"而非"内部消耗"。

| 卡片 | 效果 |
|------|------|
| 📞 甲方催单 | 下一轮共同任务限时从 5 分钟压到 2 分钟 |
| 🔀 需求变更 | 已完成的 1 个任务作废重做 |
| 👋 骨干离职 | 随机 1 名成员下一轮行动力 -1 |
| 💰 预算削减 | 全组下一轮行动力总量 -2 |
| 🗞️ 舆情风波 | 下一轮必须留 1 人专职"对外解释"，不参与任务 |
| 🎉 意外捷报 | **唯一的正面卡**：默契 +1，全组各补 1 点行动力 |

### 5. 掩护卡（原「伪装 / 防御」改造）

公开声明："这一轮 X 的危机/压力，我来扛。"
- 消耗自己 1 点行动力，该危机对队友不生效
- 默契 **+1**
- **限制**：同一人全局掩护 ≤ 2 次。超出则触发观察员提示——"过度保护"本身是信任问题（见特殊失败）

## 🎭 角色分工（6 种，映射组织职能）

每 5-8 人一组，角色固定但**每两轮强制轮换一次**（让每个人都体验"接住别人"和"被接住"）。

| 角色 | 原型 | 组织映射 | 职责 | 观察点（教练重点看） |
|------|------|---------|------|-------------------|
| 🕵️ **黄昏** · 统筹者 | 父亲 | PMO / Team Leader | 分配任务、对外交涉、控制节奏 | 是否把任务都揽给自己；是否替别人做决定 |
| 🌹 **约尔** · 守护者 | 母亲 | HRBP / 心理安全守护 | 承接情绪、兜底危机、使用掩护 | 是否过度保护；是否只护人不护事 |
| 🧠 **阿尼亚** · 感知者 | 孩子 | 氛围观察者 / 新人视角 | 每轮必须说一句"我感觉到的氛围"（只描述，不评判） | 敢不敢说真话；是否被当成"小孩子乱讲" |
| 🐕 **邦德** · 预警者 | 犬 | 风控 / 质量 | 每轮指出 1 个还没爆的隐患 | 预警是否被无视；是否变成乌鸦嘴 |
| 🎩 **弗兰基** · 信息官 | 情报商 | 中台 / 数据 / 工具 | 打通信息、记录共识、防止信息孤岛 | 信息是否真的流动；有没有囤信息换存在感 |
| 📓 **管家** · 观察员 | 管家 | 教练 / 复盘记录者 | 只记录不发言，负责判定与复盘素材 | **最爱发言的人必须当一轮**（关键规则） |

> ⚠️ **关键规则**：全场最爱发言的人，必须至少当一轮「管家」——只听不说。
> 这一条是本作最有效的设计，屡试不爽。

## 🎲 游戏流程

### 准备（10 分钟）

1. 分组（5-8 人一组），选定首轮角色
2. **写真心卡**（5 分钟，非常重要的静默时间）：
   - 每人写 1 个**真实的、与工作相关的、有点脆弱的**想法
   - 参考句式：「我最近比较担心的是……」「我希望团队能给我……」「有件事我一直没好意思说……」
   - ⚠️ 教练须强调：**不写隐私、不写对具体同事的指控、不写绩效申诉**。写"我的感受与需要"，不写"谁的问题"
3. 建立**心理安全三约定**（写在白板上，全场可见）：
   - 🔒 **出了这个门，什么都不带走**（不传播、不引用）
   - 🚫 **不追问、不安慰、不评价**（回应只做三件事：复述、共鸣、给具体支持）
   - ⏭️ **有权利跳过**（任何时候可以说"我这轮过"，无需解释）

### 回合流程（每轮 10-12 分钟，共 5 轮）

<div class="flow">

**① 抽任务（1 min）** → 抽出本轮共同任务卡，识别需要的角色组合

**② 分工（2 min）** → 黄昏分配，其他人可提出异议

**③ 执行任务（3-5 min）** → 限时协作完成，判定是否通过（+1 / -1）

**④ 坦白环节（3-4 min）** → 0-2 人坦白，走"接住/没接住"判定（+2 / -1）

**⑤ 压力卡（1 min）** → 翻外部事件卡，确认下轮要处理什么

**⑥ 微复盘（1 min）** → 每人一句话：本轮我印象最深的一个瞬间

</div>

### 胜利条件（须**同时**满足三条）

| 条件 | 阈值 |
|------|------|
| ✅ 共同任务完成数 | ≥ 4 / 5 |
| ✅ 家庭默契指数 | ≥ 8 |
| ✅ **被接住的坦白次数** | ≥ 3 |

## ⚠️ 双重特殊失败（各触发不同复盘方向）

### 失败 A：「体面的陌生人」

> **触发**：共同任务完成 ≥ 4 **且** 被接住的坦白 ≤ 1

**现象**：任务完成得漂漂亮亮，气氛和和气气，但全程几乎没人真正敞开心扉。

**复盘方向**：
- 我们的团队是"能一起干活"还是"能一起说真话"？这两件事是一回事吗？
- 那 4 个任务里有几次是"为了完成而完成"？
- 如果今天有人说了一句真话，最可能发生什么？（**这个答案就是团队真实的心理安全水位**）

### 失败 B：「情绪倾倒」

> **触发**：坦白次数 ≥ 4 **但** 共同任务完成 ≤ 2

**现象**：场面很真诚、很感动，但活儿没干，变成了诉苦大会。

**复盘方向**：
- 情绪表达如果没有承接结构，会不会变成对团队的消耗？
- 我们有没有把"说真话"和"要资源"混为一谈？
- 真实的团队里，是不是也有一两个人一直在输出情绪、却没人帮他落地？

> 🎯 两种失败**都不计胜**，但都是极好的复盘素材。教练不必避免它们发生。

## 🔍 4F 复盘框架（20-25 分钟）

| 阶段 | 引导问题 |
|------|---------|
| **Facts 事实** | 我们的默契指数是怎么走到这个数的？哪一轮是转折点？<br>有几张真心卡被**冰封**了？分别是什么主题？ |
| **Feelings 感受** | 坦白的那一刻，你身体是什么感觉？（手心出汗 / 喉咙发紧 / 想笑场）<br>被接住和没被接住，体感差别有多大？<br>当「管家」只能听不能说时，你什么感觉？ |
| **Findings 发现** | 我们团队里，谁在默默承接情绪？谁从来没有被接住过？<br>「接住」和「给建议」，我们更习惯哪一个？为什么？<br>我们把"外部压力"变成"内部指责"的次数有多少？ |
| **Future 行动** | **每人写 1 张「支援卡」**：写给现场某一位同事一句"下次你需要时，我可以……"，当场交给他。<br>团队层面认领 1 条**可验证的承诺**（如：每周站会留 3 分钟"顾虑时间"，只说担心不讨论方案）。 |

> 💡 **支援卡是本作的落点**。游戏会散场，卡可以带走。请务必留足 5 分钟做这一步。

## 🌀 变体玩法（7 种）

| 变体 | 适用 | 改法 |
|------|------|------|
| **1. 观察员模式** | 任意 | 增设 1 名纯观察员，全程记录"谁在承接 / 谁在被忽略"，复盘时先由他念观察笔记 |
| **2. 限时版** | 时间紧 | 3 轮制，任务限时压到 2 分钟，坦白时间 30 秒，保留全部判定规则 |
| **3. 角色轮换** | 默认开启 | 每两轮强制换角色，保证每人至少当过一次「管家」和一次「守护者」 |
| **4. 无声家庭** | 沟通训练 | 共同任务阶段全程禁语，只能用肢体和纸笔——坦白环节恢复正常（对比感极强） |
| **5. 部门混编** | 跨部门团建 | 每个"家庭"必须包含 ≥ 3 个不同部门成员，真心卡必须写"跨部门协作中的一个顾虑" |
| **6. 真实议题专场** | 团队已有张力 | 真心卡内容改为提前收集的匿名真实议题（教练筛过），强度高，**仅适合高信任团队** |
| **7. 反向家庭** | 进阶 / 复盘会 | 坦白内容改为"我最想对团队说的一句感谢"，专注正向反馈，适合年末或项目收尾 |

## 🧭 教练注意事项（心理安全优先）

1. **开场必须做退出机制说明**：任何时候可以说"我这轮过"，不需要解释，不会被追问，不扣分。
2. **真心卡内容要提前设边界**：不写隐私、不写对具体人的指控、不写薪酬绩效申诉。教练有权在写完后快速扫一眼并建议改写法（不公开读）。
3. **警惕"情绪倾倒"变体的误用**：变体 6（真实议题专场）**只适合已有较高信任基础的团队**，新团队使用极易失控。
4. **「管家」角色要给最爱说话的人**：这条规则会引发轻微不适，正是效果所在，但教练要在一旁兜住，别让它变成惩罚。
5. **被冰封的主题，复盘时不要点名逼问**。教练只说："我注意到有几个主题被冰封了，它们大概是关于 X 方向的，我们不追是谁，但可以聊聊这个方向。"
6. **收尾必须落到「支援卡」**。自我暴露如果没有承接和落点，比不暴露更伤团队。
7. 若现场出现真实情绪失控：**立刻中止游戏环节，转入 1 对 1 关怀**，复盘改为轻量版或延后。

## 🔐 信任挑款：这一款托付出去的是什么

🔐信任 6 款按「托付出去的是什么」分成 3 组，它属于 **💬 交出会受伤的自己（2 款）**：

> 这两款里没有人是被规则逼着接住的 —— 你说出秘密或坦白隐患，对方可以选择不接，而且不接也不会出事，只是信任就没了。间谍过家家把「藏住秘密才算赢」翻转成「秘密被安全接住才算赢」；信任厨房里冤枉一次好人信任直接 −3，隐患可以随时主动坦白、团队选择接纳则信任 +2。这是 6 款里唯一真正碰「心理安全感」的一组。

**这一款托付出去的是什么**：一段会被接住或落空的真话

- [信任挑款指南 · 💬 交出会受伤的自己这一组](../../trust.html#g-truth) —— 同组另外 1 款，附「什么情况下选它 / 什么时候别选它 / 拿不准就先拿」
- [挑款指南首页（30 秒决策表）](../../trust.html) —— 按你现在的麻烦直接对组，不用先读完 6 张卡

> 想换一层练？3 组之间的边界，以及「四个最容易挑错的地方」，都写在挑款页里。

## 🧩 这套游戏被哪些流程用过

> ⚠️ **还没有任何现成流程收录它** —— 它属于「挑一个环节塞进去」型：本页有完整玩法，但没有配套时间轴。按参数 6–16 人 / 60–90 分钟，能落地的位置是：

> 最合适的落点是[一日团建流程方案](../../flows/one-day/01-schedule.md)的**信任活动**（15:30–16:30，60 min）：本页按 60 分钟版（少一轮追问）正好一格；要跑满 90 分钟，得把「信任活动 + 整体复盘」并成一块。
>
> **半日与新人融入都装不下**：半日核心活动 I 只有 50 min，新人融入的信任段只有 30 min（02:50–03:20），本页最短 60 分钟。
>
> 上面是**建议**不是既有收录：这些流程的原表里没有它，塞进去时前后各留 5 分钟交接；塞之前先核一遍人数和时长，别看标题。
