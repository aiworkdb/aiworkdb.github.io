# 共情叙事（Empathy Storytelling）

> **一句话**：每人都讲一件「我搞砸过的事」，两分钟，不被打断——信任不是靠一起赢来的，是靠互相看见脆弱换来的。

| **游戏名称** | 共情叙事（Empathy Storytelling / Struggle Story） |
| **目的标签** | 情感信任 · 深度倾听 · 心理安全 |
| **形式标签** | 室内 · 小圈 · 坐姿 |
| **人数** | 建议 每组 5–8 人（全场 6–40 人） |
| **时长** | 40–55 min |
| **难度** | ⭐⭐⭐ 偏高（心理门槛，不是身体门槛） |
| **道具需求** | 有（提示卡 + 计时器 + 发言信物） |
| **场景标签** | 培训 · 管理层工作坊 · 长期团队复盘 |
| **核心目标** | 用「被认真听过一次」的体验，把团队从「合作顺畅」推进到「敢说真话」 |

---

**团建核心价值**：
- 👂 深度倾听：两分钟不打断，比任何「积极倾听」课程都有效
- 🫱 脆弱互惠：一个人先讲，下一个人就敢讲；教练必须先讲
- 🚫 不给建议：最难的规矩是「听完别急着帮人解决」
- 🧠 心理安全：知道同事也搞砸过，才敢承认自己搞砸了

## 1. 游戏概览

大部分团建都在制造「一起赢」的记忆：一起搭塔、一起解谜、一起喊口号。这些很有用，但它们建立的是**并肩感**，不是**信任感**。

真正让一个团队敢说「这个方案我觉得有问题」的，是另一件事：**我知道我说了不会被打分**。

共情叙事做的就是这件事。每人两分钟，讲一个自己真实的困境——不是成功故事，不是励志故事，是**当时很难受、后来也没完全解决**的那种故事。

规则只有三条，但每一条都在对抗我们的本能：

1. **不打断**（我们的本能是接话）
2. **不给建议**（我们的本能是解决问题）
3. **不追问细节**（我们的本能是好奇）

两分钟很短。但对很多人来说，这是近几年第一次有人**完整听完他说话而没有插嘴**。

## 2. 核心规则

### 前提（不满足就不做）

- **人数上限 8 人一圈**。超过 8 人，深度会断崖式下降
- **必须是自愿**，任何人可以说「我跳过」，且不需要解释理由
- **教练必须第一个讲**，且讲得比要求的更深一点——你定的是深度标尺
- 明确宣布：**今天讲的东西不出这个圈**（不是「尽量别说」，是「不许说」）

### 三段结构（发给每人一张卡）

讲的人按这三段讲，每段大约 40 秒：

| 段 | 内容 | 示例句式 |
|---|---|---|
| ① 发生了什么 | 只说事实，不评价 | 「去年那个项目，我在上线前一天发现数据算错了。」 |
| ② 我当时什么感觉 | 说情绪，不说结论 | 「我第一反应是怕，怕被发现在这么晚才看到。」 |
| ③ 什么真的帮到了我 | 说具体动作，不说感谢 | 「有个同事没问我为什么，先坐下来跟我一起查。」 |

**第 ③ 段是这个游戏的核心。** 它逼每个人回答一个问题：**别人做什么，才是真的帮到我？** 这个答案会直接变成团队的行为准则。

### 流程（40 分钟标准版）

1. **定规矩**（5 min）：念三条规则 + 保密承诺 + 「可以跳过」
2. **教练示范**（3 min）：教练讲自己的，完整走完三段
3. **轮流讲**（每人 2 min 讲 + 1 min 回应，共 24 min）
4. **回应环节**（关键）：听完的人**只能做一件事**——复述一句
   > 「我听到的是……」
   
   不许评价（「你很棒」），不许建议（「你下次可以……」），不许比较（「我也遇到过更惨的」）
5. **收束**（8 min）：每人说一句「我希望团队里多一点什么」

### 三条硬规矩（违反了教练当场打断）

| 规矩 | 违反的样子 | 正确做法 |
|---|---|---|
| 不打断 | 中途插「我也是！」 | 记在心里，等他说完 |
| 不给建议 | 「你应该早点说啊」 | 「我听到的是你当时很怕」 |
| 不追问 | 「后来那个人怎么样了？」 | 他想说会说，不问 |

### 回应句的三个模板

- ✅「我听到的是，你当时最怕的是被发现。」
- ✅「我听到的是，帮你的人是先坐下来，不是先问你为什么。」
- ❌「你好勇敢。」（评价，把人推回台上）
- ❌「我完全理解，我也……」(把话题抢过来)

## 3. 引导要点

### 讲解脚本（3 分钟）

> 接下来这一轮，跟前面所有环节都不一样。**它不好玩。**
>
> 每人两分钟，讲一件你搞砸过的事。不要讲你后来怎么翻盘的，也不要讲你从中获得了什么成长。就讲**当时那个难受的时刻**。
>
> 听的人只有一个任务：听完之后，说一句「我听到的是……」。
>
> **不要给建议。** 我知道这很难——我们这行的人，听到问题就想解决。但今天，请你忍住。因为他不需要你的方案，他需要的是**有人真的听懂了**。
>
> 最后一句：**你可以跳过。** 跳过不需要理由，也不会有人问你为什么。

### 教练在场边做什么

- **第一个讲，且讲到「我错了」这个层级**。如果你只讲了个「小失误」，后面所有人都会跟着讲小的
- **计时器放在明面上**，2 分钟到了就轻轻说一句「时间到，谢谢你」——不评判、不总结
- **有人讲着讲着停住了**：等 10 秒没人说话，就问一句「要不要停在这里？」不要催
- **有人开始给建议**：立刻举手打断，「这句是建议，我们留到后面」
- **有人开始哭**：不递纸巾、不说「没事的」，就安静坐着。递纸巾等于告诉他「这不该发生」

### 语言禁区

- ❌「大家都是一家人，随便说说」——这句话会把深度拉到零
- ❌「谢谢你的分享，非常有价值」——把人当成案例，不是人
- ❌「我们今天讲的都很真诚」——总结式表扬会让真诚变成表演
- ✅「谢谢你愿意讲这个」
- ✅「我听到的是……」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 有几个人跳过了？跳过的人后来有没有说话？（不点名，只统计）
- 有几个人的第 ③ 段说的是「具体动作」，而不是「谢谢大家」？
- 回应环节里，有几次差点变成给建议？

### Feelings（感受）

- 讲的时候，最怕的是什么？（怕被看轻？怕影响评价？）
- 听的时候，最想做的事是什么？（给建议？说「我也是」？）
- 听到别人也搞砸过，你心里松了一点吗？松在哪里？

### Findings（发现）

- 「什么真的帮到了我」这个问题的答案，有没有共同点？（通常集中在：**先不评判、先在场、先一起干**）
- 为什么「给建议」常常不是帮助？（因为建议默认「你做得不对，我教你」）
- 这个圈里，有没有人讲的困境和别人高度重合，但两个人此前从没聊过？

### Future（应用）

- 下次同事说「我搞砸了」，你的第一句话会是什么？
- 我们团队现在有没有一个「可以说搞砸了」的场合？如果没有，能不能造一个？
- 那三条规矩（不打断/不建议/不追问），能不能搬进周会？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 团队还很新（< 3 个月） | 降级为「一件让我学到东西的小事」，不要碰重大挫折 |
| 人数多（> 40） | 分圈进行，每圈配 1 名引导员（提前培训 15 分钟，只教三条规矩） |
| 时间只有 20 分钟 | 缩到 3–4 人讲，其余人只做倾听者，收束改为「一句话感受」 |
| 管理层团队 | 主题换成「一次我做错的决定」，并加一问：当时为什么没人告诉我 |
| 线上 / 远程 | 完全可行，反而更好（在家更有安全感）；要求开摄像头，按顺序讲，其余人静音 |
| 有心理创伤风险 | 提前说明「讲工作相关的事就好」，并准备心理支持渠道信息 |
| 不想碰情绪，只要轻量版 | 换成「一次被帮到的经历」——只讲第 ③ 段，正向不揭伤 |

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 三段结构提示卡 | 每人 1 张 | A6 大小，正面三段句式，反面三条规矩 |
| 计时器 | 1 个 | 必须可见，避免教练频繁看手机 |
| 发言信物 | 1 个 | 小玩偶/笔都行；拿着才能说话，放下就结束 |
| 座椅 | 每人 1 把 | 围成圈，不要排排坐面向讲台 |
| 纸巾 | 1 盒 | 放在角落，不主动递 |
| 保密承诺卡 | 每人 1 张 | 可选，签名后收走，仪式感能显著提高深度 |
