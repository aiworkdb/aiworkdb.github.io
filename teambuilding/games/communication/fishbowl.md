# 鱼缸会议（Fishbowl / 鱼缸谈话）

> **一句话**：内圈 6 个人谈话，外圈 100 个人听——但中间那把椅子是空的，谁想说话，谁就坐进去。

| **游戏名称** | 鱼缸会议（Fishbowl / 鱼缸谈话 / 金鱼缸） |
| **目的标签** | 平等发言 · 旁听学习 · 观点轮换 |
| **形式标签** | 室内 · 同心圆座位 · 开放/闭合两种模式 |
| **人数** | 全场 30–300 人（内圈 5–7 人，外圈不限） |
| **时长** | 60–120 min |
| **难度** | ⭐⭐ 偏低（形式简单，控场难） |
| **道具需求** | 有（椅子按同心圆摆放 + 1 把"空椅"标记 + 计时器） |
| **场景标签** | 大型研讨 · 专家对话 · 跨部门听证 · 高敏感议题 · 年会分论坛 |
| **核心目标** | 让大场里"谁能发言"不再由职位决定，而由"谁愿意坐进去"决定 |

---

**团建核心价值**：
- 🪑 发言权开放：一把空椅，把"旁听者"变成"潜在发言者"
- 👂 深度旁听：外圈不发言，但全程在听、在判断
- 🔄 角色轮换：闭合模式里，内圈会被整体换掉
- 🗣️ 降维对话：6 个人能真聊，60 个人只能轮流念稿

## 1. 游戏概览

鱼缸会议是一种把"大场"变成"小场"的对话结构。它解决一个非常具体的问题：**50 人以上的讨论，通常只有 3–5 个人在说话，其余人在看手机。**

形态是这样：

- 房间中央摆一个小圈（**内圈 5–7 把椅子**），这是"鱼缸"
- 外圈以同心圆方式摆更多椅子，这是"水"
- 内圈的人就一个话题展开真实对话；外圈的人**只听，不发言**
- **开放鱼缸**：内圈留 **1 把空椅子**。任何外圈的人想说话，直接坐上去；坐上去的同时，**内圈必须有一个人主动起身让位**
- **闭合鱼缸**：内圈坐满。讨论一段时间（15–20 分钟）后，内圈**整体退出**，外圈另一批人进入，组成新内圈继续同一话题

**它最妙的地方在"空椅子"**。那把椅子把发言从"被点名"变成"自己走进去"——不需要举手、不需要被允许、不需要主持人递话筒。一个人站起来走向那把椅子的动作，本身就是一次公开的表态。

**它适合的场合**：有一个真话题、观点有分歧、人多但需要深度。**不适合**：需要逐人表决、需要正式决议、或者内圈的人其实没什么可说。

## 2. 核心规则

### 准备

- **座位**：内圈 5–7 把椅子（**6 把是最优**，加 1 把空椅共 7 把）；外圈同心圆，层间距 ≥ 1.2 米
- **空椅标记**：空椅上放一个显眼的东西（彩色坐垫/卡片），让人一眼看出"这把是可以坐的"
- **场地**：任何能摆同心圆的房间。**不要用剧场式排排坐**，那会让外圈变成观众席
- **话题**：必须是一句**有张力**的话，不是"关于 XX 的思考"

### 规则（开放鱼缸）

1. 内圈 5–6 人就座，**留 1 把空椅**
2. 引导师给出话题，内圈开始真实对话（不是轮流发言）
3. **外圈只观察、倾听，不插话、不鼓掌、不嘘声**
4. 任何外圈的人想发言：**直接走到空椅坐下**
5. 坐下的同时，**内圈必须有一个人主动起身，把椅子空出来**（不许两个人挤）
6. 起身的人回到外圈，可以稍后再进来
7. 全程不设发言顺序、不限时长，但引导师可在极端失衡时介入
8. 到时后引导师收束，内圈最后各用一句话总结

### 规则（闭合鱼缸）

1. 内圈坐满 6 人，开始讨论 **15–20 分钟**
2. 时间到，**内圈全体起立退出**，回到外圈
3. 外圈中想继续的 6 人进入内圈，**新内圈先花 3 分钟"接管"**：复述上一轮听到的关键分歧
4. 新内圈继续讨论同一话题 15–20 分钟
5. 重复 2–4 轮，最后一轮结束做全场收束

### 两种模式怎么选

| 模式 | 适合 | 优点 | 风险 |
|---|---|---|---|
| **开放鱼缸** | 话题有争议、需要多方立场进来 | 流动性强，随时能补充观点 | 容易变成"轮流发表意见"，对话破碎 |
| **闭合鱼缸** | 需要层层深入、希望更多人完整体验内圈 | 每轮都能深聊，轮换彻底 | 换人时容易丢掉上轮脉络 |

> 实战建议：**前两轮用闭合（保证深度），最后一轮改成开放（保证收口）**。

### 流程（90 分钟 / 闭合 3 轮）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 摆位 + 讲规则 | 10 min | 同心圆就座，讲"只听不说"与换人规则 |
| 第 1 轮 | 18 min | 内圈讨论 |
| 接管 | 4 min | 新内圈复述上轮分歧 |
| 第 2 轮 | 18 min | 内圈讨论 |
| 接管 | 4 min | 同上 |
| 第 3 轮（转开放） | 20 min | 留空椅，允许自由进出 |
| 全场收束 | 16 min | 引导师提炼分歧点与共识点，不强行统一 |

## 3. 引导要点

### 讲解脚本（2 分钟）

> 里面这 6 把椅子是鱼缸，外面是水。
>
> 鱼缸里的人说话，水里的人听。听的时候**不要插话、不要点头、不要笑**——你们的任何反应都会影响里面的人说什么。
>
> 但里面有一把空椅子。**任何想说话的人，不用举手，直接走过去坐下。** 你坐下的同时，里面会有一个人站起来让位。
>
> 我说一句实话：这把椅子会空很久。因为站起来走过去，比举手难得多。但只要你走过去一次，后面就会有人跟着。

### 引导师在场边做什么

- **死守"外圈不反应"这条规则**。外圈一点头、一叹气，内圈就开始表演了
- **空椅久空时不要点名**。可以说一句"这把椅子还在等"，然后闭嘴。点名会毁掉整个设计
- **保护"让位"的顺畅**：第一次换人时，内圈往往会僵住，没人愿意起身。提前跟内圈打好招呼："有人进来，最近的那个人起身"
- **闭合模式里，接管环节必须真的做**。新内圈不复述，就等于重新开始聊天
- **不让内圈变成"专家席"**：如果内圈全是领导，这场就只是"领导座谈 + 观众"。**内圈必须混编**（职级、部门、立场）
- **收束时不强行统一**：鱼缸的产出是"分歧被听清楚了"，不是"达成一致"

### 四个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 空椅没人坐 | 整场 90 分钟，空椅一直空着 | 职级压力；或话题与外部人无关 |
| 内圈表演 | 内圈说话时不断看外圈反应，语句变得"正确" | 外圈没有守住"不反应" |
| 轮流发言 | 内圈 6 人自动变成"每人讲 3 分钟" | 引导师没强调"这是对话，不是发言" |
| 领导占缸 | 内圈 6 人里 4 个是管理层 | 组内圈时按职级挑人 |

### 语言禁区

- ❌「有没有人想上来分享一下？」——这是点名邀约，比空椅难十倍
- ❌「大家安静，听 X 总说完」——一句话把鱼缸变回主席台
- ✅「这把椅子空着，我先不说话。」
- ✅「刚才有两个相反的看法，谁能把它们都说清楚一遍？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 空椅一共被坐过几次？第一次是在第几分钟？
- 走出去坐下的人，和一直坐在外圈的人，有什么共同特征？
- 内圈有没有出现"轮流发言"？从第几分钟开始的？
- 收束时，能说清楚的分歧有几条？

### Feelings（感受）

- 坐在外圈听的时候，有没有某一刻特别想说话？为什么没站起来？
- 走进去坐下那一刻，什么感觉？
- 被别人让位给你的时候，什么感觉？

### Findings（发现）

- 为什么"自己走过去"比"被点名"难，但也更有分量？
- 外圈"不反应"这条规则，为什么是必须的？（因为观众的反应会让发言者开始表演，而不是思考）
- 内圈如果全是领导，会发生什么？（真话消失，只剩正确的话）
- 为什么鱼缸的产出是"分歧被听清楚"，而不是"达成共识"？

### Future（应用）

- 我们团队里，谁永远是"内圈"，谁永远是"外圈"？这个结构是怎么形成的？
- 我们的会议里，有没有"愿意就能说"的通道？还是必须先举手、被允许？
- 上一次开会，有几个人全程没说过话？他们为什么不说？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（20–30） | 内圈 5 人 + 外圈 15–25 人；1–2 轮即可 |
| 人数多（200–300） | **多缸并行**：分 4–6 个区域各开一缸，结束后各大组分享（这是官方推荐的用法，特别适合大型研讨会） |
| 只有 45 分钟 | 单轮开放鱼缸 + 15 分钟收束，内圈 6 人 |
| 线上版 | 内圈开摄像头，外圈关麦；"坐进空椅"= 自行打开麦克风并申请上台 |
| 高敏感议题 | 内圈改为**匿名代表**（每人代表一个"角色"而不是自己），降低个人风险 |
| 想强化"倾听" | 增加规则：内圈每说完一段，必须有一人**复述**后才能继续 |
| 跨部门听证 | 内圈 = 提需求的部门，外圈 = 交付方；只做 1 轮，最后交付方回应 |
| 年会分论坛 | 3 缸并行，主题不同，参与者自选 |
