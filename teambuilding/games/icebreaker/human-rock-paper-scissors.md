# 人体石头剪刀布（Human Rock-Paper-Scissors / 团体猜拳）

> **一句话**：五十个人一起出招，只要有一个人出错了，全队直接判负——所以赢的不是运气，是"能让大家同时做同一个动作"。

| **游戏名称** | 人体石头剪刀布（Human Rock-Paper-Scissors / 团体猜拳 / 巨型猜拳） |
| **目的标签** | 口令同步 · 集体一致 · 快速决策 |
| **形式标签** | 室内 / 户外均可 · 两队对抗 · 站姿/方阵 |
| **人数** | 全场 40–300 人（分 2 队或多队方阵，每队 20–100 人） |
| **时长** | 15–30 min |
| **难度** | ⭐ 低（规则 30 秒，做到一致很难） |
| **道具需求** | 无（零道具，划线即可） |
| **场景标签** | 破冰暖场 · 年会开场 · 运动会间隙 · 大型活动填充时间 |
| **核心目标** | 用"一个人出错全队输"的规则，让"协调"变成有代价的事 |

---

**团建核心价值**：
- 🗣️ 口令同步：全队必须在同一瞬间做同一个动作
- 🎯 集体一致：个体的"自由发挥"在这里是负资产
- ⚡ 快速决策：每轮只有 15 秒商量
- 😂 零门槛：不需要体能、不需要道具、不需要场地

## 1. 游戏概览

把"石头剪刀布"放大到几十上百人：**全队统一出一个手势**，两队对抗。

手势：

| 出招 | 动作 |
|---|---|
| **布** | 双手高举过头，手掌张开 |
| **石头** | 双手叉腰，身体微蹲 |
| **剪刀** | 双臂向两侧平举张开，一前一后 |

**核心规则只有一条，但它是整个项目的灵魂**：

> **全队必须完全一致。只要有一个人出的和别人不一样，全队直接判负——不管手势本身赢不赢。**

这条规则把"运气游戏"变成了"协调游戏"。50 个人要在一瞬间做出同一个动作，靠的不是默契，是**发令**：谁喊？喊什么？大家看谁？

## 2. 核心规则

### 准备

- **场地**：任何空地。两队相隔 5–8 米面对面站立，或排成方阵
- **队形**：建议**方阵**（横纵对齐），便于裁判从正面看整体
- **裁判**：1 名主裁站在侧面（能看清全队），1–2 名副裁

### 规则

1. 两队面对面，各自围成一小圈**商量本轮出什么**（时间 **15 秒**）
2. 裁判喊「预备——出！」，两队**同时**做出手势
3. **判定顺序（不可颠倒）**：
   - **第一步：先判一致性。** 队内任何一人与其他不同 → 该队**直接判负**
   - **第二步：双方都一致，再按石头剪刀布判胜负**
   - **第三步：双方都一致且手势相同 → 平局，重来**
4. 三局两胜；大场可打五局三胜
5. 每轮之间有 **15 秒**商量时间，**不许超时**（超时视为本轮弃权）

### 为什么"先判一致"这么重要

如果先判输赢，队伍会为了赢而牺牲一致（"你出布，我出剪刀"）；如果先判一致，队伍就必须**先解决协调问题**，再考虑胜负。

这个顺序决定了项目是"猜拳"还是"协作"。

### 流程（20 分钟版）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 讲手势 + 演练 | 5 min | 全场一起做三个手势，各 3 次 |
| 第 1 局 | 3 min | 15 秒商量 + 出招 |
| 第 2 局 | 3 min | 同上 |
| 第 3 局（决胜） | 3 min | 同上 |
| 复盘 | 6 min | 见第 4 节 |

### 大场变体：多方阵淘汰

300 人以上时，两队对抗不够热闹。改为：

- 分 6–8 个方阵（每方阵 40–50 人）
- **两两对抗，输的淘汰，赢的晋级**（单败淘汰，3 轮结束）
- 每轮同时进行，主裁站在中央，副裁每方阵 1 名
- 决赛时全场围观，气氛最好

## 3. 引导要点

### 讲解脚本（1 分钟）

> 规则三十秒：布、石头、剪刀。两队同时出。
>
> 但有一条最重要的：**你们队必须所有人出一样的。只要有一个人不一样，全队直接输——就算你们的手势本来能赢。**
>
> 所以你们那 15 秒，不是在想"出什么能赢"，是在想"**怎么让所有人出一样的**"。

### 教练在场边做什么

- **必须严格"先判一致"**。这一条松了，项目就废了
- **判罚要快、要响**："三队，第 7 位和第 22 位不同，三队负！"——让全场听见
- **不要提示"你们喊个口令吧"**。让队伍自己发现"没有发令者"这个问题
- **观察"谁在喊"**：每队通常会自然出现 1–2 个发令者。这个人是谁？是队长，还是嗓门最大的？
- **超时严格执行**。第一次心软，后面全是拖
- **大场淘汰赛时，被淘汰的队不要解散**，让他们当"观众评审"，看下一轮谁最齐

### 三个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 不一致判负 | 每轮都有队因为不一致输 | 没有统一口令，靠"看旁边" |
| 商量变争吵 | 15 秒里三个人各说各的 | 没有决策人 |
| 赢了手势输了比赛 | 手势明明能赢，但队内不齐 | 只顾策略，忽略协调 |

### 语言禁区

- ❌「你们怎么又不齐」——指责不提供方法
- ❌「大家听队长的」——直接给答案，跳过"自己发现"的过程
- ✅「刚才那一轮，你们是怎么做到全齐的？」
- ✅「谁在喊口令？大家看的是谁？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 三局里，有几局是因为"不一致"判负的？
- 每队有几个发令者？他们喊的是什么口令？
- 15 秒商量时间，实际用了几秒？
- 有一次是"手势能赢但不齐"输掉的吗？

### Feelings（感受）

- 出招那一瞬间，你在看谁？
- 因为别人不齐而输掉，什么感觉？
- 全队齐了并且赢了，什么感觉？

### Findings（发现）

- 为什么"先判一致"会让这个游戏完全变样？（因为目标从"赢"变成"先统一步调"）
- 为什么"看旁边"不管用？（因为 50 个人里，你旁边那个人也在看别人）
- 一个团队要同时做同一个动作，最少需要什么？（一个口令 + 所有人看同一个方向）
- 嗓门最大的人，一定是最合适的发令者吗？

### Future（应用）

- 我们团队做决策时，有没有明确的"口令"？（谁宣布、什么时候宣布）
- 我们有没有出现过"方向对了但步调不齐，结果全废"的项目？
- 我们团队里，谁是那个"喊口令的人"？他是被授权的吗？
- 如果一件事需要所有人同时动，我们靠什么保证？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（20–40） | 两队各 10–20 人，打五局三胜 |
| 人数多（200–300） | **多方阵单败淘汰**（6–8 队），3 轮结束 |
| 室内空间小 | 两队只站一排，间距 3 米；或改为"坐着出招"（用手部动作） |
| 想加难度 | 增加"反向"规则：喊"布"要出石头（考验听指令） |
| 想强化"领导" | 指定"发令官"（只有他能喊），复盘"授权与服从" |
| 想强化"沟通" | 商量时间缩到 **5 秒**（逼出极简沟通） |
| 想降火气 | 取消淘汰，改为积分制（每轮胜 1 分，打 6 轮） |
| 运动会间隙填充 | 用"多方阵淘汰"，5 分钟一轮，最适合填场 |
