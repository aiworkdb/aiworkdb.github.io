# 两真一假（Two Truths One Lie）



| **游戏名称** | 两真一假（Two Truths One Lie） |
| **目的标签** | 破冰热场 · 沟通表达 |
| **形式标签** | 室内 · 任意人数 · 智力 |
| **人数** | 5–30 人（最佳 8–20 人） |
| **时长** | 短篇 10–20 min |
| **难度** | ⭐ 简单 |
| **场景标签** | 团建 · 培训 · 通用 |
| **核心目标** | 快速破冰、让参与者记住彼此、发现共同点 |

---

**团建核心价值**：
- 💗 自我披露：说出真实的三件事的敞开心态
- 🔍 观察判断：从细节读出真假的洞察
- 🧭 深入了解：游戏化的彼此背景探索

## 2. 核心规则

### 流程

```
1. 每人准备三个关于自己的陈述句：
   - 两句是真的
   - 一句是假的（编的）

2. 轮流站在大家面前，读出三句话（不说是真是假）

3. 其他人投票：哪一句是假的？
   - 举手投票，或写在纸上

4. 公布答案：哪句是假的？

5. 可以请当事人展开讲一下那句"真的"背后的故事
```

### 陈述句示例

```
好的陈述句（具体、有画面感）：
  ✅ "我小时候在家养过 6 只猫"
  ✅ "我曾经一个人背包旅行过 3 个国家"
  ✅ "我大学学的是兽医专业"

不好的陈述句（太模糊，无法验证）：
  ❌ "我喜欢旅行"（太普通，没人会猜是假的）
  ❌ "我是个好人"（无法验证，不好玩）
```

### 胜负判定

- **无胜负**（推荐）：纯粹破冰，重点是分享和了解
- **竞赛模式**：猜对最多的人获胜（适合竞争氛围强的团队）

## 3. 引导要点

### 如何讲解（1 分钟讲完）

```
"大家每人想三个关于自己的句子：两句是真的，一句是编的。
然后读给大家听，大家投票猜哪句是假的。
最后你公布答案，还可以讲讲那两句'真的'背后的故事。

举个例子，我说三句：
  1. 我小时候在家养过 6 只猫
  2. 我大学学的是兽医专业
  3. 我曾经一个人背包旅行过 3 个国家
你们猜，哪句是假的？

（等大家猜）
答案是：第 2 句是假的——我没学过兽医😄

好，现在给大家 2 分钟，想一想自己的三句话。"
```

### 示范要点

示范时有三件事必须做到，否则场子热不起来：

1. **三条都要具体**。不要「我喜欢旅行」，要「我一个人背包走过 3 个国家」。细节是可信度的来源，也是笑点的来源。
2. **假的那条要「像真的」**。最差的选择是编一条明显离谱的（「我是宇航员」），全场一秒猜中，气氛就散了。
3. **公布答案后补一个故事**。哪怕是假的那条，也说说「为什么会编这个」——这一句往往比真话更有信息量。

### Feelings（感受）

- 编那条假话时，你有没有一点犹豫？编的是什么方向的内容？
- 大家一致猜错时，你是得意，还是有点失落？
- 听到别人讲真话背后的故事时，你对 TA 的印象有变化吗？

### Findings（发现）

- 哪一条最容易被猜中？哪一条最难？为什么？
- 大家猜的依据是什么？太离谱，还是太符合人设？
- 「被秒猜中」说明你更真实，还是更容易被预判？
- 今天你新认识的这个人，和你原本以为的一样吗？

## 4. 物资清单

零道具也能开：口头说三条、举手投票即可。

| 物资 | 数量 | 备注 |
|------|------|------|
| 纸片/便签 | 每人 3 张 | 可选，写下三条陈述后匿名投递，悬念更足 |
| 笔 | 每人 1 支 | 可选，配合纸片使用 |
| 投票卡（A/B/C） | 每人 1 套 | 可选，人多时举手看不清，举牌更快 |
| 计时器 | 1 个 | 可选，每人限时 60 秒，防止讲太久 |
