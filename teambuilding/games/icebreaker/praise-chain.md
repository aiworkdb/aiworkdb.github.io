# 夸夸接龙（Praise Chain / 全员夸夸接龙）

> **一句话**：不能说"你很好"，必须说出一件具体的事——所以这个游戏真正在测的，是你到底有没有看见过身边的人。

| **游戏名称** | 夸夸接龙（Praise Chain / 夸夸圈 / 具体赞美） |
| **目的标签** | 正向反馈 · 具体观察 · 关系修复 |
| **形式标签** | 室内 / 户外均可 · 围圈 · 坐姿/站姿 |
| **人数** | 全场 20–200 人（围成 1 个大圈，或分 4–8 个小圈同时进行） |
| **时长** | 20–40 min |
| **难度** | ⭐ 低（规则简单，说具体很难） |
| **道具需求** | 无（零道具） |
| **场景标签** | 团队氛围 · 月末复盘 · 项目收尾 · 跨部门 · 女性占比高团队 |
| **核心目标** | 用"必须具体"这条规则，暴露团队平时的反馈有多空 |

---

**团建核心价值**：
- 💬 正向反馈：把"谢谢"变成"谢谢你做了什么"
- 👀 具体观察：证明你真的看见过对方，而不是客套
- 🔗 关系修复：低成本化解小隔阂
- 🚫 反空话：禁止"很好""很棒""辛苦了"

## 1. 游戏概览

全员围成一圈，依次夸自己**右手边**的同事。规则只有一条，但极难：

> **必须说出一个具体的优点，或者一件具体的事。不能说"你很好""你很棒""你辛苦了"。**

**为什么这条规则这么关键**：夸奖的内容会立刻分成两类——

| 类型 | 例子 | 说明 |
|---|---|---|
| **空话** | 「你人很好」「你工作很努力」 | 说了等于没说，对方听完没有感觉 |
| **具体** | 「上次上线出问题，你半夜爬起来处理，第二天还照常上班」 | 对方会记住这句话很久 |

这个项目真正的产出不是"气氛变好"，而是**让每个人意识到：我对身边的人，知道得太少了。**

## 2. 核心规则

### 准备

- **队形**：围成一圈（20–30 人一圈最佳）。人多久分圈，每圈 15–25 人
- **顺序**：统一向右手边夸（每人既是"夸人者"也是"被夸者"，闭环）
- **场地**：安静即可。嘈杂环境会让人听不清，效果大打折扣

### 规则

1. 从任意一人开始，夸自己**右手边**的人
2. 内容必须满足以下**任一条**：
   - 说出一件**具体发生过的事**（时间/场景 + 他做了什么）
   - 说出一个**具体的行为特征**（"每次评审你都提前看完文档"）
3. **禁止用语**：很好、很棒、很努力、辛苦了、人不错、能力强（这些是"标签"，不是"观察"）
4. 不许重复前面用过的说法（逼人想新的）
5. 每人 **20–40 秒**，超时由主持人温和打断
6. 被夸的人**只能回答"谢谢"**，不许谦虚推辞（"没有没有"会打断这个环节）
7. 全部轮完后，进入"自由补充"：想补充夸谁就站起来说（可选）

### 流程（30 分钟版）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 讲规则 + 反例 | 4 min | 举 3 个"空话"例子和 3 个"具体"例子 |
| 第 1 圈（破冰） | 12 min | 顺时针夸右手边 |
| 自由补充 | 6 min | 想夸谁就站起来 |
| 复盘 | 8 min | 见第 4 节 |

## 3. 引导要点

### 讲解脚本（3 分钟）

> 规则一句话：夸你右手边这个人。但**必须具体**。
>
> 不能说他"人很好""工作很努力""辛苦了"——这些话我全部会打断。
>
> 要说什么？说一件**他具体做过的事**。比如"上个月那个客户投诉，是你一个人打了三个小时电话安抚下来的"。
>
> 我先说一句可能不太好听的：**如果你说不出来，不是你不会夸人，是你平时没看见。**

### 教练/主持人做什么

- **必须真的打断空话**。第一次有人说"他人很好"，立刻停下来："换一个，说一件具体的事。" 这一刀切下去，后面全场都会认真
- **帮卡住的人**：不要替他夸，而是提示"他最近帮你做过什么事？"——把问题还给他
- **控制时长**：20 秒没说完就温和打断，否则会拖到 1 小时
- **保护被夸的人**：不许起哄、不许调侃（尤其异性之间，玩笑很容易变味）
- **记录"空话率"**：这是复盘最有力的数据
- **收尾时不要总结陈词**，让最后一句话落在具体的人身上

### 三个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 空话连篇 | "他很负责""他很好相处" | 平时只看到岗位，没看到人 |
| 卡壳沉默 | 有人站了 30 秒说不出话 | 真的不了解身边的人 |
| 变成吐槽 | "他唯一的好处是……" | 团队氛围本身有问题，需先处理 |

### 语言禁区

- ❌「大家随便说说就行」——"随便"会让全场退回客套
- ❌「来，说个优点，越夸张越好」——夸张会变成表演，真诚消失
- ✅「说一件他具体做过的事。」
- ✅「你是什么时候注意到这一点的？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 全场有几句话是"具体的"？几句是"标签式的"？
- 有几个人卡壳超过 20 秒？
- 你被夸的那句话，具体到什么程度？（有场景吗？有时间吗？）
- 被夸的内容，有几件是你自己都忘了的？

### Feelings（感受）

- 说不出话的时候，什么感觉？
- 被具体夸到某件事时，什么感觉？（意外？感动？还是"原来有人看见"？）
- 听到"他人很好"这种话时，什么感觉？

### Findings（发现）

- 为什么"具体"这么难？（因为它要求你真的观察过，而不只是共事过）
- 为什么"你很棒"没有效果？（因为它是评价，不是看见）
- 一个团队如果只在下班后聊工作，会失去什么？
- 为什么被夸的人只能回答"谢谢"？（因为谦虚推辞会中断正向反馈）

### Future（应用）

- 我们团队上一次给出具体的正向反馈，是什么时候？
- 我们平时说"辛苦了"，是真的看见了，还是口头禅？
- 我们对身边的人，知道多少"工作之外"的事？
- 下周，我们能不能对一个人说一句具体的话？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（10–15） | 一圈即可，每人 40 秒，可以说 2 件 |
| 人数多（150–200） | **分 8 个小圈**同时进行（每圈 20 人），最后各圈选 1 句最打动人的话全场分享 |
| 只有 15 分钟 | 只夸右手边 1 人，每人 20 秒，不做自由补充 |
| 新团队（彼此不熟） | 改为"夸左手边的人**刚才在这个活动里的一个具体表现**"（有共同经历才夸得出来） |
| 关系紧张团队 | 改为"我观察到的一件事 + 我的一句感谢"，**禁止评价**，降低冲突风险 |
| 想加"自我觉察" | 每人夸完，被夸的人说一句"我没想到有人注意到这个" |
| 项目收尾 | 改为"这个项目里，你最想感谢谁的一件事" |
| 线上版 | 每人发一条 @某人 的具体感谢到群里，禁止"辛苦了" |
