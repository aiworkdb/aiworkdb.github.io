# 人类宾果（Human Bingo）



| **游戏名称** | 人类宾果（Human Bingo） |
| **目的标签** | 破冰热场 · 沟通表达 |
| **形式标签** | 室内 · 任意人数 · 智力 |
| **人数** | 建议 8–50 人 |
| **时长** | 热身 5–15 min |
| **难度** | ⭐ 简单 |
| **场景标签** | 团建 · 培训 · 通用 |
| **核心目标** | 快速破冰、让参与者记住彼此名字、发现共同点 |

---

**团建核心价值**：
- 👋 主动搭讪：找到话题开口的第一步
- ✨ 共同点发现：原来你也是的惊喜时刻
- 🏷️ 名字记忆：游戏化记住每个人

## 2. 核心规则

### 准备

- 提前制作 **宾果卡**（Bingo Card）：一张纸分成 5×5 的格子
- 每个格子里写一句描述，例如：
  - "去过 3 个以上国家"
  - "会玩一种乐器"
  - "养过宠物"
  - "小时候梦想的职业是警察/医生/老师"
  - "能说三种以上方言"
  - "参加过马拉松"
  - "有纹身"
  - "会做饭"
  - "害怕蜘蛛"
  - "出生在夏天"
  - _（中间格子可写"自由格"或"我是______"）_

### 流程

```
1. 每人发一张宾果卡（或用PPT投影统一卡片）
2. 参与者需要在房间里走动，找到符合格子里描述的人
3. 找到后，请对方在格子里签名字（每人只能帮你签一个格）
4. 第一个填满一行/一列/全卡的人喊"Bingo！"，游戏结束
5. 请"Bingo"的人简单介绍：你找到了哪些有趣的人？
```

### 胜负判定

- **个人赛**：第一个喊 Bingo 的人获胜
- **团队赛**：分组竞赛，全组填满最多格子的组获胜
- **无胜负**：纯粹破冰，不设获胜者，所有人完成即结束

---

## 3. 引导要点

### 如何讲解（1 分钟讲完）



> 第一个填满一整行的人喊 Bingo，然后我们请他介绍一下找到了哪些有趣的人。


### Feelings（感受）

- 走到一个不太熟的同事面前开口，你的第一反应是什么？犹豫了多久？
- 有人主动来找你填格子时，你是什么感受？
- 格子快填满却差最后一格时，你是随便找人凑，还是非要找到那个人？

### Findings（发现）

- 你填的格子里，多少是本来就知道的，多少是今天才知道的？
- 谁是全场被找次数最多的人？为什么是 TA？
- 有没有人从头到尾没被找过？如果有，说明了什么？
- 这个游戏和你们公司「跨部门找人办事」有什么相似？

### 准备时间

- **有现成卡片**：0 准备时间
- **需要制作卡片**：10–15 分钟

## 4. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
