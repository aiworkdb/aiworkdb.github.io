# 大风吹（Big Wind Blows / 大风吹小风吹）

> **一句话**：椅子永远少一把，所以每一轮都有人站着——而站着的那个人，下一轮由他决定谁必须换座。

| **游戏名称** | 大风吹（Big Wind Blows / 大风吹小风吹） |
| **目的标签** | 快速破冰 · 观察他人 · 打破小圈子 |
| **形式标签** | 室内 / 户外均可 · 围圈坐 · 站/坐切换 |
| **人数** | 全场 20–300 人（围成 1 个大圈，或分成多个圈同时进行） |
| **时长** | 20–40 min |
| **难度** | ⭐ 低（规则 1 分钟） |
| **道具需求** | 有（椅子，数量 = 人数 − 1；无椅子可用地贴/粉笔圈） |
| **场景标签** | 破冰暖场 · 新员工 · 大型活动开场 · 跨部门融合 · 年会 |
| **核心目标** | 用"必须换座"逼人离开熟人身边，是打破小圈子最快的机制 |

---

**团建核心价值**：
- ⚡ 快速破冰：第一轮 30 秒内全场就动起来了
- 👀 观察他人：喊特征的人必须观察全场
- 🔄 打破小圈子：不许坐回原位、不许坐相邻位
- 🎭 轮换主导权：每一次"站着的人"都换，人人有当主持的机会

## 1. 游戏概览

所有人围成一圈坐，**椅子比人少一把**。一个人站在中间（没有座位），他喊：

> 「大风吹——吹**戴眼镜的人**！」

所有符合条件的人必须**立刻起身换座位**。中间的人趁机去抢座位。抢不到座位的人，成为新的"风"，站到中间继续喊。

**它的机制非常精巧**：

| 设计 | 作用 |
|---|---|
| 椅子少一把 | 保证永远有一个人站着（游戏不会僵死） |
| 不许坐回原位、不许坐相邻位 | 强制打破熟人圈 |
| 喊"特征"而不是"名字" | 逼人去观察全场，而不是只认识熟人 |
| 站在中间的人换人 | 主持权轮换，避免一个人一直当主角 |

## 2. 核心规则

### 准备

- **椅子**：数量 = 人数 − 1。无椅子可用地贴/粉笔在地上画圈
- **队形**：围成一个圆，**椅子朝内**，圈中间留空
- **场地**：椅子之间留 40–50 厘米空隙（方便穿行，也防绊倒）

### 规则

1. 一人站中间当"风"，其余全部坐下
2. "风"喊：**「大风吹——吹 ___ 的人！」**（后面接一个**可见特征**）
3. 所有符合特征的人**必须立刻起身换座**
4. 换座时有两条限制：
   - **不许坐回自己的原位**
   - **不许坐自己左右相邻的两个座位**
5. "风"也同时抢座。**抢不到座位的人成为新"风"**
6. 不符合特征的人**不许动**；动了的人罚当"风"
7. **小风吹**：喊「小风吹——吹 ___ 的人」时，**不符合特征的人才换座**（反向规则，用来加难度）
8. 特征必须是**当场可见或公认**的（如"穿黑色鞋的人""戴手表的人""今天喝了咖啡的人"），不许喊"心里想什么"

### 特征库（按难度分级）

| 难度 | 示例 |
|---|---|
| 简单（一眼可见） | 戴眼镜、穿黑色衣服、穿运动鞋、扎头发、戴手表 |
| 中等（需观察） | 手机是深色的、背包是双肩的、今天穿了两件以上 |
| 进阶（需认识彼此） | 入职不满一年的、家里有宠物的、会做饭的、出过差的 |
| 高难（反向/组合） | 「小风吹」+「没戴眼镜但穿深色鞋的人」 |

### 流程（30 分钟版）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 讲规则 + 演练 | 4 min | 先喊一次"所有人"（全员换座），熟悉节奏 |
| 第 1 轮（简单特征） | 8 min | 快速热身 |
| 第 2 轮（中等特征） | 8 min | 开始需要观察 |
| 第 3 轮（进阶特征 / 小风吹） | 6 min | 加难度 |
| 收尾 + 复盘 | 4 min | 见第 4 节 |

## 3. 引导要点

### 讲解脚本（1 分钟）

> 椅子比人少一把，所以永远有一个人站着。
>
> 站着的人喊：「大风吹——吹戴眼镜的人！」所有戴眼镜的人必须起来换座位。站着的人趁机抢座位。抢不到的，就站到中间，换你来喊。
>
> 两个不许：**不许坐回原位，不许坐自己旁边那两把。**
>
> 第一轮我喊：**大风吹——吹所有人！**

（第一次喊"所有人"是关键：让全场立刻动起来，同时让所有人熟悉"换座"这个动作。）

### 教练在场边做什么

- **第一轮必须喊"所有人"**，把场子热起来
- **控制"特征质量"**：如果有人喊"吹男生"（一半人），会导致大规模混乱且容易撞。建议引导到"三类人以内"的特征
- **盯安全**：椅子密集 + 快速跑动 = 绊倒风险。提前把椅子间距拉开，并禁止推挤
- **观察"谁只坐熟人旁边"**：这是复盘的好素材
- **每 3–4 轮强制换一次"风"**（如果同一人总抢不到座位，反而会尴尬）
- **大场（150 人以上）必须分圈**：分成 4–6 个圈同时进行，各圈 30–40 人，否则跑动距离太长

### 三个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 没人动 | 喊了一个特征，全场互相看，没人起身 | 特征太冷门，或大家不确定自己符不符合 |
| 全员乱撞 | 喊"吹穿鞋的人"（等于所有人） | 特征太宽泛 |
| 熟人抱团 | 换座后又坐回同事旁边 | 没有严格执行"不许坐相邻位" |

### 语言禁区

- ❌「吹胖子」「吹戴牙套的」——涉及身体特征或可能造成羞辱，**必须立即制止**
- ❌「吹长得好看的」——主观标准，会冷场或伤人
- ✅「这个特征全场至少要有 3 个人符合，也至少要有 3 个人不符合。」
- ✅「刚才你为什么一直坐在同一个区域？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 全场有几个人换了 3 次以上座位？有几个人一次没换？
- 你一共坐到过几个不同的位置？覆盖了圈的几个区域？
- 有几次是"看到别人站起来，才跟着站"的？
- 谁喊的特征最有趣？谁喊的特征最难？

### Feelings（感受）

- 椅子被抢走、自己站着的时候，什么感觉？
- 坐到一个全是陌生人的区域，什么感觉？
- 当"风"喊出特征、看全场跑起来的时候，什么感觉？

### Findings（发现）

- 为什么"椅子少一把"这个设定这么重要？（保证永远有动力，不会冷场）
- 为什么"不许坐相邻位"？（因为人会自动回到熟人身边，这个规则强行打断）
- 喊特征的时候，你会先看谁？（熟人，还是陌生人）
- 一个新人进入团队，最像这个游戏的哪个时刻？

### Future（应用）

- 我们团队里，有没有"永远坐在同一个区域"的人？
- 跨部门协作时，我们是不是也习惯只找熟人？
- 如果我们的工作里也有"椅子少一把"（资源不足），会发生什么？
- 上一次你主动坐到"陌生人那一桌"，是什么时候？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（20–30） | 1 个圈即可；特征可更细（需认识彼此） |
| 人数多（150–300） | **分 4–6 个圈同时进行**，各圈 30–40 人；或改为"站立版"（不用椅子，用地面标记） |
| 无椅子 | 用粉笔/胶带在地上画圈，或每人站一张报纸 |
| 膝盖/腰部不便者 | 改为"站立版"（全场站立，喊到的人蹲下），减少起坐 |
| 想加难度 | 加入"小风吹"（反向）；或要求"喊完必须 5 秒内全部到位" |
| 想强化"认识彼此" | 特征限定为"入职时间""家乡省份""爱好"等需要开口问的信息 |
| 想强化"跨部门" | 加规则：**换座后必须和新邻座握手并说出对方名字** |
| 年会开场 | 用一个"全员特征"（如"吹今年加过班的人"）做笑点开场 |
