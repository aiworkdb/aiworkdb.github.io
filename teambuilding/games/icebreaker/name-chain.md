# 名字接龙（Name Chain）



| **游戏名称** | 名字接龙（Name Chain） |
| **目的标签** | 破冰热场 · 沟通表达 |
| **形式标签** | 室内/户外 · 任意人数 · 智力 |
| **人数** | 建议 6–40 人 |
| **时长** | 热身 5–10 min |
| **难度** | ⭐ 简单 |
| **场景标签** | 团建 · 培训 · 通用 |
| **核心目标** | 记住彼此名字、降低陌生感、快速热身 |

---

**团建核心价值**：
- 🏷️ 名字记忆：快速记住每个人的名字
- 👂 专注倾听：听清上一个人的信息再传递
- ⚡ 快速热身：几分钟热场的气氛唤醒

## 2. 核心规则

### 流程

```
1. 所有人站成一个圆圈，面向中央

2. 从任意一人开始（通常教练指定或自愿）：
   - 大声说自己的名字
   - 同时做一个动作（比心、跳跃、摆 pose 均可）
   - 例如："我叫张三！"（同时比心）

3. 左边的人跟着做：
   - 先复述前一个人的名字+动作
   - 再说自己的名字+动作
   - 例如："他是张三！"（重复张三的动作）"我叫李四！"（同时摆 pose）

4. 依次顺时针传递，每个人都要：
   - 复述前一个人的名字+动作
   - 再说自己的

5. 转完一整圈后，最后一个人要复述所有人的名字+动作
   （或改为：教练随机点名，被点的人要说出左边和右边人的名字）
```

### 变体规则（降低难度）

- **只说名字，不做动作**：去掉肢体记忆，适合非常内向的场合
- **只复述前两个人**：不要求复述全部，降低记忆压力
- **分成 6–8 人小圈**：大圈压力太大，拆小之后每人被点名的次数反而更多
- **允许提示**：卡住的人可以问一句「你名字的第一个字是什么」

### Feelings（感受）

- 快轮到你的时候，你在干什么？（默念？紧张？走神？）
- 有人把你的名字或动作记错了，你是什么感受？
- 全部复述成功那一刻，你是松了一口气，还是有点小骄傲？

### Findings（发现）

- 你们是怎么记住这么多名字的？靠联想、动作，还是位置？
- 谁的动作最容易被记住？为什么？
- 今天你记住了几个人？散场一周之后，还能叫出几个？
- 名字记不住，通常不是记性问题——那是什么问题？

## 3. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 场地 | 1 块 | 能围成一圈即可，无需任何道具 |
| 软球/玩偶 | 1 个 | 可选，抛球点名比按顺序点名紧张得多 |
| 姓名贴 | 每人 1 张 | 可选，新人多、跨部门场合能降低门槛 |
| 计时器 | 1 个 | 可选，记录复述全圈用时，做前后对比 |
