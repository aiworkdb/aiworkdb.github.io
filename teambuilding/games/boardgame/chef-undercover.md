# 卧底大厨

> **一句话**：一边合作出菜，一边找出内鬼——从模糊的怀疑走到具体举证，顺带体会一次被冤枉的滋味。

> 这份文档不是规则说明书，而是**团建使用指南**。完整规则和打印道具在桌游库，这里只解决一件事：怎么把这款桌游带成一场有团队成长价值的团建。

## 🎯 团建核心价值

- **观察与表达**：谁在破坏？证据全在细节里——谁总在任务环节掉链子、谁的言行对不上票。游戏逼你把「模糊的怀疑」变成「具体的举证」
- **信任与验证**：诚实厨师要合作完成任务，又要提防身边的人。合作的底线在哪里、信任的半径有多大，是这款游戏的暗线
- **被冤枉的体感**：被错票出局的人，第一视角体验「百口莫辩」——这种体感是团队信任最好的疫苗：以后投票指控别人前，先想想证据够不够
- **压力下的表现**：卧底要在众目睽睽下搞破坏，诚实方要在时限内揪人。两种角色的压力表演，比任何性格测试都直观

## ⏱️ 团建流程编排（60 分钟版）

| 阶段 | 时长 | 内容 | 教练动作 |
|------|------|------|---------|
| 导入 | 5 min | 情境代入：「餐厅明天开业，后厨混进了卧底」 | 强调：这局没有输家惩罚，只有身份体验 |
| 规则 | 8 min | 讲透：身份分配、任务环节怎么破坏、审问怎么投票 | |
| 游戏 | 25 min | 连开 2–3 局，每局强制换身份 | 记录：谁举证最有力？谁在被冤枉时怎么应对？ |
| 复盘 | 16 min | 复盘三问 + 4F 框架 | |
| 迁移 | 6 min | 连接团队信任与沟通场景 | |

## 🎓 引导要点

- **分组**：6–8 人一桌最佳（2 卧底 + 4-6 诚实）；4 人局卧底太多体验差，不建议
- **强制换身份**：每局重新抽身份，尤其让「当卧底总被抓」和「当卧底从没被抓」的人都体验两种角色——视角切换是这款游戏的核心价值
- **举证规则**：投票指控必须说「我怀疑 X，因为____」——空口指控无效。这条规则是「结构化表达」的硬训练，教练要守死
- **控场红线**：允许演技和欺骗（游戏的一部分），不允许人身攻击和贴标签；票型可以撕，关系不能撕
- **关键介入点**：如果出现「跟风票」（大家票数集中在第一个被提名的），暂停问一句：「除了他先被提到，还有别的理由吗？」

## 🔥 复盘三问（快速版）

1. 你举证最有力的一次指控，证据是什么？
2. 被冤枉（或差点被冤枉）的时候，你做的第一件事是什么？
3. 现实工作里，我们评价一个人「行不行」，证据链完整吗？

## 🎬 游戏后深度复盘（4F 框架）

| 步骤 | 时长 | 引导问题 |
|------|------|---------|
| **Facts 事实回顾** | 3 min | 每局谁赢了？关键转折是哪一轮？决定性证据是什么？ |
| **Feelings 感受分享** | 4 min | 当卧底时什么感觉？被所有人怀疑时呢？错票了好人，真相揭晓那刻什么心情？ |
| **Findings 学习洞察** | 5 min | ① 举证质量：赢家的指控靠证据还是靠感觉？② 跟风现象：有没有票是「因为别人也票他」？③ 信任半径：合作任务时，你对队友的默认信任度是多少？什么事件会击穿它？ |
| **Future 行动迁移** | 4 min | 团队立一条规矩：评价他人前先过举证关（事实+影响+证据）；被误会时先问「你看到的事实是什么」而不是先委屈。 |

## 🎯 适合的培训主题

| 培训主题 | 关键词 | 适用场景 | 迁移重点 |
|---------|--------|---------|---------|
| 信任建立与修复 | 心理安全、信任半径 | 新团队、经历过误会的团队 | 信任靠小事积累，被一件事击穿 |
| 观察与结构化表达 | 举证、事实说话 | 全员适用，管理者尤佳 | 指控前先问证据链 |
| 换位思考与同理心 | 被冤枉的体感 | 爱下结论、贴标签的团队 | 先问事实，再下判断 |

## 👥 人数与场景适配

| 规模 | 适配方案 |
|------|---------|
| 6–8 人（标准桌） | 原版体验，破冰+信任首选 |
| 12–16 人 | 餐厅争霸：两桌同时开局，「米其林评委」巡场，终局两桌交换卧底线索 |
| 20 人+ | 开放后厨区：即玩即走，教练巡回控场；想深度的组队打「三局连庄」 |
| 新员工融入 | 混编分组（新人必须分到不同桌），游戏内的合作任务是天然搭子 |
| 年会/家庭日 | 无淘汰惩罚，家属也能上桌；「餐厅开业」设定全家都有代入感 |
| 线上远程 | 部分适用（身份私信发放，任务用在线表格），体验打七折 |
