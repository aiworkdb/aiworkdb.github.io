# 纸飞机工厂（Paper Airplane Factory）

> **一句话**：三轮生产、同一批人、同一堆纸——第一轮靠催，第三轮靠改流程，产量差三倍。

| **游戏名称** | 纸飞机工厂（Paper Airplane Factory / 流水线改善） |
| **目的标签** | 领导力 · 流程设计 · 标准化 |
| **形式标签** | 室内 · 小组流水线 · 站姿/坐姿 |
| **人数** | 建议 每组 6–12 人（全场 12–48 人） |
| **时长** | 60–80 min |
| **难度** | ⭐⭐ 中等（动作简单，组织难度高） |
| **道具需求** | 有（A4 纸大量 + 卷尺 + 计时器 + 计分板） |
| **场景标签** | 管理层培训 · 流程改善工作坊 · 项目启动 |
| **核心目标** | 让团队亲身体验「提高产量的办法不是催得更狠，而是改掉流程里的等待」 |

---

**团建核心价值**：
- 🏭 分工与瓶颈：一道工序慢，全线都停
- 📏 标准化的价值：同一架飞机，十个人折出十种，验收全废
- 🔁 改善循环：第一轮交付、第二轮复盘、第三轮验证
- 🧑‍💼 领导的位置：站在产线外看，比跳进产线干更有用

## 1. 游戏概览

这是把「精益生产」压缩成 60 分钟的版本，也是最能照出团队真实工作方式的一面镜子。

规则很简单：用 A4 纸折纸飞机，**在限定时间内，产出尽可能多的「合格品」**。合格的定义只有一条——**从起飞线掷出，飞过 3 米线**。

三轮，同样的纸、同样的人、同样的时间：

| 轮次 | 允许的事 | 典型结果 |
|---|---|---|
| 第一轮 | 只有组长能说话，其他人闭嘴干活 | 产量低，废品率高，全组在等某一个人 |
| 第二轮 | 先给 8 分钟讨论流程，再开工 | 产量翻倍，出现分工 |
| 第三轮 | 再加一条：允许改工具、改工位、改标准动作 | 产量再翻，废品率降到底 |

第一轮的场面几乎每次都一样：有人折得快，有人折得慢，慢的那道工序前面堆了一摞纸，后面的人干等着。而组长在拼命喊「快一点」。

**「快一点」从来没让产量提高过。** 这句话值整个课程。

## 2. 核心规则

### 准备

- A4 纸：**每组至少 150 张**（第一轮会大量浪费，纸不够会限制体验）
- 起飞线 + 3 米线：用胶带在地上贴两条平行线
- 计分板：白板或大白纸，写「合格数 / 废品数 / 总耗时」
- 场地：每组一条 4 米长的「产线」空间（桌子拼起来即可）

### 合格标准（必须开赛前演示）

1. 从起飞线后方掷出
2. **飞过 3 米线**（不是落点过线，是飞行轨迹越过）
3. 落地后机身不断裂、不散架

教练先折一架示范，掷一次给大家看「合格长什么样」。标准一旦定下，**全程不得更改**。

### 三轮流程（60 分钟）

| 轮次 | 准备 | 生产 | 验收 |
|---|---|---|---|
| 第一轮 | 2 min（指定组长） | 8 min | 3 min（逐架试飞） |
| 复盘 | — | 8 min | 讨论流程问题 |
| 第二轮 | 8 min（讨论流程） | 8 min | 3 min |
| 复盘 | — | 6 min | 找瓶颈 |
| 第三轮 | 5 min（改工具/工位） | 8 min | 3 min |
| 总复盘 | — | 12 min | 见第 4 节 |

### 第一轮的额外限制（关键设计）

- **只有组长能说话**，其他人全程不许出声（包括不能提建议）
- 组长**不许动手折**，只能站在旁边指挥
- 任何人不得离开自己的位置

这三条会制造出标准的「糟糕管理现场」：组长喊得嗓子哑，组员憋着想法干着急，产线上堆着半成品。

### 第二、三轮放开的权限

| 权限 | 第二轮 | 第三轮 |
|---|---|---|
| 自由讨论 | ✅ | ✅ |
| 组长可动手 | ✅ | ✅ |
| 可重新分工 | ✅ | ✅ |
| 可改工位布局 | ❌ | ✅ |
| 可自制辅助工具（模板、折痕器） | ❌ | ✅ |
| 可改「标准动作」（每人固定折法） | ❌ | ✅ |

## 3. 引导要点

### 讲解脚本（3 分钟）

> 你们现在是一家工厂。产品是纸飞机，客户只有一个要求：**飞过 3 米线**。
>
> 第一轮的规矩：**只有组长能说话**，而且**组长不许自己折**。其他人闭嘴，干自己的活。
>
> 八分钟，能产多少合格品，就是多少。
>
> 我先说一句：第一轮一定很难看，这是正常的。**我要看的不是第一轮的成绩，是三轮之间的差值。**

### 教练在场边做什么

- **第一轮不救场**。让「憋着想法干着急」这个体验完整发生
- **记录第一轮的三件事**：① 组长的原话（尤其「快一点」出现了几次）② 谁最先停下手在等 ③ 半成品堆在谁面前
- **第二轮讨论时坐进去听**。大多数组会讨论「怎么折更快」，很少讨论「怎么分工」。如果没人提分工，第二轮的提升会很有限——**这正是第三轮要用的素材**
- **第三轮前给一句提示**（只给一次）：
  > 「想一件事：你们组里，谁的动作最慢？他前面的那堆纸，是不是一直在等他？」
- **验收要严格**。3 米线是硬标准，别因为「差一点」就放过。标准松了，标准化这一课就没了

### 三个必抓的观察点

| 观察点 | 现象 | 对应概念 |
|---|---|---|
| 瓶颈 | 某个工位前堆着半成品，后面的人干等 | 约束理论：产出由最慢环节决定 |
| 变异 | 十个人折出十种飞机，验收一半飞不过 3 米 | 标准化：没有统一标准就没有稳定质量 |
| 等待 | 三个人在等一个人折完 | 流程浪费：等待比慢更贵 |

### 语言禁区

- ❌（第一轮中途）「你们可以试试分工啊」——毁掉第一轮的对照组
- ❌「你们组怎么这么差」——比较组间会让人把注意力放到面子而非流程
- ✅「你们的瓶颈在哪一道工序？」
- ✅「这十架飞机，有几架是同一种折法？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 三轮的合格数分别是多少？废品数呢？
- 第一轮组长说了几次「快一点」？有用吗？
- 第一轮有几个人在中途停下来等？（等谁？）
- 第三轮有几道工序？每道工序的标准动作是什么？

### Feelings（感受）

- 第一轮憋着想法不能说话，什么感觉？
- 当组长的时候，看着产线堆货，你急吗？急的时候你做了什么？（通常是催）
- 第三轮跑顺的时候，身体感觉有什么不同？（不慌了）

### Findings（发现）

- 产量提升靠的是「更努力」还是「改流程」？（对比第一轮和第三轮的用力程度）
- 为什么第一轮一定会堆货？（因为所有人按同一个节奏做完整架飞机，快的等慢的）
- 标准化到底约束了什么、释放了什么？（约束了个人自由，释放了可预测性）
- 组长在第三轮还喊「快一点」吗？为什么不用喊了？

### Future（应用）

- 我们现在的项目里，谁是最慢的那道工序？大家是不是一直在等他？
- 我们有没有「十个人折十种飞机」的情况？（同一个需求，十个人做出十种结果）
- 上次产量上不去，我们的第一反应是「加人」还是「改流程」？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 时间只有 40 分钟 | 只做两轮（第一轮 + 第三轮），跳过第二轮，对比照样成立 |
| 人数少（< 6） | 改为「每人多道工序」，瓶颈现象同样出现 |
| 人数多（> 48） | 分组同时产线，最后比「第三轮/第一轮」的提升倍率而非绝对数 |
| 想突出质量 | 合格标准加一条：飞机落地后必须机身完整，且能再次掷出 |
| 想突出成本 | 每张纸计价，最后算「单件成本」，会逼出「少浪费」而非「多生产」 |
| 非生产团队（研发/职能） | 把「纸飞机」换成「按模板填表」，流程问题一模一样 |
| 线上 / 远程 | 改为「文档接力」：共享文档里每人负责一段，限时产出完整文档 |
