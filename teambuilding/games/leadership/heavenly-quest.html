🎯 团建价值

领导力不是「你亲自打赢了几个妖魔」，而是「你不在场的时候，队伍里有多少人能自己打赢」。

本作把这句话做成四条硬规则：引路人不能自己战斗，遇到妖魔只能说清「指路三句话」；引路人不能装备法宝，法宝必须当场分给徒弟；引路人每轮只走 1 步，不能替徒弟移动棋子；每个徒弟有三档成长位，只有从「跟着看」一路升到「独当一面」并独自打赢一场，才算出师——而出师人数是硬胜利条件。

🔎 差异化定位

区别于红黑游戏（博弈与信任的两难）、七巧板（资源分配与全局观）、沉默领袖（无声状态下的领导与跟随）——那三款练的是"如何在既定局面里做选择"。

区别于星域远征 · 继任与授权（写清授权边界 + 强制轮换 + 交接仪式）：星域远征的核心动作是授权（"你去做，超过 X 必须回来问我"），本作的核心动作是教（"我把我知道的告诉你，你来做，我不上手"）。

区别在于帝国董事会 · 增长与负债（决策节奏与扩张匹配）：那款看的是"决策带来什么结果"，本作看的是"人有没有长起来"。

本作是领导力分类中唯一把「人才培养」做成可计数硬目标的一款（出师人数 ≥3，且必须包含教练指定的"最不主动者"），也是唯一带能力成长曲线的一款——徒弟的档位真的会涨，引路人的工作是让这条曲线上升，而不是把事做完。

🔄 四处关键改造（对照原作）

#原作团建版改造为什么这么改
14 名玩家各自修行，先集齐 3 张真经到雷音寺者胜全队一支取经队，共用「传承共识」（0-12）；真经卡团队共享计数原作是竞速，团队里"我第一"和"我们成了"是两种完全不同的行为
2玩家自己掷骰打妖魔，打不过掉 1 点天命值代打禁令：引路人不能自己战斗，只能说「指路三句话」，由徒弟执行组织里最常见的失败是"这个我熟，我来"——必须做成硬规则才会被看见
3法宝卡是玩家自己的终极装备法宝不外借 ⇒ 法宝只能给徒弟，且优先给最低档的徒弟领导手里的稀缺资源往哪儿流，就是他的真实优先级
4角色能力固定（悟空/八戒/沙僧/白龙马各一条被动）三档成长位：跟着看 → 试着来 → 独当一面 → 出师原作里能力是设定的，团建里能力必须是被带出来的

🧩 核心机制

1. 共享「传承共识」（0-12）⭐

全队唯一计分。起始 4（4 代表"还愿意听你的"，不是真共识），目标 ≥ 10，归零则「取经队散伙」全体失败，直接进复盘。

每次变动都必须当场说明理由，不许默默改数字。

2. 三档成长位 + 出师（本作灵魂）⭐

每位徒弟开局都是 1 档，只能升不能降：

档位名称能做什么升级条件
1跟着看只能跟随移动；战斗由 ≥2 档的师兄代打完整复述一次引路人的指路三句话 → 升 2 档
2试着来可独立战斗，但引路人必须在同格或相邻格在引路人"在场"时独立打赢 1 场 → 升 3 档
3独当一面可独自进入妖魔洞独自打赢 1 场且引路人不在场 → 出师，共识 +2
出师是硬胜利条件，不是加分项。

3. 指路三句话（代打时必说）⭐

遇到妖魔时，引路人只能说这三句，缺任一句，徒弟本场视为盲打（骰子 −2），且共识 −1：

  1. 判断：这个妖魔的弱点是 \_\_
  2. 打法：我建议你先 \_\_
  3. 退出条件：如果 \_\_，你就撤退
教练红线：写不出来就退回重写，教练不要代笔。绝大多数"带人失败"不是不想教，是从来没说清"打到什么程度就该撤"。

4. 代打禁令与引路人限制

限制
内容
🚫 不许出手
引路人永远不能自己战斗，违反一次共识 −2
🚫 不留法宝
所有法宝卡必须当场分给某位徒弟；留给最高档/自己 → 共识 −1；给最低档 → 共识 +1
🚫 不替人走
引路人每轮只走 1 步，不能替徒弟移动棋子
🚫 不取真经
真经卡由徒弟持有，团队共享计数

5. 出师台账（不许只有一种声音）

记录官维护两栏：

  • 出师栏：谁、从几档升到几档、靠打赢了什么
  • 异议栏：每轮必须记 ≥1 条被否决的意见；为空则记录官当众问一句"真的所有人都同意吗"，仍无人提出 → 共识 −1

6. 传承共识变动表

情形变化
引路人指路三句话说全+1（每轮上限 +1）
引路人指路缺句（徒弟盲打）−1
引路人亲自出手（代打）−2
徒弟升一档+1
徒弟出师+2
法宝分给当前最低档的徒弟+1
法宝留给自己 / 分给已出师者−1
某轮异议栏为空且追问后仍无人提出−1

🎭 角色分工（6 种）

角色组织映射职责观察点（教练重点看）
🧘 引路人（师父）团队负责人 / 导师指路三句话、分配法宝、不参战是说清了还是直接上手；法宝最后给了谁
🐒 行者业务骨干（主攻）主力战斗，最先冲击 3 档升到 3 档后，会不会回头带 1 档的人
🐷 悟能运营 / 资源 / 财务管灵石仙草与补给，喊停超支是卡资源，还是做补给规划
🪷 悟净支持 / 行政 / 后勤记地图与地形，负责移动棋子会不会主动汇报"前面一格是什么"
🐎 白龙新人 / 轮岗者本局必须至少出师一次他第一次独当一面时，团队有没有给足空间与耐心
📜 功德簿（记录官）PMO / 观察员只记录不许决策，维护出师台账与异议栏团队是否允许"被否决的声音"被写下来
关键规则：引路人不是选出来的，教练开局直接指定——优先指定团队里"业务最强、最习惯自己上"的那个人。这一轮通常是他第一次体验"只能说不能做"，教练要留足时间，不要催。

🎲 游戏流程

准备（12 分钟）

  1. 分组（6-8 人一支取经队；超过 16 人建议分 2-3 队并行）
  2. 铺 5×5 地图（A3 手绘，或 25 张便签拼网格），按原作布局：灵石矿 / 仙草地 / 法宝洞 / 妖魔洞 / 仙人台 / 真经阁
  3. 每人一张成长档位卡（1 档起）；引路人拿戒尺卡（代打禁令提示）
  4. 白板画 0-12 传承共识刻度（起始 4），开一栏出师台账
  5. 教练当众指定本局「最不主动者」——这个人必须出师，否则不满足胜利条件

每轮流程（4 阶段，共 8-10 轮）

  1. 请命（定目标）：团队说出本轮要做什么、谁去、为什么
  2. 指路（三句话）：引路人对本轮可能遭遇的妖魔说清指路三句话
  3. 修行（徒弟执行）：徒弟移动、触发地形、战斗，当场判定升档 / 出师
  4. 记功（出师台账）：记录官记升档 / 出师 / 至少 1 条被否决的意见
每 3 轮：法宝分配时刻——引路人必须当场把手里所有法宝分掉，并说一句"为什么给他"。

胜利条件（须同时满足四条）

条件
阈值
✅ 传承共识
≥ 10
✅ 出师人数
≥ 3 人，其中必须包含教练指定的「最不主动者」
✅ 真经卡
≥ 4 张（团队共享）
✅ 引路人代打次数
= 0

共识 ≤ 0 → 「取经队散伙」，全体失败，直接复盘。

⚠️ 双重特殊失败（各触发不同复盘方向）

🚹 失败 A：「代打师父」

  • 触发：引路人亲自出手 ≥ 2 次，或占用法宝 ≥ 1 件。
  • 现象：队伍是打赢了，但只成就了师父一个人；徒弟档位几乎没动。
  • 复盘方向：上个季度，团队拿下的成绩里，有多少是你亲手做的？如果下个月你休假两周，哪几件事会停？

🍃 失败 B：「放养师父」

  • 触发：全局指路三句完整 ≤ 3 次。
  • 现象：师父"放权"了，但没给判断、没给打法、没给退出条件；徒弟靠自己摸，出师全靠运气。
  • 复盘方向：我们说的"放权"，到底是给了方法，还是只是不管了？
两种失败都不计胜，但都是极好的复盘素材。尤其是「代打师父」——很多团队第一次被数据点破"其实你一个人干完了全部"。

🔍 4F 复盘框架（25 分钟）

阶段
引导问题
Facts 事实
全局出师几人？其中最低档起步的是谁？引路人代打几次、指路三句完整几次？法宝最后流向了谁？异议栏空了几轮？
Feelings 感受
只能说不能做的那一刻，是着急还是轻松？<br>被指路时，听到"如果 X 你就撤退"是清晰还是束缚？
Findings 发现
哪一位徒弟的升档最关键？关键在引路人说了什么，还是徒弟自己做了什么？<br>法宝为什么流向了他？这个选择和团队真实的资源分配像不像？
Future 行动
回到岗位，下个月我打算把哪一个人从"跟着看"带到"试着来"，第一次我会怎么说这三句话？<br>我们团队有没有一份"出师台账"——谁在成长、卡在哪一档？
落点：带人不是把事分出去，是把判断、打法和撤退线一起交出去。
复盘时把写得最好的一次"指路三句话"和最差的一次并排贴出来，让团队自己说差别——这比讲十分钟的教练技术管用得多。

🌀 变体玩法（7 种）

变体适用改法
1. 观察员模式微管理问题明显时1 人全程不参与，只统计"代打次数 / 指路完整率 / 法宝流向"
2. 双队并行人多、想制造对比张力分 2 支取经队，最后对比出师人数与共识曲线
3. 真实徒弟版有明确带教目标的管理者训练徒弟换成团队里真实的新人，出师标准换成一项真实可独立完成的任务
4. 静默指路表达强势者过多指路阶段引路人只能写不能说，逼三句话写清楚
5. 师父轮换想让每个人都体验"只能说不能做"每 3 轮换一次引路人（可与星域远征串联做进阶）
6. 反向师徒想讨论"会不会带人"让仍处 1 档的徒弟当一轮引路人，给 3 档的人指路
7. 妖王加码想练承压状态下的带教每 3 轮强制翻 1 张妖王卡（需 ≥11），只能由 3 档徒弟独自打

🧭 教练注意事项

  1. 代打禁令必须严格执行——一旦允许"这个妖魔太强我自己来"，本作的教育意义就归零。
  2. 指路三句话缺一不可，尤其是"退出条件"；说不出的当场退回重说，不要代笔、不要提示答案。
  3. 「最不主动者」必须出师这一条不能通融；他第一次独当一面时，教练要主动压住其他人的"提醒"。
  4. 异议栏为空要当众追问一次——追问后仍无人提出则扣共识，并记进复盘，这不是形式主义。
  5. 不要评判谁是好 leader——教练只验收"出师人数 / 指路完整率 / 法宝流向 / 异议登记数"，不做个人能力评价。

👑 领导力挑款：这一款练的是哪一层

👑领导力 6 款按「带人这件事卡在哪一层」分成 3 组，它属于 🔑 授权与放手（2 款）：

这两款是 6 款里唯一真正在练「把事交出去」的一组，但狠的程度不同：星域远征是交出去之后还要能接回来 —— 每轮 4 个行动点指挥官只能亲掌 1 个，其余必须写清「边界：什么情况必须回来问我」，每 2 轮强制换人并复述上任判断；天庭远征更狠，引路人永远不能自己出手，遇到妖魔只能说清「判断／打法／退出条件」三句，法宝必须分给徒弟，出师人数是硬胜利条件。

这一层卡的是什么：师父忍不住自己上手

  • 领导力挑款指南 · 🔑 授权与放手这一组 —— 同组另外 1 款，附「什么情况下选它 / 什么时候别选它 / 拿不准就先拿」
  • 挑款指南首页（30 秒决策表） —— 按你现在的麻烦直接对组，不用先读完 6 张卡
想换一层练？3 组之间的边界，以及「四个最容易挑错的地方」，都写在挑款页里。

🧩 这套游戏被哪些流程用过

⚠️ 还没有任何现成流程收录它 —— 它属于「挑一个环节塞进去」型：本页有完整玩法，但没有配套时间轴。按参数 8–24 人 / 75–100 分钟，能落地的位置是：
能装下它的只有一日团建流程方案的主体活动二（13:30–15:00，90 min）：取 90 分钟版（100 分钟上限要砍掉一轮），把协作款顶掉，复盘时多问一句「刚才谁在做决定」。
领导力觉醒工作坊装不下：那套 2.5–3 小时里最长的单环节是核心活动 III（40 min），本页 75–100 分钟连一半都放不进。硬塞要连做「核心活动 II + III」（30 + 40 = 70 min）并吃掉 35 分钟的深度复盘——而复盘才是那套工作坊的产品，换掉它就白办了。
上面是建议不是既有收录：这些流程的原表里没有它，塞进去时前后各留 5 分钟交接；塞之前先核一遍人数和时长，别看标题。
