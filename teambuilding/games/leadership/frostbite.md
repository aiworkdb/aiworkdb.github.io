# 极地庇护所（Frostbite）

> **一句话**：队长的手冻僵了不能碰，队员的眼睛雪盲了看不见——唯一能穿过这个任务的东西，是一句一句说得清的话。

| **游戏名称** | 极地庇护所（Frostbite / Arctic Shelter） |
| **目的标签** | 领导力 · 角色限制 · 指令清晰度 |
| **形式标签** | 室内 · 小组 · 动手搭建 |
| **人数** | 建议 每组 4–6 人（全场 8–36 人） |
| **时长** | 50–70 min |
| **难度** | ⭐⭐⭐ 偏高（信息全断，全靠口述） |
| **道具需求** | 有（帐篷或纸箱+胶带+吸管 + 眼罩 + 计时器） |
| **场景标签** | 管理层培训 · 领导力工作坊 · 跨部门协作 |
| **核心目标** | 在「领导不能动手、成员看不见」的双重限制下，暴露指令的真实颗粒度 |

---

**团建核心价值**：
- 🧊 领导的手被冻住：想帮也帮不了，只能靠说
- 🕶️ 队员的眼睛被雪盲：看不见，只能靠听
- 🗣️ 指令颗粒度：「往左一点」到底是多少度？
- 🔁 轮换领导：每个人都当一次「只能说不能做」的人

## 1. 游戏概览

极地庇护所是一个把「领导力」压到最窄的练习：**领导唯一的能力是说话，队员唯一的输入是听觉。**

情境设定很简单：一队北极探险者遭遇暴风雪，必须在天黑前搭好庇护所。但队伍出了两个状况——

- **队长双手冻伤**，完全不能碰任何材料
- **其余队员全部雪盲**，必须戴眼罩

于是就形成了这个局面：**唯一看得见的人不能碰，唯一能碰的人看不见。**

这个设置非常狠，因为它一次抽掉了领导力的两根拐杖：**亲自上手**和**用手比划**。剩下的只有语言。而语言够不够用，平时是测不出来的——平时领导说「往左一点」，同时手已经伸过去了，队员看手就懂了。现在手不能动，那句「往左一点」立刻暴露成一个空指令。

游戏最有价值的设计是**轮换队长**。每一个人都要当一次「只能说不能做」的人，也都要当一次「看不见只能听」的人。当过后者，才会知道前者的话有多难听懂。

## 2. 核心规则

### 准备（教练必须提前自己做一遍）

- **一定要自己先搭一次。** 不同帐篷的搭法差别很大，你必须在 5 分钟内能讲清步骤
- 场地：每组至少 8 平方米，室内外均可，地面平整无尖锐物
- 材料三选一：

| 方案 | 材料 | 难度 |
|---|---|---|
| A 帐篷版 | 每组 1 顶 2 人帐篷（未组装） | 高，步骤多，最真实 |
| B 纸箱版 | 每组 8–10 个纸箱 + 2 卷胶带 | 中，适合室内 |
| C 吸管版 | 每组 100 根吸管 + 1 卷胶带 + 1 个「庇护物」（鸡蛋/气球） | 低，可室内桌面完成 |

### 规则（一句话版）

> 队长不能碰材料，队员不能看，**只能靠说**，在限定时间内搭出一个能「住人」的庇护所。

### 硬规则

1. 队长**双手背后**，全程不得触碰任何材料（教练盯场）
2. 队员**全程戴眼罩**，不得偷看
3. 队长**只能说话**，不得用手比划方向（这一条最容易被违反，也是最重要的一条）
4. 队员可以互相说话，也可以问队长问题
5. 时间到立刻停手，按当时状态判定

### 判定标准

| 方案 | 合格标准 |
|---|---|
| 帐篷版 | 帐篷完全立起，内外帐都挂上，拉绳固定 |
| 纸箱版 | 结构能立住 10 秒不倒，内部能容纳 2 人 |
| 吸管版 | 「庇护物」放在结构内，从 1 米高自由落体后不破 |

### 流程（60 分钟标准版）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 情境导入 | 5 min | 讲暴风雪情境，分配队长 |
| 队长看图 | 5 min | 队长看搭建说明（队员戴眼罩，不许听讲解） |
| 第一轮搭建 | 20 min | 队长指挥，队员动手 |
| 判定 | 3 min | 摘眼罩看结果 |
| 轮换 + 第二轮 | 20 min | 换队长，重新来一次（这次队员已知道难度） |
| 复盘 | 12 min | 见第 4 节 |

**第二轮必做。** 第一轮通常是灾难，第二轮才会出现「队长提前分工」「队员主动复述确认」这些真正想教的行为。

## 3. 引导要点

### 讲解脚本（3 分钟）

> 你们是一支北极探险队，暴风雪要来了。
>
> 队长刚才在风雪里探路，**双手冻伤了，完全不能碰任何东西。**
>
> 其余人**全部雪盲，现在开始戴眼罩**，摘下之前不能看任何东西。
>
> 也就是说：**唯一看得见的人不能碰，唯一能碰的人看不见。**
>
> 队长，你手里有一份搭建说明。你只有五分钟看它。
>
> 还有一条我要单独说：**队长不能用手指方向。** 不能说「往那边」，然后手一指。你只能靠嘴。

### 教练在场边做什么

- **死守「不许比划」**。这一条比「不许碰」更容易被违反，因为比划是本能。第一次违反口头警告，第二次就把队长的手绑在背后（用围巾轻系，不紧）
- **第一轮不要救场**。看着他们搭歪、搭塌，别出声。塌了才有复盘材料
- **记录队长说的前十句话**。复盘时原音回放，效果极强
- **记录队员的提问次数**。提问多的小组通常完成度高——这个数据能直接支撑「下属要敢问」这个结论
- **轮换时必须换人**，不能让同一个人再当队长（除非组内一致要求）

### 队长最容易犯的三个错

| 错误 | 表现 | 后果 |
|---|---|---|
| 说结果不说步骤 | 「把帐篷立起来」 | 队员完全不知道从哪下手 |
| 用相对方位 | 「往你左边一点」 | 蒙眼的人分不清左右，也分不清「一点」 |
| 一次说太多 | 连说五个动作 | 队员只记住最后一个 |

### 正确指令的四个要素

> **谁 + 做什么 + 到哪里 + 怎么算完成**
>
> ✅「小王，你的右手往前伸，直到摸到一根杆子，摸到就说『有了』。」
> ❌「小王你把那根杆子拿过来。」

### 语言禁区

- ❌「你怎么这么笨，就在你手边啊」——他看不见，「手边」对他毫无意义
- ❌「算了算了，我自己来」——队长一旦违规动手，这个游戏就废了
- ✅「摸到东西就说一声『有了』」
- ✅「你刚才说的『往左』，是往你的左还是我的左？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 第一轮有几组完成？第二轮呢？
- 队长第一轮说的前十句话里，有几句话包含了「具体距离或位置」？
- 队员主动提问了几次？提问多的组是不是完成得更好？
- 有几组的队长违反了「不许比划」？

### Feelings（感受）

- 当队长的时候，看着队员做错方向，你最想做什么？
- 当队员的时候，听到一句听不懂的指令，你是什么感觉？会不会不好意思问？
- 摘掉眼罩看到成果那一刻，第一反应是什么？

### Findings（发现）

- 为什么「往左一点」在平时够用，在这里完全不够用？（因为平时你有手、有眼神、有共同视野）
- 队员不敢提问，是怕什么？（怕显得笨、怕拖慢进度）
- 队长说得越多，队员做得越差——为什么会这样？（信息过载，且没有确认机制）

### Future（应用）

- 我们给同事派任务时，有多少句是「往左一点」？
- 团队里有没有人从不提问，只是默默做错？他为什么不敢问？
- 如果明天开始你不能「亲自上手」，你的团队还能转吗？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 室内场地小 | 用方案 C（吸管版），桌面即可完成，8 人一组也不挤 |
| 时间只有 30 分钟 | 只做一轮 + 复盘，轮换改为「复盘后口头推演第二轮会怎么做」 |
| 团队规模大（> 36） | 分大组，每组配 1 名观察员记录队长原话 |
| 想突出「授权」 | 加一条：队长可以「授权」一名队员当副手，副手可以摘下眼罩看 30 秒 |
| 想突出「汇报」 | 加一条：每 5 分钟队长必须向「总部」（教练）汇报一次进度，限 3 句话 |
| 管理层专场 | 第二轮加「预算」：材料要按件计费，队长必须申请 |
| 线上 / 远程 | 改为「盲画版」：一人看图纸口述，其他人按描述在纸上画，比对图形差异 |

### 安全提示

- 蒙眼 + 动手 = 夹手风险。材料不能有锋利边缘，胶带用撕的不用刀
- 帐篷杆有弹性，弹开可能打到脸，蒙眼者操作时队长必须提示「这根杆会弹」
- 教练全程在场内走动，随时能介入

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 帐篷（未组装） | 每组 1 顶 | 方案 A；2 人帐篷最合适，4 人帐篷太难 |
| 纸箱 | 每组 8–10 个 | 方案 B；中等大小，太软立不住 |
| 吸管 | 每组 100 根 | 方案 C；纸质吸管更好粘 |
| 胶带 | 每组 2 卷 | 纸箱版用宽胶带，吸管版用透明胶 |
| 眼罩 | 每人 1 个 | 必须遮光，队员全程佩戴 |
| 搭建说明图 | 每队长 1 份 | 打印版，只有队长能看 |
| 围巾 | 每组 1 条 | 用于「不许比划」违规时的轻系提醒，松系即可 |
| 计时器 | 1 个 | 全场可见，倒计时 |
| 「庇护物」 | 每组 1 个 | 方案 C 用：鸡蛋、气球或纸杯 |
| 急救包 | 1 个 | 常备，不用拆封 |

## 🧩 这套游戏被哪些流程用过

> ⚠️ **还没有任何现成流程收录它**。下面的落点是**建议**：塞进这一格要换掉原环节，并接受文末写的那些损失。

| 目标流程 | 能塞进哪一步 | 一组几人 / 开几组 | 要换掉谁 | 换过去会失去什么 |
| :--- | :--- | :--- | :--- | :--- |
| [半日团建模板](../../flows/half-day/01-schedule.md) | 核心活动 I · 新增方案 F（14:50–15:40，50 min） | 4–6 人/组，20 人 = 4 组（= 4 个队长轮换位）；材料走方案 C 吸管版，室内桌面即可 | 方案 A「盲行 + 信任背摔」——这一格原本的五条路线（A 信任 / B 沟通 / C 沙漠逃生 / D 棉花糖 / E 演技派对）没有一条练「指令颗粒度」 | 这一场**不做身体托付**。方案 A 的「敢不敢把后背交出去」是本页给不了的 —— 本页的蒙眼只负责「看不见」，不负责「被接住」 |

**为什么是 50 min 这一格，而不是 30 min**：本页「时间只有 30 分钟」那条变体写的是「只做一轮 + 复盘」，按本页自己的阶段表实算是 **45 min**（导入 5 + 队长看图 5 + 搭建 20 + 判定 3 + 复盘 12）—— 30 min 是漏算了导入与看图这 10 分钟的乐观值。半日 14:50 的 50 min 是本页**第一个真正装得下的格子**，还余 5 min 给摘眼罩后的那阵子笑。

**一轮定长：23 分钟**（搭建 20 + 判定 3）。这 23 分钟是硬单位，由身体决定而不是由流程决定：蒙眼的人摸到「能立住 10 秒」为止。**第二轮的 23 分钟不叠加铺垫** —— 导入 5 + 看图 5 只算一次，所以两轮 = 10 + 46 + 12 = **68 min**。这就是本页「50–70」的来历：**50 是一轮，70 是两轮**，不是「可长可短」。

由此得出一条硬判据：**≥68 min 的格子才挂得动两轮版**。全站只有 3 个格子够（一日 10:30–12:00 / 一日 13:30–15:00 / 跨部门 13:30–15:00），而这 3 格的原配都比本页更装得满 —— 所以本页只按单轮版排。**「第二轮必做」这条设计前提，在现有 20 套流程里是拿不到的**；要拿，得单独给它 70 min，或者在复盘里改成「口头推演第二轮会怎么做」（第 5 节变体里已有这条路）。

**50 分钟怎么切**：情境导入 5 + 队长看图 5（队员戴眼罩、不许听）+ 第一轮搭建 20 + 判定 3 + 复盘 12 + 余 5（摘眼罩的反应本身就是素材，别急着开口）。材料用**方案 C 吸管版**：纸箱版要 8 m²/组的场地，半日模板那一段通常只有一间会议室。

**装不下的地方**：两轮版（68 min）与本页最狠的那一段 ——「第二轮队员已经知道难度，队长会开始提前分工」—— 50 min 里拿不到。代价是这一场只能看到「第一次蒙眼时的原始状态」，看不到「知道难之后会怎么改」。**如果这场的目的就是让他看见自己带人时的焦虑，一轮够；如果目的是让他改，必须给 70 min。**

**同一格的其他候选**：半日 14:50 是**一格六条路线**（A 信任 / B 沟通 / C 沙漠逃生 / D 棉花糖 / E 演技派对 / F 本页），不是六个候选 —— 路线按「这一场要什么」选，不按「哪个更好」。本页只在「这一场要练的是**说清楚**」时用。与方案 A **互斥**（同日第二次蒙眼会打折），与方案 D、E 无关（一款搭塔、一款演戏）。

> 以上是**建议**落点，不是既有收录：塞进这一格要在流程表里补一行 F 方案、物资清单加「吸管 100 根/组 + 眼罩每人 1 个 + 搭建说明图」，并把「核心活动 I」的复盘脚本换成第 4 节的 Facts 四问。
