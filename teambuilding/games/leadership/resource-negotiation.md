# 资源谈判局（Resource Negotiation）

> **一句话**：预算只有一份，三个部门都觉得自己最该拿——谈判不是分蛋糕，是先搞清楚对方真正要的是什么。

| **游戏名称** | 资源谈判局（Resource Negotiation） |
| **目的标签** | 领导力 · 谈判博弈 · 跨部门协作 |
| **形式标签** | 室内 · 分组 · 坐姿 |
| **人数** | 建议 每组 3 队 × 3–4 人 |
| **时长** | 60–80 min |
| **难度** | ⭐⭐⭐ 较难（规则需要讲清，否则会退化成吵架） |
| **道具需求** | 有（预算卡 + 计分表 + 笔） |
| **场景标签** | 培训 · 管理层工作坊 · 跨部门融合 |
| **核心目标** | 在零和表象下找到非零和解，练习「先问需求、再谈分配」的谈判顺序 |

---

**团建核心价值**：
- 🎯 立场与利益：要的是「预算」，还是「不被砍人」
- 🔍 提问优先：先问清楚，再出价
- 🤝 创造选项：把蛋糕做大，而不是抢同一块
- 🧊 情绪管理：被拒绝时不升级对抗

## 1. 游戏概览

这是哈佛谈判法（Fisher & Ury）「立场 vs 利益」的经典演练格式。

设定：公司只有一笔 100 万的专项预算，三个部门（如研发、市场、客服）各有一份需求，每份都超过 100 万。三队要在 40 分钟内谈出一个分配方案，并且**必须三队都签字**才生效——任何一队拒签，方案作废，预算退回总部。

这个「必须全体同意」的设定是关键。它把「抢」变成了「谈」：你没法靠人多压过去，只能找对方真正在意的东西。

而每张需求卡上都藏着一个**错配**：A 部门写的是「要 60 万买设备」，但它真正的痛点是「人手不够」；B 部门写「要 50 万做投放」，真实需求是「品牌曝光」；C 部门写「要 40 万扩编」，实际最在意的是「响应时效考核」。

如果三方都只谈立场（数字），必然谈崩。只有开始问「你为什么需要这个」，才可能发现：A 的 20 万预算可以换成借调人力，B 的曝光可以用 A 的产品发布会顺带完成，C 的时效问题用流程改造就能解决一半。

**谈判的高下，不在谁拿得多，而在有没有人先问出那句话。**

## 2. 核心规则

### 准备

- 三张需求卡（每队只看到自己的），含：明面需求、预算数字、隐藏痛点（不主动说，被问到才说）
- 一张「公共资源表」：100 万预算总额 + 3 项可交换资源（人力借调、渠道位、优先排期权）
- 一张「协议单」：必须三队签字，写清金额、交换条件、执行时间
- 计时器

### 流程

1. **分角色阅读（5 分钟）**：每队读自己的卡，明确「必须拿到的底线」和「可以让的」
2. **第一轮：立场陈述（每队 2 分钟）**：只能说需求，不能提问，不能反驳
3. **第二轮：自由谈判（25 分钟）**：可自由走动、单独约谈、结盟。**允许私下双边沟通**——这一点很重要，真实的跨部门谈判从来不是三方同框
4. **签署协议（5 分钟）**：三队签字，交给教练
5. **公布结果 + 复盘**

### 规则红线

- 不许虚报数字（卡上写的预算就是真实需求，不能为了谈判而加码）
- 不许威胁（「你不给我就去老板那告你」这类，一次警告，二次出局）
- 允许隐瞒（隐藏痛点可以不说，但被问到必须诚实回答）
- 协议必须写明**交换条件**，只写金额不算完整

### 胜负判定

不用「谁拿得多」排名，用三个指标：

| 指标 | 含义 |
|---|---|
| 达成率 | 是否签出协议（三队全签 = 100%） |
| 总价值 | 三队「真实痛点被解决的程度」之和（教练按卡上标准判） |
| 关系 | 结束后三队互相打分「下次还愿意跟这队合作吗」 |

第三项常常比前两项更有讨论价值：有的方案分数很高，但没人愿意再合作。

## 3. 引导要点

### 讲解脚本（3 分钟）

> 公司有一笔 100 万。你们三个部门都想要，加起来要 150 万。
>
> 规则：谈成的方案必须三队都签字。有一队不签，钱就退回总部，谁都拿不到。
>
> 你们有 40 分钟。现在开始读卡。

（讲完就走。不要提示「你们可以私下聊」——让他们自己发现。）

### 教练在场边做什么

- **第一轮立场陈述时全程不干预**，让他们把「我们最需要」说完。这一轮通常最僵。
- 观察第二轮的三个动作：**谁先去找人单聊？谁一直在原地等？谁开始问「你为什么要这个」？**
- 记录第一次出现「问需求」这句话的时间点——这是整场的关键指标
- 如果 25 分钟过去还没有任何双边沟通，可以给一个提示：「时间是够的，你们可以走动。」但只说一次

### 安全边界（防止退化成吵架）

- 一旦出现人身攻击或情绪升级，立即暂停 30 秒，让双方各说一句「我听到的是……」
- 不许用「职级」压人（如果有上下级在同组，提前说明：本局按角色，不按职级）
- 允许「谈不成」——谈不成本身也是真实结果，复盘价值很高

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 第一次有人问「你为什么要这个」是在第几分钟？
- 有几对做了双边沟通？结盟了几次？
- 最终有没有签成？如果没签，卡在哪一条？

### Feelings（感受）

- 第一轮听完别人的需求，你的第一反应是什么？
- 别人拒绝你的方案时，你想加价还是想发火？
- 最后签字的时候，是「满意」还是「算了」？

### Findings（发现）

- 「我要 60 万」和「我缺人手」，哪一个更容易被满足？
- 我们有几次把「立场」当成了「利益」？
- 是什么让某几队愿意先让步？是算计还是信任？

### Future（应用）

- 我们部门的「明面需求」和「真实痛点」分别是什么？
- 上次跨部门争资源，我们第一句话是问需求还是报数字？
- 我们能不能约定一个动作：谈判开始前，先各问对方三个问题？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 时间紧（40 分钟） | 砍掉第一轮陈述，直接进入自由谈判 |
| 两队版本 | 总额改成 60 万，两队各要 50 万，冲突更直接 |
| 跨部门真实议题 | 需求卡换成真实部门的真实诉求（提前匿名收集） |
| 低对抗版本 | 引入「总部观察员」，只做记录不评判，减少输赢感 |
| 线上 | 用分组会议室做双边谈判，主会场做全体表决 |
