# 开放空间（Open Space Technology / OST）

> **一句话**：没有议程、没有主讲、没有分组名单——所有人围成一圈，谁有议题谁上墙，谁提的谁负责主持，全场自己长出一场会。

| **游戏名称** | 开放空间（Open Space Technology / OST / 开放空间技术） |
| **目的标签** | 自组织 · 议题认领 · 责任到人 |
| **形式标签** | 室内大空间 · 圆圈开场 · 多场次并行 |
| **人数** | 全场 50–300 人（理论 5–2000 人，实战 50–300 最好用） |
| **时长** | 240–720 min（半天 – 1.5 天，可延至 2.5 天；最小可用 4 小时） |
| **难度** | ⭐⭐⭐ 中等（流程极简，对"放权"要求极高） |
| **道具需求** | 有（大白纸/议题墙 + 便签 + 铃 + 多个可分组角落） |
| **场景标签** | 战略共创 · 组织变革 · 跨部门攻坚 · 年会工作坊 · 高分歧议题 |
| **核心目标** | 让"谁提的问题谁负责"，把抱怨转换成议程 |

---

**团建核心价值**：
- 🧭 自组织：议程不是主办方排的，是现场长出来的
- ✋ 责任绑定：提议题的人必须当场主持并产出记录
- 🦋 自由流动：不贡献不学习就换场，不需要请示任何人
- 🔇 高分歧可用：不追求当场统一，只追求把真问题摊开

## 1. 游戏概览

开放空间技术由 Harrison Owen 在 1980 年代中期提出。起因很朴素：他观察到自己办的会议里，**最受欢迎、最有产出的部分永远是茶歇**——因为茶歇时人们自己找到想聊的人，自己决定聊多久。

于是他把"茶歇的自组织"变成了正式流程。

**它的形态和任何常规会议都不一样**：

- 全场**围成一个圆圈**坐着。没有主席台，没有前排后排
- 开场只有发起人讲 3–5 分钟：为什么把大家叫来、期待什么
- 然后**当场生成议程**：谁有想谈的议题，走到圆圈中间，在纸上写下议题名，大声念出来，贴到墙上的"时间 × 地点"格子里
- **贴上去的人同时承担两个责任**：主持这场讨论、交出一份记录
- 议程填满后，大家自己看墙、自己选场次。铃响，各场次同时开始
- 全场唯一的行为规范是"**双脚法则**"：如果你在某个场次既不贡献也不学习，就用你的双脚走到别处去

**它最适合什么**：一个真实的、复杂的、大家观点不一致的、而且**必须马上行动**的问题。

**它最不适合什么**：领导心里已经有答案、只需要大家鼓掌通过的场合。这种场合用 OST 会非常难看——议题墙会立刻空掉。

### 适用性自检（五个条件，缺两个以上别用）

| # | 条件 | 自检问句 |
|---|---|---|
| 1 | 有一个**真实的业务挑战** | 我们真的有个没解决的问题吗？还是"想搞个活动"？ |
| 2 | 问题**足够复杂** | 一个人拍脑袋能定的事，不需要开放空间 |
| 3 | 参与者**观点多元** | 如果全是同一个部门同一个立场，讨论没有张力 |
| 4 | 人们对议题**有热情** | 大家在乎吗？还是"公司要求的"？ |
| 5 | 有**紧迫感** | 早该决定并行动了 |

> 🔴 **还要问发起人一句话：「你信任这个团队吗？」**
> 如果答案是否定的、或含糊的，就不要做。OST 会把控制权真的交出去——议程、结论、责任人都不由主办方决定。发起人中途反悔，比不做更伤团队。

## 2. 核心规则

### 准备

- **场地**：一个能容纳全员的开放空间（圆圈要坐得下所有人），加**至少 4–8 个可分组讨论的角落**（休息区、走廊尽头、露台都可以，不必是会议室）
- **议题墙**：一面大墙或 2–3 块大白板，画成表格：**横轴 = 时间段（如 5 个时段），纵轴 = 地点（如 6 个空间）**
- **椅子**：全员椅子围成一圈，**不要摆成剧场式**
- **铃**：一个能全场听见的铃/锣/铜钵。开场、每场次开始/结束都用它
- **物资**：A4 纸（写议题）、粗马克笔、胶带、每场次的记录纸

### 四大原则（开场必须逐条念）

| # | 原则 | 真实含义 |
|---|---|---|
| 1 | **出席的人就是对的人** | 别抱怨"关键的人没来"。来的人就是能解决问题的人 |
| 2 | **发生什么就是唯一会发生的事** | 别纠结"本来应该讨论 X"。当下发生的就是该发生的 |
| 3 | **什么时候开始都是对的时间** | 不用等"准备充分"。现在开始就是对的 |
| 4 | **结束就结束了，没结束就没结束** | 一场讨论该收就收，没收完就承认没收完，不硬凑 |

### 一条法则（双脚法则 / Law of Two Feet）

> **如果你发现自己在一个地方既不贡献、也不学习，就用你的双脚，走到你能贡献或学习的地方去。**

这条法则的作用是把"离场"从失礼变成合规。没有它，人们会因为怕冒犯而留在不相关的场次里，浪费半天。

### 规则

1. 开场**围圆**，发起人先讲"为什么有这次会"，然后引导师接手
2. 引导师宣布主题（一句话，必须与所有人相关）
3. 逐条念四大原则 + 双脚法则
4. **共创议程**：想提议题的人走到圆圈中间，写下议题名（≤10 字），向全场念一遍，贴到墙上格子里
5. **提议题的人自动成为该场次的主持人 + 记录人**
6. 议程填满（或无人再提）后，给全场 **2–3 分钟**看墙、选场次
7. 铃响，各场次**同时开始**，每场时长按议程表（通常 60–90 分钟）
8. 每场结束前 10 分钟，主持人整理本场记录（要点/分歧/待办/责任人）
9. 全部场次结束后，**全体回到圆圈**，做"收束"：各场主持人用 1–2 分钟报结论
10. 最后汇总成"**行动清单**"：做什么、谁做、什么时候

### 流程（一天版）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 圆圈开场 | 20 min | 发起人讲目的 + 引导师讲原则与法则 |
| 共创议程 | 25 min | 提议题、念议题、上墙 |
| 选场次 | 3 min | 看墙、自行分流 |
| 第 1 场次 | 90 min | 并行讨论 |
| 休息 | 20 min | 茶歇（OST 里茶歇是正式环节，不是浪费） |
| 第 2 场次 | 90 min | 并行讨论 |
| 午餐 | 60 min | — |
| 第 3 场次 | 90 min | 并行讨论 |
| 收束 | 45 min | 各场报结论 + 汇总行动清单 |
| 收尾 | 15 min | 明确下一步与责任人 |

## 3. 引导要点

### 讲解脚本（5 分钟，念完即可，不要发挥）

> 我们没有议程。议程等一下会由你们自己写出来。
>
> 规则是四条原则、一条法则。
>
> 第一，**出席的人就是对的人**。不要想"要是某某来了就好了"。来了的人，就是能解决问题的人。
>
> 第二，**发生什么就是唯一会发生的事**。不要遗憾"本来想谈另一个话题"。
>
> 第三，**什么时候开始都是对的时间**。
>
> 第四，**结束就结束了，没结束就没结束**。
>
> 一条法则：**如果你在一个地方既不贡献也不学习，就用你的双脚，走到你能贡献的地方去。** 不用跟谁请假。
>
> 现在，谁有想谈的议题？走到中间来，写下它，念给全场听。**贴上去，你就是这场的主持人。**

### 引导师在场边做什么

- **开场必须"少讲"**。引导师讲得越久，自组织越起不来。5 分钟讲完，立刻把空间交出去
- **制造"空白议程"的焦虑期并忍住不救**。刚开始墙上一定是空的，全场会尴尬 30–60 秒。**这 60 秒是整个项目的关键**——只要有人先走上去，后面就会排队。引导师上去救场，项目就废了
- **保护第一个提议题的人**：帮他递笔、帮他贴、带头鼓掌。第一个人的待遇决定了后面有几个人敢上
- **不干预场次内容**，只在走廊里走动，观察哪一场在吵、哪一场在冷
- **收束环节必须真的收**：不要变成"大家分享一下感受"。要一份能带走的行动清单
- **把记录收齐**：每场的记录纸必须收回，这是唯一可交付的产出

### 四个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 议程空墙 | 没人上墙，或只有 HR 一个人提了 3 个议题 | 发起人不信任团队；或议题被"上面定过了" |
| 明星场次 | 一个场次挤满 40 人，其他场次 2 人 | 议题写得太大（"如何提升组织能力"） |
| 无输出 | 各场聊得热闹，收束时说不出结论 | 主持人只当主持，没做记录；或没留最后 10 分钟 |
| 老议题复现 | 讨论出来的行动和去年年会一模一样 | 没有指定责任人，也没有"下次检查"的机制 |

### 语言禁区

- ❌「大家提的议题我们会统一汇总上报」——一句话杀死自组织（提了也没用）
- ❌「这个议题太敏感，换一个」——现场否决议题，等于宣布这不是开放空间
- ✅「这个议题谁提的？你愿意主持吗？」
- ✅「这场讨论，最后要交出什么？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 议题墙上最终有几个议题？其中几个是"真问题"，几个是"表态性话题"？
- 全场有多少人提了议题？占在场人数的几成？
- 有多少人用了"双脚法则"（中途换场）？
- 行动清单上有几条写明了责任人？几条写明了时间？

### Feelings（感受）

- 墙上空白那 60 秒，你什么感觉？（想上去？还是在等别人？）
- 提了议题、念给全场听的那一刻，什么感觉？
- 你在某场里"既不贡献也不学习"的时候，为什么没有走？

### Findings（发现）

- 为什么"谁提议题谁主持"这一条，能让议题质量立刻变高？（因为提了就要负责，不能只吐槽）
- 为什么必须围成圆圈，而不是排排坐？（圆圈里没有"权威位置"，发言不需要被允许）
- "双脚法则"在现实组织里对应什么？（允许人离开无效会议，且不需要解释）
- 为什么引导师"不救场"反而是对的？

### Future（应用）

- 我们平时的会议，有多少是"排排坐、一个人讲"？
- 我们团队里，提问题的人会不会被默认"那就你来做"？如果会，大家就都不提了——我们怎么破？
- 下一次真问题出现时，我们能不能不用"成立专项组"，而是让提问题的人主持？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 半天版（4 小时） | 开场 15 + 议程 20 + 2 场次（各 70）+ 收束 40 |
| 人数多（300+） | 场地分区，每区一套议题墙；收束改为"每区选 2 场汇报" |
| 线上版 | 用共享表格当议题墙 + 多个分组会议室；双脚法则改为"随时可以退出会议室" |
| 议题太长 | 强制"**10 字以内 + 一个动词**"，如"缩短上线周期"而不是"关于研发效能的思考" |
| 高冲突议题 | 允许"同一议题开 2 场"（不同立场各开一场），收束时并列呈现 |
| 想产出更硬 | 每场必须填模板：**结论 / 分歧 / 下一步 / 责任人 / 时间**，缺一项不算完成 |
| 与管理层专场 | 开场加一条"**当场承诺资源**"，其他不变 |
| 年会 / 大型场 | 议题墙最终拼成"问题地图"，贴在会场入口，标注各场结论 |

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 议题墙（大白板/大白纸） | 2–3 块 | 必须画成"时间 × 地点"网格 |
| A4 纸 | 每人 3–5 张 | 写议题用 |
| 粗马克笔 | 每人 1 支 + 备用 20 支 | 议题字要大，远处要看得见 |
| 胶带 / 蓝丁胶 | 若干 | 贴议题、贴记录 |
| 铃 / 铜钵 | 1 个 | 声音必须能全场听见 |
| 记录纸（A2/A1） | 每场次 1 张 | 必须回收 |
| 椅子 | 按人数 | 围圆摆放，不许剧场式 |
| 指示牌 | 每区域 1 个 | 标清"1 号区/2 号区"，否则人会迷路 |
| 茶歇 | 按人数 × 2 次 | OST 里茶歇是正式环节（自组织就发生在这里） |
