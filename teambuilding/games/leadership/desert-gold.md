# 沙漠掘金（Desert Gold / 沙漠掘金沙盘）

> **一句话**：一千块启动资金、一头骆驼、二十五天——你是买水保险地活着回来，还是赌一次天气去挖更多金子？

| **游戏名称** | 沙漠掘金（Desert Gold / 沙漠掘金沙盘 / 掘金者） |
| **目的标签** | 资源配置 · 风险决策 · 目标管理 |
| **形式标签** | 室内会议室 · 每桌一组 · 围桌推演 |
| **人数** | 全场 20–100 人（每桌 6–8 人一组，超过 50 人需分批或多讲师） |
| **时长** | 240–360 min（含 60–90 分钟深度复盘） |
| **难度** | ⭐⭐⭐ 中等（规则 20 分钟讲完，决策一直难） |
| **道具需求** | 有（地图 + 物资卡 + 天气卡 + 记账表 + 金币/代币，每桌 1 套） |
| **场景标签** | 中高层管理 · 新晋管理者 · 跨部门管理者 · 战略共识 |
| **核心目标** | 让"目标没定清、资源没规划、风险没评估"这三种病在沙盘里当场发作 |

---

**团建核心价值**：
- 💰 资源配置：一千块怎么分，决定了能不能活着回来
- 🎲 风险决策：抄近路还是走安全线，赌天气还是买保险
- 🎯 目标管理：出发前有没有明确"我要挖多少金"
- 👥 角色分工：谁决策、谁记账、谁谈判、谁被边缘化

## 1. 游戏概览

这是国际上最经典的体验式管理课程之一，也是国内中高层团建用得最多的沙盘。它把一次 25 天的沙漠探险压缩进几小时，用**资金、物资、天气、路线、金子**五个变量，还原企业经营的基本结构：

| 沙盘元素 | 现实映射 |
|---|---|
| 探险队 | 公司/团队 |
| 金子 | 团队绩效 |
| 水与食物 | 运营成本 |
| 天气 | 市场环境 |
| 路线选择 | 经营思路 |
| 启动资金 | 预算 |
| 骆驼载重 | 产能/资源上限 |
| 25 天期限 | 战略周期 |

**为什么它对管理层特别有效**：它不靠讲师讲道理。它让管理者在 3 小时里**亲手做十几个真实决策**，然后在复盘时发现自己用的还是工位上那套习惯——保守的继续保守，冒进的继续冒进，垄断信息的继续垄断信息。

> ⚠️ **参数说明（重要）**：市面不同版本的沙漠掘金数值不同（启动资金、物资价格、天气概率、挖金速度都有差异）。本节给出的是一套**自洽、可完整跑完 25 天**的参数，可以直接执行。如果要替换成你手上的商业版道具，**必须保持参数内部一致**（成本 × 天数 ≈ 资金，挖金收益 > 日成本），否则会出现"怎么算都必亏"或"怎么算都稳赢"，项目直接失效。

## 2. 核心规则

### 准备

- **场地**：会议室，每桌一组，桌距 ≥ 1.5 米（避免互相偷看）。前方需投影或大白板公布天气与物价
- **每桌物资**：地图 1 张、物资卡 1 套、天气牌 1 套、记账表 1 张（**必须用，不许心算**）、代币若干
- **分组**：每组 **6–8 人**（这是硬上限。超过 8 人，一定有人全程旁听）
- **角色**：每组推选 ① 队长（决策）② 财务官（管钱记账）③ 物资官（管水/食物/载重）④ 情报官（看天气、谈判）⑤ 记录官（记关键决策理由）

### 地图与路线

```
                藏宝山（挖金）
                    │ 2 天
                 王陵（抽卡）
                    │ 2 天
   大本营 ──3 天── 绿洲（免费取水）──3 天── 岔路口
      │                                      │
      └──4 天── 村庄（高价补给）─────────────┘
```

- **大本营出发 → 藏宝山**：最短 6 天（经绿洲），最长 10 天（绕村庄/王陵）
- **藏宝山停留挖金**：最多 5 天
- **返回大本营**：与去程同天数
- **25 天硬上限**：第 25 天结束仍未回到大本营 → 该队**判定"困死沙漠"，收益归零**

### 核心参数（可直接执行）

| 项 | 数值 | 说明 |
|---|---|---|
| 启动资金 | 1000 元 | 全场相同，不许追加 |
| 骆驼载重 | 60 单位 | 水/食物各 1 单位，帐篷 5，指南针 1，望远镜 1 |
| 期限 | 25 天 | 硬上限 |
| 挖金速度 | 第 1 天 300，第 2 天 300，第 3 天 200，第 4 天 100，第 5 天 50 | 边际递减，逼你决定"什么时候走" |

**大本营物价**

| 物资 | 价格 | 作用 |
|---|---|---|
| 水 | 30 元/份 | 每日必需 |
| 食物 | 20 元/份 | 每日必需 |
| 帐篷 | 300 元/顶（占 5 载重） | 沙尘暴时消耗减半 |
| 指南针 | 150 元/个 | 免疫"迷路"事件（绕路 +2 天） |
| 望远镜 | 200 元/个 | 可提前 1 天看到天气 |

**补给点**

| 地点 | 可提供 | 价格/条件 |
|---|---|---|
| 绿洲 | 水 | **免费，每队限取 8 份**（只此一次） |
| 村庄 | 水、食物 | 水 60 / 食物 40（大本营 2 倍价），无装备 |
| 王陵 | 抽卡 | 付 100 元入场，绕路 2 天 |

### 每日消耗

| 天气 | 概率 | 行进 | 消耗 |
|---|---|---|---|
| 晴天 | 55% | 可 | 水 1 + 食物 1 |
| 高温 | 30% | 可 | **水 2** + 食物 1 |
| 沙尘暴 | 15% | **不可行进** | 水 2 + 食物 2（原地消耗）；有帐篷则减半 |

> 天气由讲师每天现场抽牌公布，**全场同一套天气**（不是每组各抽）。这很重要——它模拟的是"共同的市场环境"，而不是"各家运气不同"。

### 规则

1. 出发前，各组有 **20 分钟**做预算与采购，**必须填记账表**
2. 每天按：**讲师公布天气 → 各组申报行进/停留 → 扣物资 → 更新位置**
3. 物资归零（水或食物任一为 0）→ 该队当天**原地失去行动力**，直到有补给（若无法补给则判定失败）
4. 载重超限 → 出发前必须丢弃物资（丢弃不退钱）
5. 到达藏宝山后可选择停留挖金，**每天只能选"挖"或"走"**
6. 回到大本营后结算：**带回金子数量 = 绩效**；未归队 = 0
7. 全程不允许跨队借贷，但**允许口头承诺、结盟、交换情报**（不强制履约）

### 流程（六小时版）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 开场导入 | 30 min | 背景、目标、规则、角色分工 |
| 预算与采购 | 20 min | 填记账表、买物资、称载重 |
| 推演（前 12 天） | 60 min | 逐日结算 |
| 中途复盘点 | 15 min | 不评判，只公布各组估值与位置 |
| 推演（后 13 天） | 65 min | 逐日结算至第 25 天 |
| 结算公布 | 20 min | 各组金子数、资产排名 |
| **深度复盘** | 75 min | 见第 4 节（这一节才是产品本体） |
| 收尾 | 15 min | 奖项 + 合影 |

## 3. 引导要点

### 讲解脚本（5 分钟）

> 你们是一个探险队。有一千块钱、一头骆驼、二十五天。
>
> 目标是带回尽可能多的金子。但有一个前提：**必须在第 25 天之前活着回到大本营。** 回不来，金子再多也是零。
>
> 每天我会公布天气。晴天走得动，高温要多喝水，沙尘暴原地不动、物资双倍消耗。
>
> 有一个绿洲，水是免费的，但只能取一次、限八份。
>
> 我最后说一句：**这个沙盘没有标准答案。** 你们做的每一个决定，我都会记下来，等一下复盘的时候，我们一条一条看。

### 教练在场边做什么

- **只做三件事**：公布天气、结算物资、观察决策过程。**绝不指导策略**
- **必须记录五类素材**（这是复盘的全部弹药）：
  1. 出发前有没有明确"要挖多少金"这个目标
  2. 采购时谁在做决定、谁在记账、谁没说话
  3. 第一次遇到高温/沙尘暴时的反应
  4. 有没有队伍之间谈判/结盟，谁先开口，承诺有没有兑现
  5. 决定"什么时候离开藏宝山"的那一刻，是谁拍的板
- **中途复盘点不要点评**，只报数据。一评点，后面 13 天的行为就全被污染了
- **不要提示"你水不够了"**。让人真的渴一次
- **结算时不要安慰**。困死沙漠的队伍就报"归零"，这个痛感是必须的

### 四个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 没定目标就出发 | 被问"要挖多少金"时答不出来 | 习惯"先干起来再说" |
| 只算平均值 | 按"平均天气"备物资，第一次高温就崩 | 用期望值做决策，忽略尾部风险 |
| 独裁式决策 | 队长一个人拍板，财务官只记账 | 压力下自动回到层级习惯 |
| 沉没成本 | 金子挖不够不甘心走，最后回不来 | 不愿意承认前面的投入收不回来 |

### 语言禁区

- ❌「你们这个买法不对」——当场指导会让后面全是"按教练说的做"
- ❌「我提醒一下，沙尘暴概率是 15%」——规则已讲，重复提醒等于给答案
- ✅「刚才这个决定，是谁提的？有人反对吗？」
- ✅「你们出发前，定的目标是多少金？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 出发前，你们定的目标是多少金？最后带回多少？
- 有几个队困死在沙漠？他们是在第几天开始出问题的？
- 采购时，水买了多少份？依据是什么（算出来的，还是感觉的）？
- 藏宝山停留了几天？决定离开的那一刻，谁拍的板？

### Feelings（感受）

- 第一次遇到高温那天，什么感觉？
- 物资只剩个位数时，队伍的气氛变了吗？
- 看到别的队带回更多金子，什么感觉？

### Findings（发现）

- 为什么"没定目标"的队伍，最后都没挖够？（因为"挖到不想挖"和"挖到目标"是两种完全不同的决策）
- 为什么按"平均天气"备物资会崩？（平均值掩盖了方差，而经营死于方差）
- 队伍里谁的意见最容易被忽略？他的意见里有没有对的？
- 王陵那张卡，是"机会"还是"陷阱"？取决于什么？
- 如果重来一次，你们会改哪一个决定？

### Future（应用）

- 我们今年的目标，具体是多少？（能不能一句话说出来）
- 我们的预算，是按"平均情况"做的，还是按"最坏情况"做的？
- 我们团队里，谁是"财务官"（只管执行不开口）？他的判断有没有被浪费？
- 我们上一个项目，有没有"沉没成本"导致不肯止损的时刻？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（20 以下） | 2–3 组，可直接对抗；推演可加速（每天 1 分钟） |
| 人数多（50–100） | **分批**（每批 40 人）或增配讲师（每 30 人 1 名）；6–8 人一桌是硬上限 |
| 只有 3 小时 | 天数缩到 15 天，挖金上限 3 天，复盘压到 45 分钟 |
| 想强化"跨部门" | 强制混编（每组含 3 个以上部门） |
| 想强化"风险" | 天气概率改为 晴 40 / 高温 35 / 沙尘暴 25（尾部风险加大） |
| 想强化"谈判" | 增加"村庄物资有限，先到先得"规则 |
| 想强化"领导力" | 每组设"观察员"（不给决策权，只观察并最后反馈） |
| 新员工 / 基层 | 参数放宽（启动资金 1500，天气概率下调），重点放在"分工与沟通"而非"战略" |
| 线上版 | 用共享表格做地图与记账，讲师在群里逐日公布天气 |
