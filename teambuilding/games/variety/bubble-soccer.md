# 泡泡足球（Bubble Soccer / 泡泡足球 · 撞撞球）

> **一句话**：套上一个大泡泡，撞人变成合法的——但你能不能站起来，取决于队友有没有扶你。

| **游戏名称** | 泡泡足球（Bubble Soccer / 泡泡足球 · 撞撞球 · 太空球足球） |
| **目的标签** | 释放压力 · 互助起身 · 轮换配合 |
| **形式标签** | 户外草坪 / 室内馆 · 分队对抗 · 撞球跑动 |
| **人数** | 全场 20–60 人（分 2–6 队，每队 5 人上场，轮换制） |
| **时长** | 90–120 min |
| **难度** | ⭐ 低（规则 2 分钟讲完） |
| **道具需求** | 有（充气泡泡服 每人 1 套 + 球门 2 个 + 足球 2–3 个 + 打气泵） |
| **场景标签** | 户外团建 · 减压 · 年轻团队 · 年会 · 家庭日 |
| **核心目标** | 用"摔倒了要人扶"这件小事，让"互助"变成身体记忆 |

---

**团建核心价值**：
- 😂 释放压力：撞球是唯一被允许的"合法冲撞"，笑点密集
- 🤝 互助起身：套着泡泡球摔倒后自己起不来，必须有人拉
- 🔄 轮换参与：单轮 2 分钟，人人能上场
- 📸 出片率极高：泡泡球本身自带喜剧效果

## 1. 游戏概览

每人套一个直径 1.2–1.5 米的透明充气泡泡（只露出腿），5 人对 5 人踢足球。因为有泡泡缓冲，**撞人是被允许的**——这也是它欢乐的全部来源。

**但它有一个被低估的机制**：套上泡泡球以后，**摔倒了很难自己站起来**。球体把人包裹住，手脚都够不到地面。你必须等队友过来拉你，或者自己想办法滚一圈借力。

所以它表面上是"撞球游戏"，实际上是"**你倒下时会不会有人来**"。

**为什么它适合大场轮换**：单轮只打 2 分钟（防闷热），所以 60 人可以分 6 队轮换，一小时内人人能上 1–2 次。这是少数"人多也不排队"的高强度项目。

## 2. 核心规则

### 准备

- **场地**：草坪（最佳）或体育馆。**必须四面有围挡**（泡泡球会弹很远）。场地 **25 m × 15 m**
- **球门**：2 个小球门（宽 1.5 m），无守门员
- **泡泡服**：每人 1 套，**穿前检查气密与肩带**
- **着装要求**：运动鞋（**不许穿钉鞋**）、长裤、**摘掉眼镜/手表/首饰**、**不许穿裙装**
- **打气泵**：现场必须有 1 台 + 备用泡泡服 2–3 套

### 规则

1. 每队 **5 人**上场，**单轮 2 分钟**（到点必须换人，不许延长）
2. 用脚踢球进对方球门得 1 分
3. **允许用泡泡撞击对手**（这是游戏的一部分），但有三条禁令：
   - **禁止从背后撞击站立的对手**（最容易造成颈椎/膝伤）
   - **禁止冲撞已倒地的人**
   - **禁止两人夹击一人**
4. 手不能碰球（除守门员外，本游戏不设守门员，故**全员不得用手**）
5. 球出界 → 由裁判从边线抛回场内
6. 摔倒者由**最近的人**拉起，或自己滚动借力起身；**裁判不进场扶人**（除受伤）
7. 单轮 2 分钟到点立即停，**所有人必须脱下泡泡服散热 3 分钟**再下一轮

### 安全红线

| 项 | 要求 |
|---|---|
| 单轮时长 | **≤2 分钟**（闷热是最大风险，不是撞击） |
| 摘眼镜 | 必须。泡泡内空间小，镜片碎裂风险高 |
| 禁忌人群 | 颈椎/腰椎病、心脏病、高血压、孕期、近期手术、严重近视（>600 度不建议） → **不上场** |
| 倒地 | 不得从倒地球员身上跨过或压上去 |
| 补水 | 每轮后必须补水，夏季加电解质 |
| 叫停 | 裁判喊停时所有人**站定不动**，不许继续撞 |

## 3. 引导要点

### 讲解脚本（2 分钟）

> 规则两分钟讲完：踢球进门得分，可以撞人。
>
> 三条不许：**不许从背后撞站着的人，不许撞已经倒下的，不许两个人夹一个。**
>
> 还有一件事：**你摔倒了，自己是起不来的。** 等一下你会体验到——躺在那儿，看着天，等着有人来拉你。
>
> 每轮两分钟，到点就换。别硬撑，闷在里面很难受。

### 教练在场边做什么

- **严格 2 分钟一轮**。超时是唯一的安全隐患来源
- **盯"背后撞击"和"撞倒地者"**，这两个是真实伤害的主要成因
- **不要进场扶人**（除非受伤）。让队友去扶，这是项目的核心体验
- **观察"谁去扶人"**：每次有人倒地，第一个过去的是谁？总是同一批人吗？
- **安排"轮换表"**：60 人 6 队，每轮 2 队上场，其余等待。等待区要有遮阳与饮水
- **结束后统一脱装备、散热、补水**，不要马上进入复盘

### 三个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 闷热不适 | 有人在泡泡里脸色发白、想吐 | 单轮超时，或夏季未控温 |
| 无人扶人 | 有人倒地 20 秒没人管，自己挣扎 | 队伍把"赢球"看得比"队友"重 |
| 围殴式冲撞 | 三个人一起撞一个人 | 没有裁判控场，或规则没讲清 |

### 语言禁区

- ❌「撞他！撞倒他！」——教练带头鼓励冲撞，安全事故几乎必然
- ❌「你怎么不扶一下」——事后指责，不如复盘时提问
- ✅「有人倒了，最近的那个人过去。」
- ✅「刚才你躺在地上那 10 秒，在想什么？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 全场一共摔倒几次？平均多久有人去扶？
- 第一个去扶人的，总是同一个人吗？
- 有几次是"队友在忙着抢球，没人管倒地的人"？
- 单轮 2 分钟里，平均能跑动几次？

### Feelings（感受）

- 躺在地上起不来、等人来拉的时候，什么感觉？
- 你去拉别人的时候，什么感觉？
- 撞到人那一刻，什么感觉？（爽？还是有点过意不去？）

### Findings（发现）

- 为什么"套上泡泡就允许撞人"反而让人更放得开？（因为规则明确了边界，边界内的行为不需要内疚）
- 为什么摔倒了要"别人拉"？（因为泡泡球的设计把"独立"变成了不可能——现实里也有很多这样的时刻）
- 为什么"从背后撞"比"正面撞"危险得多？（因为看不见，无法准备）
- 赢球和扶人冲突时，队伍通常选哪个？

### Future（应用）

- 我们团队里，有人"摔倒"（出问题/掉队）时，第一个过去的是谁？
- 我们会不会因为"忙着抢球"而忽略倒地的队友？
- 我们的规则里，有没有明确"什么可以做、什么不可以"？（边界不清时，人要么过度保守，要么过度冒进）
- 我们上一次被人"拉起来"是什么时候？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（10–20） | 3v3，场地 20 m × 12 m，单轮 90 秒 |
| 人数多（60） | 6 队轮换，每轮 2 队，**必须打印轮换表** |
| 夏季高温 | 单轮缩到 90 秒；改为傍晚/室内空调馆；每轮后强制脱装备 |
| 冬季 | 可正常进行（泡泡内反而保暖），但注意场地结冰 |
| 室内馆 | 需层高 ≥4 m、四面软包；地面不能太滑（摔倒是必然的） |
| 女生比例高 | 强制混编（每队至少 2 名女生）；降低对抗强度，改为"撞球保龄"等轻玩法 |
| 只有 60 分钟 | 3 轮 × 2 分钟 + 10 分钟复盘 |
| 想强化"互助" | 加规则：**每次得分前全队必须都站起来过**（迫使互相扶） |
| 年会 / 家庭日 | 改为"泡泡球保龄球"（撞倒瓶子计分），零对抗，安全得多 |
