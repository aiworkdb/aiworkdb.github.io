# 攻防箭（Archery Tag / 攻防箭对抗）

> **一句话**：中箭就出局，但打掉箭靶上的圆孔能把队友救回来——所以最强的队伍不是射得最准的，是最会救人的。

| **游戏名称** | 攻防箭（Archery Tag / 攻防箭 / 箭术对抗） |
| **目的标签** | 攻守取舍 · 救援协同 · 压力决策 |
| **形式标签** | 户外封闭场地 · 阵营对抗 · 跑动 + 掩体 |
| **人数** | 全场 20–100 人（分 2–6 队，每队 5–8 人上场） |
| **时长** | 120–180 min |
| **难度** | ⭐⭐⭐ 中等（射术门槛低，战术门槛高） |
| **道具需求** | 有（反曲弓 + 泡沫箭 + 全脸护具 + 掩体 + 靶） |
| **场景标签** | 户外团建 · 年轻团队 · 销售团队 · 竞技型团队 |
| **核心目标** | 用"救不救队友"这个选择，暴露团队的资源分配偏好 |

---

**团建核心价值**：
- 🎯 攻守取舍：射人还是打靶救人，每一箭都是资源分配
- 🤝 救援协同：牺牲自己的输出机会去复活队友
- 💥 压力决策：被瞄准时的判断速度
- 🛡️ 零疼痛对抗：泡沫箭头，安全但足够刺激

## 1. 游戏概览

攻防箭（Archery Tag）把"射箭"和"躲避球"揉在一起：用低磅数反曲弓射出**泡沫头箭**，被击中即淘汰。场地上有掩体和中央的箭堆，哨响后双方冲出去抢箭，然后开打。

**它的关键设计是"复活机制"**：

- 每队阵地后方有一个**靶**（五孔靶）
- **打掉靶上的小圆孔** → 可以复活 **1 名**已淘汰队友
- **打掉靶中心的大圆孔** → 可以复活 **全队**

这个机制把游戏从"谁射得准"变成"**谁愿意放弃输出机会去救人**"。已经占优的队伍要不要花箭去救人？落后队伍要不要冒险冲靶？——每一箭都是一次取舍。

**为什么它适合团建**：它同时提供"个人技术高光"（射中很爽）和"集体救援叙事"（复活全队那一刻全场沸腾），情绪曲线非常完整。

> 🔴 **安全前提**：这是本库里**唯一必须配专业护具的项目**。全脸面罩、低磅弓、泡沫箭完好，三者缺一不可。不建议任何机构自行组织。

## 2. 核心规则

### 准备（由专业教练执行）

- **场地**：封闭平地，**20 m × 40 m**，两侧各设一方阵地。四周必须有硬隔离（围网/围栏），**严禁观众站在场侧**
- **掩体**：每方 3–5 个充气/木质掩体，布置在本方半场
- **箭堆**：场地中央放箭（双方共用），哨响同时冲抢
- **护具**：**全脸面罩**（必须，不许只戴护目镜）；建议加护胸
- **弓**：低磅数反曲弓（**15–25 磅**），拉力过大会导致泡沫头穿透力过强
- **箭**：泡沫头箭，**每支使用前必须检查泡沫头无破损、箭杆无裂纹**。破损箭一律弃用

### 规则

1. 每队 5–8 人上场，哨响后从本方阵地冲向中央箭堆抢箭（**每人最多抱 3 支**）
2. 被箭**直接击中身体或装备**即淘汰，须高举弓、走出场外到"淘汰区"
3. **箭落地后可以用**（捡起来继续射），但**射出的箭必须先落地才能被捡**
4. **禁止近距离射击**：距离对方 **3 米以内不得放箭**（硬规则，违反即本人淘汰）
5. **禁止射头部**（面罩能挡，但仍是禁区）；**禁止射已淘汰的人**
6. 打掉靶上**小圆孔** → 复活 1 名队友；打掉**中心大圆孔** → 复活全队
7. 复活后从本方阵地重新入场，**不可带箭入场**（要重新去抢）
8. 一方全员被淘汰 → 该局结束，另一方胜
9. 单局 **8–10 分钟**，到时按存活人数判定

### 安全红线（教练必须逐条念，且现场执行）

| 项 | 要求 |
|---|---|
| 面罩 | **全程不得摘下**，包括在场边休息时 |
| 近射 | 3 米内不得放箭；对方举手示意"近距离"必须停射 |
| 箭头 | 每局开始前逐支检查泡沫头；破损即弃 |
| 弓 | 不得空放（dry fire），不得对人拉满不放 |
| 观众 | 必须在围网外，**不得站在场侧 5 米内** |
| 身体状况 | 肩袖损伤、颈椎病、高血压、孕期 → 不上场（可做记分/裁判） |
| 叫停 | 教练喊"停"时**所有弓立即放下、箭不得再射** |

## 3. 引导要点

### 讲解脚本（4 分钟）

> 规则很简单：被箭打中就出局。但是——**你们阵地后面那个靶，能救人。**
>
> 打掉小孔，救回一个队友。打掉中间那个大孔，**全队复活**。
>
> 所以你们每一箭都要想一件事：这一箭，是去射人，还是去打靶？
>
> 安全三句：**面罩不许摘。三米内不许放箭。我说停，所有人的弓立刻放下。**
>
> 违反任何一条，本人直接出局。

### 教练在场边做什么

- **安全员必须多于裁判**。100 人场至少 4 名安全员，站在场地四角
- **开场前逐支检查箭**，这个过程不要省。一支破损泡沫箭就能造成眼部伤害
- **盯"近射"和"摘面罩"**，这两个是最高频违规，也是最容易出事的
- **记录"救援决策"**：哪一队在领先时还去救人？哪一队在落后时放弃救队友只顾射人？
- **不要在场上指导战术**。这个项目的战术选择就是它的全部内容
- **每局结束留 30 秒**，让双方看一眼靶上的孔——那是他们这一局所有取舍的物证

### 四个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 全员抢箭 | 哨响后 8 个人全冲中央，本方阵地空无一人 | 没有分工 |
| 只顾射人不救人 | 打掉 5 个人，但自己队只剩 2 人 | 把"输出"当唯一价值 |
| 箭荒 | 前 2 分钟把箭射光，后面干站着 | 没有"箭是资源"的意识 |
| 违规近射 | 紧张时对 1 米外的人放箭 | 兴奋压过规则记忆 |

### 语言禁区

- ❌「你怎么不救人？」——当众指责会引发对立
- ❌「射那个最弱的」——把对抗变成针对个人
- ✅「刚才那个大孔，你们为什么没打？」
- ✅「箭只剩 2 支的时候，你们在想什么？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 全场一共复活了几次？其中"全体复活"有几次？
- 领先的时候，队伍还去打靶吗？
- 落后的队伍，是选择救人还是继续射人？
- 有多少支箭是在"没有明确目标"的情况下射出去的？

### Feelings（感受）

- 被击中出局、走到场边看队友打，什么感觉？
- 队友打掉圆孔把你救回来，什么感觉？
- 你们队放弃救人的时候，被放弃的那个人是什么反应？

### Findings（发现）

- 为什么"救一个人"要花掉一箭，而"射一个人"只要一箭——两个选择为什么不等价？（因为救人改变的是"人数"，射人改变的是"对方人数"，两者数学上等价，但心理上完全不同）
- 领先时为什么更不愿意去救人？（沉没成本与风险厌恶）
- 为什么必须限制"每人最多 3 支箭"？（资源约束才会产生取舍）
- 如果取消复活机制，这个游戏会变成什么？（纯射击比赛，团队价值消失）

### Future（应用）

- 我们团队在资源紧张时，优先保"输出"还是保"人"？
- 我们有没有"救人机制"？（帮落后的同事补位、给新人时间成长）
- 领先的时候，我们还会做长期投入吗？还是开始保守？
- 我们的"箭"（预算/人力/时间）有没有被无目标地消耗掉？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（10–16） | 3v3，场地 15 m × 30 m；单局 6 分钟 |
| 人数多（80–100） | **多场地并行**，各场地循环赛；或改为"轮换制"（每队打 3 局即换） |
| 零基础居多 | 增加 30 分钟射术练习（打静止靶），再进对抗 |
| 女生比例高 | 降低弓磅数（12–15 磅），缩短场地到 15 m |
| 只有 90 分钟 | 练习 25 + 2 局对抗 30 + 复盘 20（去掉循环赛） |
| 场地无围网 | **不做**。必须有硬隔离，否则箭飞出场地是重大风险 |
| 想强化"资源" | 箭改为"每队每局固定 10 支"，不再从中央抢（取舍更极端） |
| 想降低对抗 | 改为"打靶赛"（只打靶不打人，比命中数） |
| 室内 | 需层高 ≥4 m 且全封闭，一般不建议 |
