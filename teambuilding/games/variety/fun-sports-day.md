# 大型趣味运动会（Fun Sports Day / 企业趣味运动会）

> **一句话**：两百个人、八个项目、一张积分榜——不拼个人体能，拼的是"每个项目都有人愿意上"。

| **游戏名称** | 大型趣味运动会（Fun Sports Day / 企业趣味运动会 / 职工运动会） |
| **目的标签** | 全员参与 · 班组荣誉 · 积分协作 |
| **形式标签** | 户外操场 / 草坪 · 多项目轮转 · 分队对抗 |
| **人数** | 全场 50–500 人（分 6–20 队，每队 10–30 人） |
| **时长** | 240–420 min（半天 – 一天） |
| **难度** | ⭐⭐ 偏低（单项都简单，组织难度全在轮转） |
| **道具需求** | 有（充气道具 + 标志桶 + 积分板 + 哨子 + 号码背心） |
| **场景标签** | 职工运动会 · 年会 · 企业家庭日 · 制造/一线团队 · 大型团建 |
| **核心目标** | 用"轮转积分"让每个人至少上场一次，而不是只有运动好的几个 |

---

**团建核心价值**：
- 🏃 全员参与：项目多、门槛低，体能差的人也有位置
- 🏅 班组荣誉：以队为单位积分，个人英雄主义无效
- 🔄 轮转组织：多项目并行轮换，200 人不用排队等到天黑
- 🎉 氛围拉满：充气道具 + 加油声 + 颁奖，是最不需要"讲道理"的团建

## 1. 游戏概览

这是大型团建里**最稳、最不容易翻车、也最容易被低估**的一类。它的结构不是"玩一个游戏"，而是"组织一场小型赛事"：

- 全场分成 6–20 支队（按部门/班组/随机混编）
- 设 6–10 个**趣味项目**，每项 8–15 分钟
- **多项目同时进行，各队轮转**（这是关键：200 人如果排队玩一个项目，一天只能玩 3 个）
- 每项按名次计积分，最后按总积分排名
- 中间穿插 1–2 个"全员同框"项目（如百人拔河、大合影）

**为什么它比"分组玩一个游戏"更适合 100 人以上**：

| 单项目大场 | 趣味运动会 |
|---|---|
| 只有 1 个高潮点 | 6–10 个高潮点 |
| 观众多、参与者少 | 轮转制，人人要上场 |
| 体能差的人全程旁观 | 项目难度错开，总有适合的 |
| 一旦下雨/道具坏，全场崩 | 单项目出问题可跳过，不影响整体 |

## 2. 核心规则

### 项目库（按场地与人数自由组合）

**A 类：充气竞速（需采购道具，出片最好）**

| 项目 | 人数 | 规则要点 |
|---|---|---|
| **趣味毛毛虫** | 6–8 人/组 | 跨坐充气毛毛虫，双手抓把手，同步跑至折返点换组返回；步调不一致会原地打转 |
| **运转乾坤** | 6 人/组 | 双手高举巨型充气球跑至折返点，换人返回；球不能落地 |
| **同舟共济（充气筏）** | 8–10 人/组 | 全队站充气筏上，靠移动筏子前进；有人落地即罚时 |
| **龟兔赛跑** | 10 人（分 2 组） | 钻入充气龟/兔道具内，往返接力 |
| **旱地龙舟** | 8–10 人/组 | 跨骑充气龙舟，靠腿部同步"划"向前 |
| **车轮滚滚** | 6–8 人/组 | 队员在气垫上保护瑜伽球，其余人推动气垫前行 |

**B 类：零/低道具（不需采购，可自行组织）**

| 项目 | 人数 | 规则要点 |
|---|---|---|
| **不倒森林** | 8–12 人/组 | 每人手掌按住一根立杆，统一口令同时换位，所有杆不能倒 |
| **合力筑塔** | 6–10 人/组 | 每人拉一根绳控制挂钩，把积木逐块吊起叠塔 |
| **珠行万里** | 8–15 人/组 | 每人持半管接力传乒乓球至终点容器（库内已有单款，此处作为运动会项目） |
| **集体长绳** | 10–20 人/组 | 8 字跳接力，2 分钟内计通过人次 |
| **拔河** | 15–20 人/队 | 三局两胜；**必须按体重分级或抽签，避免实力悬殊** |
| **指压板接力** | 6–8 人/组 | 指压板上完成俯卧撑/跳绳/踢毽等任务后接力 |

**C 类：全员同框（放在开场或收尾）**

| 项目 | 人数 | 规则要点 |
|---|---|---|
| **百人拔河** | 全员 | 分两方（按单双号），一次定胜负，纯氛围 |
| **超级障碍赛** | 分批 | 充气跨栏 + 钻洞 + 平衡木，计时通关 |
| **大合影 / 航拍** | 全员 | 摆 LOGO 或年份数字 |

### 赛制

1. 每队 10–30 人，选出 ① 队长（统筹）② 项目负责人（每项 1 人，负责组队与交接）③ 记分员
2. **轮转制**：设 N 个赛点，各队按"轮转表"依次轮换，每站 12–15 分钟（含讲解 + 1–2 轮比赛）
3. 每项名次积分：第 1 名 = 队数 +1 分，第 2 名 = 队数 分……递减（避免并列）
4. 违规罚则：轻违规 +5 秒，重违规（如全程不落地却落地）该项目记 0 分
5. 中途退赛/弃权：该项目记 0 分，不影响其他项目
6. 最终按总积分排名；设"最佳协作""最佳风采""全员完赛"等非竞技奖

### 轮转表示例（8 队 8 站）

| 队伍 | 09:30 | 09:50 | 10:10 | 10:30 | 10:50 | 11:10 | 11:30 | 11:50 |
|---|---|---|---|---|---|---|---|---|
| 1 队 | 毛毛虫 | 不倒森林 | 运转乾坤 | 合力筑塔 | 同舟共济 | 长绳 | 旱地龙舟 | 拔河 |
| 2 队 | 不倒森林 | 运转乾坤 | 合力筑塔 | 同舟共济 | 长绳 | 旱地龙舟 | 拔河 | 毛毛虫 |
| … | 依次轮转，每队走完 8 站 | | | | | | | |

> ⚠️ **轮转表必须提前打印、人手一份、贴在每个赛点。** 现场靠喊"下一队去哪"是大型运动会最常见的崩盘原因。

### 流程（一天版）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 签到 + 发号码背心 | 30 min | 分队、发背心、领积分卡 |
| 热身 + 开幕 | 20 min | 全员热身操、领导致辞、队旗展示 |
| 上午赛段 | 120 min | 4 站轮转 |
| 午餐 | 60 min | — |
| 下午赛段 | 120 min | 4 站轮转 |
| 全员同框项目 | 20 min | 百人拔河 / 超级障碍赛 |
| 统计 + 颁奖 | 30 min | 积分统计、颁奖、航拍合影 |

## 3. 引导要点

### 讲解脚本（开幕 2 分钟）

> 今天不比谁跑得快。比的是**每一队有没有把每个项目都玩完、玩明白**。
>
> 一共八个项目，每个项目十二分钟。你们会按手上的轮转表走，走完八个。
>
> 三个规则：**第一，每个项目都要有负责人**，交接的时候人要对接上；**第二，人不齐不开赛**，缺人这项就记零分；**第三，赢不赢不重要，别受伤。**
>
> 现在，第一站，出发。

### 组织者（总裁判）在场边做什么

- **控的是"表"不是"人"**：全程盯轮转表的时间节点，到点吹哨换站，不许某一站拖延
- **每个赛点必须有 1 名裁判 + 1 名安全员**，裁判只管规则，安全员只管人
- **提前 30 分钟检查所有充气道具**：漏气、绳断、拉手脱落是最常见的开场事故
- **广播要密**：每 10 分钟播报一次积分榜前 3 名，这是氛围的燃料
- **厕所/饮水/医疗点位置必须在开场讲清**，200 人场这是刚需
- **颁奖要给足**：哪怕是小奖品，也要有音乐、有上台、有合影

### 四个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 轮转堵车 | 某站排队 30 分钟，后面全乱 | 没留"讲解 + 2 轮"的时间余量 |
| 强队通吃 | 一个队包揽前几名，其他队躺平 | 项目同质化（全是体能型） |
| 有人全程不上场 | 每项都是同 8 个人 | 没有"每项负责人"机制，也没规定轮换 |
| 道具事故 | 充气道具爆裂、拉手脱落 | 开场未检查，或超载使用 |

### 语言禁区

- ❌「大家加油，争第一！」——只强调名次，弱队第 3 站就放弃
- ❌「这个项目女生就别上了」——一句话把一半人排除
- ✅「这一项你们队谁负责？下一位交接给谁？」
- ✅「这站玩得最开心的是哪个环节？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 你们队有几个项目是"人不齐"开赛的？
- 八站里，有几个人从头到尾没上场？
- 每项负责人交接时，有没有出现"下一站不知道去哪"？
- 总积分第一的队，是不是每项都参加了？

### Feelings（感受）

- 站在场边看别人比赛时，什么感觉？
- 自己队某个项目搞砸了，队里什么反应？
- 颁奖那一刻，什么感觉？

### Findings（发现）

- 为什么"积分制 + 轮转制"能让更多人上场？（因为每站都要重新组队）
- 为什么"项目负责人"这个角色这么关键？（交接点是唯一会掉链子的地方）
- 为什么项目要"难度错开"？（全是体能型，体能差的就自动退出了）
- 运动会和真实项目有什么像？（都有排期、交接、资源、临场应变）

### Future（应用）

- 我们团队里，谁是"从头到尾没上场"的人？为什么？
- 我们的工作有没有"轮转表"（明确的交接节点）？还是靠喊？
- 我们的"项目库"是不是太单一（只有一种类型的人能发光）？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 只有半天 | 保留 5 站（3 充气 + 2 零道具）+ 1 个全员项目 |
| 人数 300–500 | 分 A/B 两个大赛区，各 8 队，独立轮转；颁奖合并 |
| 雨天预案 | 移到体育馆/厂房；或改为"室内趣味运动会"（不倒森林、合力筑塔、长绳、指压板） |
| 体能差异大 | 提高"低体能"项目占比（合力筑塔、珠行万里、不倒森林），降低竞速类 |
| 年龄跨度大 | 取消"十人九足"等易摔项目；拔河改为"分级拔河"（按体重分档） |
| 制造/一线团队 | 加入"班组技能闯关"（如安全操作、装配速度），把生产技能变成项目 |
| 企业家庭日 | 增加亲子项目（袋鼠跳、亲子接力），大人小孩混编 |
| 想强化"跨部门" | 强制混编分队（不许同部门成队），队名自取 |

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| 充气道具（毛毛虫/乾坤球/龙舟等） | 按项目 | **开场前 30 分钟逐件检查气密与拉手** |
| 标志桶 / 锥形筒 | 每站 8–12 个 | 划线、折返点 |
| 号码背心（分队色） | 按人数 | 颜色必须一眼可分 |
| 积分板（大白板/展架） | 1–2 块 | 全场可见，实时更新 |
| 轮转表（打印） | 每队 1 份 + 每站 1 份 | **最重要的物料，必须有** |
| 哨子 / 扩音器 | 每站 1 个 + 全场 1 套 | 200 人场必须有扩音 |
| 秒表 | 每站 2 个 | 计时类项目 |
| 瑜伽球 | 每站 2–3 个 | 车轮滚滚等 |
| 指压板 | 每站 1 套 | 接力类 |
| 长绳 | 2–3 根 | 集体跳 |
| 医药包 + 冰袋 | 2 套 | 扭伤是最高频伤情 |
| 饮用水 / 遮阳棚 | 按人数 | 夏季必备 |
| 奖品 / 奖牌 | 按队数 | 含非竞技奖（最佳风采等） |
