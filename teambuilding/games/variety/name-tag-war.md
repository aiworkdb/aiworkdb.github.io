# 撕名牌大战 (Name Tag War)

> **综艺竞技 · 奔跑吧同款 · 大型户外**  
> 适合：全员运动会 / 户外团建 / 男生多的团队

---

## 🎯 游戏目标

《奔跑吧》的标志性环节，团建版安全重制：每人身后贴一张名牌，在规定区域内互相追逐，撕下对方名牌得分，名牌被撕者出局（或转为「裁判/摄影师」）。这是把综艺效果拉满的最强方案，也是规则和安全要求最高的一个——本方案已内置全套安全条款。

**团建核心价值**：
- 🏃 体能释放：一小时的奔跑，抵得上一个月的健身房
- 🎯 策略博弈：结盟、诱敌、围剿，职场剧本实时上演
- 📺 综艺效果：有导演、有反转、有表情包，摄影素材管够
- 🤝 跨层融合：没人管职级，只看谁跑得快

## 👥 分队规则

- 按袖标颜色分队，每队选1名「队长」（可发动一次「护盾」技能：本队一人5秒内不可被撕）
- 平衡体力：每队至少2名女生、混合不同部门
- 男女同场规则：男生只能撕男生，女生只能撕女生（避免体型差的冲撞风险），跨性别撕名牌需「喊名确认」后由本人配合撕（接触即算）

## 🎮 游戏流程

### 规则讲解（5分钟）

1. 场地边界、出界=自动出局
2. 禁止动作：拉拽衣服、推搡、绊人、抱摔、撕非名牌部位
3. 护盾技能每队限1次，队长发动
4. 名牌被撕：主动停赛，去「休息区」当摄影师/啦啦队（不罚下场看手机）

### 第一轮：混战（15分钟）

- 四队混战，撕任一非本队队员的名牌
- 撕得1张名牌=该队+1分，被撕者出局

### 中场：任务时间（10分钟）

- 每队抽1个「锦囊任务」：全队与陌生人合影/找到隐藏道具/摆指定姿势
- 完成任务+3分，把「纯体力局」变成「体力+脑力局」

### 第二轮：联盟战（15分钟）

- 第一名和第四名自动结盟，二三名结盟（平衡机制）
- 结盟方共享积分，最后联盟对抗

### 结算（5分钟）

- 公布得分，冠军颁奖（建议实物大奖+「全场最快」单项奖）
- 全员大合影，导出表情包

## 🛡️ 安全条款（本方案核心，缺一不可）

1. **热身必做**：5分钟踝关节、膝关节、肩关节活动，缺席者不许上场
2. **场地验收**：提前一天检查地面（无碎石/无积水/无坑洼），划定边界并口头警告
3. **禁止接触清单**：拉衣、推搡、绊人、扑倒、锁喉——犯规2次该队-2分，恶意犯规直接罚下
4. **护具建议**：眼镜党戴运动眼镜或隐形，否则只能当摄影师
5. **随时退出**：任何人喊「停」或面露难色，裁判必须立即暂停其比赛，不劝不劝
6. **雨天备案**：场地湿滑顺延，绝不硬上
7. **保险**：户外版务必确认公司活动意外险覆盖当天（行政确认，不口头确认）

## 💡 教练引导指南

**开场话术**：
> 「这是今天唯一一个会出汗的环节。规则只有一条底线：可以拼命跑，不能拼命拽。累了随时喊停，去当摄影师，一样算参赛。」

**控场三招**：
- 有人太较真动手：立刻暂停，宣布犯规，让其队「冷静3分钟」
- 有人摸鱼躲远：任务环节强制参与，且躲远=本方失分
- 女生被针对围攻：重申「同性可撕」规则，裁判重点盯防

**复盘三问（快速版）**：
1. 你们队的护盾技能用对时机了吗？现实中的「底牌」该什么时候亮？
2. 联盟战中，你们是怎么决定「信任谁」的？工作里的跨部门结盟像不像？
3. 全场跑得最猛的人，是策略型还是莽夫型？你属于哪种？
### 🎬 游戏后深度复盘（4F 框架 · 正式团建 10–15 分钟）

> 时间紧用上面三问快速带过；运动会/管理层融合场景建议用完整框架收口。

| 步骤 | 时长 | 引导问题 |
| :--- | :--- | :--- |
| **1️⃣ 事实回顾** | 2–3分钟 | 护盾用在了哪一刻？联盟是怎么形成的？最后一名队员怎么被干掉的？ |
| **2️⃣ 感受分享** | 2–3分钟 | 被围剿时肾上腺素飙升的瞬间你在想什么？出局后当摄影师，心态转变了吗？ |
| **3️⃣ 学习洞察** | 4–6分钟 | 关于策略：联盟里你们怎么决定信任谁？和工作中的跨部门结盟像不像？<br>关于底牌：护盾=底牌，什么时候亮最值？现实中的底牌该什么时候亮？<br>关于角色：全场最猛的人是策略型还是莽夫型？你的团队更需要哪种？ |
| **4️⃣ 行动迁移** | 3–5分钟 | 画出团队的「结盟地图」：哪些部门是盟友、哪些该结盟还没结盟？下一步怎么破冰？ |

## 🔄 变体玩法

### 变体1：坐姿版（零身体接触）

围成圈坐好，只能「撕」相邻三人的名牌（伸手可及范围），配上真心话任务。适合办公室/会议室/完全不能动的场合。

### 变体2：夜光版（ evening ）

关灯+荧光棒+荧光名牌，安全升级（场地缩小），氛围拉满。

### 变体3：亲子版（家庭日）

儿童专场：慢动作规则（必须「树懒速度」移动），撕掉后要回答一个问题才能得分。无任何追逐风险。

## 🎯 适合的培训主题

### 1. 策略执行与临场应变

**关键词**：结盟博弈 · 诱敌布局 · 底牌管理

**适用场景**：销售团队 / 竞赛型团建 / 市场活动

**迁移重点**：结盟与背叛、护盾时机、诱敌分工，是商战策略的具象化沙盘，复盘「哪步棋赢了/输了」比复盘「谁跑得快」有价值得多。

### 2. 跨层级融合与去职级化

**关键词**：共同目标 · 扁平协作 · 管理层融入

**适用场景**：层级森严的组织 / 高管与员工融合 / 全员运动会

**迁移重点**：场上「没人管职级，只看谁跑得快」的体验，是打破层级隔阂的最短路径，适合管理层与执行层关系紧张的组织。

### 3. 规则意识与安全管理

**关键词**：边界意识 · 底线思维 · 安全退出

**适用场景**：大型活动组织者培训 / 户外活动 / 风控意识

**迁移重点**：这款游戏的安全条款本身就是教材：任何「玩得起」的活动，前提是规则被设计好、退出权被尊重。

## 📝 常见问题

**Q：有人就是不想跑，能只围观吗？**
A：能，且必须给个体面的角色：官方摄影师、积分员、DJ。**任何岗位都算参赛，颁奖一视同仁。**

**Q：女生参与度低？**
A：同性可撕规则+中场任务多为解谜型（女生优势项）+设置「最佳摄影奖」等非体力奖项。

**Q：场地不大，40人太挤？**
A：缩到20人上场，其余人「竞猜团」+摄影师，分时段轮换。
