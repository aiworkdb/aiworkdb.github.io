# 王牌对王牌 (Trivia Show)

> **综艺竞技 · 团队竞答 · 室内高能**  
> 适合：会议室就能开 / 全年龄 / 压轴环节

---

## 🎯 游戏目标

把《王牌对王牌》的综艺竞答搬进会议室：抢答、风险押注、表演题、惩罚机制全套配齐。比「知识竞赛」多了表演和押注的博弈，比「你画我猜」多了知识的硬核。一个主持人+一个计分板就能开演，是室内团建的收视率之王。

**团建核心价值**：
- 📺 综艺仪式感：队名、口号、擂主挑战，参与感从进场开始
- 🎲 风险决策：押分机制让「会不会」变成「敢不敢赌」
- 🎭 表演释放：比划题让放得开的人成为全场明星
- 🧠 团队知识库：题目可定制为公司历史/产品/行业梗

## 🎲 核心机制

### 四类题型（每轮换着来）

| 题型 | 形式 | 综艺效果 |
| :--- | :--- | :--- |
| 抢答题 | 主持人念题，举手/按铃抢答 | 拼手速，笑料百出 |
| 风险题 | 押注积分（10/20/50），答对翻倍答错扣光 | 赌性大发，逆转神器 |
| 表演题 | 你画我猜/动作接龙/方言演绎 | 全场笑声峰值 |
| 线索题 | 逐条放出线索，越晚答对分越少 | 逆向思维，适合压轴 |

### 王牌技能（每队1次）

- **双倍卡**：本题得分×2
- **跳过卡**：跳过一道必错题
- **求助卡** ：「场外观众」（未上场的同事）30秒代答

### 惩罚机制（轻量，主打气氛）

答错方表演一个「综艺小惩罚」：模仿表情包/用方言读台词/单脚站立答下一题。**禁止任何喝罚酒、怪味饮料等身体惩罚**。

## 🎮 游戏流程

### 开场（5分钟）

- 各队起队名+口号+登场动作（中二一点更好）
- 发三张王牌技能卡，宣布押注规则

### 第一关：抢答赛（12分钟）

- 10题快问快答，答错不扣分（降低门槛，人人参与）
- 题目示例（定制向）：公司哪年成立？咱们产品口号是什么？老板口头禅是什么？

### 第二关：风险局（12分钟）

- 5题，每题押注10/20/50分
- 领先方会被针对：落后方获得「押注优先权」（可先押后看题）

### 第三关：表演赛（12分钟）

- 比划题接龙：每队1人看词，全队接力比划，3分钟猜对最多者胜
- 可换成「公司产品用身体摆出来」

### 终局：线索抢答（8分钟）

- 1道终极题，5条线索逐条放出
- 使用求救卡/双倍卡的最后机会，逆转只在这一题

### 结算（5分钟）

冠军奖+「最快手速奖」「最佳演技奖」「赌神奖」。

## 💡 教练引导指南

**主持人是灵魂**：语速快、会拱火、敢调侃。经典话术：
> 「三号队还有50分没押，这是你们最后的倔强吗？」

**控场三招**：
- 有人太强连续答对：给ta队派「 Silent 一轮」禁赛（平衡机制）
- 冷场：上表演题，笑声一响气氛就回来了
- 题目争议：主持人秒判「以我为准」，赛后可以争论

**复盘三问（快速版）**：
1. 押注50分那题，你们队是怎么决策的？现实里你敢 all in 吗？
2. 求助卡你们用对时机了吗？工作中你什么时候承认「我需要支援」？
3. 笑到最后的队，是知识最多还是策略最稳？
### 🎬 游戏后深度复盘（4F 框架 · 正式团建 10–15 分钟）

> 时间紧用上面三问快速带过；管理者培训/企业文化活动建议用完整框架。

| 步骤 | 时长 | 引导问题 |
| :--- | :--- | :--- |
| **1️⃣ 事实回顾** | 2–3分钟 | 最大一次押注押了多少？对了吗？求助卡用在了哪一题？如果重来一次怎么分配？ |
| **2️⃣ 感受分享** | 2–3分钟 | 押上全部积分时手抖吗？求助卡用出去/没舍得用时，各是什么心情？ |
| **3️⃣ 学习洞察** | 4–6分钟 | 关于风险决策：all in 是怎么做出来的？信息充分吗？赌性和计算怎么区分？<br>关于求助：什么时候承认「我需要支援」最难？我们团队的求助文化好吗？<br>关于策略：冠军队赢在知识、策略还是胆量？对应工作中的哪种竞争力？ |
| **4️⃣ 行动迁移** | 3–5分钟 | 给手头一个项目「押注」：如果只能押 20/50/100 三档投入，你押哪档？为什么？ |

## 🔄 变体玩法

### 变体1：主题定制版（推荐）

题目全部换成公司内容：发展史、产品线、行业黑话、同事趣事。**定制题库是这类游戏口碑爆炸的关键。**

### 变体2：家庭友好版（家庭日）

加入儿童题、常识题、长辈年代题，混合分队（一家一队）。

### 变体3：线上版（远程团队）

腾讯会议+微信群抢答（拼打字速度）+线上你画我猜。体验保留80%。

## ⚠️ 参与限制与安全

- **零身体接触**：全程坐姿竞答，轮椅使用者可直接担任队长
- **不喝酒**：惩罚只有表演，无任何饮食类惩罚；赌注只是积分
- **防霸凌**：禁止拿同事隐私/外貌/地域编题；题目提前过一遍行政
- **自愿上场**：可担任「场外观众」参与求助卡机制，同样有奖
- **时长封顶**：60分钟，宁可砍题不许拖

## 🎯 适合的培训主题

### 1. 风险决策与期望值思维

**关键词**：押注博弈 · all in 与止损 · 风险偏好

**适用场景**：管理决策训练 / 经营模拟 / 创业者团建

**迁移重点**：押注机制把「会不会」变成「敢不敢赌、押多少」，是风险决策的零成本试错场，可延伸讲解期望值与止损线。

### 2. 组织知识资产化

**关键词**：定制题库 · 集体记忆 · 文化传承

**适用场景**：新员工培训 / 企业文化融入 / 司庆与周年活动

**迁移重点**：公司历史、产品线、行业梗进题库，玩着游戏就把「组织记忆」传递了，是新员工融入的高黏性形式。

### 3. 求助行为与协作文化

**关键词**：承认不足 · 场外支援 · 资源调度

**适用场景**：团队互助建设 / 跨部门支援机制 / 管理者培养

**迁移重点**：求助卡「用还是不用」折射团队心理安全感——不敢求助的团队，协作必然卡壳，值得管理者复盘。

## 📝 常见问题

**Q：题目总超时怎么办？**
A：备30题只准备20题的时间；主持人有权「本题作废，下一题」。

**Q：有人藏私不答题？**
A：规则改为「每人限答2题，超次数无效」，强制轮换。

**Q：赌神队靠押注一路领先？**
A：押注上限设50分封顶+「押注优先权」给落后方，两招搞定。
