# 巅峰乐团（Rock Band / 巅峰乐团 · 乐队的夏天）

> **一句话**：主唱只有一个，但让一首歌成立的，是后面那群不出声的人。

| **游戏名称** | 巅峰乐团（Rock Band / 巅峰乐团 / 乐队团建） |
| **目的标签** | 角色互补 · 分工排练 · 舞台呈现 |
| **形式标签** | 室内舞台 / 宴会厅 · 分组排练 + 汇报演出 · 站姿 |
| **人数** | 全场 50–200 人（分 4–8 支乐队，每队 8–12 人） |
| **时长** | 150–210 min |
| **难度** | ⭐⭐ 偏低（不需要真会乐器，靠角色分配） |
| **道具需求** | 有（道具乐器 + 音响 + 麦克风 + 舞台灯光 + 服装道具） |
| **场景标签** | 年会 · 周年庆 · 年轻团队 · 销售团队 · 氛围型团建 |
| **核心目标** | 让"不是主角的人"也必须有明确任务，否则整场演出只剩一个主唱 |

---

**团建核心价值**：
- 🎤 角色互补：主唱、乐手、和声、伴舞、舞美，缺一个就单薄
- 🔁 分工排练：每个人都要练自己的部分，不能靠一个人撑
- 🎭 舞台呈现：从排练到正式演出，压力真实
- 🎉 情绪高点：灯光、音响、欢呼，是年会最好的收尾

## 1. 游戏概览

全场分成若干支"乐队"，每队选一首歌，分配角色，排练 90 分钟，然后依次上台演出，由全场或评委打分。

**关键前提：绝大多数人不会乐器。** 所以这个项目的设计不是"教人演奏"，而是**"用角色把每个人放进去"**：

| 角色 | 人数 | 任务 | 不需要什么 |
|---|---|---|---|
| 主唱 | 1–2 | 唱主旋律 | 不需要好听，需要敢唱 |
| 吉他手 | 1–2 | 道具吉他 + 夸张动作 | 不需要会弹 |
| 贝斯手 | 1 | 道具贝斯 + 稳定站姿 | 不需要会弹 |
| 鼓手 | 1 | 电子鼓垫/道具鼓，负责打拍子 | 不需要技术，需要稳 |
| 和声组 | 2–4 | 副歌部分齐唱 | 不需要独唱能力 |
| 伴舞组 | 2–4 | 编 8 拍动作 | 不需要舞蹈基础 |
| 舞美/道具 | 1–2 | 服装、手举牌、彩带 | 不需要上台 |

**它和非洲鼓/箱鼓的区别**：那两个是"全员同质"（都在打鼓），这个是**"全员异质"**（每个人角色完全不同）。所以它的教学点不是"同步"，而是"**每个人是否都有自己的位置**"。

## 2. 核心规则

### 准备

- **场地**：一个主舞台（≥6 m × 4 m）+ 若干排练角落（每队一个，需能放音响）
- **设备**：每队 1 套音响（蓝牙音箱即可）+ 2 支无线麦 + 伴奏音频（提前剪好）
- **道具乐器**：道具吉他/贝斯（不发声）、电子鼓垫或道具鼓、沙锤/铃鼓
- **曲库**：提前给 20–30 首"人人会唱"的歌（副歌部分必须耳熟），**不许多选，先到先得**
- **服装**：每队 1 个"造型包"（头巾/墨镜/彩带/发光手环等）

### 规则

1. 每队 **8–12 人**，**必须用满 5 类角色**（主唱/乐手/鼓/和声/伴舞），缺一类扣分
2. 每队从曲库中**选 1 首**（先到先得，不许重复）
3. 排练时间 **90 分钟**，期间可自由使用排练区
4. 演出时长 **3–4 分钟**（伴奏已剪好，超时掐断）
5. 评分维度：**完成度（40）/ 全员参与（30）/ 舞台表现（20）/ 创意（10）**
6. **"全员参与"是硬指标**：任何一人没有明确任务，该项记 0 分
7. 演出顺序现场抽签
8. 全场投票（每队 1 票，不能投自己）+ 评委打分，各占 50%

### 流程（三小时版 · 60 人 6 队）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 讲规则 + 分组选曲 | 20 min | 分 6 队、抢曲、发道具 |
| 角色分配 | 15 min | 定主唱/乐手/和声/伴舞/舞美 |
| **排练** | 75 min | 分段练 + 合排（至少 2 次完整走台） |
| 造型准备 | 15 min | 换装、化妆、道具 |
| **汇报演出** | 45 min | 每队 3–4 分钟 + 串场 |
| 投票 + 颁奖 | 15 min | 全场投票、颁奖 |
| 复盘 | 20 min | 见第 4 节 |

## 3. 引导要点

### 讲解脚本（3 分钟）

> 每队一首歌，九十分钟排练，然后上台。
>
> 有一个硬要求：**你们队必须有主唱、乐手、鼓手、和声、伴舞，五类角色都得有人。** 少一类，直接扣分。
>
> 还有一条更硬的：**如果有人没有明确任务，这项记零分。** 不是"少扣点"，是零分。
>
> 所以你们分角色的时候，别只找会唱的那两个人。**去找每个人能干什么。**

### 教练在场边做什么

- **角色分配阶段必须盯**。这是全场最容易出问题的环节：通常 3 个人抢主唱，5 个人"都行"
- **逼出"每个人都有任务"**：看到一个队分工完成，逐个问"你负责什么？"答不出来的，现场补
- **不教唱功**。教"怎么站""怎么看观众""副歌怎么一起进"
- **排练最后 20 分钟要求"完整走台"至少一次**，不许一直在练片段
- **演出时当"暖场"**：每队上台前带头喊队名，把气氛推起来
- **投票前提醒"不能投自己"**，并当场唱票

### 三个必然出现的失败模式

| 失败模式 | 表现 | 根因 |
|---|---|---|
| 一人乐队 | 主唱唱全场，其他人在旁边晃 | 没有角色设计，伴舞/和声不知道干嘛 |
| 排练空转 | 90 分钟全在练副歌，从没完整走过 | 没有"走台"意识 |
| 上台僵住 | 排练挺好，上台全忘 | 没有模拟演出（对着人练） |

### 语言禁区

- ❌「你唱得不太行」——当众否定主唱，后面没人敢上
- ❌「你就跟着晃就行」——"跟着晃"等于没有任务
- ✅「你这一段具体做什么？几拍进？」
- ✅「刚才那次走台，哪个环节断了？」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 你们队有几个人的角色是"明确可描述"的？几个是"大概跟着"的？
- 排练 90 分钟里，完整走台了几次？
- 演出时，和声组和伴舞组在做什么？观众看得见他们吗？
- 全场投票，票最集中的是哪一队？他们赢在哪？

### Feelings（感受）

- 被分到"伴舞"或"舞美"时，什么感觉？
- 上台前那一刻，什么感觉？
- 全场跟着唱的时候，什么感觉？

### Findings（发现）

- 为什么"一人乐队"也能演完，但不好看？（因为演出是"整体呈现"，不是"声音输出"）
- "没有明确任务记零分"这条规则，改变了什么？（逼团队给每个人找位置）
- 为什么必须"完整走台"？（片段练习不会暴露衔接问题）
- 主角和配角的关系是什么？（配角不是"不重要"，是"让主角成立"）

### Future（应用）

- 我们团队里，谁是"主唱"？谁是"伴舞"？伴舞的角色被描述清楚了吗？
- 我们有没有"完整走台"（端到端演练）？还是只测自己那块？
- 我们的项目里，有没有人"没有明确任务"却在团队里？
- 上一次我们公开庆祝一个"配角"的贡献，是什么时候？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 人数少（30–40） | 3–4 队，每队 8–10 人；排练 60 分钟 |
| 人数多（150–200） | 8–10 队，分两批演出；或改为"合唱+乐队"混合形式 |
| 只有 2 小时 | 排练压到 45 分钟，要求"只演副歌"（1.5 分钟/队） |
| 无音响设备 | 改为"清唱 + 身体打击乐"（拍手/跺脚/拍腿），反而更有团建感 |
| 想强化"跨部门" | 强制混编，且规定"主唱不能是本部门负责人" |
| 想弱化"才艺" | 禁止独唱，全部改为"合唱 + 动作"，让不会唱的人也能参与 |
| 年会 | 最后一队演出后接"全员大合唱"，把气氛推到收尾 |
| 管理层专场 | 曲目限定"年代金曲"，加"高管致敬环节" |
