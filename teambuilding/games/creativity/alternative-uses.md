# 一物百用（Alternative Uses）

> **一句话**：一个纸杯能有多少种用法？限时、计分、不许重复——把「想不出」变成「来不及写完」。

| **游戏名称** | 一物百用（Alternative Uses Task） |
| **目的标签** | 创意激发 · 发散思维 · 快速产出 |
| **形式标签** | 室内 · 分组 · 坐姿 |
| **人数** | 建议 每组 4–8 人 |
| **时长** | 25–40 min |
| **难度** | ⭐ 简单（零门槛，但想拿高分很难） |
| **道具需求** | 有（纸 + 笔，或用白板记录） |
| **场景标签** | 团建 · 培训 · 工作坊 · 会议暖场 |
| **核心目标** | 用极低门槛的发散任务，让团队看到「创意产量」和「评判过早」之间的关系 |

---

**团建核心价值**：
- 💡 发散产量：先求多，再求好
- 🔀 联想跳跃：从功能联想到结构、情绪、场景
- 🚫 延迟评判：想到就写，不先审自己
- 🤝 集体接力：别人的半成品是你的起点

## 1. 游戏概览

这是心理学家 Guilford 用来测「发散思维」的经典任务：给你一个常见物品（砖头、纸杯、回形针），在两分钟里尽可能多地说出它的其他用途。评分看三个维度——**数量**（想得多不多）、**流畅性**（说得顺不顺）、**独创性**（别人想不到的）。

搬到团建场景，它有一个别的好处：**门槛极低，但天花板很高**。任何人两分钟都能写出 3 个，但写出 30 个、其中有 5 个是全场独一份的，非常难。这就让不同岗位、不同资历的人站在同一条起跑线上。

更关键的是，它把「创意」这个虚词变成了可数的数字：我们组 3 分钟出了 18 个，另一个组出了 41 个。为什么？复盘时答案往往指向同一个东西——**有没有人在过程中说「这个不行」**。

## 2. 核心规则

### 准备

- 每组一张 A4 纸、一支笔（多人共用一张纸，逼着接力）
- 教练准备 3–5 个物品，按「常见但有结构」的原则选：
  - 纸杯（好，有形状、有材质、有用途）
  - 回形针（经典，但容易被「掰直当针」锁死）
  - 砖头（经典，容易出建筑类同质答案）
  - 雨伞（有趣，能引出情绪和场景联想）
  - 一次性筷子（本土化，答案接地气）

### 流程

**第一轮：个人限时（2 分钟）**

每人一张小纸条，独立写，不许说话。2 分钟到，停笔，报数。

这一步很重要：它给出「个人基线」。多数人写 5–9 个。

**第二轮：小组接力（5 分钟）**

全组合用一张纸，轮流写，一人写一个就传给下一个人。规则：

- 不许重复（同组内重复作废）
- 不许说「这个没用」（说了扣 3 个）
- 每人至少写 2 个，写不出的可以「跳过」，但跳过的人下一轮要补 3 个

**第三轮：分类与打分（5 分钟）**

把全组的答案按「联想类型」分类，通常能分出四类：

| 类型 | 例子（纸杯） | 说明 |
|---|---|---|
| 功能替换 | 笔筒、花盆、量杯 | 换用途，最容易 |
| 结构改造成 | 剪开当漏斗、撕碎当填充物 | 改变形态 |
| 场景移植 | 停电时的蜡烛台、小孩的传声筒 | 换场景 |
| 象征 / 情绪 | 写上愿望放河里、当「最后一杯」的仪式道具 | 最稀有，分最高 |

计分：基础分 = 有效答案数；独创分 = 只有本组写出的答案数 ×3；扣分 = 被否定的次数 ×3。

### 胜负判定

总分最高组获胜。但**公布时只公布「独创答案」清单**，不公布总分排名——让注意力落在「谁想出了别人想不到的」而不是「谁赢了」。

## 3. 引导要点

### 讲解脚本（1 分钟）

> 两分钟，一个纸杯，能有多少种用法？写下来。
>
> 不用想对不对，先写。写得越离谱越好——待会儿我们按「只有你们组想到」来加分。

### 教练在场边做什么

- **第一轮一定有人写不完 3 个**，不要说「加油想」，说「写下来就赢了一半」。
- 第二轮会自然出现两种角色：有人疯狂输出，有人卡住。**记录谁在卡住时被谁接走**——这是复盘的金句来源。
- 有人开始自我审查（「这个太扯了吧」），立刻介入：「扯的加 3 分」。
- 第三轮分类时，帮团队把答案归到四类里，他们会惊讶于自己「原来想了这么多不同方向」。

### 常见卡点

| 卡点 | 处理 |
|---|---|
| 「想到的都被人写了」 | 这正是重点：接力不是抢答，别人写了你可以改造 |
| 全程沉默的成员 | 不点名，改为「每人至少 2 个」的规则兜底 |
| 有人一直说「这不算吧」 | 记一次否定，扣分，公开但不点名 |

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 第一轮个人平均写了几个？第二轮小组总共写了几个？
- 我们的答案里，四类各占多少？
- 全场独创答案有几个？分别是谁写的？

### Feelings（感受）

- 卡住的那 30 秒，你在想什么？
- 有人说「这个不算」的时候，你还想继续说吗？
- 发现自己想出全场唯一答案时，什么感觉？

### Findings（发现）

- 三个人一起想，为什么能比三个人分别想加起来还多？
- 我们的答案为什么大量集中在「功能替换」这一类？
- 从「想不出」到「来不及写完」，中间发生了什么变化？

### Future（应用）

- 我们团队在提想法时，最常出现的「自我审查」是哪一句？
- 下次头脑风暴，能不能先定一条「前 10 分钟不评判」的规则？
- 如果把这套「先求量」的机制搬到周会，会怎么改？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 会议暖场（10 分钟） | 只做第一轮 + 报数，快速破冰 |
| 大团队（>50 人） | 每组独立计分，只公布「全场独创榜」前 10 条 |
| 产品团队 | 物品换成「我们产品的某个功能」，任务变成「它还能怎么用」 |
| 管理层 | 第三轮加上「哪一个答案最有可能真的做出来」，从发散转收敛 |
| 线上 | 用共享文档或聊天框刷答案，按时间戳统计 |

## 6. 物资清单

- [ ] 每组 1 张 A4 纸 + 1 支笔
- [ ] 每人 1 张小纸条（第一轮个人用）
- [ ] 3–5 个「题目物品」实物（纸杯、回形针、筷子等，实物比图片有效）
- [ ] 计时器
- [ ] 白板（板书四类联想 + 独创榜）
