# 六顶思考帽（Six Thinking Hats）

> **一句话**：让全场同时只戴一顶帽子——把「反驳」和「构想」分到不同时间，会议就不会一边想一边杀。

| **游戏名称** | 六顶思考帽（Six Thinking Hats） |
| **目的标签** | 结构化讨论 · 平行思维 · 创意激发 |
| **形式标签** | 室内 · 小组围坐 · 讨论型 |
| **人数** | 建议 每组 4–12 人（全场 4–36 人） |
| **时长** | 45–60 min |
| **难度** | ⭐⭐ 中等（规则简单，执行纪律难） |
| **道具需求** | 有（六色帽子/色卡 + 白板 + 计时器） |
| **场景标签** | 培训 · 管理层工作坊 · 真实议题研讨 |
| **核心目标** | 用「一次只允许一种思维」的纪律，切断「提出即被否定」的循环 |

---

**团建核心价值**：
- 🎩 平行思维：不是争论谁对，是所有人同时换个角度看
- ⏱️ 分离生成与评判：绿色帽子时不许说「这不行」
- 🗣️ 均衡发言：戴同一顶帽子时，每个人都有话可说
- 🧭 蓝色控场：谁在管流程，比谁说得对更重要

## 1. 游戏概览

爱德华·德·博诺（Edward de Bono）的六顶思考帽，本质不是「创意工具」，而是**会议纪律**。

它的洞察很朴素：一场会议之所以低效，不是因为大家不够聪明，而是因为**六种思维同时在场**——有人正在构想，有人已经在挑毛病，有人还在讲感受，有人在算成本。所有人都在说，但没有人在同一个频道上听。

六顶帽子做的事，是把这六种思维**排成一列**，一次只开一盏灯：

| 帽子 | 管什么 | 典型句式 |
|---|---|---|
| ⚪ 白帽 | 事实与数据 | 「我们现在确定知道的只有三个数字。」 |
| 🔴 红帽 | 直觉与情绪 | 「我不喜欢这个方向，说不出为什么。」 |
| ⚫ 黑帽 | 风险与问题 | 「如果供应商延期，这条线会断。」 |
| 🟡 黄帽 | 价值与好处 | 「它至少能省掉两道审批。」 |
| 🟢 绿帽 | 新想法与可能 | 「如果反过来做呢？」 |
| 🔵 蓝帽 | 流程与总结 | 「我们还有 8 分钟，先收一下黑帽。」 |

关键在于**纪律**：戴绿帽时，黑帽的话**不许说出口**——不是不许想，是不许说。这一条守住了，团队的创意产量会明显不同。

## 2. 核心规则

### 准备

- 一个**真实议题**（不要用假议题，假议题会让这个工具变成表演）
- 六色帽子各一顶，或六色卡片（每人一套更好，可以举牌）
- 白板分区：六顶帽子各留一块区域记录
- 一名**蓝帽主持人**（教练或组长），负责切换帽子和控时

### 标准流程（45 分钟）

| 步骤 | 帽子 | 时长 | 做什么 |
|---|---|---|---|
| 1 | 🔵 蓝 | 3 min | 定义议题、说明流程、定时间 |
| 2 | ⚪ 白 | 7 min | 只列事实：已知什么、缺什么数据 |
| 3 | 🟢 绿 | 10 min | 只产想法，不评价，不讨论可行性 |
| 4 | 🟡 黄 | 6 min | 每个想法至少找一条价值 |
| 5 | ⚫ 黑 | 8 min | 逐个找风险，一条一条写 |
| 6 | 🔴 红 | 3 min | 只表态：直觉上选哪个，不许讲理由 |
| 7 | 🔵 蓝 | 8 min | 收敛：选 1–2 个方向，定下一步和负责人 |

**顺序可以调，但绿帽必须在黑帽之前。** 这是这个工具唯一不能妥协的地方——先想，再判。

### 三条硬规则

1. **同一时间只有一顶帽子在场**。有人戴错帽子说话，主持人立刻打断：「这句是黑帽，先记下来，等下说。」
2. **绿帽阶段禁止任何否定**。包括「这个可能有点难」「想法不错但是」——「但是」之后的话一律留到黑帽。
3. **红帽不许解释**。说「我感觉不行」就够了，说理由就变成黑帽了。

### 计分（可选，做成竞赛）

| 项 | 分值 |
|---|---|
| 绿帽阶段每产出一个想法 | +1 |
| 黄帽阶段为一个想法找到 2 条以上价值 | +2 |
| 黑帽阶段指出的风险有具体触发条件 | +2 |
| 戴错帽子说话 | −1 |

## 3. 引导要点

### 讲解脚本（3 分钟）

> 接下来的 45 分钟，我们要做一件反人性的事：**把「我觉得不行」这句话，憋 20 分钟再说。**
>
> 为什么要憋？因为在一场正常的会议里，第一个说「这不行」的人，往往决定了后面所有人都不敢说话。不是因为他有理，是因为**他占了时间**。
>
> 六顶帽子就是把时间切开。绿帽那 10 分钟，谁都不许说不行。你想说，写在纸上，等下黑帽那 8 分钟我们专门听。
>
> 一句话：**先让它长出来，再决定砍不砍。**

### 教练在场边做什么

- **死守绿帽**：这是全场最容易崩的一环。第一次有人否定，必须立刻打断，且要打断得**干脆但不羞辱**
  > 「这句特别好，是黑帽的内容，我帮你记在黑板右侧，第 5 条。」
- **黄帽阶段最容易敷衍**（大家会说「挺好的」）。要求：每条价值必须有主语和动词
  > ❌「效率更高」 ✅「客服不用再手抄一遍工单，每天省 40 分钟」
- **黑帽阶段防止变成人身攻击**：黑帽批的是**方案**，不是提方案的人
- **红帽阶段要快**：3 分钟，一人一句话，不许展开，展开就破功
- **蓝帽收尾必须落到「谁、做什么、什么时候」**，否则整场会变成一次有趣的空谈

### 常见崩盘点

| 崩盘点 | 症状 | 处理 |
|---|---|---|
| 绿帽被污染 | 第三分钟就有人说「预算不够」 | 立刻打断，把话写进黑帽区 |
| 黄帽敷衍 | 全是「挺好的」「有价值」 | 要求「具体到谁受益、省了什么」 |
| 黑帽失控 | 从批方案变成批人 | 明确「只说方案的风险，不评价提出者」 |
| 蓝帽缺位 | 没人控时，某顶帽子聊了 20 分钟 | 蓝帽必须拿计时器，且有权打断任何人 |

### 语言禁区

- ❌「大家畅所欲言」（等于没有规则）
- ❌「这个想法很好，但是……」（「但是」是绿帽杀手）
- ✅「这句是黑帽，我记下来，第 12 分钟我们一起看」
- ✅「绿帽还有 6 分钟，再来五个」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 绿帽 10 分钟产出了几个想法？比平时一场会议多还是少？
- 有几次「戴错帽子」被打断？集中在哪顶帽子？
- 黑帽列出的风险里，有几条是真会发生、有几条只是想象？

### Feelings（感受）

- 憋住「这不行」的那 10 分钟，难受吗？难受在哪？
- 听到自己的想法被黄帽认真找价值，什么感觉？
- 红帽那 3 分钟，说「我就是感觉不行」的时候，有没有松了口气？

### Findings（发现）

- 为什么「先想再判」比「边想边判」产量高？（评判会让人自我审查，好想法在成形前就被掐掉）
- 团队里谁最常在绿帽阶段说黑帽的话？他是故意的吗？
- 六顶帽子真的需要六顶吗？哪一顶对这个团队最关键？（通常是黑帽——因为大家太熟练了）

### Future（应用）

- 下次评审会，能不能把「提问题」单独排一个时段？
- 我们的周会现在同时开着几顶帽子？
- 团队里有没有人从来只戴黑帽？他是不是被这个角色困住了？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 时间只有 25 分钟 | 只用三顶：绿（10）+ 黑（8）+ 蓝（7），跳过白/黄/红 |
| 人数多（> 36） | 分桌同时进行，每桌一个真实议题，最后蓝帽交叉汇报 |
| 团队还很客气（不敢批） | 先做「黑帽专场」：只找问题，且要求每人必须提两条 |
| 团队天天吵架（批太多） | 先做「黄帽专场」：每个方案必须找三条价值 |
| 教学 / 培训场景 | 用假议题练手（如「公司要不要取消周会」），练熟再上真题 |
| 线上 / 远程 | 用六色虚拟背景或表情符号代替帽子，白板用共享文档分六区 |
| 儿童 / 学生场 | 简化为三顶：好消息（黄）/ 坏消息（黑）/ 新点子（绿） |
