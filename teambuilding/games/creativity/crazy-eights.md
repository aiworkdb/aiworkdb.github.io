# 疯狂八格（Crazy Eights）

> **一句话**：一张 A4 折成八格，八分钟画八个想法——前三个必然平庸，好东西藏在第五格以后。

| **游戏名称** | 疯狂八格（Crazy Eights / 8 Ideas in 8 Minutes） |
| **目的标签** | 创意激发 · 快速发散 · 破除完美主义 |
| **形式标签** | 室内 · 个人产出 + 小组分享 · 坐姿 |
| **人数** | 建议 每组 4–8 人（全场 4–40 人） |
| **时长** | 30–45 min |
| **难度** | ⭐ 偏低（不需要会画画） |
| **道具需求** | 有（A4 纸每人 1 张 + 深色马克笔 + 计时器） |
| **场景标签** | 工作坊 · 产品共创 · 培训 · 项目启动 |
| **核心目标** | 用时间压力强行越过「第一个想法」，把产量和质量的真实关系摆到台面上 |

---

**团建核心价值**：
- ⏱️ 时间压力：8 分钟 8 个，没空自我审查
- ✏️ 画而不是写：画面绕过语言审查，想法出得更快
- 📉 破除完美主义：第 3 格之后必然开始「凑」，凑出来的往往是新方向
- 👀 集体可见：八格摊在桌上，谁的哪个想法好一目了然

## 1. 游戏概览

大部分人做创意时的真实流程是：想到第一个点子 → 觉得还行 → 开始打磨它 → 会议结束。

问题不在第一个点子差，在于**它挡路了**。研究结构化创意方法的机构反复验证一件事：一个团队前 10 个想法基本是「显而易见」的那一批，真正有价值的往往出现在第 15 个之后。

疯狂八格就是一台「强制越过前 10 个」的机器。

做法极简单：一张 A4 纸对折三次，得到八个格子。**八分钟，八格，每格一个想法。** 一格一分钟。

一分钟画一个想法，意味着：
- 没时间画得好看（所以只能画概念）
- 没时间自我审查（所以什么都会往外冒）
- 没时间停下来想「这可行吗」（所以可行性判断被推迟了）

到第 4、5 格的时候，人会开始慌，然后开始「乱来」。**乱来的那几格，通常是全场最有意思的。**

## 2. 核心规则

### 准备

- A4 纸每人 **3 张**（不止一张，因为要跑 2–3 轮）
- 深色马克笔每人 1 支（细笔会让人忍不住画细节）
- 计时器必须全场可见（投影倒计时最好）
- 提前把纸折好：对折 → 再对折 → 再对折 = 8 格

### 流程（40 分钟）

| 轮次 | 时长 | 内容 |
|---|---|---|
| 第 0 轮 热身 | 2 min | 「8 分钟 8 种画法表达『开会』」，纯热身，不讨论 |
| 第 1 轮 自由发散 | 8 min | 针对议题，8 格 8 个想法 |
| 中转 | 3 min | 自己回看，圈出 2 个 |
| 第 2 轮 加约束 | 8 min | 同一议题，但加一条硬约束（如「零预算」） |
| 第 3 轮 反转 | 8 min | 「怎么让这个议题彻底搞砸」，8 格 |
| 分享 | 10 min | 每人讲 1 个最好的 + 1 个最离谱的 |

### 三条规则

1. **一格一个想法，不能重复**。真正卡住时允许「这一格空着」，但空格要标出来（空格数量是重要的复盘数据）
2. **只能画，不能写字**（最多允许 3 个字的标注）。写字会让人开始写句子，句子会拖慢速度
3. **不许评判**。画完之前，任何人不能说「这个不行」

### 加约束的三种选法（第 2 轮用）

| 约束 | 效果 |
|---|---|
| 零预算 | 逼出「用现有资源」的方案 |
| 明天上线 | 逼出「最小可行」的方案 |
| 只能用一个按钮 / 一句话说清 | 逼出「极简」的方案 |
| 给 10 岁小孩用 | 逼出「易懂」的方案 |

## 3. 引导要点

### 讲解脚本（2 分钟）

> 接下来八分钟，你会画八个想法。**每格一分钟。**
>
> 我知道你想说「我不会画画」。这个不重要——**画得像不像，跟想法好不好，完全没关系。** 火柴人、方块、箭头、圈，都行。
>
> 重要的一件事：**第一格那个想法，你现在脑子里已经有了。** 第八格那个还没有。我们今天要的是第八格。
>
> 所以别在第二格停下来打磨。**一格一分钟，时间到就换格，画不完也换。**

### 教练在场边做什么

- **严格读秒**：「还剩 6 分钟 / 4 分钟 / 1 分钟」——时间压力是核心机制，松了就失效
- **盯住停下来打磨的人**：「时间到，换下一格」，不要等他画完
- **记录空格数**：有人第 6 格开始空，有人第 8 格还在画。这个分布是复盘的关键数据
- **第 2 轮加约束时，看有没有人明显变快**（约束会提速，因为搜索空间小了）
- **分享阶段规则**：每人必须讲一个「最离谱的」。这条能救回那些被自己否掉的怪想法

### 常见反应与应对

| 反应 | 意思 | 应对 |
|---|---|---|
| 「我没想法了」 | 大概率在第 4–5 格 | 「那就在第 5 格画『没想法』，然后第 6 格画『有了』」 |
| 「这个太傻了」 | 好信号 | 「傻的就画，傻的才值钱」 |
| 「能不能画大一点」 | 想把一个想法画细 | 拒绝：「一格就是这个大小」 |
| 「我能不能写字」 | 想把想法说清 | 「最多三个字」 |

### 语言禁区

- ❌「画得真好看」（会让人开始在意画工）
- ❌「这个可行吗」（第 3 轮之前禁止问可行性）
- ✅「还有 40 秒，第五格」
- ✅「先把最傻的那个讲出来」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 三轮各画满了几格？空格集中在第几格？
- 有几个人在第 5 格之后冒出了后来被选中的想法？
- 第 2 轮加约束后，产量变多还是变少？

### Feelings（感受）

- 第 4、5 格时那种「没想法了」的感觉，具体是什么样？
- 画到「太傻了」的那一格时，你有没有想划掉它？
- 看到别人的某个格子，是不是「这个我也想过但没画」？

### Findings（发现）

- 为什么前 3 格特别快、第 5 格特别卡？（因为前 3 格是记忆里现成的，第 5 格开始才真的要生成）
- 划掉的那几个「傻想法」，有没有在别处出现？（通常是有的，别人捡走了）
- 约束让创意变多还是变少？为什么？（约束缩小了搜索空间，反而让人更快找到东西）

### Future（应用）

- 下次讨论方案，能不能先强制每个人都写 8 个，再开始讨论？
- 团队里有没有人总是第一个发言、然后大家都跟着他？（这就是「第一格效应」）
- 那些被自己划掉的傻想法，我们有没有一个地方可以存着？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 时间只有 20 分钟 | 只做第 1 轮 8 min + 第 3 轮 8 min + 分享 4 min |
| 团队抗拒画图 | 改为「8 格写 8 个关键词，每格不超过 3 个字」 |
| 人数少（< 4） | 缩短为「四格四分钟」，同样有效 |
| 人数多（> 40） | 完全可并行，分享阶段改为「把纸摊在桌上，贴圆点投票选 5 张」 |
| 产品/设计团队 | 第 3 轮改为「画 8 个界面的 8 种布局」——这就是设计冲刺里的经典变体 |
| 线上 / 远程 | 用共享白板的八宫格模板，每人一格带名字；或用拍照上传 |
| 领导力 / 战略主题 | 第 1 轮改为「8 种让团队两年后消失的方式」，冲击力很强 |

## 6. 物资清单

| 物资 | 数量 | 备注 |
|------|------|------|
| A4 纸 | 每人 3 张 | 提前折好八格，省 2 分钟 |
| 深色马克笔 | 每人 1 支 | 黑色或深蓝，细头即可；彩色笔会让人分心 |
| 计时器 | 1 个 | 最好投影倒计时，全场可见 |
| 圆点贴 | 每人 3 个 | 可选，用于投票选优 |
| 议题卡 | 每桌 1 张 | 写清议题与第 2 轮的约束条件 |
| 桌面分隔 | 可选 | 大桌用纸板隔开，避免互相看 |
