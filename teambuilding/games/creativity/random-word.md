# 随机词联想（Random Word Association）

> **一句话**：从一个毫不相干的词出发，强制连到你的难题上——大脑讨厌这种跳跃，但跳出来的东西往往是你自己想不到的。

| **游戏名称** | 随机词联想（Random Word Association / 强制连接） |
| **目的标签** | 创意激发 · 类比思维 · 打破惯性 |
| **形式标签** | 室内 · 小组或个人 · 讨论型 |
| **人数** | 建议 每组 4–10 人（全场 4–40 人） |
| **时长** | 30–40 min |
| **难度** | ⭐ 偏低（零道具门槛，纯脑力） |
| **道具需求** | 有（随机词卡/词典 + 白板 + 计时器） |
| **场景标签** | 工作坊 · 培训 · 头脑风暴前的热身 · 卡壳时救场 |
| **核心目标** | 用「无关输入」切断既有思路，逼出平时不会出现的类比 |

---

**团建核心价值**：
- 🎲 随机输入：越不相关，越能撞出新东西
- 🔗 强制连接：不允许说「没关系」，必须找到关系
- 🧠 类比思维：把别的领域的解法搬过来，是最省力的创新
- ⚡ 即插即用：五分钟就能救活一场卡住的会

## 1. 游戏概览

头脑风暴卡住的时候，最没用的建议是「再想想」。

因为卡住的不是思考能力，是**搜索路径**——大脑总是沿着已经走过的路再走一遍，所以第二遍想到的还是第一遍那些。

随机词联想做的事，是在这条路上**扔一块石头**。

方法是：随便挑一个跟议题毫无关系的词（「章鱼」「地铁」「冰箱」都行），然后强制回答一个问题：

> **「这个词，跟我们的问题有什么关系？」**

大脑不喜欢这种跳跃，第一反应一定是「没关系」。但规则不允许说没关系，所以它只能开始找——而**找的过程，就是新路径被踩出来的过程**。

比如议题是「怎么让周会不那么浪费时间」，随机词是「章鱼」：

- 章鱼有八条腕，每条都能独立行动 → 能不能让每个议题有独立的「负责人」自己推进？
- 章鱼换颜色伪装 → 我们的周会是不是一直在「装正常」？
- 章鱼断腕求生 → 哪个议题可以砍掉？
- 章鱼的腕有主副之分 → 我们的会有没有「主议题」和「陪跑议题」？

四个想法里，至少两个是平时想不到的。而它们全部来自一个跟「周会」毫无关系的词。

## 2. 核心规则

### 准备

- 随机词来源三选一：**词卡袋**（提前准备 50 张）、**随机词典翻页**（翻到哪页选第 3 个词）、**随机词网站/App**
- 白板中间写议题，四周留白用于连线
- 每组一个计时器

### 流程（35 分钟）

| 步骤 | 时长 | 做什么 |
|---|---|---|
| 1 亮议题 | 3 min | 白板中央写清议题，一句话说清「要解决什么」 |
| 2 抽词 | 1 min | 每组抽 1 个词，大声念出来（不许换词） |
| 3 自由联想 | 5 min | 先只对这个词联想：它有什么特征？越具体越好 |
| 4 强制连接 | 8 min | 每条特征都问一句「这跟议题有什么关系」 |
| 5 提炼 | 8 min | 从连接里挑 3 条，写成可执行的想法 |
| 6 再来一轮 | 8 min | 换一个词，重复 2–5（第二轮的词通常更离谱，效果更好） |
| 7 分享 | 2 min | 每组讲最好的一条 |

**第 3 步是很多人会跳过的一步，也是最重要的一步。** 直接问「章鱼跟周会有什么关系」，人只会发愣；先把章鱼的特征列出来（八条腕、会变色、无脊椎、喷墨、吸盘），才有东西可连。

### 三条规则

1. **不许换词**。抽到「马桶」也得用——恰恰是这种词最容易出好东西
2. **不许说「没关系」**。必须给出一个连接，哪怕牵强
3. **先列特征，再做连接**。跳过第 3 步的游戏会退化成尬聊

### 连接句式（发给每人一张）

> 「**（词的某个特征）**……如果我们把它搬到议题上，会变成**（什么做法）**？」

例：
> 「章鱼每条腕能独立行动……如果我们让每个议题有独立负责人自己推进，会变成**周会只处理『跨议题冲突』，其余异步解决**。」

## 3. 引导要点

### 讲解脚本（2 分钟）

> 抽一个词，然后把它跟我们手上的问题连起来。
>
> 我知道你的第一反应是「这两个没关系」。**没关系是允许的，但不允许说出来。** 你要做的是找到一个关系。
>
> 提示一下方法：**别直接连。先看这个词有什么特征。** 章鱼有什么特征？八条腕、会变色、喷墨、软。每一条特征，都可能是通往答案的一扇门。

### 教练在场边做什么

- **抽词必须真随机**。教练自己挑词会下意识挑「好连的」，效果直接减半
- **第一轮往往很尬**，这是正常的。撑过 5 分钟，通常第 3 条连接开始有意思
- **有人给出牵强连接时，别否定**，追一句：「再往下推一步会怎样？」
- **记录「最牵强但最有启发」的那条**，复盘时它是最好用的例子
- **第二轮换更离谱的词**（第一轮用「雨伞」「电梯」，第二轮用「葬礼」「口香糖」）

### 词库建议（按「好连程度」排序）

| 层级 | 例词 | 适用 |
|---|---|---|
| 具体物品 | 雨伞、电梯、冰箱、钥匙、胶带 | 第一轮，容易上手 |
| 自然物 | 章鱼、珊瑚、蜂群、苔藓、火山 | 特征丰富，连接点多 |
| 抽象概念 | 时差、回声、债务、方言、排队 | 适合战略/组织类议题 |
| 反常识词 | 葬礼、监狱、赌场、减肥、离婚 | 第二轮，冲击力最强 |

### 语言禁区

- ❌「这个太牵强了」——牵强是过程，不是结果
- ❌「换一个词吧」——换词等于放弃
- ✅「它有什么特征？再来三条」
- ✅「牵强没关系，往下推一步」

## 4. 复盘问题（4F 框架）

### Facts（事实）

- 两轮各产出了几条连接？有几条最后变成了可执行想法？
- 哪一条最牵强？它有没有带来什么？
- 有多少人第一反应是「没关系」？后来找到关系了吗？

### Feelings（感受）

- 抽到一个完全不相关的词时，第一秒的心情是什么？（抗拒？想笑？）
- 找到第一个连接的时候，是「硬凑」还是「真的通了」？
- 听别人讲他的连接，有没有「这我绝对想不到」的时刻？

### Findings（发现）

- 为什么「无关输入」反而有用？（因为它不在这条老路上，逼你绕道）
- 「先列特征再连接」和「直接硬连」效果差多少？（试过的人都知道差很多）
- 团队里谁的连接最离谱？他是不是平时最容易被否掉的那个人？

### Future（应用）

- 下次开会卡住，能不能随手抽个词救场？
- 我们行业之外，有没有哪个领域的做法可以整体搬过来？
- 那些「太离谱」的同事，我们是不是一直在浪费他们？

## 5. 变体与适配

| 场景 | 调整方式 |
|---|---|
| 时间只有 10 分钟 | 单轮：抽词 + 列特征（3）+ 连接（5）+ 分享（2） |
| 人数多（> 40） | 每组抽不同的词，最后交叉分享，看看不同词撞出的差异 |
| 团队很安静 | 改为「接力」：一人说一个连接，下一个人必须接着上一个人的往下推 |
| 想更刺激 | 抽两个词，要求同时用上（「章鱼 + 地铁」） |
| 产品命名 / 品牌 | 直接用名词库，要求每个词产出一个名字 |
| 线上 / 远程 | 用随机词网站共享屏幕抽词，白板共享；效果几乎无损 |
| 儿童 / 学生场 | 用图片代替词，抽一张图卡即可，门槛更低 |
